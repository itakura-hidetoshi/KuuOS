    Prior-proof subject recall v0.2¶

    The v0.1 literal gate can still fail to retrieve old mathematics if an agent forgets the old theorem names. This additive stage accepts Japanese/English research subjects and expands a small, source-anchored topic index across Qi, F112, GK5, history/obstructions and gauge structures.

    The initial catalog is grounded in the original Lean source at canonical main 61a75099b6f989b7b68a977af2c264b3820cd2b6. It records paths, exact Git blobs, declarations and narrowly scoped retrieval hints. A new HEAD does not by itself retire prior mathematics. Changed blobs, missing declarations, an unindexed subject or unresolved comparisons hold for source re-observation. No complete semantic retrieval or certificate of novelty is claimed.

    Notably the original fourteen-cell file already contains raw noncommutative pasting inequality, integer-blindness, conditional finite conservative core nonexistence and the pentagonator fifteen-boundary inequalities. The original Qi v4.0 contains restricted non-descent/non-recovery results. These are prior results to inspect and reuse; they must not be repeatedly proposed as new. The three gauge actions still need an explicitly typed compatibility map if one is proposed. The exact unresolved mathematical difference must first be checked against all other related modules, not guessed from this index.

    Call recall_subject with exact materialized canonical source, fresh MCP HEAD, and a natural-language topic. The receipt expands known topic neighbors, reobserves original declaration lines/blobs, and invokes v0.1 lexical source retrieval using the discovered names. Review each anchor separately with its path, blob, line, declaration, relation, reason, assumptions_comparison and conclusion_comparison. The ordinary v0.1 all-hit file review remains required. Bind subject_receipt_digest and the original synthesis request to the review. A duplicate anchor blocks a new-result proposal even if the file-level review was overly broad. A missing/unresolved anchor holds. Complete anchor source texts must be provided to build_subject_research_synthesis, which then calls the v0.1 gated original CodeAI provider path.

    In MCP-only research, look up the subject catalog, retrieve the actual original Lean source and related files at the observed head, and record comparisons. Do not claim the Python scanner ran in such a session. Unknown research topics require additional cross-family discovery and indexing or equivalent explicit review. No prior proof needs re-proving solely because of a retrieval defect.

    Scope: initial curated C60/Qi/GK5/F112 subject recall, not universal memory, not automatic theorem equivalence, not a Lean certification. Existing proof, root, toolchain and repair-memory policies are unchanged.

    Canonical update and cross-family descent recall (2026-11-24)¶

    The source catalog now includes original AQ–AU contextual 15-cell and Peiffer descent signatures and Qi v5.99 (main ff0c871aca2a37df4fb1753c0319321b8419b413). These are retrieval anchors, not a fresh Lean certification. In particular AS already proves base-exchange identification iff group-valued descent; AU already proves conditional Type-valued receiver descent assuming core and whisker compatibility. Do not propose these as new results. Their group-level defect equalities do not identify distinct geometric 15-cell paths. Qi v5.99 also already proves compensated C60 Slot/Dart/Edge covariance and conditional joint fidelity of the original bracket and full typed Sigma unit history in the primitive-unit fragment. The physical shadow is not raw faithful. Do not infer a new global or unrestricted descent from these local signatures. Search additional existing higher-cell and receiver modules before deciding the next mathematical delta.
