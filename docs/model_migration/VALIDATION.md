# Portable Bootstrap v0.1 検証範囲

## 作成したもの

2026-09-08、KuuOSの正本main `0e6987a4de0fbc03f5b6d537afa06b153d294c07`を参照し、単独で読める日本語の起動文、移行手順、履歴テンプレート、16件の行動テスト、未実施の評価テンプレート、出典一覧を追加した。

変更は文書・JSONテンプレートとREADMEの入口だけで、Lean・runtime・CI定義を変更しない。個別の対話履歴は公開成果物に含めない。

## 静的な検証

確認対象は次のとおり。

- JSONが解析でき、テストIDが一意で、意味と履歴の区分が存在すること。
- 出典一覧のGit blob SHAが参照コミットのtreeと一致すること。
- ローカルな文書リンク先が既存treeまたは今回の追加ファイルに存在すること。
- 履歴・評価テンプレートが未記入・未実施であり、合格結果を埋め込んでいないこと。
- 起動文に四原則、10段階の思考ルート、個別履歴の欠落、実務継続、訂正・再観測、検証範囲の区別が記載されていること。

既存GPT GitHub integration surfaceは次のコマンドで確認する。

```bash
python3 scripts/validate_gpt_github_integration_v0_1.py
```

このvalidatorは既存の連携規約を調べるもので、新しい起動文を使うモデルの行動を採点するものではない。

全リポジトリの`make all-governance-checks`は今回のローカルな文書検証では実行していない。変更範囲に対応する既存PRワークフローの結果は、PRに結びつく実際のrun・commitで確認する。未完了のCIを成功と扱わない。

## 行動検証は未実施

GPT-6でのcold比較、独立した継承テスト、長い会話を挟んだretention、新規会話へのreentryは、この文書の作成・静的検証とは別である。GPT-6実測合格、旧モデルとの同等性、品質改善率、完全な履歴復元を主張しない。

[EVALUATION_TEMPLATE.json](EVALUATION_TEMPLATE.json)は未実施のひな型であり、測定結果ではない。[移行手順](README.md)に従って試験を実施した後に、各応答と判定理由を別の記録に残す。

## 継承しない主張

モデルの重み・人格・会話の自動記憶・権限が移植されたという主張はしない。起動文の読了、静的チェック、CI成功、行動テストの合格を区別する。Leanの証明範囲や、PR #1558のvalidation-onlyという地位も変えない。
