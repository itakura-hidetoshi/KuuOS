# Dependent Origination — External Scaled-Anodyne Generator Comparison Formal v1.46

## Scope

Version 1.45 closes the internal KuuOS scaled small-object argument and proves a native weak factorization system for the canonical horn-cylinder generator family

\[
T.
\]

The remaining comparison problem is external: suppose another implementation supplies a proposed standard scaled-anodyne generator family

\[
E.
\]

The goal is not to require literal equality of generator lists.  Instead, v1.46 identifies the exact closure-level comparison needed to prove that both presentations generate the same lifting theory.

## Generated classes

For any morphism property \(E\) in `ScaledSSet`, define

\[
\mathcal A_E := E^{\perp\perp}=E.\mathrm{rlp}.\mathrm{llp},
\qquad
\mathcal F_E := E^\perp=E.\mathrm{rlp}.
\]

The canonical KuuOS classes are

\[
\mathcal A_T=T^{\perp\perp},
\qquad
\mathcal F_T=T^\perp.
\]

## Generator-level comparison certificate

`ScaledAnodyneGeneratorComparison E` contains exactly two statements:

\[
\boxed{T\le \mathcal A_E}
\]

and

\[
\boxed{E\le \mathcal A_T}.
\]

The first says each canonical KuuOS attachment generator is generated by the external family.  The second says each external generator is already canonical generated-anodyne.

No equality of raw generator sets is assumed.

## Closure equality

Every class of the form \(E^{\perp\perp}\) is orthogonally saturated.  The canonical class \(T^{\perp\perp}\) is the least orthogonally saturated class containing \(T\).

Therefore the two comparison inclusions imply

\[
\boxed{E^{\perp\perp}=T^{\perp\perp}}.
\]

Applying right orthogonality gives

\[
\boxed{E^\perp=T^\perp}.
\]

Thus the external and canonical presentations have literally equal generated left and right classes.

## Weak factorization system transport

Version 1.45 already proves unconditionally that

\[
(T^{\perp\perp},T^\perp)
\]

is a Mathlib native weak factorization system.

Since the external generated classes are equal to the canonical ones, v1.46 transports this result directly:

\[
\boxed{(E^{\perp\perp},E^\perp)\text{ is a weak factorization system}.}
\]

Importantly, the external generator family does **not** need its own small-object, smallness, or presentability proof.

The external generated left class also inherits the canonical cellular description

\[
\operatorname{Retr}\,
\operatorname{TransfiniteComp}\,
\operatorname{Pushout}\,
\operatorname{Coproduct}(T).
\]

## Fibrancy

External-generator fibrancy is defined by

\[
E^\perp(X\to *).
\]

The right-class equality proves

\[
\boxed{
X\text{ externally fibrant}
\iff
X\text{ canonically attachment-fibrant}.
}
\]

Hence external fibrancy supplies the same two-sided terminal RLP, horn-family strictification, and strict scaled-horn filling theory already constructed in the canonical route.

## Global Duskin consequence

When source and target global Duskin nerves are externally fibrant for generator presentations satisfying the comparison certificate, they can be converted to the existing attachment-fibrant model-equivalence package.  The established homotopy-class/prism machinery then gives presentation-independent strict global Duskin fibrancy.

## Mathematical boundary

This file deliberately does **not** claim that pinned Mathlib already contains Lurie's standard scaled-anodyne generator family.

The future external comparison task has now been reduced to two concrete generator-level theorems:

\[
\boxed{T\le E^{\perp\perp}}
\qquad\text{and}\qquad
\boxed{E\le T^{\perp\perp}}.
\]

Once an external standard generator family is formalized, proving these two inclusions is sufficient to inherit the complete canonical KuuOS weak-factorization and strict-fibrancy spine.
