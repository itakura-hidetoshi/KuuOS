# Dependent Origination Contextual Core v1.0

## Purpose

This layer returns to the original structural question: what should count as the
formal parent notion of dependent origination before any physical, quantum,
history, or memory realization is chosen?

The answer remains the v0.1 idea:

```text
context category C
        |
        v
state-valued functor C -> Type
```

A context object is not interpreted as an independently existing substance.
It is a conditioned presentation.  A context morphism is an admissible relation
or transition, and the functor maps that morphism to transport between the
corresponding state fibers.

The core law is only functorial composition:

```text
transport(id) = id
transport(f ; g) = transport(g) o transport(f).
```

No invertibility is part of the parent definition.

## 1. Why return to the contextual parent

The later v0.8-v0.16 quantum/process-tensor work is a mathematically useful
specialization, but it is not the definition of dependent origination.

Likewise:

- a groupoid describes reversible presentation changes;
- a free monoid describes finite event histories;
- an additive monoid describes one-parameter semigroup transport;
- a memory-lifted carrier describes explicit history retention;
- a Choi/process-tensor realization describes a finite-dimensional quantum
  operational specialization.

All of these live below the same contextual parent.

## 2. Maps between dependent-origination systems

Given two state functors `D` and `E` on the same context category, a `SystemHom`
is a fiberwise map

```text
eta_X : D(X) -> E(X)
```

such that every contextual transport square commutes:

```text
D(X) --D(f)--> D(Y)
 |              |
eta_X          eta_Y
 |              |
 v              v
E(X) --E(f)--> E(Y).
```

This is the natural-transformation level of the dependent-origination
architecture.

Identity and composition are formalized, so system maps themselves compose.

## 3. Reversible presentation equivalence is extra structure

`SystemEquiv D E` consists of forward and backward transport-compatible maps
which are pointwise inverse.

This distinguishes two notions that must not be conflated:

```text
ordinary contextual transport
```

and

```text
reversible equivalence of presentations.
```

Dependent origination requires the first, not the second.

## 4. Change of contextual lens

For a functor

```text
F : Fine -> Coarse
```

and a dependent-origination system on `Coarse`, the new `reindex` construction
pulls the system back to `Fine`:

```text
Fine --F--> Coarse --state--> Type.
```

This is the formal meaning of changing the contextual lens without changing the
parent transport principle.

A `ContextSpecialization Fine Coarse` is therefore simply a context functor.
Such specializations compose.

This is intentionally weaker and more general than saying that one theory is a
subtype of another.

## 5. Groupoid specialization

If the context category happens to be a groupoid, every context morphism has an
inverse.  Functoriality then proves that transport is an actual equivalence of
state fibers:

```text
D.transport f : D(X) ~= D(Y).
```

The inverse is transport along `inv f`.

Therefore the new theorem proves:

```text
groupoid context
=>
no irreversible transport at any context morphism.
```

This cleanly locates gauge/descent-style reversible presentation changes:

they are a specialization of dependent origination, not its parent definition.

## 6. Irreversible transport remains admissible in the parent

For an arbitrary category there is no inverse morphism requirement.

The predicate

```text
IsIrreversibleAt D f
```

means that the state transport associated with `f` is not bijective.

Nothing in the parent structure rules this out.

This is essential for keeping ordinary irreversible updates, coarse graining,
positive-time transfer, and other directed processes inside the same parent
notion without pretending that they are groupoid morphisms.

## 7. Finite history is a one-object specialization

The existing `HistoryTransport Event State` satisfies

```text
eval [] = id
eval (left ++ right) = eval left o eval right.
```

v0.6 already proved that this is exactly a functor from the one-object free
history category generated by finite event words.

v1.0 re-exposes this explicitly as

```text
HistoryTransport.asContextualSystem.
```

Therefore finite history is not a second definition of dependent origination.
It is one concrete source category for the parent state-valued functor.

## 8. Memory is an enlarged-state specialization

The v0.7 memory-lifted construction remains in the non-quantum core spine.

The important architectural distinction is:

```text
history syntax
!=
memory state
!=
summary factorization.
```

A history can act on an enlarged `(Visible x Memory)` carrier while preserving
the same compositional parent law.

This is enough to represent genuine history-sensitive behavior without making
non-Markovianity part of the parent definition.

## 9. Parent/specialization hierarchy

The intended hierarchy is now:

```text
Dependent origination parent
  = contextual state functor + composable transport

  +-- reversible/groupoid presentation
  |     +-- gauge/action-groupoid
  |     +-- Cech/descent style changes
  |
  +-- one-object history presentation
  |     +-- free finite event words
  |     +-- memory-lifted history
  |     +-- optional summary/semigroup factorization
  |
  +-- directed noninvertible presentation
  |     +-- irreversible updates
  |     +-- positive-time transport
  |
  +-- downstream realizations
        +-- process tensor
        +-- Choi/quantum comb
        +-- other domain-specific semantics.
```

The branches below the parent can be mathematically strong, but none is allowed
to redefine the parent notion by silently adding its own assumptions.

## 10. Philosophical scope

This is a mathematical structural interpretation of dependent origination, not
a claim that category theory is identical with Buddhist doctrine.

The intended correspondence is narrower:

- state is conditioned by context rather than postulated as one fixed
  context-free substance;
- relations compose before any reversible or dynamical specialization is
  chosen;
- invariant semantics may be added as a readout, but is not confused with the
  contextual presentation itself;
- reversible equivalence is additional structure, not a default metaphysical
  assumption;
- history and memory are explicit specializations rather than hidden inside the
  word "relation".

This preserves the original KuuOS design principle:

```text
Dependent origination is composable contextual transport before
object-substance specialization.
```

## 11. Scope boundary

The v1.0 core aggregate deliberately imports no Choi matrix, completely
positive map, quantum comb, Hamiltonian, spectral gap, or physical Yang--Mills
claim.

Those layers remain available downstream, but the formal meaning of dependent
origination is again anchored at the contextual parent level.
