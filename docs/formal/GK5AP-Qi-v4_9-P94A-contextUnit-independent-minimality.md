## 2. Distinguishing the left and right primitive unit families

GK5AO already proved that `horizontalUnit` cannot be generated by
P93 plus `leftContextUnit` and `rightContextUnit`, with exact minimum
occurrence count one. GK5AP proves that the remaining **two** primitive
families are each independently indispensable.

On the **actual Type-valued P92B 3-proof term**, define two
`ZMod 2` observers `I_L`, `I_R`. Both assign 0 to original
F55 generators, `assocNaturality`, and `refl`; negation to
`symm`; and addition to `trans`.

| P92B constructor | `I_L` adjustment | `I_R` adjustment |
| --- | --- | --- |
| `leftContext` | +1 | 0 |
| `rightContext` | 0 | +1 |
| `precompose` | +1 | 0 |
| `postcompose` | 0 | +1 |

The *actual* P92B horizontal three-proof operation is a
`postcompose(leftContext f, ...)` followed by
`precompose(..., rightContext g)`.
It adds **two** ones in each observer, hence in `ZMod 2`:

```text
I_L(horizontal(f,g)) = I_L(f) + I_L(g)
I_R(horizontal(f,g)) = I_R(f) + I_R(g)
```

Both observers are preserved by all **16** original P93 four-cell
constructors, including genuine interchange. Under the three extra
P94A generators their respective source–target changes are:

| P94A primitive | delta `I_L` | delta `I_R` |
| --- | ---: | ---: |
| `horizontalUnit` | 0 | 0 |
| `leftContextUnit` | 1 | 0 |
| `rightContextUnit` | 0 | 1 |

Thus even **with horizontalUnit and the opposite context-unit freely
available**, a left normalization must use `leftContextUnit`, and a
right normalization must use `rightContextUnit`.
