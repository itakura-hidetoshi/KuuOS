## Deployment boundary

The socket is local-only, private-directory mode 0700, socket mode 0600, same UID; same UID is a single trust domain, not independently administered production identity. There is no network listener or OAuth/MCP protocol server. The client helper has no verification or display authority. A request has one LF-delimited frame; after the first accepted frame the connection is closed, and no second request is processed. The deadline bounds input reception, not all verification execution time. A lost reply does not grant replay; the existing trusted client must still verify current state before rendering. Process compromise or access by a hostile same-UID principal is outside this trust boundary. Production requires independent host identities, protection of private keys and anchors, authorized private-source retrieval and pinned execution; no real ledger content, private question, or signing key was transferred. The available VerifyOS connector remains test-only.
