    2. 証明された内容（同一の依存型fiber内）¶

    新合同性商 SelectedRawCongruentNineteen において：

    1. raw反転は完全ordered List Bool traceを保持し、raw reverse-countを厳密に1増加させる。
    2. 二変数raw chainは左右のraw reverse-countを加算する。
    3. 既存v5.43のselectedContextEighteenDoubleReverseはordered traceを保持し、raw反転回数を2増やすため、新商でも二重反転後のクラスは元のクラスと異なる。
    4. したがって二重反転を消去するSelectedRawCongruentNineteenの真正Type値比較は存在しない。新商上の二重反転写像も、与えられた点では固定点を持たない。
    5. raw反転はこの特定のraw chainとstrict identityに対する右逆元ではない。raw syntax上の反転を、群oidの逆射と同一視しない。
    6. 任意の実際に与えられた18D証拠Mについて、二重反転をn回繰り返す。依存型始終点は保存され、Trace(M_n)=Trace(M)、ReverseCount(M_n)=ReverseCount(M)+2*n を証明した。
    7. 同じ族について新商クラス[M_n]はNatから単射であり、この族の真正比較が存在するのはm=nの時、かつその時に限る。
    8. その証拠のordered trace値が固定されたfiberにNat ↪ {q // Trace(q)=Trace(M)}を構成。指定Jのstrict identityが与えられれば、J→Jの空trace fiberにもNatを埋め込める。
    9. 完全ordered trace観測は新商で一般には忠実でなく、与えられたinhabited fiberに全クラスを戻すtrace decoderは存在しない。

    5. 障害として保持するもの（NO_DATA）¶

    全16D／17D fiberのinhabitance、全fiberでの非自明性、一意な元Type値証拠の完全復元、raw構文の群oid化、元の旧5/6変量すべての新商降下、全新商の可算性・分類、異なるfiber間のwhiskering、無条件20D gluing、KuuOS全体の大域的一致は証明していない。

    本結果は与えられた同一依存型fiber内の具体的無限部分族と、局所的な非降下を認証する。trace一致を新商上の同一性と誤認してはならない（Preference ⇏ Descent ⇏ Authority）。

    6. 次の形式化対象¶

    v5.53では、新商の二つの保存観測 (orderedTrace, reverseCount) の共同fiberが何を区別でき、何を識別できないかを、具体的に構成可能な証拠対に限定して検討する。v5.52はその全分類を主張しない。別候補として既存v5.47の他の各旧計数について新商降下の可否を1個ずつ形式化する。
