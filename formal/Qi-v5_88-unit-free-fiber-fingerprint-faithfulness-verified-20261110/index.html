    Qi v5.88 — 真正raw旧18D同一fiber内のunit-free部分における内部括弧観測の忠実性（Lean4形式証明）¶

    2．真正旧18Dの同一exact N→N fiberに入るunit-free部分¶

    元の16D親文脈で真正17D証拠端点 N : SelectedContextualSeventeen W l r H Kを固定する。独立補助構文 SelectedV588UnitFreeTermはstrict・raw reversed・非結合二分木joinedのみを持つ。新しい同値関係・代理旧18D証拠Typeを定義したものではない。

    selectedV588UnitFreeRawEmbed l r Nは、この部分構文の各値を元の SelectedLocalEighteen W l r N N に、元の .strict N・.reverse・.chain構成子だけで埋め込む。各分枝は同一の真正raw17D端点N→Nにとどまる。後段の忠実性はこの実際に構成された像上のみの主張であり、任意の元旧18D証拠に対する大域主張ではない。

    3．内部括弧観測の構文復元と元raw証拠値の識別¶

    元のv5.73独立構文 SelectedInheritedOldInnerBracketを変えず、unit-free構文の独立読取りselectedV588UnitFreeBracketと部分パーサselectedV588UnitFreeParseを定義した。元のoldUnitLeft・oldUnitRightはparserの値noneに明示的に残す。

    parse (bracket t)=some tを全unit-free項tについてLean4で証明。従ってbracketは単射で、元の型付き旧18D証拠上の観測定理

    selectedLocalEighteenInnerBracket l r (selectedV588UnitFreeRawEmbed l r N t)=selectedV588UnitFreeBracket t

    と合わせて、embed(N,t)=embed(N,u) ↔ bracket(t)=bracket(u)を得る。実際のembed(N,-)も単射。等号反映は元raw旧18D Type値の等号であって、観測値を元証拠に代入したり、元証拠構成子を上書きしていない。

    4．独立した元旧5／新7真正商とType19D比較の限定忠実性¶

    inherited (embed(N,t))という元の真正18D証拠を使用し、元のv5.73「継承内部括弧列の旧5・新7商への独立降下」定理と接続して、次を別々に形式証明した。

    • 元旧5構成子selectedNineteenClass：[inherited(embed t)]old=[inherited(embed u)]old ↔ t=u。
    • 独立新7構成子selectedRawCongruentClass：[inherited(embed t)]new=[inherited(embed u)]new ↔ t=u。
    • 真正新7商で1回raw反転guardを付けた reverse(inherited(embed t)) の像でも新商等号↔ t=u。
    • 元旧SelectedLocalNineteenおよび別の元新SelectedRawCongruentNineteenの各型付き比較TypeのNonemptyが個別にt=uと同値であり、両比較の居住性が一致するのはこの限定像のみ。
    • 元の同一N→N fiberに実際に構成されるstrict Nとreverse(reverse(strict N))はraw旧18D値として相異なり、旧新真正商でも別クラス。raw二重反転を勝手な群oid逆射と同一視していない。

    5．unitLeft・unitRightによる観測範囲の境界¶

    独立のselectedV588InnerUnitCountを内部括弧木に定義した。unit-freeのすべての深さ・入れ子の木についてその値は0である。unit原子が一つでもある任意の観測値はunit-free構文像に属さない。

    元の真正型付き旧18D SelectedLocalEighteen.unitLeft before F G C afterと.unitRight before F G C afterは、それぞれ元v5.73のoldUnitLeft・oldUnitRightを観測する。いずれもunit-free像に属さず、両観測原子も別である。

    この「部分parserが適用できない」ことは元旧18Dの全体に同指紋・異raw証拠対があるという存在証明ではない。真正unit生成元を含む任意の元旧18D証拠を、上のunit-free復元器で復元できるとは主張しない。とくにv5.87の異なるraw17D fiber間の総空間衝突を同一fiber衝突に言い換えない。
