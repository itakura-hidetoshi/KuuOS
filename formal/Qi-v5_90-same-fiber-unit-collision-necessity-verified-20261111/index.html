    Qi v5.90 — 真正旧18D同一exact fiberの指紋衝突には両側のunit構成子が必要（Lean4形式証明）¶

    2026年11月11日 JST。canonical正本：itakura-hidetoshi/KuuOS／main。元の真正17D依存端点を固定した旧18D SelectedLocalEighteen W l r N N、その元内部括弧観測、元の旧5／別の新7選択19D商およびそれぞれの型付き19D比較を対象にする。以下の必要条件は衝突の存在証明でも十分条件でもない。「空・縁起・二諦・中道」との対応は解釈／命名の層で、Lean4が哲学的概念を証明した意味ではない。

    2．観測と元の証拠値の区別¶

    前段v5.89で、元旧18Dの実際の5構成子に直接 selectedV589OriginalUnitCount を再帰定義し、unitCount=0の場合に限り元証拠がv5.88の忠実なunit-free構文像で尽くされることを証明済み。

    Qi v5.90は元の真正旧18D M,L : SelectedLocalEighteen W l r J N の同じ依存添字を保持し、 selectedLocalEighteenInnerBracket l r M = selectedLocalEighteenInnerBracket l r L から selectedV589OriginalUnitCount l r M = selectedV589OriginalUnitCount l r L を証明（selectedV590BracketEq_originalCountEq）。これはv5.89の証明済みOriginalUnitCount_observedを両側に使った観測整合性であり、M=Lを無条件に主張しない。

    3．同一N→N exact fiberで証明された必要条件¶

    真正同一raw17D端点 N について

    M L : SelectedLocalEighteen W l r N N
bracket(M) = bracket(L)
M ≠ L
--------------------------------
0 < OriginalUnitCount(M) ∧ 0 < OriginalUnitCount(L)

    を selectedV590BracketCollision_requiresPositiveUnits として形式証明。

    その反対方向は主張していない。証明の中心は、bracket(M)=bracket(L)で一方の元unitCountが0なら、まずunitCountの一致によりもう一方も0と判明し、v5.89の元依存型の全zero-unit像の忠実性から真正raw旧18D証拠がM=Lになる、という論理である。

    selectedV590BracketEq_leftFreeReflectとselectedV590BracketEq_eitherFreeReflect は「一方がunit-free」という片側条件だけからraw等号を反映する。前提を弱化したのではなく、他方のunit-free性を既証明の観測保存則で導いたもの。

    4．旧5商・新7商・元の型付き19D比較の独立した必要条件¶

    同じN→N fiber上の元旧18D証拠M,Lを真正18Dの.inherited M、.inherited Lとして埋め込む。v5.73で証明済みの本来の継承内括弧列観測に対する降下定理を、それぞれ本来の旧5商と本来の新7商へ別々に適用し、商クラス等号から元内部括弧観測等号を得る。

    • selectedV590OldClassEq_impliesBracketEq／selectedV590NewClassEq_impliesBracketEq：各々の真正商で同一クラスなら元旧18Dのsource-inner bracketが一致する。
    • selectedV590OldClassEq_leftFreeReflect／selectedV590NewClassEq_leftFreeReflect：各々の真正商で同一クラス、かつ元の一方のunitCountが0なら、本当の元旧18D raw証拠は等しい。
    • selectedV590OldClassCollision_requiresPositiveUnits／selectedV590NewClassCollision_requiresPositiveUnits：各々の真正商で同一クラスでも元のraw証拠が異なる仮定の下では、両側で元unitCountが正。
    • selectedV590OldTypedCollision_requiresPositiveUnits／selectedV590NewTypedCollision_requiresPositiveUnits：元の別々の型の選択19D比較が実際に存在して、raw元証拠が異なると仮定したときにも、同じ必要条件が成り立つ。

    これらは Nonempty の証拠が与えられた場合の含意であり、どちらのType19D比較の居住性も新たに生成していない。旧5商と新7商の大域同値も宣言していない。

    6．未認証障害・次段候補¶

    認証済み：同じ真正raw17D N→N fiber内で、同指紋だが異なる元raw旧18D証拠の存在を仮定したなら、どちらもunit構成子を一つ以上持つ。元旧5・新7真正商のクラス等号、別々の元Type19D比較が仮に異raw値を結ぶ場合にも同じ必要条件。

    NO_DATA：unit構成子を含む同一fiberの同指紋・異raw証拠対が実際に存在するか、正のunitCountが衝突の十分条件になるか、元のunitLeft／unitRightパラメータから型付き衝突を構成できるか、全旧18D分類、旧新19D比較の大域同値、異fiber transport／WORLD／20D降下、実行・制度的権限。前段v5.87の異なるraw17D fiberを跨ぐtotal-space collisionをここに移し替えない。

    Qi v5.91候補：元のunitLeft／unitRightを含む正のunitCount領域で、同一真正raw17D fiberの居住性・中間端点整合・source-inner-bracketの単位原子以外のパラメータ情報を調べる。衝突の存在を結論へ先取りせず、実際の型付き証拠構成が成立した場合にのみ局所認証を拡張する。
