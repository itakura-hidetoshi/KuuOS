    1. 元の型付き十セルcritical pairを独立第十一セルで比較¶

    Qi v5.15で元P/M交換と九セル左単位の間に、同じ生九セル始終点を持つ二つの生十セル証拠を構成済み：

    pmLeftUnitCriticalExchangeThenUnit l r
pmLeftUnitCriticalUnitThenExchange l r

    pmLeftUnitCriticalRawTenGapは両者が生Type値として厳密に異なることを示す。今回この実際の二端点間に、新しい独立Type

    MixedExchangeUnitElevenCell W l r xi zeta

    を定義し、ちょうど一種類だけの新しい非strict比較生成元exchangeUnitを付加した。残りはstrict、十一セル反転・連鎖、および既存十セルのsymm・trans・nineReverse・nineChain・reverseContext・chainContext・whiskerLeft/Right・inverseContext・compositeContextの型付き閉包。合計14種類の構成子。

    mixedExchangeUnitElevenCell_relativeNecessityは、新比較の存在と元生十セルstrict Eqの不存在を同時に証明。mixedExchangeUnitElevenCell_noRawEqualityInterpreterは、選択した新第十一セル証拠の一般的な生十セル等号解釈が存在しないことを証明した。

    重要な限定： これは独立した高次比較presentationへの原始生成元の追加であり、元sourceに以前からこの生成元が存在していたという主張ではない。任意の高次coherence・普遍thinnessを仮定しない。

    2. 選択第十一セル商と十セル順序traceの非降下¶

    mixedExchangeUnitEleventhSetoidは元の平行十セル証拠Type上のNonempty (MixedExchangeUnitElevenCell ...)を同値関係として用いる。mixedExchangeUnitEleventhClass_eq_iffでクラス等号と第十一セル比較可能性を必要十分条件として証明。

    元の十セル値に対して、

    [ \boxed{[\Theta_{EU}]{11}=[\Theta{UE}]{11}} \quad\text{ただし}\quad \boxed{\Theta{EU}\ne\Theta_{UE}\quad\text{(raw Type)}} ]

    が成立する。

    元の原始十セルtraceはそれぞれ[false,true]（旧比較→新単位）と[true,false]（新単位→旧比較）で異なる。このリストを全代表元に忠実な形で新商に降下させる関数は存在しない（mixedExchangeUnitEleventhClass_noRawTraceDescent）。また全元十セル証拠へ復元する左逆は存在しない（mixedExchangeUnitEleventhClass_noRawRetraction）。

    ここで「商で等しい」と「生の元証拠が等しい」は独立した命題のまま保持した。

    3. 新たな二つのNat値観測量の降下¶

    元十セルmixedUnitAssocTenRawTraceを追跡し、新観測量を

    [ N_{\mathrm{old}}(\Xi)=#{\mathrm{false\ in\ trace}(\Xi)}, \qquad N_{\mathrm{unit}}(\Xi)=#{\mathrm{true\ in\ trace}(\Xi)} ]

    として定義した。falseはv5.14由来のprevious第十セル証拠wrapper、trueはv5.15で新規追加した左・右単位第十セル生成元を数える。assocやstrictはこの特定の二成分観測では0を寄与する。古い第十セル証拠の内部履歴まで数える観測量と混同しない。

    今回の新生成元で比較した二経路は、いずれも

    [ \bigl(N_{\mathrm{old}},N_{\mathrm{unit}}\bigr)=(1,1) ]

    であり順序は異なるが計数は等しい。

    mixedExchangeUnitElevenCell_preservesTenthEventCountは、全14種類の第十一セル構成子について任意のBool選択に対する計数保存を構造帰納法で証明した。特に反転・連鎖、九セル・十セルの合成文脈と対応づく。

    mixedExchangeUnitEleventhOldCountとmixedExchangeUnitEleventhUnitCountは本物のNat値Quotient.liftであり、代表元への評価等式も形式証明された。単に二つの例で値が等しいという主張ではない。

    4. 第十一セル追加後にも残る二つの独立障害¶

    一つ目は、元のP/M交換の十セル証拠を逆向きと連結した真正往復：

    eleventhOriginalPMTenRoundtrip l r

    同じ九セル始終点を持つ反射十セルと比較すると

    [ (N_{\mathrm{old}},N_{\mathrm{unit}}) =(2,0)\quad\text{対}\quad(0,0). ]

    二つ目は、真正九セル左単位の十セル証拠とその逆向きによる往復：

    eleventhOriginalUnitTenRoundtrip l r

    その九セル始終点での反射十セルと比較すると

    [ (N_{\mathrm{old}},N_{\mathrm{unit}}) =(0,2)\quad\text{対}\quad(0,0). ]

    これらは元九セル始終点の異なる二つの局所fiber上の反例であり、両往復ループ間の直接比較を主張しない。

    eleventhOriginalPMTenRoundtrip_noComparisonとeleventhOriginalUnitTenRoundtrip_noComparisonでそれぞれの第十一セル比較不存在を、全構成子保存不変量から証明した。選択十一セル商の異なるクラス・mixedExchangeUnitElevenCell_notGloballyThinも形式証明済み。

    今回、新しい逆元消去十一セルを追加していない。将来その種の独立比較を追加すれば、この二成分計数が降下不能となりうる。今回の障害は選択した十一セル文法に相対的であり、任意の高次圏で逆向き証拠を相殺できないという普遍定理ではない。

    先行の九セル・八セル証拠の非比較はmixedExchangeUnitElevenCell_retainsNinthObstruction／mixedExchangeUnitElevenCell_retainsEighthObstructionとして保持した。第十一セル比較だけから存在しない下位証拠を生成しない。

    5. 元P77/GK5CG真正Type値sourceへの特殊化¶

    pentagonActualPMUnitEleventhCompletionは、任意の真正P77 final raw indexで、元GK5CG long/short五セルType値によって今回の独立第十一セル比較が実在することを構成し、同時に旧PentagonAdjoinedSixCellEqualityInterpreterの不存在を保持する。

    元F55/P77/GK5CGと旧独立六・七・八・九・十セルのLean定義・型付き履歴は一切変更していない。

    6. 次段Qi v5.17¶

    第十一セル後の新課題は、選択した十一セル文法における十セル逆元往復の比較障害と、十一セル交換生成元の左右whiskering／二つの貼り合わせ履歴の高次critical pairの区別である。

    次の独立十二セル候補は、元の型付き十一セル証拠から具体的な平行二経路を構成し、その生十二次比較が必要な理由・残存障害を先に明示して絞り込む。無条件のthinness、元source strict Eq、任意の高次coherenceを導入しない。
