    1. 真正三重whiskeringと生の順序履歴¶

    任意の真正元第十二セル証拠 T : MixedExchangeInverseTwelveCell H K と、 元第七セル文脈 before、inner、outer を同一の正確な型付き元境界上で指定する。 元のwhiskerLeftとwhiskerRightだけから次の二つの真正旧12D証拠を構成：

    • originalTripleWhiskerRLR = whiskerRight (whiskerLeft before (whiskerRight T inner)) outer
    • originalTripleWhiskerRRL = whiskerRight (whiskerRight (whiskerLeft before T) inner) outer

    適用順序はそれぞれ R→L→R および L→R→R。 ここで順序表現は 生第十セルの外側からの前置履歴 と区別する。 元第十セル xi の真正 mixedTenWhiskerRawTrace は

    [ \boxed{\begin{aligned} \operatorname{Trace}{10}(R(L(R(\xi)))) &= [1,0,1] \mathbin{+!+} \operatorname{Trace}{10}(\xi),\ \operatorname{Trace}{10}(R(R(L(\xi)))) &= [1,1,0] \mathbin{+!+} \operatorname{Trace}{10}(\xi). \end{aligned}} ]

    originalTripleWhisker_traceValues・originalTripleWhisker_orderObstruction が両履歴の生の非等号を証明。一方 originalTripleWhisker_lengthCollision は長さが等しいことを証明。 同一Nat計数は履歴順序の保存に十分でない。 元旧第十二セルの相異なる依存fiberをEqで偽装しない。 本段は三重文脈全体に無条件な旧12D比較を主張しない。

    2. 旧第十二セルの合成輸送は厳密なraw関手性ではない¶

    真正元旧第十二セル T:H⇒K、U:K⇒L が同じ元6D〜11D fiberで合成可能な場合に限る。 二通りの旧12D証明値

    [ \begin{aligned} L(R(T\mathbin{\cdot}U)) &\neq L(R(T))\mathbin{\cdot}L(R(U)),\ R(L(T\mathbin{\cdot}U)) &\neq R(L(T))\mathbin{\cdot}R(L(U)) \end{aligned} ]

    は、それぞれ同じ正確な旧12D依存Typeに属するが whiskering構文子とchain構文子の位置が異なる。

    oldRightTransportComp_rawDistinct と oldLeftTransportComp_rawDistinct はこのraw非等号を証明。 旧12Dに存在しない合成自然性を黙って仮定しない。

    3. 新しい選択合成第十三セルpresentation¶

    別Type CompositionalWhiskerThirteen を導入する。 v5.22 SelectedWhiskerNaturalityThirteen の型付き証拠を selectedで忠実に埋め込む一方、従来の元12D raw比較とは混同しない。

    この新presentationには、形式的な strict/reverse/chain、 第十二セルの前後合成に作用する prepend/append、 括弧付けを比較する associator、 追加で選択した rightTransportComp/leftTransportComp を実装。

    特に rightTransportComp／leftTransportComp は、 第2節でraw非等号を証明した二種類の12D経路に対する新しい選択13D比較である。 元のMixedExchangeInverseTwelveCellに厳密等式や 元から存在した13D自然性を付け足したものではない。

    4. 元第十二セル合成と第十三セル自然性のcritical cube¶

    元のT,U、左文脈before、右文脈afterを固定。 u_T,u_Uを genuine right-then-left のframed12D旧輸送、 v_T,v_Uを genuine left-then-right のframed12D旧輸送とする。 d_H,d_K,d_Lはそれぞれ元v5.18の真正 doubleWhisker。

    貼り合わせる二端点は

    [ P_{\mathrm{expanded}}=(u_T\cdot u_U)\cdot d_L, \qquad Q_{\mathrm{expanded}}=d_H\cdot(v_T\cdot v_U). ]

    pastedNaturalityMiddle は次の全過程を型付き13D証拠として構成：

    1. associator(u_T,u_U,d_L) で最初の括弧付けを変更。
    2. prepend u_T (selected (naturality U)) で後段の真正自然性squareを適用。
    3. 逆associator(u_T,d_K,v_U)で中間経路を結合。
    4. append (selected (naturality T)) v_Uで前段の真正自然性squareを適用。
    5. associator(d_H,v_T,v_U)で最終括弧付けを一致させる。

    pastedCompositionalNaturality はさらに rightTransportComp と逆 leftTransportComp を接続し、 元の単一合成T.chain Uに対する直接自然性経路と 完全に同じframed12D始終点へ貼り合わせる。

    独立に directCompositionalNaturality は v5.22の naturality (T.chain U) を直接使う。 directPastedThirteen_rawDistinct はこの二つの 選択13D生証拠の非等号を証明する。

    5. 条件付き選択第十四セルとauthority境界¶

    新しい別Type SelectedCompositionFourteen に strict/reverse/chain と、合成可能な実在旧12D証拠 T,Uを明示的に要求する局所生成元 criticalCube を加えた。

    [ \boxed{ \mathrm{Selected14} \bigl(\mathcal N(T\cdot U),\, \mathrm{Paste}(\mathcal N(T),\mathcal N(U))\bigr) } ]

    selectedCompositionFourteen_conditionalCube は 選択14D比較の存在と、生13D二経路の非等号を同時に証明。 selectedCompositionFourteen_noRawEqualityAtCube は この選択14D証拠を生13Dの厳密Eqへ読み替える普遍的解釈の不存在 を証明する。

    この14D比較は生成元の明示的な追加による存在である。 真正旧元13D法則の発見、raw経路の同一視、 任意三重whiskeringの全ての面に関するglobal cube充填、 さらに15D以上の整合性までの証明ではない。
