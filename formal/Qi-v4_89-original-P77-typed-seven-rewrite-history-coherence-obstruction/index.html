    1. Qi v4.88からの数学的問題¶

    Qi v4.86では、元の真正GK5CG保守的五セルTypeから得た選択五セル語 L₃(i)、L₂(i) を始終点とする、別presentationの六セル自由語 PentagonAdjoinedSixCell を追加。Qi v4.85では元の五セル語の厳密不一致を形式証明済み。

    Qi v4.87では、新六セルの構文次数 degree が等しい平行な生証明語を商に送った。Qi v4.88では真正L₃(i)≠L₂(i)を使い、次数は端点のポテンシャル差だけで決まり、新商が局所thinであると証明した。しかしこの商の等号だけでは、元の生六セル語cがdへどう書き換えられるかという証拠履歴を保持しない。

    v4.89ではその証拠履歴自体を新たなType値として作る。元sourceに六セル／七セルがすでに存在したという主張ではない。

    2. 新七セルType値帰納文法¶

    PentagonAdjoinedSixCell.SevenRewrite W l r c d : Type は、元の生の六セル証明語 c,d : PentagonAdjoinedSixCell W l r w z を添字として両方保持する。

    書換え生成元は13種：

    1. refl — 証拠履歴の反射
    2. symm — 七セル履歴の反転
    3. trans — 履歴の縦合成
    4. congrInv — 六セル反転への文脈適用
    5. congrComp — 六セル合成への左右文脈適用
    6. leftUnit — 左単位
    7. rightUnit — 右単位
    8. assoc — 合成の結合則
    9. inverseRight — 右逆元消去
    10. inverseLeft — 左逆元消去
    11. doubleInverse — 二重反転
    12. inverseId — 恒等の反転
    13. inverseComp — 合成の反転則

    次数一致を要求するだけの任意のdegreeWitness生成元は追加していない。 したがって商の等号と実際の書換え履歴は混同されない。局所書換えの導出可能性は個別に構成・検査する。

    3. 全構成子に対する次数健全性¶

    sevenRewrite_degreeSound は、13構成子すべての帰納法で

    [ \boxed{\mathrm{SevenRewrite}(c,d)\Longrightarrow\deg(c)=\deg(d)} ]

    を証明。合成文脈では加法の整合、逆元文脈では符号反転、結合則では整数加法の結合則、inverseCompでは反転した和の整合をLeanの整数群計算で導いた。

    sevenRewrite_quotientSound はこの証明をv4.87のCoherentHom商の等号 [c]=[d] に送る。ただし c=d という生六セル証明語の厳密等号へは送らない。

    sevenRewrite_degreeObstruction は deg(c)≠deg(d) なら新七セルのNonemptyを否定。特にselfPentagonLoop_noSevenRewriteは、新presentationで追加元の両端を同一視した場合l=r=w、pentagon:w→w の次数が1、refl:w→wの次数が0となり、その両者をつなぐ七セル書換えは存在しないことを証明した。これは元sourceの七セル不存在とは別問題である。

    4. 非自明な履歴・旧厳密等号への戻り障害¶

    sevenRewrite_zigzagRight は、次の書換えをcongrComp・inverseRight・leftUnitの証拠を合成したType値で構成する：

    [ (c\circ c^{-1})\circ c\xRightarrow{\mathrm{new\ seven}} c. ]

    sevenRewrite_zigzagLeft も対称的に構成する。

    sevenRewrite_roundtrip_exists_notStrict は、新しいpentagon生成元について

    [ \mathrm{Nonempty}(\mathrm{SevenRewrite}(p\circ p^{-1},\mathrm{refl})) \quad\land\quad (p\circ p^{-1}\ne\mathrm{refl})_{\mathrm{raw}} ]

    を同時に証明。したがって、新七セルの全証拠を生六セル語の厳密等式に解釈する写像は存在しない（sevenRewrite_noStrictInterpreter）。元の五セルへの全端点保存EqualityInterpreter不存在も引き続き保持する。

    5. 真正全P77 raw terminalへの型付き適用¶

    pentagonActualSevenRewrite_roundtrip、pentagonActualSevenRewrite_exists_notStrict、pentagonActualSevenRewrite_zigzag、pentagonActualSevenRewrite_zigzagQuotientSound、pentagonActualSevenRewrite_withOriginalNoGo、pentagonActualSevenRewrite_noStrictInterpreterを形式証明。

    任意の真正最終raw添字iに対して元の五セル値L₃(i)／L₂(i)を厳密なType値として保持し、それらを両端とする新六セルの往復とジグザグを、新七セルの証拠履歴として型付き構成。元F55/P77/GK5CG source、元四セル電荷+1 no-go、五セルの厳密不一致を変更しない。

    この結果は具体的な局所書換えの健全性・存在証明であり、商で同じ次数を持つ任意の平行六セル語が必ずこの13種の局所書換えで接続できること（完全性）はまだ証明していない。

    6. CI・実装・再観測¶

    7. 次の研究候補 Qi v4.90¶

    明示的な七セル局所書換えが、元の五セル端点が異なるときすべての平行な六セル証明語を接続するかという完全性が次の真の課題。証拠履歴を保存した正規化アルゴリズム・上下文脈との可換性と停止性を、帰納Type値で構成する。v4.88のthin商だけを根拠に局所書換えの完全性を推論しない。
