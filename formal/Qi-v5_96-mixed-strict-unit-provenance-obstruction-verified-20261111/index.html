    2．本当の同一J→N fiberにおける混合配置の指紋剛性¶

    M,L : SelectedLocalEighteen W l r J N は同一の元raw17D J→N fiberの真正証拠とする。元のv5.73内部括弧を Bracket、真正元v5.89 unit数を UnitCount と略す。

    hbase : Bracket(M) = Bracket(L)
hunit : 0 < UnitCount(M)
P_m(M) = v5.94 genuine original strict prefix of length m
S_n(L) = v5.94 genuine original strict suffix of length n

    この明示した条件の下で次をLean4形式証明した。

    Bracket(P_m(M)) = Bracket(S_n(L))
  ↔ m = 0 ∧ n = 0

P_m(M) = S_n(L)
  ↔ m = 0 ∧ n = 0 ∧ M = L

    証明は、v5.94の実strict葉数の加算式とBracket(M)=Bracket(L)からm=nを導き、正の共通長ではprefixの最外左葉がoldStrictだがsuffixの最外左部分木には本当の元unit葉が残り、元unit数が0ではないことから括弧一致を排除する。元括弧一致・正unit数を外した全域の結論には一般化しない。

    3．真正型付きunit payload履歴は同じでも括弧は別¶

    任意の本当のM:J→NでUnitCount(M)>0なら、m+n>0を満たすすべての自然数対について、

    History(P_m(M)) = History(S_n(M))
Bracket(P_m(M)) ≠ Bracket(S_n(M))
P_m(M) ≠ S_n(M)

    を証明した。ここでHistoryは元v5.92の完全な型付きunit atom履歴であり、元before/F/G/C/after・元raw17D始終端・元の旧18D unit証拠自体を残す。履歴一致と元raw等号・括弧等号を混同しない。

    さらに、もし元M,Lの括弧と型付きunit履歴がともに一致し、UnitCount(M)=1、M≠Lの証拠が本当に供給された場合にも、非自明な混合paddingは履歴一致を維持する一方、括弧は一致しない。元源対の実在は仮定ではなく未解決の問題であり、条件付き定理がそれを構成するものではない。

    4．制限された混合1-unit衝突像は厳密に分類可能¶

    新selectedV596MixedOneUnitCollisionExists l r J N m nは、元source同士の内部括弧が等しいこと、UnitCount(M)=1、混合padding後の括弧等号・raw不等号を含む、限定された元旧18D依存型の存在Propである。

    MixedOneUnitCollisionExists(m,n)
  ↔ m = 0 ∧ n = 0 ∧
    V593OneUnitSourceCollisionExists(J,N)

    を形式証明。従ってm+n>0では、この限定された混合paddingによる1-unit衝突は不可能と証明された。ただし元v5.93の0/0の源衝突の存在または不可能性を証明したわけではない。また、元source括弧一致を仮定しない他の構成法、全旧18D生証拠・商全域、異fiber貼合への不可能性も主張しない。

    5．真正unitLeft／unitRightの元パラメータを保持¶

    元v5.35の真正unitLeft before F G C afterおよび独立のunitRight before F G C afterのそれぞれについて、元v5.92の履歴が、対応する正しいJ,Nと元の真のunit証拠を含むsingleton Sigma payloadであることをLean4で確認した。

    左右の元raw17D端点は一般には別の依存型であり、元生証拠同士の等号を捏造しない。一方、共通の内部括弧観測の値oldUnitLeftとoldUnitRightは区別される。さらに左右それぞれの本当の1-unit源について、任意のm+n>0で完全型付き履歴一致、括弧不一致、真正raw証拠不一致を元の同一fiber内で検証した。

    7．障害（NO_DATA）とQi v5.97候補¶

    認証済み：元の同一J→N fiber、元括弧一致・正のunit数という条件に限定した混合strict配置の括弧等号・raw等号の必要十分条件、完全型付きunit履歴不変のもとでの非自明混合配置の分離、限定混合1-unit衝突の正padding時不可能性、左右元unit源の独立型付きsingleton payload。

    未認証（NO_DATA）：元旧18Dの同じJ→N fiberでUnitCount(M)=1かつBracket(M)=Bracket(L)かつM≠Lとなる元source対の実在・不可能性。一つの制限付きmixed presentationの不可能性を全源空間の不可能性へ昇格しない。元旧5／新7選択19D比較の全域的同値、異fiber gluing、WORLD／20D降下、制度的行為権限も未認証。

    v5.97候補：元内部括弧のoldUnitLeft／oldUnitRightの葉位置を固定した上で、元v5.92 Sigma型付きunit payloadの一致が真正元生証拠の等号を反映する局所断片を検証する。一般源への降下条件を別途示すまでは、局所結果を全域に拡張しない。
