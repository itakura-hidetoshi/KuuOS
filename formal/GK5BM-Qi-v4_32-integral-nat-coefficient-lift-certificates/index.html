    F112-P94D3GK5BM／Qi v4.32 — 有理補間係数の整係数・非負Nat係数の必要十分条件¶

    正式証明記録：2026年11月4日 JST。 唯一のcanonical theorem-bearing branchは itakura-hidetoshi/KuuOS main 。strict 空 authority、独立Kuu→Qi、元F54二Nat／二圏／Blocksと元F55 Type値証拠履歴、公開root107を維持。append-only。

    1. 独立GK5BM：有理多項式の係数持ち上げの必要十分条件¶

    • 独立GK5BM PR #3064 MERGED。最終exact-source HEAD 951f25bf3162743d6b8ecab8bd66fdb6ae93147e、test-merge ec7cf6cb3d125d712c5ae4b4f8ab1fac216e6306、squash 3ed73fdbc9236bb24b73ebd5df08b9f216a04f59。source/test-merge/squash Git tree d340d7ebeecad7c6657167b9bb80b938057b4885一致。
    • exact-source CI #41739642619：Strict Lean 9,282/9,282、Governance 30/30 SUCCESS。新規11宣言の#print axiomsでsorryAxなし。新規ファイル・公開集約ビルド成功、Lean warning/error 0/0。
    • 独立Leanソース：248行、既存定理は変更なし。

    GK5BLは異なる整数節点上の観測値から有理多項式Q∈ℚ[X]を構成したが、任意の整数値観測から整数係数性は自動的には従わない。GK5BMでは任意のQ: Polynomial Ratについて、係数ごとに元の整数またはNatを与える条件を完全に区別した。

    (∃ P:ℤ[X], P.map(Int→Rat)=Q) ↔ ∀ k, ∃ z:ℤ, (z:Rat)=Q.coeff k.
(∃ P:ℕ[X], P.map(Nat→Rat)=Q) ↔ ∀ k, ∃ b:ℕ, (b:Rat)=Q.coeff k.
(∀ k, ∃ b:ℕ, (b:Rat)=Q.coeff k)
  ↔ ∀ k, (∃ z:ℤ, (z:Rat)=Q.coeff k) ∧ 0≤Q.coeff k.

    十分性は構成的で、全係数の指定原像c(k)から有限supportを使いP=∑_{k∈support(Q)}monomial(k,c(k))を実際に構成し、P.map=Qを証明した。任意のLagrange補間についてもこの必要十分条件が成立する。負の有理係数や整数像にない係数が存在すれば、非負Nat係数多項式の持ち上げは不可能。

    真正型付きP92B証拠fでは、GK5BJの非負Nat発生回数b_k(f)とGK5BLの構成的補間定理から、真の整数観測を補間したRat[X]にNat[X]多項式持ち上げの存在を証明した。元F55/P77真正四セル商の降下した多項式値についても同様に構成した。ただしNat[X]多項式が存在することから、別の元F55 Type値証拠・P94A四セル・元P77商類の等しさを導かない。

    真正北C60の元F54 long→short Homに属するあらゆる元F55証拠について、選択構造像φ(f)の整数観測から補間した多項式が非負Nat係数の持ち上げを持つことを形式化。元P77 source四セル商に対しても、商へ降下した多項式値にNat係数持ち上げの存在を証明した。一般の有理観測データに対する必要十分条件も保持する。

    具体的な真正北pentagon primitiveP=1と元double inverse＋真正右F55単位P=X²は三点{0,1,2}でNat係数持ち上げを持つ。選択P92B endomorphism loop対A=X³+2・B=2X²+Xは四点{-1,0,1,2}からそれぞれ持ち上がる。一方、-X∈ℚ[X]は深さ1の負係数を持ちNat係数へ持ち上がらないという任意有理データの障害例もLeanで確認。選択endo-loopはoriginal→phi local seamの反例と混同しない。

    3. 数学的な権限境界と次段階¶

    整係数・非負Nat係数多項式の存在は、元のF54/F55 Type値証明項の実現可能性を意味しない。元P77商の値と商類そのものを同一視しない。P94A保存不変量の一致からP94A四セルは生成しない。GK5BHW=1は局所seamの必要条件のみであり十分性は未証明。旧P89 BadPair反射は条件付き、真正北C60第五Dart物理閉路と分離した。全GK5AY seam、GK5BA kit、Gray、hyperdescentは未証明。

    次GK5BN（仮称）： 上記係数持ち上げの一意性・Nat係数の有限supportと、補間データの離散有限差分／整除証明書を結び、検証可能な整数性条件をより計算的に記述する。有限の整数値観測のみから整係数性を無条件に主張せず、元のType値実現可能性を独立obstructionとして維持する。
