    Qi v5.72 — 継承葉数まで観測しても残る旧18D根構成子の順序履歴（Lean4形式証明・公理監査）¶

    2. 証明した独立順序不変量¶

    旧 SelectedLocalEighteen は strict・unitLeft・unitRight・reverse・chain の5構成子を持つ。新しい独立Enum SelectedInheritedSourceRootTag は、元の依存旧18D証拠 M を消去せず、その最外構成子のラベルのみを読む。

    selectedContextEighteenInheritedRootList は真正raw18D値を構造再帰する。元 inherited(old18) 葉にはold18のroot tagを1要素加え、raw strict は空列、raw reverse と原7D whiskeringは内側の列を保持し、raw chain A B は左右の列を 順序付き連結する。元のraw18D chain の結合律は仮定していない。

    この観測について： - 旧 SelectedLocalNineteen の5構成子全部で保存性を形式証明。元の unitPrepend・unitAppend が消すのはraw strictであり、inherited(old18) 自体ではない。 - 独立新 SelectedRawCongruentNineteen の7構成子全部で保存性を形式証明。raw reverse、左右raw chainについて真の帰納仮定から整合性を証明。 - 旧商・新商へ別々に Quotient.lift で降下し、旧→新projectionによる因子化の可換性を証明。元Type値や元比較規則は変更なし。

    3. 新しい真正18D Type値の反例¶

    任意の元17D端点 N の真正 N→N fiberで、元 SelectedLocalEighteen の strict N と chain (strict N) (strict N) はどちらも本物のold18D証拠であり、同じ元端点を持つ。これらを原raw18D reverse(inherited(_)) に持ち上げたものを X、Y とし：

    X := reverse (inherited (old18.strict N))
Y := reverse (inherited (old18.chain (strict N) (strict N)))
A := chain X Y
B := chain Y X

    と構成した。二つの真正raw18D値について、既存9変量、全 Nat→Nat 祖先塔、全 Nat→Nat 直接連続反転数塔、完全ordered raw reverse run list、v5.70非結合的単位簡約括弧構造、v5.71 inherited葉数（双方2） がすべて一致することを証明。

    一方、新しく独立に読んだ順序付き元証拠root listは：

    InheritedSourceRootList(A) = [strict, chain]
InheritedSourceRootList(B) = [chain, strict]

    で相異なる。これは単なる葉数差ではない。新順序列が真正新7構成子商へ降下するため、A/Bは異なる新商クラスであり、両者の真正 SelectedRawCongruentNineteen Type値比較も存在しない。

    さらに実際に提供された任意の元raw18D M:J→N に限り、chain M A と chain M B を同じexact fiber J→N で構成。すべての既存観測とinherited葉数は等しく、元証拠root listは共通prefixに対するリストの左消去則からなお相異なる。よって新結合商観測はそのfiberで非単射となり、root list decoder／全クラスdecoder不存在も得る。任意の指定 J→J には元 strict J で確かな具体例がある。

    5. 境界と次段¶

    • 新root tagは最外構成子5値の観測だけであり、同じ chain タグの二つの元old18D証拠や、その内部の入れ子構造を同一視／分類したものではない。現在の新結合観測へroot tag listまで加えたときの全商クラス識別性はNO_DATA。
    • 次段Qi v5.73は、同じ順序付きroot tag listを持ちつつ相異なる元old18D証拠の内部構文を、真の旧新比較と整合する独立不変量として読めるかを調べる。v5.72の現在の証拠対はroot tag順序で区別されるため次段へそのまま流用しない。
    • 任意異端点fiber非空性、元証拠値全体の無条件復元、20D gluing、全WORLD貼合、institutional authorityも未認証（NO_DATA）。
