    2. 選択17Dの独立真正文脈閉包と元証拠の単射保持¶

    v5.33の元選択17D生証拠SelectedLocalSeventeen W l r H Kを、 独立のSelectedContextualSeventeen W l r H Kへinheritedでそのまま埋め込む。 oldSeventeenToContextual_injectiveは、この生の型付き証拠の埋込みが単射であることを証明した。

    新規whiskerLeft・whiskerRightは、元の真正SevenRewriteと ContextFrameElevenの六セル境界が適合するときだけ17D比較を16D始点・終点ともに輸送する。 strict/reverse/chainと併せ6種類の構成子を備え、 selectedContextualSeventeen_leftStable/rightStableにより真正文脈下での局所安定性を証明。 旧17Dのraw Eqを導く新公理や構成子は追加しない。

    selectedContextualSeventeen_preservesSixteenTraceは6構成子の帰納で 16D生証拠の外側第七セルの順序付きList Bool履歴を比較前後で保存する。 selectedContextSeventeenSetoidは、同一の真正15D端点を持つ平行16D生証拠について 選択17D比較の存在を同値関係として商を構成した。 selectedContextSeventeenClass_eq_iffは、商クラスEqと実際の17D比較の存在が同値と示す。 selectedContextSeventeenTraceOnQuotientは全順序履歴の真正Quotient.liftを与える。

    一方、旧v5.33の真正17D局所単位比較では、raw16Dの単位前置・後置の先頭タグ3と0が異なるが商クラスは等しい。 selectedContextSeventeen_noFirstTagDescentで、生16D先頭タグを再現する商上写像の不存在を証明。 文脈順序履歴は降下する／raw構成子タグは降下しない。

    3. 従来の不可能条件を保持したまま隣接交換を構成¶

    v5.34でSelectedMixedTraceRespectingHigherGateの不成立が形式証明済み：

    [ \mathrm{Trace}(L(R(H)))\ne\mathrm{Trace}(R(L(H))). ]

    これは順序を変更しない高次gluing条件の障害である。 v5.35では新しいSelectedOuterAdjacentSwapを、共通観測先List Boolにおける 有限な隣接交換の証拠Typeとして構成した：

    [ [\mathrm{false},\mathrm{true}]\mathbin{+!+}h \quad\Rrightarrow{\mathrm{swap}}\quad [\mathrm{true},\mathrm{false}]\mathbin{+!+}h. ]

    selectedMixedOuterAdjacentSwapは真正元第七セルによるv5.33の二種16D文脈輸送から、 実際の履歴観測に対してこの証拠を構成する。 selectedAdjacentSwap_changesTraceは両観測が異なることを、 selectedAdjacentSwap_preservesCountsは左右の出現回数は同じことを証明する。

    SelectedMixedTraceChangingCertificateは次の完全な局所資料を保持する： 元v5.18 double-whiskerに由来する12D始点・終点の真正橋、 v5.30の選択13D左右混合interchangerと選択14D自然性squareを含む 元v5.33の真正SelectedMixedLowerHigherPacket、 さらに上記の有限隣接swap Type値、左右出現回数の等号証明。

    selectedMixedTraceChangingCertificateはこのパケットを旧証拠から構成し、 selectedMixedTraceChange_possible_strictTraceImpossibleは同じ文脈・元添字条件で

    [ \boxed{ \operatorname{Nonempty}(\mathrm{TraceChangingCertificate}) \quad\land\quad \neg\operatorname{Nonempty}(\mathrm{TraceRespectingHigherGate}) } ]

    を証明した。

    これは「観測の隣接交換が可能」「観測を変えないgluingは不可能」の両立である。 隣接交換は共通観測値でのType値証拠であって、異なる依存15D/16Dの raw証拠Eqでも、すべての高次交換を実現する18Dセルでもない。 trace変更型のより高次な元証拠輸送には、別の明示的な互換証拠が必要である。

    4. 厳密な同一端点での局所選択18D¶

    元v5.33の真正選択17D局所unitLeft/unitRightを独立の17D閉包へ含め、 その比較の前後それぞれに17Dstrictを貼り合わせた左右2系列の生17D経路を構成した。

    selectedSeventeenUnitPrependLeft/AppendLeftと selectedSeventeenUnitPrependRight/AppendRightは、 それぞれ完全に同じ16D始終点を持ち、先頭構成子観測は3／0。 selectedSeventeenUnitLeft_rawDistinct/right_rawDistinctは生17D値の非等号を証明する。

    新しい独立SelectedLocalEighteenはこの2系列だけを unitLeft/unitRightという局所18D比較生成元として追加し、 strict/reverse/chainで閉包する。 selectedLocalEighteen_leftWitness/rightWitnessは 選択18D比較の存在と生17D値の非等号を同時に証明。 selectedLocalEighteen_noRawEqualityInterpreterは、 選択18D比較を生17D Eqへ読み替える普遍解釈を否定する。

    無条件の左右二重文脈18D交換、他の依存fiberへの全面的extension、 元証拠のstrictification、全体coherenceは証明していない。

    5. 次の研究：Qi v5.36¶

    2. 独立選択18Dからの17D商と、外側順序履歴の保存・非保存を形式証明する。
    3. 順序を保つ降下・入れ替えを許す互換・阻害されるgluingのauthority境界を維持する。
