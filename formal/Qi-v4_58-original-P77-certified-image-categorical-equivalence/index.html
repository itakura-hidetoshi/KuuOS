    1. 真正sourceと元P77のcertified image¶

    Qi v4.53の5本の本物の有向FivefoldEdge（e01/e12/e23/e04/e43）からの自由圏FivefoldFreePathCategoryをsourceとする。Qi v4.54で真正元F55/P77のType値四セルを、元GK5CGの保守的Type値5-cellの存在のみで商にしたtarget FivefoldP77ConservativePoint f g h k を保持する。

    Qi v4.57の FivefoldP77ImagePoint f g h k は、各Homを

    { z : GenuineOriginalP77ConservativeQuotientHom //
    ∃ sourcePath : OriginalFivefoldTypedFreePath,
      F.map sourcePath = z }

    という元P77の真正商クラス＋本物の型付き到達証拠で構成した別圏。数値chargeの一致でも、物理C60 Edge列の一致でもない。v4.57はfivefoldP77ImageFactorのFull・Faithfulおよび元targetへのfivefoldP77ImageInclusionのFaithful・NonFullを既に証明していた。

    2. Source→imageの対象全射性¶

    今回のfivefoldP77ImageFactor_obj_surjectiveは、任意の像圏対象 Y : FivefoldP77ImagePoint f g h k に対し、元ラッパーが実際に保持する Y.vertex : FivefoldPathVertex が原像であることを示す：

    ∃ X : FivefoldFreePathCategory,
  (fivefoldP77ImageFactor f g h k).obj X = Y

    元FivefoldIndex = FivePhase = ZMod 5の型を崩さず、対象のsurjectivityを直接証明した。このため固定mathlibのFunctor.essSurj_of_surjから、fivefoldP77ImageFactor_essSurjとして真正Functor.EssSurjを得る。

    3. 実際のMathlibカテゴリー同値¶

    fivefoldP77ImageFactor_isEquivalenceは、v4.57で証明した実際のFunctor.Full・Functor.Faithful、v4.58のFunctor.EssSurjを合成し、真のFunctor.IsEquivalenceを構成。固定mathlibのFunctor.asEquivalenceから

    fivefoldP77ImageEquivalence :
  FivefoldFreePathCategory ≌ FivefoldP77ImagePoint f g h k

    を定義した。これはデータを持つ真正圏同値であり、単なる論理的Nonemptyや対象の個数合わせではない。

    fivefoldP77ImageEquivalence_functorでそのforward functorが既存のfivefoldP77ImageFactorに定義のうえで完全一致することを形式証明。fivefoldP77ImageQuasiInverseは実際のinverse Functorを与え、fivefoldP77ImageUnitIsoとfivefoldP77ImageCounitIsoは、それぞれ

    𝟭 FreePathCategory ≅ ImageFactor ⋙ ImageQuasiInverse
ImageQuasiInverse ⋙ ImageFactor ≅ 𝟭 CertifiedImageCategory

    という真正の自然同型を構成する。元のP77証拠クラスは置換されず、像のHomは旧GK5CG保守的5-cellによる商のまま。

    4. 元P77全targetとの正確な障害¶

    fivefoldP77ImageEquivalence_comp_inclusion：

    ImageEquivalence.functor ⋙ ImageInclusion
  = fivefoldP77ConservativeFunctor

    を真正Mathlib functor等号で証明。これにより、旧v4.54元P77関手の因子分解を保持する。

    ただし、Qi v4.56の実際の元P77逆向きe01四セル（元P77 symm構成子、charge -1）には、有向自由経路の像から到達できない。よって、旧fivefoldP77ConservativeFunctorとfivefoldP77ImageInclusionのどちらもFullではない。この事実から、fivefoldP77ConservativeFunctor_not_isEquivalence・fivefoldP77ImageInclusion_not_isEquivalenceが、それぞれその関手はFunctor.IsEquivalenceではないことを証明した。他に一切のカテゴリー同値が存在しないという一般的非同値定理ではない。

    最終fivefoldP77ImageEquivalence_obstruction_splitは、真正source↔certified image同値の存在、元targetへの包含の非同値、元のsource→全targetの因子分解を一つの証明命題として保持する。

    確定した対象: 正真正銘の元FivefoldEdge自由経路圏と、元GK5CG保守的証拠により到達が認証されたP77商像圏とのカテゴリー同値。完全な元targetの元四セル構文を不正にstrict化する主張ではない。
