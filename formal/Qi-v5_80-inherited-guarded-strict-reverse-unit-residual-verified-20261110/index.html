    旧selected19の単位規則の正確な境界¶

    元SelectedLocalNineteenのunitPrepend／unitAppendは、真正な旧18D Type値Mを継承したinherited Mの直前・直後へraw strictを一つ置く操作に対してのみ、比較証拠を与える。

    この事実は、任意のraw reverseやraw chainの左右でstrictを自由に消去できるという一般単位律ではない。本研究ではこの区別を消さず、元の比較関係に新しい構成子を追加していない。

    新たな独立SelectedInheritedGuardedRawTreeは、inherited・strict・reversed・joinedの自由な非結合構文木である。selectedInheritedGuardedRawJoinが直接簡約するのは次の2式だけ：

    join(strict, inherited) = inherited

    join(inherited, strict) = inherited

    他のraw joinを勝手に同一視しない。元の真正依存contextual18D証拠の六構成子を構造再帰でこの補助構文木に写す。元Type値自体は上書きしない。whiskerLeft／whiskerRightは内部観測を維持する。

    真正型付き比較の保存と両商への独立降下¶

    • 元の旧selected19全5構成子で新観測が保存されることを、真正比較証拠に関する帰納法で証明。特にunitPrependとunitAppendは上記2つの正確な式を使う。
    • 新SelectedRawCongruentNineteenの全7構成子でも保存。raw reverse、左右raw chainの合同性を構造的に証明。
    • 元5構成子商selectedNineteenSetoid、新7構成子商selectedRawCongruentSetoidそれぞれへ独立したQuotient.liftを構成。旧→新商射影との因子化を証明。旧新Type値比較そのものを同一視しない。

    v5.79全観測が一致する真正18D証拠対¶

    任意に与えられた真正17D端点Nに対しS = strict Nとして、同一真正N→N fiberで元18D構成子だけから次を作る。

    A = chain (reverse S) S

    B = chain S (reverse S)

    両者の元九観測、二本の全Nat→Nat無限塔、ordered反転run、v5.70単位簡約非結合raw括弧、旧18D継承葉数・ordered根タグ・完全内部構文、v5.74 reverse site列[0]、v5.75イベント語[rawReverse]、v5.76継承葉保持括弧reversed unitは一致する。無限塔は全次数の等式とfunextで証明した。

    さらにraw chainの一方の子がreverseであるため、最大の非自明strict-only鎖は存在しない。従ってv5.77枝形summary、v5.78反転祖先深度summary、v5.79左右経路summaryはそれぞれ両者で(none, [])に一致する。以前の完全観測を捨てたり有限サンプルへ弱めたりせず、真正新商上のselectedRawCongruentFullV579QuotientObservation全体が等しいことを証明している。

    対して新SelectedInheritedGuardedRawTree観測では：

    G(A) = joined (reversed strict) strict

    G(B) = joined strict (reversed strict)

    となり、自由補助構文木の値は異なる。新観測の真正新商への独立降下を使い、新7構成子商クラスの不一致、真正新19D型付き比較の不存在、指定したN→N商でのv5.79全観測非単射、新guarded treeおよび商クラスのdecoder不存在をLean4で形式証明した。証拠のraw文字列が違うというだけでは商の非同一性を主張していない。

    証明の範囲・次段Qi v5.81¶

    証明したのは、実際に与えられた17D端点Nが作る同一N→N fiberでの局所非単射性である。任意の異端点J→N fiberの無条件非空性、旧新商の大域完全分類や完全忠実性、20D gluing、WORLD横断降下、制度的・実行権限は未認証（NO_DATA）として保持する。
