    2. 新しい数学的不変量 — 元F55 wrapper数¶

    選択P92Bの真正Type値付き3-cell証拠wに対し、N(w) := w.gk5bbOriginalCount : Natを定義する。単なる物理shadowでも数値等号でもなく、選択三セル証明構文のoriginal wrapperの個数を数える。具体的に

    N(P92B.original(f))          = 1
N(P92B.refl(route))          = 0
N(P92B.assocNaturality(...)) = 0
N(P92B.symm(w))              = N(w)
N(P92B.trans(u,v))           = N(u) + N(v)
N(P92B.horizontal(u,v))      = N(u) + N(v)
N(P92B.left/rightContext(w)) = N(w)
N(P92B.pre/postcompose(w))   = N(w)

    NativeF55P93AssocFourCell.gk5bbOriginalCount_soundでは元P89からのraw埋め込みを含むP93C全16構成子の保存を真正帰納法で証明。NativeF55P94UnitFourCell.gk5bbOriginalCount_soundではP94A全19構成子の保存を証明し、P94Aが新規に加えたhorizontalUnit・leftContextUnit・rightContextUnitの3ケースまで調べる。以前GK5AMの文脈偶奇はP93Cで保存されても追加P94A contextUnitでは破れるが、この自然数wrapper個数はP94Aでも保存される。

    3. 無条件不存在（構成子別）¶

    真の元F54経路rの元F55恒等3-cellにはN(original(ident(r)))=1、選択側N(refl(r))=0。P94A四セルがNを保存するため、

    ¬ Nonempty (P94A(original(F55.ident(r)), P92B.refl(r)))

    を任意の元F54依存型経路で無条件にLean証明。さらに元F55合成可能な証拠f,gについて、

    N(original(F55.trans(f,g)))      = 1
N(P92B.trans(original(f), original(g))) = 2
¬ Nonempty (P94A(original(F55.trans(f,g)),
                   P92B.trans(original(f),original(g))))

    を証明。これはGK5AZ／GK5BAのidentおよびtrans局所shellが、単に未構成なのではなくこのP94A証明体系の中では不可能であることを示す。

    4. GK5AY／GK5BAの全域seamに関する結論の更新¶

    元F54の実在する経路rを持つ依存型source slotでは、GK5AYの一様なNativeGK5AYOriginalPhiSeam first lastが存在するとbridge(ident(r))を与えて3の不存在に矛盾する。ゆえに¬ Nonempty GK5AYOriginalPhiSeamを無条件に証明。同じ理由で9構成子のstrong NativeGK5BAConstructorShellKitも存在しない。これまでのGK5AY・GK5BAで示した条件付き組立て定理は数学的に正しいが、真正に inhabited な元F54経路文脈ではその前提は成立しないという新しいno-goを証明した。

    これは元P89→P94Aクラス写像の無条件単射性や非単射性を証明するものではない。また、個別に成立する元F55証拠fの直接seamすべてを否定しない。全域seamという統合的条件と、局所高次証拠の存在条件は分離して扱う。

    5. 真正北C60での異なる複合例¶

    元pentagon＋右identity：実在nativeGK5AINorthPentagonWithIdentityのraw全体wrapperから、2個のraw wrapperを持つtrans(original(p),original(ident))への分解shellは不可能。しかし最終的なφ(trans(p,ident))=trans(original(p),refl)のwrapper数は1であり、raw全体wrapperと同じ。したがってこの不変量だけでは直接raw→φ seam不存在を結論できない。

    元pentagon＋その逆：実在nativeGK5BBNorthPentagonReverseCycle := trans(p,symm(p))において、再帰φ側はoriginal(p)とsymm(original(p))の2個のwrapperを持つ。一方raw全体wrapperは1個であり、この個別の直接seamも不存在とLean証明。

    北の全域seam／kit：正真正銘のnorthNativeF45PentagonShortという元F54経路があるため、¬ Nonempty (NativeGK5BAConstructorShellKit (.pentagon .north) Site Site)および¬ Nonempty (NativeGK5AYOriginalPhiSeam northFirst northLast)を無条件に証明。
