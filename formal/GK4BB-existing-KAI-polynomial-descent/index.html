    F112-P94D3GK4BB — 既存 K_AI への真正F54全多項式行列の降下¶

    2026-11-01 JST。canonical main / 定理PR #2845 MERGED。

    1. 中心定理¶

    GK4AVにより、元F54完全依存型経路の整数多項式行列P_r(X) ∈ Mat₂(ℤ[X])は、元F55全9、P92B全9、構造比較seam全14および拡張3構成子で保存され、元P92B存在商Qと独立構造商Sへ別々に降下していた。GK4BAにより旧AH行列一つ、すなわちP_r(4)の一致が多項式行列全体の一致と同値であることもLean4で証明済み。

    既存の第二kernel商K_AIの観測値はO_AI=(O_AE,M_AF,M_AH)であり、その最後の実成分はM_AH=P(4)である。したがって既存観測の等式から、元Qの多項式全体が代表元に依存せず一致する。これを固定mathlibの本当のQuotient.liftで定義した。

    NativeGK4SKernelClasses (nativeGK4AIP92Family p D E) first last
    →  NativeGK4AVValue

    定理nativeGK4BBPolynomialOnAIは、新しい商を導入せず既存K_AIに全多項式族を降下させる。

    2. Lean4で証明した6宣言¶

    正式Leanソース。

    1. nativeGK4BBPolynomialOnAI：元P92Bの真の商同値を保持した明示的Quotient.lift。
    2. nativeGK4BBPolynomialOnAI_class：すべての元Q類の像が元nativeGK4AVP92Valueと厳密に一致。
    3. nativeGK4BBPolynomialOnAI_eval_four：任意z ∈ K_AIで、降下した多項式行列のX=4評価がnativeGK4AIKernelValue zの旧AH成分と一致。
    4. nativeGK4BBPolynomialOnAI_eq_iff_AH：K_AI上の多項式値の一致が、その旧AH成分の一致と同値。これはK_AIのクラスu=vが旧AH一致と同値、という主張ではない。
    5. nativeGK4BBPolynomialOnAI_unique：元Qの全代表元について元多項式値を復元する降下関数は一意。
    6. nativeGK4BBPolynomialOnAI_structural：独立構造商S→既存K_AIの実比較写像と、既存のS側多項式降下との正確な可換三角形。

    この結果は元Q自身の未証明圏公理も、元Type値の新しい3-cellも必要としない。独立構造商S、元Q、既存K_AIを同一視せず、その比較・出典・Type値境界を保持している。

    4. 数学的・authority境界¶

    GK4BAで否定した「旧AH評価が同じなのに多項式が違う」という候補が、ここでは既存K_AIの普遍的な降下可能性へつながった。新しい多項式観測は、既存K_AIが保存する情報以上に元Q/S類を分離できない。これは多項式の全成分・全次数を同時に扱う定理であり、次数上界だけではない。

    一方、K_AIの値には元四成分や別の旧AF行列も含まれるため、多項式降下が忠実である、あるいはK_AIの元クラスが旧AHだけで一意になるとは主張しない。K_AIから元Qや独立Sへの逆向き忠実性、真正14D無条件Countable、固定単一旧類ファイバー無限性、算術slice全域到達、19D filler、global strict、hyperdescentはなお未証明。
