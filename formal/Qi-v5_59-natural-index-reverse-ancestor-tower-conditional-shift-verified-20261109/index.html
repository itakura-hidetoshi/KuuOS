    2. 数学的定義：自然数次数の反転祖先鎖¶

    真正の SelectedContextualEighteen 証拠Mを元16D fiber・真正17D二端点に保持して、selectedAncestorTowerByProof をMそのものに対する構造再帰で構成し、selectedAncestorTowerCount l r n M を定義する。

    C₀(M) = 1                    -- 形式的seed。反転回数ではない
Cₙ₊₁(inherited old18) = 0
Cₙ₊₁(strict J) = 0
Cₙ₊₁(reverse M) = Cₙ₊₁(M) + Cₙ(M)
Cₙ₊₁(chain M L) = Cₙ₊₁(M) + Cₙ₊₁(L)

    二つの元whiskering構成子について、元のType値の内部を消去したり同一視したりせず、証拠Mを構造的にたどる。それぞれが内部のframed／16D文脈を変えうるので、再帰関数の文脈添字を外側に固定しない。C₀の定数性は独立の帰納証明で確定した。

    selectedAncestorTower_preservesOld と selectedAncestorTower_preservesNew は、任意の n : Nat について、それぞれ元selected19の5構成子と独立したv5.50新比較7構成子でCₙが保存されることを形式証明する。新比較 rawReverse では同次数の比較帰納法仮定と、ひとつ低い次数の帰納法仮定を組み合わせる。

    selectedAncestorTowerOnOldQuotient と selectedAncestorTowerOnNewQuotient で各次数を双方の商へ別々に降下し、selectedAncestorTower_factorsOld で元商から新商への射影との因子化を証明する。

    3. 真正N→N証拠対における条件付き昇次数¶

    既存の固定された真正17D端点Nと、その同じfiberに属する実在する18D値A,Bを入力として受け取る。

    L(A,B) = chain (reverse A) B
R(A,B) = chain A (reverse B)

    任意の n : Nat について、

    • Cₙ(A)=Cₙ(B) なら Cₙ₊₁(L)=Cₙ₊₁(R)。
    • Cₙ(A)≠Cₙ(B) なら Cₙ₊₁(L)≠Cₙ₊₁(R)。
    • ∀ k<n, Cₖ(A)=Cₖ(B) なら ∀ k≤n, Cₖ(L)=Cₖ(R)。
    • Cₙ(A)≠Cₙ(B) なら、二点を結ぶ真正 SelectedRawCongruentNineteen 比較の Nonempty は否定される。

    最後の結合結果が selectedAncestorShift_residualGate。局所的な観測一致を商クラス全体の同一性へ無条件に昇格しないための、供給証拠対に条件付けた一般次数の非比較定理である。すべての次数でそのような証拠対が実在する、という命題ではない。
