    Qi v5.98 — 反転を伴う真正1-unit・unit-free文脈における局所共同観測忠実性（Lean4形式認証）¶

    2. 対象を制限した理由と真の元raw証拠¶

    元の真正依存型 SelectedLocalEighteen W l r J N において、v5.97の selectedV597OriginalPrimitiveUnit l r M が成立する元 M : J → N を固定する。すなわち、v5.73の元内部括弧が文字通り oldUnitLeft または oldUnitRight である単独元unit葉に限る。真正unit数は1で、v5.92の完全型付きSigma payloadは元証拠 M 自身を保存する。

    独立に、v5.88のunit-free構文 t : SelectedV588UnitFreeTerm を使用する。これはstrictだけではなく、元reverseと二変数chainを任意の非結合括弧配置で含めることができるが、元unit葉は含まない。v5.88埋め込みは本当の17D添字J→JまたはN→Nを持つ旧18D値を構成する。

    この二要素から、既存の真正元rawコンストラクタで次の2族を構成する：

    Left(t,M)  := reverse (chain (UnitFreeRawEmbed J t) M) : N → J
Right(t,M) := reverse (chain M (UnitFreeRawEmbed N t)) : N → J

    新しい18D証拠型を作らず、原始unit payloadを架空のラベル・代理型へ置換しない。いずれも外側reverseを含む真正の元旧18D証拠であり、unit数は厳密に1である。

    3. Lean4で検証された局所結果¶

    • selectedV598UnitFree_historyNil：任意のv5.88 unit-free構文から得た元旧18D証拠の完全型付き元unit履歴は空リスト。
    • selectedV598ReverseLeft_bracket／selectedV598ReverseRight_bracket：v5.73の元非結合括弧観測は、外側reverse・左右chain配置・unit-free構文全体・元unit葉の内部括弧を保持する。
    • selectedV598ReverseLeft_history／selectedV598ReverseRight_history：左右いずれのunit-free文脈の追加・外側reverseも、原始unit葉Mの完全なv5.92 Sigma unit payload履歴を変更しない。
    • selectedV598ReverseLeft_oneUnit／selectedV598ReverseRight_oneUnit：真正元unit数は左右とも1。
    • selectedV598ReverseLeft_jointEq_iff／selectedV598ReverseRight_jointEq_iff：同じ方向の2値と同じ真正依存型J→Nの原始unit葉M,Lについて、 (Bracket(A)=Bracket(B) ∧ History(A)=History(B)) ↔ (t=u ∧ M=L)。
    • selectedV598ReverseLeft_rawEq_iff／selectedV598ReverseRight_rawEq_iff：同じ限定族では元の真正raw証拠値そのものの等号が(t=u ∧ M=L)と同値。元19D商クラスの等号に言い換えていない。
    • selectedV598Mixed_bracketNe／selectedV598Mixed_rawNe：単独unit葉とunit-free文脈を左右で逆配置すれば、元括弧・元raw値は一致しない。
    • selectedV598Mixed_historyEq_iff_sourceEq／selectedV598Mixed_samePrimitive_historyGap：左右の配置を変えても完全型付き履歴はunit葉の元sourceを復元するが、配置そのものを同一化しない。

    この結果はv5.94の線形strict前置／後置から、入れ子reverseと非結合chainを持つunit-free文脈＋単独unit葉＋外側reverseへ拡張する。すべての一般的な1-unit元旧18D証拠を覆うものではない。

    5. 残余障害（NO_DATA）と次段の境界¶

    • v5.93の真正同一J→Nfiber・unit数1・同じv5.73元内部括弧・異なる元raw証拠の存在／不可能性は依然 NO_DATA。
    • このv5.98定理が示すのは、原始unit葉の値をSigma履歴に保存した、制限された2種の反転文脈での局所復元である。すべての1-unit旧18D内部の非自明なreverse/chain再帰の網羅的な復元は未認証。
    • 旧5／新7の元19D比較関係全域の同値、異fiber間の証拠同一化やgluing、WORLD／20D大域降下、AIの行為権限はここからは導けない。局所faithfulnessを無条件に大域化しない。
    • 次のQi v5.99候補は、真正1-unit元証拠の任意のchain枝に生じる中間17D添字と一つの元unit payloadを保ちつつ、局所復元のために追加すべき添字／再帰位置情報を特定し、復元不能箇所を独立obstructionとして残すことである。
