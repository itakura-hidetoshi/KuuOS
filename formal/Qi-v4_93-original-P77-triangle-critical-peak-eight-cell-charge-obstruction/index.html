    1. 対象：v4.92の限定的LocalCriticalPeakの外側¶

    v4.89のSevenRewrite(c,d) : Typeは13種類の明示的な新七セル書換えを保持する。v4.91の独立したEightCell(H₁,H₂) : Typeには22生成規則があり、v4.92ではzigzagと独立書換えの交換を起点とした局所critical peak族の合流を証明した。

    その族だけでは、六セルの単位則と結合則が重なった二つの七セル履歴の比較可能性は証明されない。Qi v4.93では数学的に重要な一段強い主張、すなわち元の八セル22生成規則からは実際に導出不能であることを整数値で形式証明した。

    2. 七セル生構文上の整数不変量¶

    sevenTriangleCharge : SevenRewrite(c,d) → ℤを六セル次数商とは別に、七セル構文の構造再帰で定義する。

    [ \begin{aligned} Q(\mathrm{refl}) &= 0, & Q(\mathrm{symm}\,H) &= -Q(H),\ Q(\mathrm{trans}(H,K)) &= Q(H)+Q(K),& Q(\mathrm{congrComp}(H,K)) &=Q(H)+Q(K),\ Q(\mathrm{congrInv}(H)) &=Q(H),& Q(\mathrm{assoc}) &=1,\ Q(\mathrm{inverseRight}) &=1, \end{aligned} ]

    他の元七セル局所規則（単位、左逆元消去、二重反転、恒等逆、合成逆）に対する値は0とする。このQは元のGK5CGの五セル値、六セルdegree、あるいは新高次商そのものではない。

    eightCell_preservesTriangleChargeは、v4.91の元八セル22構成子すべてへの構造帰納により

    [ \boxed{ E:\mathrm{EightCell}(H_1,H_2) \;\Longrightarrow\; Q(H_1)=Q(H_2) } ]

    を形式証明する。特に元zigzagダイヤモンドの両経路でQ=1となり、元の比較生成元は矛盾しない。

    3. 二つの真正な三角形critical peak¶

    左側：六セル生語((refl w ; c) ; d)から(c;d)への二つの実七セル証明書を定義する。

    • sevenLeftTriangleDirect c d := congrComp (leftUnit c) (refl d)：内側の単位を先に消去。
    • sevenLeftTriangleViaAssoc c d := trans (assoc (refl w) c d) (leftUnit (trans c d))：結合変換を先に適用し、外側単位を消去。

    右側：((c;d);refl z)から(c;d)への二つの証明書。

    • sevenRightTriangleDirect c d := rightUnit (trans c d)。
    • sevenRightTriangleViaAssoc c d := trans (assoc c d (refl z)) (congrComp (refl c) (rightUnit d))。

    sevenLeftTriangle_chargeGapとsevenRightTriangle_chargeGapがどちらも

    [ \boxed{Q(H_{\mathrm{direct}})=0,\qquad Q(H_{\mathrm{viaAssoc}})=1} ]

    を証明。既証明の八セル不変性と合わせ、

    [ \boxed{ \neg\operatorname{Nonempty} \bigl(\mathrm{EightCell}{\mathrm{old}} (H{\mathrm{direct}},H_{\mathrm{viaAssoc}})\bigr) } ]

    を、左・右それぞれsevenLeftTriangle_noOldEightCell／sevenRightTriangle_noOldEightCellで形式証明した。既存22生成規則の範囲における真のobstructionであって、単なる推測や検索不能の主張ではない。

    4. sourceを保つ独立した八セル拡張¶

    元のEightCell型は変更せず、別のType値presentationTriangleEightCellを新設した。元八セルの証拠を.originalで保ち、追加した原始整合性生成元は左・右の三角形二種類のみ。他は反転・連鎖・whiskering・逆／合成文脈への型付き閉包である。

    triangleEightCell_leftNewNotOld／triangleEightCell_rightNewNotOldは、新しい局所証拠が存在する一方、元八セルの同じ比較Typeは空であることを同時に示す。triangleEightCell_noOldInterpreterは、すべての新比較を元八セルへ戻す関数の存在を¬ Nonempty (∀..., TriangleEightCell → EightCell)という正しいLean4の命題で否定する。

    重要：これは元sourceの定理や構文を保った別presentationへの追加であり、八セル比較関係そのものについて「変更前と同値」という意味ではない。

    5. 限定的critical peak族の拡張と構成的な合流¶

    TriangleCriticalPeakは、v4.92LocalCriticalPeak、左三角形、右三角形を原始ピークとし、指定された型付き文脈・連鎖でのみ閉じた9構成子の新帰納Typeである。

    triangleCriticalPeak_fillは全構成子に対して構造帰納を行い、各ピークPから実際の新八セル証拠を構成する。

    [ \boxed{ P:\mathrm{TriangleCriticalPeak}(H_1,H_2) \longmapsto \mathrm{TriangleEightCell}(H_1,H_2) } ]

    triangleCriticalPeak_joinableはそのNonempty版。任意の七セル履歴同士が比較可能とする生成元は導入していない。

    6. 新旧八セル履歴商の関係¶

    新しいTriangleEightCellによる比較存在をSetoidとして構成し、別のtriangleHistoryClass商を導入。

    triangleHistoryClass_eq_iffは

    [ [H_1]{\triangle}=[H_2]{\triangle} \quad\Longleftrightarrow\quad \operatorname{Nonempty}(\mathrm{TriangleEightCell}(H_1,H_2)) ]

    を形式証明する。oldHistoryClass_descendsToTriangleは、旧八セル履歴商での一致が新商でも保存されることを証明。

    さらにtriangleHistoryClass_strictlyNewは上記三角形の二経路について

    [ \boxed{ [H_{\rm direct}]{\triangle}= [H{\rm viaAssoc}]{\triangle} \quad\land\quad [H{\rm direct}]{8}\ne [H{\rm viaAssoc}]_{8} } ]

    を証明。新商が旧八セル履歴商より真に粗いことを、元八セルの不変量から定量的に裏付けた。

    7. 元P77・GK5CGへの適用と厳密戻り障害¶

    pentagonActualTriangle_newVsOldWithSourceObstructionは、任意の真正P77最終raw添字iにおける、元GK5CGの保守的五セル値二端点に対応する本来の六セル生成元cとその反転を使う。

    同じ元source添字で、新拡張三角形比較は存在し、元22規則八セル比較は存在しない。また元のPentagonAdjoinedSixCellEqualityInterpreter不存在も同時に証明する。

    元F55/P77/GK5CGの五／六／七／八セルsource構成子を変更・追加していない。新七セル生構文の厳密Eq、旧sourceの厳密Eq、旧八セル証明、新拡張Type、二段階の履歴商は常に別々に保持する。

    8. Lean4修正履歴と公理監査¶

    初回exact-source CI #42212768586のStrict Leanは、数学的証明ではなくLean4の型／構文の2点で失敗した。

    • TriangleEightCell → EightCellはType値であり、その関数全体のPi型に命題否定¬を直接適用できない。正しい形¬ Nonempty (∀ ..., TriangleEightCell → EightCell)へ修正。
    • namespace終端直前の宣言未接続docstring /-- ... -/を通常コメント /- ... -/に変更。

    修正後のHEAD bacc45cc...で 全10,292 Leanジョブ SUCCESS。22宣言の#print axiomsは標準公理propext、Classical.choice、Quot.soundに限定、sorryAxなし。変更Lean warning/error0/0。

    9. 次候補Qi v4.94¶

    • 七セルの逆元消去・反転・結合則が重なる追加critical triangle／squareについて、旧Q不変量の障害判定と、新TriangleEightCellの局所整合性を検討。
    • 新拡張の文脈合成の自然性と、元のLocalCriticalPeakからの証拠経路が複数ある場合のさらなる高次obstructionを区別。
