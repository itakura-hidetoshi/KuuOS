    2. 元selected 19D比較が保存する新しい不変量¶

    v5.37の独立SelectedContextualEighteenはinherited、whiskerLeft、whiskerRight、strict、reverse、chainの6構成子を持つ。既存SelectedLocalNineteenの5生成元はstrict、元18D inheritedへのunitPrepend／unitAppend、比較のreverse／chainに限られる。

    新しいselectedContextEighteenActiveChainCountは、raw18D構文のchainで左右の外側七セル順序履歴の連結が空でないときだけ1を追加する自然数不変量である。旧inheritedとstrictは空の外側履歴を持つため、従来の19D単位貼合せの2生成元ではこの数が変わらない。selectedLocalNineteen_preservesActiveChainCountは5生成元すべてで保存することをLean4で証明。

    selectedNineteenActiveChainOnQuotientは、この証明を使って真正同一fiberの19D証拠商にQuotient.liftで値を降下させる。既存の完全順序List Bool traceとは別の独立した商上観測であり、raw先頭constructor tagを大域化しない。

    3. 同一完全fine履歴でも19D商で異なる真正証拠¶

    真正元18D証拠Mから、既存v5.38の正しいLR二重文脈輸送 X = selectedEighteenLeftAfterRight(M) を取る。Xの外側履歴は false :: true :: Trace(M) なので長さが2以上。

    同じ厳密な17D始終点の依存fiber内で、新しい生18D値 Y = chain (strict source) X を構成する（selectedMixedLeftStrictPrepend）。新しい19D unit比較生成元は追加しない。

    selectedMixedLeftStrictPrepend_traceは Trace(Y) = Trace(X) を完全な順序付きリスト等式として証明する。一方selectedMixedLeftStrictPrepend_activeChainCountはXの外側履歴が非空なら Active(Y) = Active(X) + 1 と証明する。真正19D比較はActiveを保存するため、selectedMixedLeftStrictPrepend_classDistinctは同一fiberで [X]₁₉ ≠ [Y]₁₉ を証明し、selectedMixedLeftStrictPrepend_noLocalは両者間の真正SelectedLocalNineteen Type値比較の非存在まで示す。

    ここでは完全fine trace一致は19D商の証拠一致を意味しない。同じ履歴長どころか履歴リスト全体が一致しても、局所19D比較が存在するとは限らない。この反例は元のselected presentationに相対的であり、別のpresentationでの比較まで否定するものではない。

    4. v5.41の非定数transportのkernel完全分類¶

    v5.41の実構成されたselectedMixedLengthBoundary Mはsourceの完全traceの長さのみを符号化し、真正RL証拠列selectedMixedRightTracePowerに送る。selectedMixedLengthRawTransport_eq_of_lengthは同じsource履歴長なら像のraw18D証拠値が一致することを示す。

    v5.41で証明済みの長さ反映と組み合わせ、selectedMixedLengthDescend_eq_iff_traceLengthは実際の異なる19D商型間で、任意のq₁,q₂に対して次の必要十分条件を証明する。

    descend_length(q₁) = descend_length(q₂)
    ↔ length(Trace(q₁)) = length(Trace(q₂))

    したがって同じ完全履歴を持ちつつ元19D商で異なる前節の[X]と[Y]は、像で一致する（selectedMixedLengthDescend_collapsesStrictPrepend）。これによりselectedMixedLengthDescend_notInjectiveは、v5.41の具体的な非定数商輸送の非単射性をLean4で証明する。

    selectedMixedLengthBoundary_noReflectionおよびselectedMixedFaithful_notLengthBoundaryは、この具体的境界では全source19D Type値比較を反映できず、v5.40の強いSelectedMixedNineteenFaithfulBoundary.reflectLocalを付けられないことを形式証明する。

    5. 権威境界・次段¶

    認証済み： 第2の真正19D商上観測ActiveChain、同一fine履歴・異なる19D商クラスの具体的構成、v5.41境界のkernel iff長さ、非定数かつ非単射の具体的実例、その境界に対する比較反映不可能性。

    未認証／NO_DATA： すべての境界transportの非忠実性。とりわけ長さとActiveChainの両方を保つ別のtransportが元のすべてのType値19D比較を反映するかは未構成。全域swap自然性、真正異fiber20D高次交換、元証拠の生Eqも未認証。今回の一つの写像に対する非単射を一般の不可能性へ昇格させない。
