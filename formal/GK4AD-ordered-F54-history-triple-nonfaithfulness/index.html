    1. 真正原F54履歴に対する非可換観測¶

    GK4ADOrderedHistoryInvariant Leanは、元F54の実RotationEdge.forward、RotationEdge.backwardと二NatcastDepthsを保持した上で、整数値順序momentを追加する。

    値域 NativeGK4ADValue := (Int × Nat) × Int を、((charge,backwardCount),orderedMoment)として解釈し、演算

    (c,b,m) ⋄ (d,e,n) = (c+d, b+e, m+n+c*e)
unit = (0,0,0)
cast = (1,0,0)
forward = (-1,0,0)
backward = (-1,1,0)

    を定める。この演算は結合的・単位的だが非可換。cast ⋄ forward = unit は真正F54原assocが「1 cast、1 forward」を含むことに正確に対応する。真正RotationChainは途中の全原F45木・原Type値回転方向を保持し、元DepthRotationRouteのchain、cast、trans、leftContext、rightContextをすべて直接帰納的に観測する。

    真正比較証拠の全構成子を個別検証：

    • 元F55全9構成子（3対2 pentagon、2対2 disjointSquare、symm/trans、左右文脈、pre/postcompositionを含む）。
    • 元P92B全9構成子（真正associator-naturalityを含む）。非可換なu,v,wの並びを入れ替えず、同じ順序の結合律と原assoc値unitでsoundnessを導く。
    • 元F54構造seam全14構成子と拡張構造比較全3構成子。

    従ってこの新しい順序付き観測は、元P92B証拠存在商Qと独立構造比較商Sに別々にQuotient.liftで降下。元Q→S正準射との可換性、実構造商合成の非可換積保存、構造単位を形式化。元Type値3-cellは観測値一致から生成しない。

    2. 同じ三成分観測だが異なる実構造商類を構成¶

    GK4ADTripleNonfaithfulness Leanは、実際に証言された元F54 rot : LocalRotation p before afterから真正前進・逆向き物理backtrackB : DepthRotationRoute before beforeを使用。実C := castDepths rfl rfl beforeも同じ元F54 self-endpointを持つ。

    u = trans C B
v = trans B C

    この2本は元F54の実Type値証拠履歴として完全に型付き、かつ実三成分観測が厳密に一致する。

    O_AA([u]_S) = O_AA([v]_S) = ((false,-1),1)
orderedValue(u) = ((-1,1), 0)
orderedValue(v) = ((-1,1),-1)

    順序付き不変量orderedMomentが元P92B全比較および構造seam全比較を通じて保存されるため、元Qと独立構造商Sの双方で実際に[u]≠[v]と証明。しかしGK4AAの真のS→K_AA比較はO_AAの値が同じであることと像の同値が必要十分なので、

    [u]_S ≠ [v]_S
F_AA([u]_S) = F_AA([v]_S)

    よってS→K_AAは実F54局所回転を持つ任意の型付き自己Homで非単射・非忠実。本当のC60北側六角形northHexagonNativeLeftRotationにも無条件で適用する。

    3. GK4ACとの差異と権限境界¶

    GK4ACで得たNat ≃ Fiber(K_AA→K_X,[R_0]_{K_X})は異なる二つの第二商を比較する完全ファイバー同値。一方GK4ADは独立構造商Sから三成分第二商K_AAへの比較の非忠実性を新しく確定する。両者は矛盾しない。Q・S・K_AA・K_Xを混同せず、歴史的元F19/F28/F54との無条件完全同値は主張しない。

    元P92B商Qの結合律・左右単位、歴史的完全型付き同値、真正14D無条件Countable、19D filler、global strict n、hyperdescentは依然未証明。strict空中心、独立Kuuは一presentation、Gray非再導入、append-only／tighten-only／same-root／overwrite-forbiddenを維持。
