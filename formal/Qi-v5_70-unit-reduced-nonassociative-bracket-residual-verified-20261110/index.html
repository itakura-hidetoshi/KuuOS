    Qi v5.70 — 全二重無限観測＋順序付き反転ランでも残る非結合的括弧構造の障害（形式証明・公理監査）¶

    新しい証明済みの非結合的単位簡約括弧構造¶

    真正17D端点Nの同一N→N dependent fiberで、本来のSelectedContextualEighteenのstrict、reverse、chainだけを用いて、

    R := reverse (strict N)
A := chain (chain R R) R
B := chain R (chain R R)

    を構成した。両方とも真正元18D Type値であり、別の観測用proxyの構文木に置き換えて元の証拠を消したものではない。

    元証拠から独立して読むSelectedRawUnitReducedBracketはunit、単項reversed、二項joinedの自由な非結合構文である。selectedContextEighteenUnitReducedBracketは元18D上の構造再帰で、strict／inheritedをunitへ、whiskerを内側の値へ、raw reverseをreversedへ、raw chainを単位簡約付き二項joinedへ写す。単位は消去するが結合則を付け足さないため、

    bracket(A) = joined (joined (rev unit) (rev unit)) (rev unit)
bracket(B) = joined (rev unit) (joined (rev unit) (rev unit))
bracket(A) ≠ bracket(B)

    が元証拠の異なる括弧構造を識別する。

    この新しい観測の保存性を旧SelectedLocalNineteenの5構成子すべて、新SelectedRawCongruentNineteenの7構成子すべてに対して構造帰納法で証明した。旧unitPrepend/unitAppendで元inheritedとstrictの単位簡約が合い、新rawReverseとrawChainRight/rawChainLeftで実際の帰納仮定と構文木関数の互換性が成立する。独立する旧商・新商のそれぞれへQuotient.liftで降下し、既存の旧→新projectionを通じて因子化することも証明済み。元18D Type値、旧19D比較、新7構成子19D比較のいずれも変更していない。

    すべての既存観測が一致する真正証拠対¶

    AとBは、raw合成の括弧構造だけが異なり、元Type値上で以下を機械的に証明した。

    ∀ n : Nat, AncestorTower_n(A) = AncestorTower_n(B)
∀ n : Nat, ConsecutiveRunCount_n(A) = ConsecutiveRunCount_n(B)
OrderedRunList(A) = OrderedRunList(B) = [1,1,1]
Trace(A) = Trace(B)
TopReverseFlag(A) = TopReverseFlag(B)
AdjacentReverseCount(A) = AdjacentReverseCount(B)
NineObservation(A) = NineObservation(B)

    祖先塔・全連続反転計数の等式に使うのは、元raw chainにおける数値計算のNat.add_assocであって、元18Dのraw chain自体を結合的と仮定する証明ではない。反転ランの順序付きリストも完全に一致する。別に構成した単位簡約括弧不変量が異なるため、新7構成子商の二つのクラスは異なり、真正新19D Type値比較も存在しない。

    正確な同一fiberへの輸送と完全観測の非単射性¶

    元18Dの実在するM : SelectedContextualEighteen W l r J Nが与えられた場合に限って、chain M A・chain M Bを同じJ→N exact dependent fiberへ構成する。既存の全祖先塔、全run-count塔、ordered-run list、九観測は一致したままである。一方で、新しい構文木上は、共通するbracket(M)との単位簡約付き二項joinedを経ても、右側の異なる括弧構造が残ることを証明した。従って真正新商の各クラスも不一致。

    結合観測を

    Obs_(double∞+ordered)(q)
 = (NineFullTower(q), AllConsecutiveRunCountTower(q), OrderedRunList(q))

    として実際の新商上に定義し、供給されたMのある同一fiberで非単射、新たな括弧不変量の全域decoder不存在、および全商クラスdecoder不存在を証明した。任意に指定されたJ→Jには真正strict Jがあるので、その実在する証拠を使用したendomorphism版も得た。異端点fiberの勝手な非空仮定は導入していない。

    次段Qi v5.71（未認証）¶

    新しい括弧形まで加えた観測の単射性を断定しない。次段では、単位簡約の仕方自体が失う原証拠の情報、あるいは異なる元Type値から同一括弧形への真のfiber、旧新商への保存条件を具体的に調べる。今回のA/Bは新括弧形で区別されるので、そのまま次段の反例にはならない。
