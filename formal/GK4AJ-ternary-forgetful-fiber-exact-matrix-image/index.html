    1. 元F54真正依存型sourceからの三類ファイバー¶

    元F54三経路・相異・忘却値のLeanソースは、実際のrot:KuuNativeF45Tree.LocalRotation p before afterから、同じ元F45型付き自己Homに属する物理backtrackBと、元のdouble-Nat castDepths自己経路Cを使う。

    w0 = C ; B^12 ; C
w1 = B^3 ; C ; B^6 ; C ; B^3
w2 = B^6 ; C^2 ; B^6

    これらは任意の記号文字列ではなく、全て元F54のDepthRotationRoute.trans、元nativeGK4FBacktrack rotと元nativeGK4WCastRoute beforeから構成した真正依存型source経路。元F55・P92BのType値比較やF54の独立構造seamを数値観測から作成しない。

    真正四成分値と最初のGK4AF行列値（前段の積観測全体）は、3経路すべてで厳密に一致する：

    O_AE(w0) = O_AE(w1) = O_AE(w2) = (false, -22, 12, -132)
M_AF(w0) = M_AF(w1) = M_AF(w2) = [[1,2],[0,1]]

    旧行列で元物理backtrackの像B1がB1^3=-I、B1^6=Iとなる、表現由来の追加関係がこの等値ファイバーを生む。しかし元Sでこの3経路を同一視するType値証拠が存在するとは推論しない。

    一方、GK4AHから継承した独立の真正Type値保存行列M_AHは

    M_AH(w0) = [[ -23, -34], [ -48,  -71]]
M_AH(w1) = [[1561, 638], [-2640,-1079]]
M_AH(w2) = [[-599,-274], [1104,  505]]

    と評価され、特に各左上成分 -23、1561、-599 は相異なる。真正第二kernel商K_AIは積観測 O_AI=(O_AE,M_AF,M_AH) の値一致を元Qに課した商なので、三類[w0]_{K_AI}・[w1]_{K_AI}・[w2]_{K_AI}はpairwise unequal。他方、真正忘却U_{AI,AG}:K_AI→K_AGでは旧積観測が一致するため全3類が同じ旧K_AG値へ写る。

    したがって、元LocalRotationを持つ任意の真正自己Homで、ひとつの実K_AGファイバーに少なくとも3個の相異なるK_AI類が存在。元C60北側六角形northHexagonNativeLeftRotationについても独立に特殊化しLean4で証明。

    2. 一般の元F45型付きHomにおける正確なファイバー分類¶

    任意の旧ファイバー上の第二行列像同値Leanでは、任意の元F45の同じ型付きsource/targetに属するx,y:K_AIについて

    x = y  iff
  (U_AI,AG(x) = U_AI,AG(y) AND M_AH(x) = M_AH(y))

    をLean4で証明。これは前段K_AIの第二等値kernel定義と、K_AI→到達可能三重積観測値圏が各Homで単射という確定結果から導いたもので、元S→K_AI全域忠実性の仮定は不要。

    固定された実際に到達可能な旧K_AG類qについて

    Fiber(q) := {x : K_AI | U_AI,AG(x)=q}
SecondMatrix_q : Fiber(q) → IntegerMatrix2x2

    を元の依存型Homごとに構成。SecondMatrix_qが単射であることを証明し、さらに

    Fiber(q) ≃ {m : IntegerMatrix2x2 | ∃ x : Fiber(q), SecondMatrix_q(x)=m}

    という真正なLean Equiv.ofBijectiveを証明。値域は全整数行列ではなく、そのファイバー内で元F54経路から到達した第二行列値の集合である。三類実例はこの単射の正確な実観測証拠となる。

    3. CI／Lean elaboration修正履歴¶

    初回workflow #41186504054は、Leanインストール時にrelease.lean-lang.orgのDNS解決に失敗。GitHub MCPからfailed jobsを同じsource HEADのまま再実行したところツールチェーン導入が成功し、初めてLeanソースへ到達した。そこで真正三経路の旧観測一致・第二行列値計算は成功した一方、3組の類相異証明のrwにおいて、congrArg (fun z => ...)が未展開で、既存nativeGK4AJClassN_matrix補題のパターンと一致しない構文的elaboration failureが3件発生。さらに存在定理で元rotを宣言の型に書かずproof本体のみで使ったため、section変数の自動generalizationに含まれずunknown identifierとなった。

    最終修正では、3件の相異証明にchange (nativeGK4AIKernelValue ...).2 = ... at hmを先行させ、その後に既証のnativeGK4AJClassN_matrixでrw。存在定理には本物の(rot : KuuNativeF45Tree.LocalRotation p before after)を明示。数学的仮定を弱めず、全新規Leanファイル・imports・元F54構成子・元P92B/Q/S dependent signaturesを確認した。

    4. 研究境界・次のGK4AK（未証明）¶

    今回証明したのは旧K_AGの一つの真正ファイバーに少なくとも三類のK_AIが存在すること、および各ファイバーの第二行列到達像による正確な分類。S→K_AIの全域忠実性・非忠実性は今回未決着。これらを混同せず、GK4AKでは例えば旧行列の周期から生成される大きな有限ファイバーのパラメータ族、または元F54の二行列を超えて区別されない本物のS類の探索を行う。
