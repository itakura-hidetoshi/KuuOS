    2. 独立GK5BY — 任意の真正整数係数多項式のCRT自然性¶

    前段GK5BWは任意有限被覆s・任意自然数法m_iに対し、L_s=Finset.lcm s mとして、大域ZMod L_sとgcd重なりで互換な局所剰余族の真正Subring、R_sの間に環同型Φ_s:ZMod L_s ≃+* R_sを構成。GK5BXでは包含u⊆t⊆sに関する大域制限q_st・局所制限ρ_stの恒等／合成、Φの自然性・逆自然性・三段塔をLean4で証明済み。

    GK5BYでは任意の真正P:Polynomial Intに拡張し、各大域・局所環でPolynomial.eval₂RingHom (Int.castRingHom _) xを構成した。これにより各xについてP↦P(x)は真正なRingHomであり、加法・乗法を保存する。固定mathlibの実定理Polynomial.ringHom_eval₂_intCastRingHomにより、任意の有限被覆制限とCRT環同型についてRingHom同士の等式：

    q_st(P(x)) = P(q_st(x))
ρ_st(P(a)) = P(ρ_st(a))
Φ_s(P(x)) = P(Φ_s(x))

    を形式証明した。さらにu⊆t⊆sの二段制限を直接制限と比較し、大域・局所の各多項式評価塔およびCRT環同型全体の三段可換性を証明した。

    元の任意の符号付き整数z:Intを先にPolynomial Intで評価してからZMod L_sへ移した結果と、ZMod L_s内でPを評価する結果は文字どおり等しい。法0ZMod 0=ℤ・空被覆・非coprime・負係数を含み、次数上界・L_s|d!・支配的局所法などの仮定は不要。

    CI修正記録¶

    最初のCIは最後の三段自然性のrw方向だけが逆で、書換え対象Φ_t(q_st x)が目標内に見つからないLean4 elaboration失敗だった。既存GK5BXの自然性Φ_t(q_st x)=ρ_st(Φ_s x)を逆向きに適用するrw [← ...]へ最小修正した。全358行の新規Leanソース、依存定義、固定mathlibの該当APIを照合し、数学的命題・前提条件・結論を変更せず最終CIで13定理全部sorryAxなし。

    3. Qi v4.43 — 真正北C60の元符号付き整数numeratorでの多項式自然性¶

    Qi v4.43は元GK5BQの同一の真正符号付き整数分子nativeGK5BQClearedNumerator d j values : Intを保持し、任意の別の整数係数多項式Q:Int[X]をその元整数に評価する。得られた真正整数Q.eval NのZMod L_s合同類は、大域CRT上での多項式評価と一致し、GK5BW環同型を通した元compatible局所剰余族全体にも一致する。

    元整数多項式Q,Rに関する加法・乗法の保存、大域・局所への任意部分被覆制限、一段と二段の制限で同じ数値を再現する等式をLean4形式化した。対象となる元分子はnatAbs表示で作り直さない。法0・空被覆を含む。

    真正元F55の異なる二つのType証拠、primitive P=1 と double inverse＋元F55右単位 P=X² の既存P92B整数深度多項式値を同じ外側のQによる算術塔へ投入した。二つの元Type証拠はいずれも数値的な三段CRT自然性を満たし、既存の明示的2≤d・L_s|d!の下で最小被覆の数値的CRT零証明書も維持する。一方、元original→phiの構造的seamはprimitiveで存在、double inverseで不存在。この境界は同一の型付きLean定理fivefoldGK5BYNorthBothOuterPolynomialTowerButOppositeSeamsとして保持した。

    本成果は、数値的多項式の評価・演算・自然性から元F55 Type source、P77商類等号、P94A四セル、全GK5AY seam、P89無条件反射、W=1→seamを推論しない。元F54二Nat・二圏・Blocks、元F55 Type歴史、真正第五Dart北C60物理gauge、条件付きP89反射は別authorityとして保持する。
