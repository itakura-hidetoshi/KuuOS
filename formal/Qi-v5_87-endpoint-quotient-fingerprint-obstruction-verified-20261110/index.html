    2．元Typeを失わない総空間と観測の定義¶

    同じ16D親文脈における真正17D端点Typeを Seventeen(H,K) とする。新しい総空間は元の型に基づく

    Σ J : Seventeen(H,K), Σ N : Seventeen(H,K), SelectedLocalEighteen W l r J N

    である。このSigmaは元raw17D端点J,Nを証拠値とともに保持し、単一の固定されたJ→N fiberではない。

    独立観測 selectedV587TotalInnerBracket は実際の旧18D証拠の内部括弧構文を読む。複合観測 selectedV587TotalJoint は

    (selectedEighteenClass l r J, selectedLocalEighteenInnerBracket l r M)

    と定義した。第一成分は元17D端点の真正 selected18D quotient classであり、元旧・新19D商とは別物である。第二成分はv5.73で認証済みの独立raw括弧観測。これを元の依存型証拠と同一視しない。

    3．総空間における具体的衝突と正確な識別条件¶

    任意の真正17D端点Jについて、strict J : SelectedLocalEighteen W l r J Jを実際の元証拠値として総空間に埋め込む。その埋込はraw端点を保持するため単射である。全Jについて innerBracket(strict J)=oldStrict。

    strict-loop像上では、joint観測等号と元17D quotient class等号が同値であることを独立定理で示した。従って、その像上のjoint観測単射性と、元17D quotient射影の単射性が同値。

    v5.35の実際に供給されたbefore : SevenRewrite、F,G : ContextFrameEleven、C : SelectedContextualThirteen、after : SevenRewrite について、

    J = selectedSeventeenUnitPrependLeft ... と N = selectedSeventeenUnitAppendLeft ...

    は元17D raw Type値としてJ≠N。一方、v5.36の元SelectedLocalEighteen.unitLeft比較により本来の17D商で[J]18=[N]18。その結果、二つの真正strict J : J→Jとstrict N : N→Nは総空間において異なる元証拠値だが、共にoldStrictを観測し、元17D商クラスも同じ。従ってjoint観測の総空間上での非単射と、普遍的なraw総空間復元decoderの不存在を形式証明。

    同じ主張を元のunitRight生成元からも独立して証明した。左右とも元の真正17D／旧18D証拠、元selected18商を使い、代理Typeの同一視ではない。

    4．認証の範囲・obstructionを消さない¶

    上の二つのstrict loopは異なる元17D端点 fiber J→J と N→N に属している。元のJ≠Nは明示的に保たれている。商クラス[J]18=[N]18は型付き証拠のraw端点の等号を与えない。これを口実に、二つの元旧18D証拠を同じfiberへcastして比較していない。

    したがって、Qi v5.86で条件とした「同一raw17D fiber上のM≠LかつinnerBracket(M)=innerBracket(L)」を無条件に構成したという主張はしていない。元旧5／新7 selected19 Type値比較も、異なるraw端点の間では直接形成しない。任意のbefore,F,G,C,afterの居住性や接続証拠を無条件に仮定しない。総空間での局所観測衝突を、fixed-fiberでの大域的結論に昇格しない。
