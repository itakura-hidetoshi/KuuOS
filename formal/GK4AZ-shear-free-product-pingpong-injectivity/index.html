GK4AZ defines: - Two independently defined monoid/group homomorphisms Multiplicative ℤ →* Equiv.Perm (ℤ×ℤ): nativeGK4AZUpperHom, nativeGK4AZLowerHom. - Boolean-labeled factors nativeGK4AZFactors and two disjoint nonempty strict cones nativeGK4AZCones. - A finite 3-element injection into Multiplicative ℤ establishing the nontrivial-size hypothesis of mathlib ping-pong. - The full pointwise cross-cone condition for every nontrivial element of either cyclic factor: nativeGK4AZPingPong.

    Syntax and elaboration lessons (not assumptions)¶

    The first exact-source CI failed, revealing five actual Lean elaboration issues: - ext z decomposed product-coordinate extensionality too early; repaired with apply Equiv.ext; intro z, then definally matching the full permutation equality. - on syntax requires open scoped Function with autoImplicit false. - Pointwise action of a group on Set requires open scoped Pointwise; HSMul is not available otherwise. - Cardinal #(Multiplicative Int) uses open Cardinal and Cardinal.mk_le_of_injective. - Inverse action rewrites must be specialized after Bool case analysis to the actual upper/lower group hom, not kept as an abstract conditional Factors expression.

    The final source uses the unchanged mathematical assumptions, preserves the complete original file and includes every declaration in #print axioms; no sorry or admit.
