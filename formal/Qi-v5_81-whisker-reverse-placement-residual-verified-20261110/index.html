    Qi v5.81 — 真正whiskering／raw反転の配置履歴障害（Lean4形式証明・実公理監査）¶

    2026年11月10日 JST。対象は元の真正contextual18D依存Type証拠、元selected19の5構成子と別Typeで与えた新raw-congruent selected19の7構成子、実際に供給された同一端点fiberの元Type値・真正商である。「空」「縁起」との対応は命名・解釈層にとどまり、証明された等式や商の普遍的意味であるとは主張しない。

    2．初期証拠対の失敗を保存したobstruction¶

    元の外側7D whiskering列List Boolは、whiskeringの左／右と出現順を記録する。ただしこの列の一致は、v5.80完全観測の一致を意味しない。

    真正のN→Nを一つ供給し、S = strict Nとすると、当初検討した - U = whiskerLeft before F G (reverse S) - V = reverse (whiskerLeft before F G S)

    は同じwhiskered N'→N' fiberでも、すでに認証済みのTopReverseFlagがそれぞれ0と1である。同様に右whiskeringについても0対1で区別される。したがって、これらを「v5.80完全観測が等しい反例」と呼ぶことはできない。

    初回CI #42757546906では完全観測の等式をrflで処理しようとして失敗した。次の #42758221615、#42758832191で積型分解とfunextを進めた結果、残る第九観測座標のTopReverseFlagの不一致が明示された。これは単純なLean4構文エラーではなく、元証拠対に対する数学的障害である。

    selectedWhiskerLeft_unmaskedTopFlagObstructionとselectedWhiskerRight_unmaskedTopFlagObstructionを新たに形式化し、旧観測の不一致を隠さず保存した。既存TopReverseFlagの定義・商降下・旧新比較の生成元を変更せずに修正した。

    3．真正の同一fiberで成立するstrict-prefix証拠対¶

    真に与えられたSevenRewrite before、対応するContextFrameEleven F,G、元17D端点Nに対してN' = whiskerLeft before F G N、S' = strict N'と置く。元の依存Type18D構成子だけで真正N'→N'証拠 

    A = chain S' (whiskerLeft before F G (reverse (strict N)))
B = chain S' (reverse (whiskerLeft before F G (strict N)))
    を作る。右の場合も、真に供給されたafterとN' = whiskerRight F G N afterに対し、同じstrict N'を両者の外側左子として置く。

    共通strict-prefixにより両者の最上位は真正raw chainとなり、以前の0対1のTopReverseFlag障害は同一値0に揃う。旧19D比較の適用範囲を拡張するのではなく、元の型付き18D証拠を新たに構成した。

    元九変量観測（TopReverseFlagを含む）、二本の全Nat→Nat祖先塔／連続run塔、ordered反転run、元旧18D継承根・完全内部括弧、反転siteとイベント語、v5.77 strict-only最大枝形、v5.78反転祖先深度、v5.79左右経路、v5.80 inherited-guarded raw treeの完全な直積観測が、この両証拠で等しいことをLean4で証明した。無限塔の等式は各次数からfunextで構成する。有限サンプルに弱めていない。

    4．新しい独立観測と真正商での識別¶

    別定義の非結合SelectedWhiskerPlacementTreeは、真正継承旧18D値の内部構文観測source、raw strict、左右whiskerラッパー、raw reversed、raw joinedを保存する。直下の厳密なsourceとstrictの単位2式のみ簡約し、raw反転・whiskerとの一般単位律や結合律を課さない。元証拠のType値自体をこの独立構文で置き換えない。

    共通strict-prefix付きの真正証拠では新観測が 

    left A : joined strict (left (reversed strict))
left B : joined strict (reversed (left strict))
right A: joined strict (right (reversed strict))
right B: joined strict (reversed (right strict))
    となり、各対は自由補助構文として異なる。

    新観測が元旧selected19の全5構成子、新SelectedRawCongruentNineteenの全7構成子で保存されることを各Type値比較に関する帰納法で証明。元旧商・独立新商それぞれへのQuotient.lift、旧→新射影との因子化、v5.80 guarded treeへのforgetful projectionも証明した。

    したがって、供給された各真正whiskered N'→N' fiberに限って、二つの新7構成子商クラスの不一致、元新Type19D比較の不存在、v5.80完全商観測の非単射性、新商クラスを完全観測から復元するdecoderの不存在が形式的に成立する。これは生構文文字列の違いから商の違いを推測した結果ではない。

    成立条件は、実際に与えられたSevenRewriteとContextFrameElevenおよび真正17D端点Nに限る。任意のwhiskering文脈の無条件存在、任意異端点fiberの居住性、旧新商の大域分類・忠実復元、20D gluing、WORLD横断降下、制度的・実行権限は未認証（NO_DATA）として残す。
