    1. 本来のF54 Type値証拠から四成分観測を構成¶

    四成分観測のLeanは、GK4ADの非可換順序付きmomentを用いて、真正元F54経路rに

    O_AE(r) =
  (grade(r), (castCharge(r), backwardCount(r), orderedMoment(r)))
NativeGK4AEValue = Bool × ((Int × Nat) × Int)

    を定義。値域の積は、Bool.andとGK4ADの非可換Heisenberg型積である：

    (g,(c,b,m)) ⋄ (h,(d,e,n)) =
  (g && h, (c+d, b+e, m+n+c*e))
unit = (true,(0,0,0))

    結合律・左右単位と、O_AEの真正原F54合成・元F45左右文脈に対する厳密な整合性をLeanで証明。元F55全9、P92B全9（本物のassociator自然性を含む）、構造seam全14、拡張構造比較全3についてGK4ADで証明済みの元Type値soundnessを利用し、Q元P92B証拠存在商と独立構造商Sへ別々に降下。元Q→S可換性と本来の構造商合成に対する非可換積保存を証明する。元P92Bの存在商Qそのものに未証明の圏公理を追加しない。

    2. 四成分から旧三成分への射影は定理であり仮定ではない¶

    元F54観測の整合・S→K_AE比較Leanは、GK4ADで構成した元F54順序付き値の最初の2座標が、本物の元GK4W castChargeとGK4Z backwardCountに一致することを、元RotationEdge全方向・任意の中間木を持つRotationChain・DepthRotationRoute全5構成子で帰納的に証明する。

    raw.gk4adValue.1 =
  (raw.gk4wCastCharge, raw.gk4zBackwardCount)
forgetMomentValue(O_AE(raw)) = O_AA(raw)

    これは既存の別々に構成したQ/Sの商観測の一致を検証する橋であり、観測値だけで元のType値3-cellを生成する主張ではない。さらにGK4Tの実14 seam条件から真正S→K_AE比較を構成し、比較がHom全射であることと、「比較像の等号 iff 真正四成分観測値の等号」を証明。真正構造圏Sから四成分値の一対象Mathlib圏への関手も実装。

    3. 本物の第二P92B観測kernel圏 K_AE¶

    真正四成分第二kernel圏Leanは、元P92B証拠存在商Qを四成分観測値一致でさらに商にした本物のGK4S第二商K_AEを定義し、Mathlib Categoryの左右単位と結合律を、元Qの未証明の圏公理を一切使用せず、到達四成分値の非可換結合律・単位律から証明。真正S→K_AE比較はHomごとに全射。K_AE→四成分値のMathlib観測関手はHomごとに単射であり、到達像への忠実性を持つ。これはS→K_AEの忠実性を証明したことではない。

    4. 新しい本物の忘却関手 K_AE→K_AA は非忠実¶

    真正第二商間の忘却Leanは、上記の射影整合定理を使ってK_AE→K_AAのwell-definedな商写像とMathlib関手を構成。これはHomごとに全射で、構造商Sからの両比較関手の正準三角形が可換になる。

    GK4ADで作った実元F54型付き経路C;B（二Nat cast、前向き＋逆向きbacktrack）とB;Cは、既存三成分O_AA=((false,-1),1)では等しいが、GK4ADの非可換orderedMomentがそれぞれ0と-1。したがって真正第二商K_AEでは相異なるが、K_AAへの像が一致する：

    [u]_(K_AE) ≠ [v]_(K_AE)
ForgetMoment([u]_(K_AE)) = ForgetMoment([v]_(K_AE))

    よって本物のK_AE→K_AA忘却関手は、真正F54局所回転を持つ任意の型付き自己Hom上で非忠実。実際のC60北側六角形のnorthHexagonNativeLeftRotationでも無条件に成立。GK4ACの別のK_AA→K_XファイバーNat≃Fiber、GK4ADの別のS→K_AA非忠実性と整合するが、S→K_AE全域忠実性は今回未証明である。

    5. CIのエラーとLean記法・依存関係の修正¶

    初回 exact-source CI #41180654899 は、四成分比較のBool射影にBool×Intを取り出したLean型不一致と大文字・小文字不一致の公理表示名2か所で失敗。比較ファイルを修正した後の #41180893741 では、本物の第二商圏ソースが自動転記された未定義nativeGK4AEQuadComparisonを参照していたため、実際のnativeGK4AEComparisonに修正し、比較の単射性必要十分条件を追加。#41181122967 では、忘却関手の2か所で、商代表元が⟦q⟧表示のまま、nativeGK4SKernelClassを使う定理とrwが一致しなかった。そこで元のGK4AAの証明構造と対応させてchangeで型付き商代表元・元P92B四→三観測の定義を明示。これらは追加公理・観測の同一視ではなく、Lean elaborationとdefinitional equalityの修正。

    6. 権限境界・次段階¶

    元Q・独立構造商S・四成分第二商K_AE・三成分第二商K_AA・旧二成分第二商K_Xは各々異なるpresentation。今回証明したのはK_AE→K_AAの非忠実性およびK_AEの真正第二圏構成であり、S→K_AEの全域忠実性は未解決。元P92BQの結合律・左右単位、歴史的完全型付き同値、真正14D無条件Countable、19D filler、global strict n、hyperdescentも未証明。

    次候補GK4AF（未証明）：同一四成分観測値を持つが異なる独立S類を生む、原F54のより高次の順序・文脈・反復履歴不変量の構成、または忠実性の必要十分条件を調べる。決して四成分だけで全局所構造を同一視しない。
