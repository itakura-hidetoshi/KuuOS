    Qi v5.50 — 型付きraw文脈合同性の自由閉包と旧19D商の厳密な情報損失¶

    検証記録日：2026-11-09 JST

    1. 根拠（正本・機械検証）¶

    正本：itakura-hidetoshi/KuuOS、canonical main。定理・公開集約は別PRで実際にMERGED済み。

    • Qi v5.50 Lean4定理PR #3380 MERGED：d4a85788b5c6c724d3a45f356b3eb82e2db82632。
    • 公開import PR #3381 MERGED：889c10fa66ba2531854153a2d3d5ce266464290e。
    • 形式証明Lean全文、新規1ファイル421行、元のLeanソース・比較構成子・Type値証拠は変更なし。

    2. 元のselected19 presentationから独立した型付き閉包¶

    元の19D比較SelectedLocalNineteenは、strict・unitPrepend・unitAppend・比較証拠のreverse・比較証拠のchainだけからなる。Qi v5.49はこれがraw18D reverse および raw18D chain の合同性を持たないことを形式証明している。

    本研究では、元定義を変更せず、別名で独立した新presentationSelectedRawCongruentNineteen W l r J N M L : Typeを構成。ここでJ,Nは元の同一16D fiber上の真正17D証拠端点。

    新Type値比較の生成元は7種類：

    1. inherited：元の真正SelectedLocalNineteen Type値証拠をそのまま埋め込む。
    2. strict：同一raw証拠の反射。
    3. reverse：比較証拠の対称。
    4. chain：比較証拠の推移。
    5. rawReverse：J→Nで比較可能なraw証拠にraw反転を適用し、逆endpoint N→Jで比較証拠を構成。
    6. rawChainRight：J→Nの比較を、指定された真正raw X:N→Sとの右合成J→Sへ輸送。
    7. rawChainLeft：指定された真正raw X:J→NとN→Sの比較を左合成J→Sへ輸送。

    これらは元の比較公理を改変したものではない。新しい比較閉包が識別を追加することを、旧商と新商を別々の型として保持することで明示する。raw whiskerLeft/whiskerRight、異なる16D fiber間交換・20D gluing生成元は追加していない。

    3. 最小性（全ての閉包関係への普遍的証明）¶

    定理selectedRawCongruent_minimalは、厳密な端点添字を持つ任意のProp値関係

    R(J,N) : Raw(J,N) → Raw(J,N) → Prop

    が、元19D比較の包含、反射・対称・推移、raw reverse、raw右・左chainの合同性を満たすなら、新presentationの任意の真正Type値証拠A : SelectedRawCongruentNineteen ... M LからR(J,N)(M,L)が従うことを構造帰納法で証明する。これが指定7生成元に関する最小性であり、それ以上の大域的比較や自由な元証拠の消去を主張しない。

    4. 新しい商と降下¶

    新Type値比較のNonemptyを同一fiberの同値関係としてselectedRawCongruentSetoidを構成。商クラス一致と真正比較の存在の同値を証明した。

    [M]_new = [L]_new ↔ Nonempty(SelectedRawCongruentNineteen ... M L)

    従来のselected19商から新商への射π : Quot_old(J,N) → Quot_new(J,N)を、元19D比較証拠をinheritedで保存することでQuotient.liftにより構成。任意の指定厳密fiberでπは全射と証明した（空fiberでは空性の範囲で成立）。

    新商上では、元raw反転

    Reverse_new : Quot_new(J,N) → Quot_new(N,J)

    および真正raw chain の二変数合成

    Chain_new : Quot_new(J,N) → Quot_new(N,S) → Quot_new(J,S)

    をそれぞれ実際に構成し、rawクラス上で期待される作用の等式を証明した。これらは新商だけの降下であり、旧商に元raw操作が降下したという主張ではない。

    5. 旧障害を保持した情報損失の定理¶

    Qi v5.49の与えられた元旧18D証拠M:J→Nを用い、旧商では比較不可能と形式証明済みの三つの組を新Type値比較で結んだ。

    • reverse(prepend(M)) と reverse(inherited(M))。
    • chain(prepend(M), strict N) と chain(inherited(M), strict N)。
    • chain(strict J, prepend(M)) と chain(strict J, inherited(M))。

    新比較のType値証拠はそれぞれrawReverse、rawChainRight、rawChainLeftから直接構成。新商がこれらを同一視する一方、旧商では異なることから、次の非単射定理を証明した。

    ¬ Injective (π_(N,J))     -- raw reverse を用いる場合
¬ Injective (π_(J,N))     -- strict right raw chain を用いる場合
¬ Injective (π_(J,N))     -- strict left raw chain を用いる場合

    いずれも当該Mが実際に与えられた厳密fiberの範囲に限る。全fiberの非空・非単射や、新しいpresentationによる忠実比較反映は主張しない。むしろ元商との差は具体的なobstructionとして記録される。

    8. 保存条件・研究の限界と次段¶

    元F55/P77/GK5CGから元selected19までのType値証拠、証明履歴、独立presentations、公開root107を保持。Lean v4.30.0-rc2、mathlib 5450b53e5ddc75d46418fabb605edbf36bd0beb6を固定し、保護#1558はDraft／OPEN／未マージ。append-only／tighten-only／overwrite-forbidden／same-root。

    新presentationの全射は忠実性ではない。今回、与えられた元18D証拠のあるfiberで非単射も証明した。数値観測の一致をraw証拠の同一性に昇格させない。別の16D fiberにまたがる文脈合同性、7D whiskeringへの自然性、20D coherenceやgluingは未認証のまま維持する。

    次段Qi v5.51の研究候補： 新商でも保存される元18D ordered traceやその他の不変量を、7構成子全ての保存証明によって商へ降下させる。文脈合同性の拡張で残るobstructionを具体的に観測し、局所性から大域性への不正な昇格を避ける。
