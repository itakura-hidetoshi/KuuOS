    1. 数学的対象と厳密な制限¶

    旧GK5CG真正元五セルType pentagonFinalConservativeLoop と元P77 raw terminal i、実際の五角3辺・2辺五セル値 L₃(i)／L₂(i) を継承する。v4.85ではこれらの元五セルType値の厳密不一致を証明済み。v4.86のPentagonAdjoinedSixCellは明示的に別の自由六セルpresentationであり、元F55/P77/GK5CGには六セル生成元を追加していない。

    v4.87は生六セル証明語のsigned degreeを導入し、同じ始点・終点を持つ証明語を次数一致で商化した。v4.88では、端点が異なるという真正条件から、次数が端点だけに依存することを証明した。元sourceで六セルや七セルが元から存在するとの主張ではない。

    2. 端点ポテンシャルによる次数の決定¶

    任意の型Wと異なる二端点l≠rに対し、新presentationのポテンシャルを [ H_r(w)=\begin{cases} 1 & (w=r),\ 0 & (w\ne r) \end{cases} ] と定義する。LeanはendpointHeightの決定可能性にClassicalを使用し、任意型Wの等号に決定性を仮定として追加しない。

    degree_eq_endpointHeight_sub により、任意の型付き生六セル語 c : AdjoinedSixCell W l r w z について

    [ \boxed{\deg(c)=H_r(z)-H_r(w)} ]

    を構成子 refl・symm・trans・pentagon の完全帰納で形式証明した。ここから allParallel_degreeCoherent と loop_degree_zero を得る。元のF55/GK5CG四セル電荷と、新六セルの構文次数は区別する。

    3. 到達性と三形の正規代表¶

    任意の元Wの端点w,zで、新文法の比較可能性は次と必要十分である：

    [ \boxed{ \mathrm{Nonempty}(\mathrm{SixCell}(w,z)) \iff (w=z)\lor(w=l\land z=r)\lor(w=r\land z=l). } ]

    comparison_nonempty_iff_endpointShape はendpointsSupportedの帰納と、三種類の構成子証拠によってLean4で証明済み。

    新EndpointNormalはrefl、pentagon、symm pentagonの三形から成る。任意の生六セル語cについて、その端点を保ち次数整合する三形の代表dの存在をexists_endpointNormalで証明。selectEndpointNormalはこの存在証明からClassical.chooseで代表を選択する非計算的選択であり、raw c=dという厳密等式は主張しない。

    4. 新しいcoherence商における完全性と局所thin性¶

    homDegreeはCoherentHomから整数への次数不変量を定義し、合成・反転を保存することをhomDegree_comp／homDegree_inverseで証明する。

    homDegree_eq_iffは一般の平行する新商六セルq₁,q₂について

    [ \boxed{\deg(q_1)=\deg(q_2)\iff q_1=q_2} ]

    を示す。さらにl≠rならhomDegree_eq_endpointHeight_subとallParallel_coherentHom_eqによって

    [ \forall q_1,q_2:\mathrm{CoherentHom}(w,z),\quad q_1=q_2 ]

    となる。全Homが非空という主張ではない：coherentHom_nonempty_iff_endpointShapeが非空条件を正確に分類する。coherentHom_hasEndpointNormalはすべての商クラスに上記三形の代表が存在することを証明し、coherentHom_self_eq_idは新商内の任意自己射が恒等射であることを示す。

    5. 真正P77原点への形式化とsource authority¶

    実際の任意元P77 raw terminal i、任意の元GK5CG五セル始終点w,zについて以下を新Leanモジュールで証明した：

    • pentagonActualSixCell_degree_endpointPotential：真正端点のポテンシャル差による構文次数。
    • pentagonActualSixCell_allParallelCoherent：平行する生六セル語の次数整合。
    • pentagonActualSixCell_allRawEndpointNormal：任意の型付き生六セル語の三形代表存在。
    • pentagonActualSixCell_allParallelHom_eq：商クラスの局所thin性。
    • pentagonActualSixCell_endpointComparison_unique：異なる真正元五セル値L₃(i)、L₂(i)間で、新商比較クラスが非空かつ一意であることと、元の厳密不一致の同時保存。

    これらは新presentationと選択した次数商の結果である。元GK5CGで六セル生成元が存在した証拠、元の五セルType値の等号、その他のhigher fillerの不存在の証明ではない。

    新規Leanモジュール446行程度＋formal/KuuOSFormal.lean import1行。旧定理・pin・manifest・workflow・公開root・保護PRは変更なし。

    初回CIは、任意型Wの比較でDecidable (w=r)を自動合成できないことを検出。既存宣言を弱めずendpointHeightの定義内にclassicalを明示した。次の検証ではmathlibのタクティク推奨 intro b hab がwarningAsError=trueにより失敗と判定されたため、証明の2つのintroを単一記法に整理した。いずれも数学的仮定は変更せず、最新HEADで全10,287 Lean jobs、Governance30/30、20件公理監査、Git tree一致が成功した後、指定HEADをsquashマージした。

    現在の次数商は意図的にthinである。次段階では、商の同値と異なるType値の上位比較証拠、正規化証拠履歴、別presentationのcompatibility、元sourceに押し戻すために本当に必要な条件を形式化する。全ての生六セル語の元証拠履歴とその商クラスを同一視しない。
