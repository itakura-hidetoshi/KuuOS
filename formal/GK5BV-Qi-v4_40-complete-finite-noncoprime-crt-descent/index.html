    2. GK5BV — 有限個の重なる法に対する完全CRT降下¶

    前段GK5BUでは「大域解⇒すべてのpairwise gcd整合性」「失敗組があれば解なし」「解は有限lcmを法に一意」「局所法が支配的なら構成可能」までを証明していた。GK5BVは支配的局所法という仮定を撤去し、必要十分条件を完成した。

    真の任意有限添字集合s:Finset ι、任意の自然数法mᵢ:Nat、独立局所代表aᵢ:Natについて

    (∀ i∈s, ∀ j∈s, aᵢ ≡ aⱼ [MOD gcd(mᵢ,mⱼ)])
   ↔
(∃ x:Nat, ∀ i∈s, x ≡ aᵢ [MOD mᵢ]).

    を固定mathlibで無条件にLean4形式証明した。互いに素、非零法、支配的局所法、元F55 Type源の存在などの仮定なし。空の有限集合も包含する。

    主要補題は任意a,b,c:Natについての

    gcd(lcm(a,b),c) = lcm(gcd(a,c),gcd(b,c)).

    ゼロを含む場合を個別処理し、非零の場合には固定mathlibのNat.factorization_gcd・Nat.factorization_lcm・Nat.factorization_injと分配格子の点ごとのmin/max恒等式を使用した。これをFinset.lcmへ帰納的に拡張した上で、現在の大域代表と新しい局所法の共通部分上の整合性を導出し、前段GK5BTの真正Nat.chineseRemainder'で逐次再合成した。存在証明に追加公理や架空の剰余代表はない。

    L = Finset.lcm s m とすると、すべての大域解は法Lで一意。Classical.chooseは証明済み存在定理からのみ代表を選択し、そのx % Lはすべての局所条件を保持する。L≠0なら正規化解は0≤x%L<L。法0の局所条件が存在する場合も、mod0を等号と解釈した同じ一般定理が成立する。

    さらに

    ¬ ∃ global x
 ↔ ∃ i∈s, ∃ j∈s, ¬(aᵢ ≡ aⱼ [MOD gcd(mᵢ,mⱼ)])

    の有限obstruction必要十分条件を証明。数値的な局所・大域descend可能性と元F55 Type-valued seamは同一概念ではない。

    CI修正記録¶

    初回CIはゼロケースの等式向き2箇所、Finsupp格子演算と汎用DistribLatticeインスタンスの型差異、GCDMonoid.lcm／Nat.lcmの補題適用名違いが原因。左右対称化、Finsupp.inf_apply／sup_applyの点wise min/max証明、固定mathliblcm_eq_nat_lcmによる橋渡しに修正。既存定理と新規定理の数学的仮定・結論は弱めず、最終CIで9定理全てsorryAxなし。

    3. Qi v4.40 — 真正北C60の数値値と元seamを分離¶

    元GK5BQの実際の符号付き整数分子N_(d,j)(v)∈Intから各局所法についてN.natAbs % mᵢを観測する。一般GK5BVの有限CRTで再合成した正規化大域代表は、元のN.natAbsと法Finset.lcmで同じ合同類である。したがって

    normalized finite CRT glue ≡ 0 (mod Finset.lcm)
 ↔ (Finset.lcm:ℤ) ∣ N_(d,j)(v).

    ここで絶対値表現が残すのは元符号付き整数Nの整除判定であり、元符号を剰余列から復元できるという主張ではない。

    実際の整数係数多項式P:Int[X]についてnatDegree(P)≤d、Finset.lcm moduli ∣ d!を明示すれば、全j≤dで有限CRT合成類が零になる。元F55 Type値の真正北証拠では既存のP92B整数深度多項式値、元F55/P77商類では既に降下した整数多項式値にのみこの条件付き定理を適用した。

    • 元primitiveP=1と別のdouble inverse＋元F55右単位P=X²は、上述の有限lcm整除条件の下、双方とも全係数で数値的有限CRT gluingが成立する。
    • fivefoldGK5BVNorthBothFiniteZeroButOppositeSeams：この二つの真正元F55 Type値証拠はともに算術的有限CRT零だが、元original→phiの局所seamは前者で存在、後者では不存在。数値gluingは構造的Type seamの十分条件ではない。
    • 独立局所例のFin 3で、法4,6,9、代表1,3,0は実際に大域代表9を持つことを型付き証明。これらの法は互いに素でなく、単独で他の全てを支配する局所法もない。元Finset.lcmの合同類としての一意性も証明。
    • 真正北第五Dart物理C60と元P89 BadPair条件付き反射は旧来のType定理から継承。数値合同条件から新しい元F55 source、P77商類同一性、P94A四セル、GK5AY全域seam、P89無条件反射、W=1→seam、GK5BA kit、Grayを導出しない。

    4. 次の研究境界¶

    GK5BW（仮称）：今回の必要十分条件と正規化大域代表から、有限局所剰余系の環としてのfiber product／互換族と大域ZMod(L)の間の実際の環同型、局所制限・再合成の加法／乗法自然性、obstructionの型付き境界を検討。数学的な数値環同型と元F55 Type証拠・4セル・seamの構造的再構成は引き続き別課題。この時点では次研究計画であって証明済みではない。
