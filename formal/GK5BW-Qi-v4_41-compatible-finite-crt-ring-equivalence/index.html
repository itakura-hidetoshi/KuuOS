    2. GK5BW — 互換な有限局所剰余族の真の環同型¶

    任意の有限添字集合s:Finset ι、任意の自然数法m:ι→Natについて、L=s.lcm m。局所値の依存積 (i:{i // i∈s}) → ZMod (m i) のうち、各二局所のgcd上への真正ZMod.castHom射影が一致するものをnativeGK5BWCompatibleSubring s mとして実際のSubringに構成した。

    数学的定理：

    ZMod (Finset.lcm s m) ≃+*
  nativeGK5BWCompatibleSubring s m

    この同型は単なる大域代表∃xではない。大域環から局所環への成分ごとのZMod.castHomをRingHomとして定義し、局所互換性、加法・乗法・単位元の保存、単射性、全射性を証明し、RingEquiv.ofBijectiveへ接続した。全局所値からの単射はFinset.lcm_dvdとZMod.intCast_eq_intCast_iff_dvd_subに基づく。

    ゼロ法と空被覆も含む。 L=0の場合は元の被覆に法0の実サイトが存在することをFinset.lcm_eq_zero_iffで取り出し、ZMod 0の真正符号付き整数代表で全局所を再構成する。L≠0ではすべての局所法が非零となり、既証明GK5BVの一般有限非互いに素CRTから自然数大域代表を構成する。互いに素、非零、非空、支配的サイトの仮定は一切加えていない。

    CI修正履歴：独立GK5BW初回のSubring.one_mem'簡約と、ZMod.castHom・ZMod.cast間の型照合、法0のgcd正規化に伴うLean4 elaboration問題を、固定mathlibのZMod.cast_intCast／ZMod.cast_natCast／ZMod.cast_idを明示して修正。数学的な命題・仮定・結論は不変。最終9,301ジョブ成功、公理監査7定理sorryAxなし。

    3. Qi v4.41 — 真正北C60符号付き整数値と有限被覆制限の自然性¶

    元GK5BQの同一の符号付き整数nativeGK5BQClearedNumerator d j values : Intを、絶対値ではなく直接ZMod Lへ移し、独立GK5BWの実際の環同型により互換な局所剰余族へ写した。各元局所サイトでの座標は元整数のZMod (mᵢ)への符号を保つ剰余射影と一致し、同型の逆写像で元の数値合同類を回収する。

    任意の有限部分被覆t⊆sで、lcm_t | lcm_sを証明し、局所互換剰余環から部分被覆への真正RingHomを構成。大域ZMod側のZMod.castHomと局所側の被覆制限が可換となる環同型の自然性を、固定mathlibのRingHom.ext_zmodで型付き証明した。元符号付き整数numeratorの局所座標は部分被覆への制限後も一致する。

    さらに、実際の元F55 primitive original source（深度多項式P=1）と、真正double inverse＋元F55右単位source（P=X²）について、双方とも全有限非互いに素CRTの数値環同型を利用できるが、元original→phiの構造的seam判定は前者が存在／後者が不存在であることを1つの型付き定理として保持した。既存のlcm_s | d!と2≤dの明示的条件下では両者の数値的有限CRT零証明書も同時に成立する。

    CI修正履歴：初回Qiの2箇所のNativeC60FivePhaseGauge未解決は既存名前空間のopen不足であり、既存のKUOS.Architecture.WuxingCyclicPathsを参照して修正。仮定を変更せず最終10,228ジョブSUCCESS・8定理sorryAxなし。

    4. 構造的 authority 境界と次の研究¶

    ZMod L ≃+* compatible local ringは数値／環のdescentであり、元F55 Type値のsource、P77商類の等号、P94A四セル、GK5AYの全域seam、P89無条件反射、W=1→seamを証明するものではない。元F54の真正二Nat・二圏・Blocks、F55のType値履歴、真正北C60第五Dart物理gauge、条件付きP89障害を別authorityとして保存する。Gray圏の復元・GK5BA kitは追加しない。strict 空と独立Kuu→Qiを同一視しない。

    次GK5BX（研究計画、未証明）： 真正環同型と有限被覆制限の自然性を、有限包含の合成／恒等に関する擬関手的コヒーレンス、必要なら元整数多項式値の評価自然性へ拡張する。その際も算術的descentからの元F55 Type gluingを推論せず、obstructionを別定理として保持する。
