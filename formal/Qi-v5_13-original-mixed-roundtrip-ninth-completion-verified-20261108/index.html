    1. 真正M往復の厳密な障害から独立九セル補完へ¶

    前段Qi v5.12の元SevenRewrite二端点が一致する生の第八比較

    ninthMixedRoundtrip l r
ninthMixedReflexive l r

    は、元mixedResidue生成元の出現回数が 2対0 で区別できる。前段では全PentagonCancelNineCell構成子がM回数を保存するため、これらの間の旧九セル比較の不存在を形式証明済みである。

    今回は、旧九セル文法を変更せず、独立の新Type

    MixedCancelNineCell W l r q q'

    にただ一種類の真正な原始比較

    MixedCancelNineCell.cancelMixed

    を構成。その添字は上記の元八セル二証明値そのものである。全既存PentagonCancelNineCell比較はpreviousで保持し、向き反転、連鎖、八セル比較の逆向き・合成・whisker・逆文脈の型付き閉包だけを許可した。

    mixedCancelNineCell_strictlyNew は新比較の存在・旧比較不存在・元生八セルstrict Eq不存在を一つの定理として証明する。旧九セルや元strict Eqへの普遍的解釈はmixedCancelNineCell_noPreviousInterpreterとmixedCancelNineCell_noRawEqualityInterpreterで反証した。

    これは選択された独立の新九セルpresentationの存在を示すものであり、元F55/P77/GK5CGに最初から存在するcanonical九セルを発見した、あるいは元八セルを厳密に等置した、という主張ではない。

    2. 選択商の厳密な粗化と観測量の降下¶

    mixedCancelNinthSetoidとmixedCancelNinthClassを真正な元八セル証拠Typeの上に定義した。旧九セル商の等しい元証拠は新九セル商でも等しくなる（pentagonCancelNinthClass_descendsToMixedCancel）。今回の真正M往復・反射対は旧商では別クラス、新商では同クラスとなる（mixedCancelNinthClass_strictlyNew）。

    この新商から元の全生八セル証拠への左逆復元を否定するmixedCancelNinthClass_noRawRetractionも形式証明。

    M回数は、この新たな具体的比較で

    [ N_M(\mathrm{MixedRoundtrip})=2,\qquad N_M(\mathrm{Reflexive})=0 ]

    となるため、同じ新商で両者を同値にしたとき、元のM回数を忠実に降下させられない（mixedCancelNinthClass_noMixedCountDescent）。

    しかしPとMの回数の偶奇は全新九セル構成子で保存される：

    [ \boxed{ N_P(q)\equiv N_P(q')\pmod2,\qquad N_M(q)\equiv N_M(q')\pmod2. } ]

    mixedCancelNineCell_preservesPentagonParityとmixedCancelNineCell_preservesMixedParityは全構成子の構造帰納法によるもので、単に代表元上の例を示したものではない。真正のNat値Quotient.liftで

    mixedCancelNinthPentagonParity
mixedCancelNinthMixedParity

    を構成し、双方の代表元計算も証明した。偶奇一致から任意の比較可能性を推論しない。

    3. P/M両往復を補完しても残る、新たな整数値obstruction¶

    独立の構文的観測量ninthResidualChainChargeを、元の自由八セルType上に定義した。

    • 元の四重五角形一生成元fourfoldPentagonの寄与は(-1)。
    • 元の旧mixedResidueイベントは1個につき(-1)。
    • 自由八セルchain構成子は左右の値の和に +2 を加える。
    • 八セルの逆向きや単独文脈は値を保存し、compositeContextは加法的に振る舞う。

    これにより、元P/Mの相殺という選択に対し、別個に自由合成の構文履歴を追跡できる。

    全ての旧FourfoldMixedNineCell、前段PentagonCancelNineCell、今回MixedCancelNineCellの全構成子に関して、この整数が保存されることを三段の構造帰納法で証明：

    fourfoldMixedNineCell_preservesResidualChainCharge
pentagonCancelNineCell_preservesResidualChainCharge
mixedCancelNineCell_preservesResidualChainCharge

    したがってこの値もmixedCancelNinthResidualChargeとして真正Quotient.liftで新商へ降下する。

    ここで、元の反射八セル証拠(\mathrm{Id}_8)と、その自由八セル合成(\mathrm{Id}_8;\mathrm{Id}_8)は同じ元七セル始終点を持つにもかかわらず、

    [ \boxed{ \begin{aligned} Q(\mathrm{Id}_8;\mathrm{Id}_8)&=2,\ Q(\mathrm{Id}_8)&=0. \end{aligned}} ]

    そのためninthDoubleReflexive_noMixedCancelComparisonによって、今回の新九セル文法には両者間の比較が存在しないと証明した。新商でも区別され（ninthDoubleReflexive_distinctMixedCancelClass）、任意並行八セルを比較可能とするglobal thinnessも成立しない（mixedCancelNineCell_notGloballyThin）。

    重要な点：この反例はP/Mの出現回数がともに0であっても成立し、単なるP/M回数の保存からは見えない自由合成のobstructionである。既存の選択文法に関する否定定理であって、将来別に追加される高次比較の普遍的不存在ではない。

    4. P往復消去 × M往復消去の真正高次critical overlap¶

    真正元P77/GK5CGに由来するfourfoldMixedResidueFirst l rという元七セル履歴を持つ同じ元七セル始終点で、次の四つの元八セル証拠を構成した。

    Top     = (P-roundtrip) ⊗ (M-roundtrip)
MidP    = (P-reflexive) ⊗ (M-roundtrip)
MidM    = (P-roundtrip) ⊗ (M-reflexive)
Bottom  = (P-reflexive) ⊗ (M-reflexive)

    上→MidPとMidM→下には、前段の真正cancelPentagonをpreviousとして用いる。上→MidMとMidP→下は今回の新cancelMixedを真正合成文脈に入れたもの。

    originalDoubleCancellationLocalDiamondによって四辺と完成経路の型付き九セル証拠を構成した。同じ端点の二経路

    originalDoubleCancellationPThenM l r
originalDoubleCancellationMThenP l r

    について、旧cancelPentagonをtrue、今回のcancelMixedをfalseとする生九セルイベントtraceを新規定義（旧P/Minterchangeはこの特定観測では記録しない）。

    [ \operatorname{trace}(P;M)=[\mathrm{Pcancel},\mathrm{Mcancel}], \quad \operatorname{trace}(M;P)=[\mathrm{Mcancel},\mathrm{Pcancel}]. ]

    originalDoubleCancellationTraceValuesは2つを定義上の等式として証明し、originalDoubleCancellationRawNineGapは元の生九セル証明がstrict Eqではないことを形式証明した。

    ここから「第十セル比較が存在しない」とは推論しない。二つの九セル証拠を接続する独立した第十セルcoherenceが次の局所課題となる。

    5. 元sourceを保持した真正P77 final raw indexへの特殊化¶

    pentagonActualMixedRoundtripNinthCompletionは任意の元P77最終raw indexで、実際のpentagonFinalConservativeLoop、pentagonLongConservativeFiveCell、pentagonShortConservativeFiveCellを用いて今回の新比較のType値存在を構成する。

    同時に、元の¬ PentagonAdjoinedSixCellEqualityInterpreterも保持し、既存F55/P77/GK5CG・六セル・七セル・八セル・旧九セルpresentationを一切変更しない。
