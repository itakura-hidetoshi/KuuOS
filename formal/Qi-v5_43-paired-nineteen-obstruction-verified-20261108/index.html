    2. 真正19D商上の二変量観測¶

    元v5.37/v5.42の証明済み不変量、完全順序付き外側履歴selectedNineteenTraceOnQuotientと、selectedNineteenActiveChainOnQuotientを組にして

    I(q) = (length(Trace(q)), ActiveChain(q)) : Nat × Nat

    をselectedNineteenLengthActiveObservationとして各々の厳密な17D始終点fiberの真正19D商上に定義した。selectedNineteenLengthActive_onClassで元の生18D証拠値に対する計算則、selectedNineteenLengthActive_eq_iffで二つの成分がともに一致することと二変量観測Eqの同値を証明した。観測商を元Type値証拠同一性と同一視していない。

    3. 二変量の一致を反映する実在する型付き境界¶

    固定mathlibのNat.pair（Mathlib.Data.Nat.Pairing）と既存のselectedMixedLengthCodeで、指定LR証拠の二変量baseを0へ送り、残りを単射的に符号化するselectedMixedPairedCodeを定義。selectedMixedPairedCode_injectiveを形式証明した。

    真正RL18D証拠の既証明列P_R(n)へ、sourceの二変量符号を指数として渡すselectedMixedPairedRawTransportを構成。元の指定LR証拠は真正RL証拠に写り、selectedMixedPairedAnchoredが実際の指定19D比較のType値を保持する。sourceの真正19D比較はTraceとActiveを保存するので、輸送先の真正SelectedLocalNineteen.strictによりselectedMixedPairedBoundary.localTransportを構成した。

    最も強い証明済みのkernel分類は、任意の同じLR 19D fiberの商クラスq₁,q₂についての

    descend_paired(q₁) = descend_paired(q₂)  ↔  I(q₁) = I(q₂)

    （selectedMixedPairedDescend_eq_iff_observation）である。これはこの具体的なtransportについて二変量の等値関係を保存・反映するという主張で、sourceとtargetの数値的二変量そのものの全域一致や全域swap自然性は主張しない。v5.42の同一fine trace・Active差1の厳密なX/strict-prepend(X)は、この新しい境界では像が異なる（selectedMixedPairedDescend_separatesStrictPrepend）。

    4. 同一二変量fiberに残る厳密なobstruction¶

    新たに生18D構文のreverse構成子の回数selectedContextEighteenReverseCountを数え、既存SelectedLocalNineteenの5構成子すべてがこの数を保存することを証明。これをselectedNineteenReverseCountOnQuotientで真正19D商へ降下した。

    任意の真正生18D値Xに対し、同一依存fiberでD(X) = reverse(reverse(X))を構成すると、

    Trace(D(X)) = Trace(X)
ActiveChain(D(X)) = ActiveChain(X)
ReverseCount(D(X)) = ReverseCount(X) + 2

    がLean4で成立する。従ってI([D(X)]) = I([X])だが、[D(X)]₁₉ ≠ [X]₁₉であり、selectedNineteenLengthActive_notInjectiveで二変量観測の非単射性を元18D証拠が存在するfiberごとに証明した。これは選択した19D presentationに相対的な証明である。

    二変量境界のkernelはIのEqと正確に一致するため、selectedMixedPairedDescend_notInjectiveが具体的境界の非単射性を証明。selectedMixedPairedBoundary_noReflectionがその境界に全SelectedLocalNineteen比較を逆向きに反映するType値証明書を付与できないことを形式証明する。

    5. 権威境界と未構成領域¶

    認証済み： 二変量の真正19D商観測、Nat.pairによる型付きanchored LR→RL輸送、全source商クラスでのkernel iff観測二変量Eq、同一fine traceだがActiveが異なる証拠の分離、二重反転による同一二変量・異なる19D商クラスの実例、その具体的輸送の非忠実性、指定証拠でのcoarse swap観測Eq。

    未認証／NO_DATA： 別の完全忠実な境界transportの一般的存在・不存在、全sourceについてのswap自然性、元の生Type値のEq、異fiber20D交換・無条件高次gluing。二変量反映や選好だけを元証拠一致・降下・行為権限へ昇格させない。

    次段Qi v5.44： 真正19D商上のReverseCountを含む観測フィルトレーションの段階的強化と、より強い観測に対してなお残るType値比較障害を探索する。既存presentationに新たな逆元キャンセル公理・交換公理を加えず、未構成の一般忠実性はNO_DATAのまま保持する。
