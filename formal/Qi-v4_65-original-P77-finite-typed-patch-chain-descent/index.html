    1. 任意有限段の真の型付き証拠構造¶

    FivefoldP77RawPatchBlock f g h k u v は、元の型付き端点 u,v、任意の添字型 Index : Type、Nonempty Index、そしてその添字から元F55/P77生四セルへ至るraw写像を保持する。生四セルそのものを数値chargeへ置き換えず、互換性をデータ定義の内部へ隠さない。

    各ブロックの互換性 fivefoldP77RawPatchBlockCompatible は次の二条件の連言である。

    • 任意の二つの元patch raw i・raw j 間に本物のGK5CG保守的Type値五セルが存在する。
    • あるpatch raw i に対し、元の型付きsource有向自由経路の真正P77評価から到達する本物のGK5CG保守的Type値五セルが存在する。

    FivefoldP77RawPatchChain は nil と cons block tail を持つ依存帰納型である。任意個のブロックについて中間頂点の型を保存するため、これは数値のリストや無型の辺列ではない。零段の空鎖と任意有限段の鎖の両方を扱う。

    2. 全段のdescent必要十分条件と一意性¶

    FivefoldP77RawPatchChainWitness は各段について「すべてのraw patchを元の保守的P77商へ厳密に評価する真正Quiver.Path」を保存する、Type値の証拠付き有限経路列である。

    主定理 fivefoldP77RawPatchChain_witness_iff は任意の有限型付き鎖Cに対して、

    Nonempty (FivefoldP77RawPatchChainWitness C)
  ↔ fivefoldP77RawPatchChainCompatible C

    を数学的帰納法で証明する。右辺は全段における真正元GK5CG Type値五セルのpatch間互換性と各段の少なくとも一つの真正source anchorの連言である。元四セルのchargeの範囲内という数値条件だけではない。

    fivefoldP77RawPatchChain_witness_subsingleton は元P77 Faithful関手から全段の復元証拠付き経路列が高々一つであることを導く。互換性が成立するとき fivefoldP77RawPatchChain_witness_unique は ∃! により存在と一意性を与える。これは元のsource有限経路列の型としての一意性であり、chargeだけの一致ではない。

    3. 全有限鎖の真正合成・復元整合性¶

    fivefoldP77RawPatchChainPath は各段で復元された元有向source経路を端点を壊さず連結する。fivefoldP77RawPatchChainTarget は各段の元F55/P77四セル商クラスを、真正元P77の保守的垂直合成によって順序通りに結合する。

    fivefoldP77RawPatchChainPath_eval が証明する可換性は、

    OriginalP77Functor.map (TypedPathOfChain C witness)
  = OriginalP77ConservativeCompositeOfRawPatches C

    である。左辺は元source有限経路の本物のFunctor像、右辺は元GK5CG Type値五セルの関係で商にした本物のP77四セルの垂直合成である。ゼロ段では元の反射四セル、帰納段ではFunctor.map_compと元source patchの評価証拠を使う。

    さらに fivefoldP77RawPatchChainCertified は元の証拠付き依存Subtype FivefoldP77PartialDomain 上に真の合成クラスを構成し、

    CertifiedChain.val = OriginalP77ConservativeCompositeOfRawPatches
PartialRecover(CertifiedChain) = TypedPathOfChain C witness
OriginalP77Charge(CertifiedChain.val)
  = Int.ofNat (TypedPathOfChain C witness).length

    をLean4で証明する。chargeはType値復元後の観測量であって、元四セルの証拠同一性や到達可能性を決める手段ではない。

    4. 正確な障害境界¶

    fivefoldP77RawPatchChain_cons_typeGapは、ある指定段のGK5CG保守的Type値五セル互換条件が失敗すると、その段を含む指定された因子別経路列の復元証拠は存在しないことを形式化する。

    これは全targetにおける任意の別の合成因子分解の否定ではない。元P77全targetへの全域復元、合成全体から中間patchすべてへの無条件到達反射、逆向きsource辺の捏造、新pentagonator、Grayや一般siteでのsheaf降下を主張しない。

    5. Lean4の修正根拠と再検証¶

    初期CIでは、元patchブロックが任意の添字Type・元F55/P77の依存データを保持するため、通常のTypeに結果を固定した帰納型FivefoldP77RawPatchChainのconsで宇宙レベル不足が発生した。後続のidentifier未解決はこの帰納型の宣言不成立に連鎖した。元の証拠や命題を減らさず、帰納型を適切な高いTypeに置き、依存再帰定義の束縛パラメータ等を固定Lean4構文に合わせて修正した。初回の失敗を成功と混同しない。
