    2. 第六観測量ActiveDepthの同一fiber商への降下¶

    既存のSelectedContextualEighteenの生構文に対し、selectedContextEighteenActiveDepthを定義した。これは生chain内部の入れ子に関する自然数不変量であり、各chain M Lの子孫に存在するactive chain数を加算する。外側履歴が非空か否かを観測する従来のActiveChainCountとは異なり、同じ活動数でも結合順序の深さが異なる場合を識別する。

    selectedLocalNineteen_preservesActiveDepthは既存の真正SelectedLocalNineteenの5構成子すべてについて保存性を証明。旧18D inheritedに限るunitPrepend・unitAppendは新しい深さの差を発生させない。実際の型付き比較を使うselectedNineteenActiveDepthOnQuotientのQuotient.liftおよびクラス計算則selectedNineteenActiveDepth_onClassをLean4で構成した。元の生証拠値を等号で潰していない。

    3. 真正同一fiberにおける五変量一致・第六変量相違¶

    任意の元18D証拠M : SelectedContextualEighteen W l r J Nから、真正17D endpointの同一fiber J → J 内に

    B := chain M (reverse M)
A := reverse B
L := chain (chain A B) (strict J)
R := chain A (chain B (strict J))

    を構成した（selectedDepthLoop、selectedDepthBracketLeft、selectedDepthBracketRight）。

    元Mの外側fine trace長が正という明示条件の下で、selectedDepthBrackets_trace、selectedDepthBrackets_active、selectedDepthBrackets_reverse、selectedDepthBrackets_leftNested、selectedDepthBrackets_reverseLeftが、L/Rの完全外側履歴と従来の5数値観測すべての一致を証明する。

    一方、新しい深さに対しselectedDepthBrackets_depthDiffは

    ActiveDepth(L) = ActiveDepth(R) + ActiveChain(B)

    を証明する。selectedDepthLoop_activePositiveが0 < ActiveChain(B)を確保するので、両者のActiveDepthは異なる。旧19D比較はActiveDepthを保存するから、selectedDepthBrackets_classDistinctは[L]₁₉ ≠ [R]₁₉、selectedDepthBrackets_noLocalは元の真正SelectedLocalNineteen Type値比較の非存在を証明する。

    selectedNineteenFiveObservationはQi v5.45の真正4変量観測にReverseLeftCountを追加したもの。selectedDepthBrackets_fiveEqで上記の二つが同じ5数値を持つことを示し、selectedNineteenFive_notInjective_of_tracePositiveで非空fine履歴を持つ元Mが存在する同一J→J fiberにおける五変量観測の非単射を証明した。

    この定理は指定の正の履歴を持つ元証拠に依存する。任意の依存fiberに無条件の反例がある、あるいはすべての型付き境界transportが忠実でないという主張ではない。

    4. CI失敗、修正の来歴と権限境界¶

    初期のexact-source CIでは、List.length_appendとif_posの正規化が局所条件と合っていないため、Leanのchangeとomegaで失敗した。旧19DのType値証拠や仮定を変えず、各条件付き分岐の正値を明示して局所的に修正し、sorryAxの連鎖を除去した。

    またQi v5.45の正式記録がmainに追加されたため、GitHub MCPで新しい証明ブランチを非破壊的な二親コミットとして最新mainに同期した。元定理ソース391行は変更せず、source/test-merge treeを一致させて最新HEADに対する新規CIを再実行し、SUCCESSを確認してから統合した。

    認証済み： 現行selected 19D商の第六観測量ActiveDepth、五つの旧比較構成子に対する保存性、同一fiberでの実在する5数値一致・第六値相違、同fiber内の真正19D商の不一致と比較非存在、条件付き五変量観測の非単射、既存公開集約への取り込み。

    未認証／NO_DATA： 第六観測を含む型付き境界transportの構成、任意fiberでの五変量非単射、別の忠実LR→RL transportの存在・不存在、全域swap自然性、元Type値の生Eq、無条件20D交換・高次gluing。五数値の選好・一致を元証拠同一性や権限へ昇格させない。

    次段Qi v5.47： ActiveDepthを第六変量に追加した厳密19D商観測と、元Type値を保存する条件付き型付きLR→RL transportの具体的構成を検討する。さらに同一六変量fiberに残る新しいobstructionを探索し、追加構成子・仮定による安易な解消はしない。
