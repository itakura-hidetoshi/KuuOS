    1. 問題設定：二つの偶奇は独立か¶

    Qi v5.03で独立したBalancedUnitEightCellを追加し、元整数Uは新商へ降下しないが、 R mod 2とU mod 2はどちらもBool値として降下すると証明した。

    ここで、二つのBool値を固定された七セル始終点上の独立した二ビットと仮定するのは正しくない。 元の自由六セル構文に含まれるsymmとtransの数を数える sixRawShapeWeightを新たに定義した。

    F(refl(w)) = 0                 F(pentagon) = 0
F(symm(c)) = F(c) + 1
F(trans(c,d)) = F(c) + F(d) + 1

    任意の元13構成子の真正七セル履歴 H : SevenRewrite ... c d に対して、 Lean4で次のmod 2の境界コサイクル条件を構造帰納法で証明した。

    (F(c) + R(H) + U(H)) mod 2 = F(d) mod 2

    ここで R = sevenIdentityBalance、 U = sevenUnitStepCharge であり、対象は商以前の元の全七セル生構文である。 したがって同じ元六セル始終点c,dをもつ任意の二つの平行履歴H1,H2について、

    R(H1) mod 2 = R(H2) mod 2
    iff
U(H1) mod 2 = U(H2) mod 2

    という必要十分な偶奇連動が得られる。 Lean定理はsevenRawBoundaryParitySound、 sevenParallelBoundaryParity、sevenParallelParityCouplingである。 これは平行履歴間の比較存在や元source strict Eqを意味しない。

    2. 新しい整数V：単位則と逆元消去の合計¶

    新しくsevenTotalReductionCharge : SevenRewrite ... → ℤを構造再帰で定義した。 元の13構成子のうちleftUnit、rightUnit、 inverseLeft、inverseRightへ+1、 残る局所生成元には0を与える。

    symmで符号反転、transとcongrCompで加算、 congrInvで保持する。

    V(H) = signed_count(leftUnit, rightUnit, inverseLeft, inverseRight)

    元のEightCell全22構成子、TriangleEightCell、 InvolutionEightCell、InverseCompEightCell、 IdentityEightCell、UnitDiamondEightCell、 そして最新v5.03のBalancedUnitEightCellの 全生成元と文脈閉包に対して整数Vが厳密に保存される ことを定理ごとにLean4で証明した。

    とくにv5.03の唯一の新原始生成元balancedUnitでも 元の二経路のVはともに3である。 新選択商上の真正な整数観測量 balancedUnitHistoryTotalReductionをQuotient.liftで構成した。 これは元の整数Uを再度降下させる操作ではない。

    3. 合成逆元消去の二つの真正履歴¶

    任意のw : Wについて、元六セル語 (refl(w);refl(w));inverse(refl(w);refl(w))を考える。

    第一の七セル履歴は直接inverseRight(refl(w);refl(w))で消去する。 第二は、inverseCompで逆元を分配し、 assocとsymm(assoc)で順序を組み直した後、 inverseRightを二度、leftUnitを一度使って同じrefl(w)へ至る。

    これらは同一のraw六セル始終点を持つ sevenCompositeInverseCancelDirectと sevenCompositeInverseCancelViaという元の型付き七セル履歴である。

                         Direct       Via
整数V                  1           3
R mod 2                0           1
U mod 2                0           1

    この単一ペアは二偶奇が異なるので、これだけを新たな偶奇不可視障害とは主張しない。

    4. 二組の型付き横合成：二偶奇不可視の比較不能性¶

    前段の元六セル平行履歴を二つ横合成した。 sevenDoubleCompositeCancelFirstと sevenDoubleCompositeCancelSecondは元の SevenRewrite.congrCompから構成した真正の七セルType値であり、 始終点は完全に同一である。

                                First       Second
R mod 2                       0            0
U mod 2                       0            0
新しい整数V                   2            6
raw六セル始終点              完全一致

    現行BalancedUnitEightCellのいかなる比較でもVは保存されるため、 比較証拠があると2 = 6が必要になり矛盾する。

    Lean4で次の命題を形式証明した。

    sevenDoubleCompositeCancel_noComparison
sevenDoubleCompositeCancel_distinctClasses
sevenDoubleParity_notCompleteForBalancedUnit
sevenTotalReduction_notFactorThroughParities

    これにより二偶奇が両方一致することは、現行高次商での比較可能性の十分条件ではないと確定。 さらにVは二偶奇の任意の非線形関数からすら普遍的に復元できない。 なお、今回の二履歴について以前の三整数(T,J,K)の一致までは主張しない。

    5. 真正P77最終raw添字への輸送とauthority境界¶

    sevenDoubleCompositeSourceFirst cと sevenDoubleCompositeSourceSecond cは、 二組横合成した比較不能な履歴に同じ真正六セル値cを貼ったものである。 元の型付き添字、元R/Uの偶奇一致と整数Vの2対6を保つ。

    pentagonActualDoubleCompositeResidualWithSourceObstructionは、 任意の真正P77最終raw添字に対して、 元pentagonAdjoinedSixCell_generatorにより

    • 同じ真正GK5CG sourceのType値証拠をもつ二履歴の両偶奇一致
    • 完全な旧BalancedUnitEightCell構文で比較不可能
    • ¬ PentagonAdjoinedSixCellEqualityInterpreterの維持

    を同時に示す。

    旧八セルpresentation、商、自由七セル構文、 元F55/P77/GK5CG source・strict Eqと証拠履歴を変更していない。 独立Kuuのpresentationと元sourceのauthorityを混同しない。
