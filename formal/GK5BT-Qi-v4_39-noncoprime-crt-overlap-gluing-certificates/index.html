    2. 独立GK5BT：条件付き重なりCRT¶

    先行GK5BSの素数冪ごとの互いに素なCRT環同型を、共通因子を持つ任意の二法m,n:Natに拡張する。重なりgcd(m,n)上での厳密な整合を、真のMathlib Nat.ModEq によって

    a ≡ b [MOD gcd(m,n)]
 ↔ ∃ x:Nat, x ≡ a [MOD m] ∧ x ≡ b [MOD n]

    として必要十分に形式化した。一般に無条件の合成は成立しない。固定mathlib Nat.chineseRemainder'から実際にxを構成し、Nat.mod_lcmを用いて全ての解が法lcm(m,n)で同じ合同類に属することを証明。二法が非零なら0≤x<lcm(m,n)の正規化代表が一意。零法は対応する解の存在・同値の一般定理に含むが、厳密な上界には非零条件を明示する。

    不整合a % gcd(m,n) ≠ b % gcd(m,n)は大域代表の不存在と同値な算術的obstruction。整合は加法と乗法に対して保存される。これは局所値の合成であり、元F55 Type値証拠の構造的gluingとは別。

    元GK5BQの整数分子N_(d,j)(v)∈Intを一切改変せず、自然数の剰余合同として扱うため|N|=N.natAbsから二局所値を作る。二局所値は自動的にgcd上で一致し、再合成値は|N|と法lcmで一致する。符号を局所剰余から復元する主張はしない一方、

    glue(|N| mod m, |N| mod n) ≡ 0 (mod lcm(m,n))
  ↔ (lcm(m,n):Int) ∣ N

    は元の符号付き整数Nについて必要十分。負値・零を含む実観測列の整除判定が失われない。

    初回CIのrintro ⟨x,hx,hy⟩で、既に分解した合同条件にさらにhx.1・hx.2を適用したLean4 projection errorを、hx・hyに修正。命題・仮定を弱めず15定理を検証した。

    3. Qi v4.39：真正北C60への接続¶

    実際の元F55 Type値fからの既存P92B整数多項式の値、元F55/P77商qからの降下多項式値を別々に扱う。次数natDegree(P)≤dおよび明示的なlcm(m,n)∣d!の下、全j≤dの元GK5BQ整数分子はd!で割り切れるから、非互いに素な局所剰余の合成も法lcmでゼロとなる。仮定を隠して任意の二法でゼロになるとは主張しない。

    • 重なる二法m=2,n=6：gcd=2、lcm=6=(3!)。真正元primitiveP=1と元double inverse＋F55右単位P=X²は、4観測点{0,1,2,3}に拡張した双方の全係数でCRT零証明書を持つ。異なる元Type履歴を同一視しない。
    • 真正選択P92BループP=X³+2とQ=2X²+Xも、同じ4観測点・二法に対して別個のCRT零証明書を持つ。
    • 分離定理fivefoldGK5BTNorthBothOverlapZeroButOppositeSeams： 元primitiveとdouble inverseは双方gcd=2の重なり整合とlcm=6の大域算術再合成を満たすが、元original→phi seamは前者で存在、後者で不存在。この同じLean4定理により算術的gluingは元F55構造的seamの十分条件でない。
    • 単純な数値例ではx≡1 (mod 4), x≡2 (mod 6)はgcd上で不整合なので大域解がない。対照的にx≡1 (mod 4), x≡3 (mod 6)は整合し、正規化した大域代表はx=9とLean4で形式化した。

    Qi初回CIの唯一の失敗は、定義別名nativeGK5BTOverlapCompatibleのままdecideを呼んだ型クラス合成不足。合同式を実際の余りの等式にchangeで展開して計算し、17定理の条件・型付き主張を変更せず全検証を成功させた。

    従来の真正第五Dart物理C60 gauge、条件付き元P89 BadPair反射、元F54二Nat・二圏・Blocks、F55 Type値履歴を保持。数値のCRT整合性から新規F55 Type源、P77商類等号、P94A四セル、全GK5AY seam、W=1→seam、P89無条件反射、Gray圏復元、GK5BA kitを導出しない。

    4. 次の研究¶

    GK5BU（仮称）：二つの重なり法から、任意の有限局所被覆(mᵢ,aᵢ)へ拡張する。全ての重なりgcd(mᵢ,mⱼ)上のpairwise compatibilityと、lcmᵢmᵢ上の単一大域代表の存在／一意性を、順次中国剰余合成とČech型の局所・大域整合性として形式化する。構造的F55 Type値・P94A四セルのobstructionは独立に残す。現時点では次研究目標であり、成立済みとは記録しない。
