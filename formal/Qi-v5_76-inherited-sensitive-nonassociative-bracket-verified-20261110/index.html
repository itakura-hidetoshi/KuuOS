    真正継承葉を消去しない非結合構文¶

    v5.70の従来raw単位簡約括弧は、元のinherited(old18)葉も単位として消去する。この情報損失を分離する独立観測SelectedInheritedSensitiveRawBracketを元の真正Type値上に構造再帰で定義した。

    inherited old18       ↦ source
strict N              ↦ unit
whiskerLeft/Right A   ↦ B(A)
reverse A             ↦ reversed (B(A))
chain A C             ↦ join (B(A)) (B(C))
join unit t           ↦ t
join t unit           ↦ t
join s t (otherwise)  ↦ joined s t

    sourceは、任意の旧18D依存Type証拠の等式ではなく、継承葉が存在したという新しい独立構文原子。非単位元同士のjoinedには一般の結合則を課さない。実際の旧selected19の5構成子すべて、独立した新raw合同性の7構成子すべてで保存性を形式証明。特に旧unitPrepend／unitAppendはraw strict単位を挿入・除去するにすぎず、一般のrawchain結合則を与えない。新rawReverse・rawChainLeft・rawChainRightでも帰納仮定と構文変換の互換性を確認した。

    旧商と新商には別々のQuotient.liftで降下し、元の旧→新商projectionへの因子化を証明した。元Type18Dと独立旧・新Type19Dは変更も同一視もしていない。

    全v5.75観測一致と新しい商障害¶

    任意に実在する元17D端点Nについて、真正元SelectedContextualEighteenの厳密な構成子で同一N→Nの二証拠を作る。

    I = inherited (SelectedLocalEighteen.strict N)
R = reverse (strict N)
A = chain (chain I R) I
B = chain I (chain R I)

    両者は旧九観測、全次数の祖先塔Nat→Natと全次数の直接連続反転数塔Nat→Nat、完全ordered反転ラン列、v5.70の非結合単位簡約raw括弧、継承葉数（両方2）、元old18D根タグのordered列（両方[strict,strict]）、元old18Dの完全内部非結合構文リスト（両方[oldStrict,oldStrict]）、v5.74のordered反転位置葉数列（両方[0]）、v5.75の完全イベント語（両方[inherited,rawReverse,inherited]）まで一致する。無限塔の関数等式はfunext、次数別Nat.add_assoc、Prod.extにより証明した。Natの加算の結合則から元証拠のchain結合則は推論していない。

    新観測の値だけは以下で異なる。

    B(A) = joined (joined source (reversed unit)) source
B(B) = joined source (joined (reversed unit) source)

    二つの自由な非結合値はDecidableEqで異なり、新観測は実際の新7構成子商へ独立に降下する。従って真正の新商クラスが異なり、両証拠間の新19D Type値比較は存在しない。v5.75の全観測を新イベント語まで含めた結合商観測は、この真正同一端点N→N商上で非単射。新括弧と商クラスをその観測から復号する全域decoderも存在しない。

    認証境界と次段Qi v5.77¶

    証明は元の真正17D端点Nが与えられたN→Nfiberにおける局所非単射性である。任意の異端点J→Nfiberの非空性・同様の非単射性は主張しない。新しい継承葉保持括弧まで観測に加えた後、すべての実際の商クラスを完全に復元できるかも未認証（NO_DATA）。今回の二証拠は新括弧観測で区別されるので次段の反例に流用できない。
