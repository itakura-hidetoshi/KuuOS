    2. 独立GK5CF — 真正元F55の高次Pentagon境界¶

    GK5CEの5種の型可変多項式代入RingHom等式とは独立に、真正元F55の4つの合成可能なType値付き証拠f,g,h,kを、その元F54依存型始終端のまま次の5括弧付けとして構成する：

    (((f·g)·h)·k)
((f·(g·h))·k)
((f·g)·(h·k))
(f·((g·h)·k))
(f·(g·(h·k)))

    元P77の真正結合律四セル、左whiskering、右whiskering、逆転で五角形の5本のType値付き四セルを構成。上側3辺と下側2辺を別々の本物のP77四セル鎖として得て、それぞれ歴史的な7段old埋め込みで元raw-wrapper端点のP94A四セルへ移送した。

    正確な境界： 上下2本の四セル証拠は存在するが、その証明項同士の等式、pentagonatorの五セル、自然同型の無条件高次同一視は証明していない。元P77で得た5辺に沿ってNonempty(SeamAt(f))を移送でき、5頂点の局所original→再帰φ seam存在性が同値になる。全元F55証拠に一様に存在するGK5AY seamはGK5BBのno-goにより依然として不可能。

    GK5CEの数値RingHom Pentagonを、5等式からなるProp nativeGK5CFNumericalPentagonBoundaryとして明示し、実際の証明項nativeGK5CEFourPentagon_boundaryと区別した。高次比較条件nativeGK5CFPentagonHigherComparisonは、この数値Propと真正P94A local seamの存在の連言であり、数値Propが常に成り立つため、高次比較成立とlocal seam存在が必要十分。数値等式単独から元F55の証拠は復元できない。

    北C60の反例： 真正元pentagon primitivepは局所seamが実在する。一方同じ元F54 long→short Homの元F55symm(symm(p))は、選択φの元wrapper数N=1、符号付き個数S=1をprimitiveと共有しても、反転深度重みW=4対rawW=1の障害によりlocal seamは存在しない。両者の数値RingHom Pentagonが無条件に整合しても、高次Type証拠存在性は異なる。

    3. Qi v4.50 — 元符号付き北C60 signed CRTと実在する元F55五角形¶

    元GK5BQのnativeGK5BQClearedNumeratorに評価する4区間型可変多項式代入を用い、真の有限非互いに素CRT環同型・大域ZMod・局所gcd互換Subring・全被覆制限・三段塔のRingHom自然性を保持した。

    実際のsigned CRT RingHom等式を別のProp fivefoldGK5CFNorthSignedCRTRingHomBoundaryとして定義。その数値条件に独立GK5CFの真正元F55 local seam条件を重ね、元北sourcesrcに対して

    SignedCRT ∧ HigherOriginalPhiPentagon(src)
    ↔ Nonempty(SeamAt(src))

    を、独立したLean証明として成立させた。

    さらに、元F55 primitiveまたはdouble inverse ＋ 元F55の本物の右identityを3回という4要素の五角形を実際に作った。primitive側はP77/P94A右単位の真正四セル輸送によって5頂点すべてに個別seamを構成。double inverse側は同じく元F55/P77型付き証拠で移送を逆向きに適用し、5頂点全部のseamが成立することは不可能と証明。元P77五角形の存在そのものは両側で成立し、失われるのはoriginal→選択φの局所高次seamである。

    真正北C60の三段CRT環同型/被覆制限の等式が成立することと、double inverseの局所高次seam不存在が同時に証明された。数値CRTのdescentと元Type証拠のdescentは別のauthority・obstructionを持つ。

    4. Lean4修正記録と今後の課題¶

    GK5CF初回CIでは、nativeGK5CEFourPentagon_boundary ...という定理の証明項を∧の命題位置に置いたためLean4で型不一致を生じた。5辺のRingHom等式を別Propとして完全に定義し、元定理を証明項として使うよう修正。命題の弱化なし。変更Leanファイル全文・imports・依存定義・固定mathlib API照合後、再CI 9,319／9,319で成功。Qi v4.50も同じ区別を継承し初回exact-source CIで10,246／10,246成功。

    次GK5CG（研究課題）： 2経路の元P77四セルを証明項として保持したまま、どの追加の型付き五セル／高次比較証拠でpentagonatorが存在するかを検討する。元P94Aの19構成子に対する全域正規化、元P89 class mapの無条件反射、逆向きQi→独立Kuu、原始元F55証拠の数値CRTからの無条件復元は主張しない。
