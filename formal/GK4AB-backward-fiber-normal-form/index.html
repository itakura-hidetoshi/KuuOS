    権限境界と真正Type値経路¶

    形式証明Leanは、元F54DepthRotationRouteの真正Type値経路を保持し、元P92B比較証拠存在商Q、独立F54構造比較商S、実三成分第二商K_AA、旧二成分第二商K_Xを混同しない。すべての依存型F45 Hom境界、D/E二圏、四Blocks、二つのNat depthを保持。観測値一致から元P92B Type値3-cellを製造しない。

    I. 全依存型Hom上のkernelファイバー分類¶

    任意の真正F45型付き境界first,lastと、実K_X二段kernel商類qに対して、

    F_q := { z : K_AA(first,last) // ForgetBackward(z) = q }
beta(z) := (GenuineTripleKernelValue(z)).2 : Nat

    を定義。nativeGK4ABFiberBackward_injectiveはbetaの単射性を証明する。理由は、F_qでは旧二成分(Bool,Int)が固定されており、第三成分backwardCountまで一致すれば三成分観測値全体が等しく、既存のK_AA→三成分真正到達値の単射により実K_AA類が一致するため。

    より強くnativeGK4ABFixedFiberEquivRangeで

    F_q ≃ Set.range beta ⊆ Nat

    を真正Lean Equivとして構築した。特に任意の実二段目忘却ファイバーはCountableであり、元の任意D/E圏の一般Countableや真正14D無条件Countableは仮定しない。Set.rangeは実際に到達した整数だけで、すべてのNatが実現すると仮定しない。

    nativeGK4ABKernelBackward_composeで真正K_AA圏の合成に対するNat加法性と単位0を証明。S→K_AAに沿った第三成分もGK4Zの真正S backwardCountと一致する。

    II. 真正F54 balanced towerが正の全階層を尽くす¶

    任意の実rot : KuuNativeF45Tree.LocalRotation p before afterについて、GK4Zで元F54RotationEdge.forward・RotationEdge.backwardと実二Nat castDepths証拠から構成した自己経路塔R_kの真正K_AA商類をT_kと置く。

    O_X(R_k) = (false,-2)         -- 旧K_Xで全段同一
O_AA(R_k) = ((false,-2),k+1) -- 新K_AAで全段異なる
beta(T_k) = k+1

    F := ForgetBackward^{-1}([R_0]_{K_X}) は、元二段商における真の型付きファイバー。本GK4ABで、任意z : Fについて

    beta(z) = 0
   OR
exists k : Nat, z = T_k

    および

    (exists k, z = T_k)  IFF  beta(z) > 0

    を形式化した。これは無限個の単射例を持つというGK4AAより厳密で、正の全逆回転数での完全なファイバー正規形である。

    III. 唯一残るゼロ階層 obstruction の必要十分条件¶

    nativeGK4ABLocalFiber_zero_uniqueにより、beta(z)=0を満たす実F商類は存在したとしても高々1つ。

    nativeGK4ABLocalFiber_backward_rangeは正確に

    range(beta) = {n : Nat | n > 0 OR (n = 0 AND exists z:F, beta(z)=0)}

    と証明。nativeGK4ABLocalFiber_tower_surjective_iffは

    Surjective(T : Nat -> F)
  IFF
forall z : F, beta(z) != 0

    を証明。右辺が成立すればnativeGK4ABLocalFiber_tower_bijective_if_no_zeroで真正元F54 balanced towerの全ファイバー上の全単射を得る。

    重要：beta=0の実類が存在しないことはGK4ABでまだ未証明。 したがってファイバーが本当にNatそのものと同値であるとの無条件主張はしない。可算無限性自体はGK4AAで既に証明済み。真正C60北側六角形についても、本GK4ABの正値正規形の無条件な特殊化を検証した。

    次段階GK4AC：物理回転の向きと単調rank¶

    beta=0でもO_X=(false,-2)となる実F54自己経路が存在するかを判定する。候補は、F45の二分木で左枝の葉数を使った自然数のrankWを構成し、真正前向きLocalRotationではWが厳密減少、castDepthsでは不変、左右文脈では単調性保存と証明すること。これによりbackwardCount(r)=0の元F54型付き自己経路でrotationCount(r)>0が不可能となれば、ゼロ障害が排除され、Nat ≃ Fを無条件で得る。ただしこれはまだ証明されていない研究方針である。

    GK4AA→GK4ABはK_AA→K_X忘却の厳密分類。S→K_AAの全域忠実性は依然未証明で、別の問題として保持。元P92B Qの結合律・左右単位、歴史的完全型付き同値、真正14D無条件Countable、19D filler、global strict n、hyperdescentも未証明。strict空中心、独立Kuu一presentation、Gray非再導入、公開root107、保護PR #1558 Draft/OPEN/未マージ、append-only/tighten-only/same-root/overwrite-forbiddenを保持。
