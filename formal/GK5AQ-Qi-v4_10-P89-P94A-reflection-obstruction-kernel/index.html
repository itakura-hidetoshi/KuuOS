    1.1 The actual typed obstruction¶

    Let f,g be original F55 Type-valued 3-proof terms on exactly the same genuine F54 two-Nat source/target trees and route endpoints, and φ the constructor-recursive GK5AI map into P92B.

    BadPair(f,g) :=
  Nonempty (P94AFourCell (φ f) (φ g))
  ∧ ¬ Nonempty (P89FourCell f g).

    nativeGK5AQBadPair is a statement about genuine four-cell evidence, not shadow equality, false conflation of .original f with φ f, or a physical C60 Edge asserted to be an abstract NatIso.

    The source P89 quotient → selected P94A quotient map was unconditionally constructed by GK5AN. GK5AQ proves, at every correctly dependent typed F54 boundary:

    (∃ original f g, BadPair(f,g))
    ↔ ¬ Function.Injective(P89ToP94AFourClassMap).

    nativeGK5AQBadPair_iff_class_gap further characterizes a bad pair as two unequal original P89 classes with equal selected P94A images.

    1.2 Stable kernel and shadow invisibility¶

    The true bad-pair property is symmetric. If f~f' and g'~g in genuine original P89, then a bad pair (f',g') transports to a bad pair (f,g), via GK5AN's fully typed P89 4-cell lift.

    Every bad pair also satisfies:

    f.nativeShadow = g.nativeShadow

    for the entire original signed pentagon, signed square, and odd ZMod 2 phase triple. This uses genuine P94A four-cell shadow soundness and GK5AJ structural preservation. The numerical/full signed observer is therefore incapable of distinguishing a bad pair, if such a pair exists. The theorem does not manufacture a bad pair from coincident shadows.

    1.3 Why the three P94A unit primitives are not automatically bad¶

    GK5AO/GK5AP proved separate irredundancy of all three selected P94A primitives (horizontalUnit, leftContextUnit, rightContextUnit), relative to the existing P94A presentation.

    But the original P89 already embeds all three corresponding P80 unit 4-cell witnesses. GK5AQ constructs original P89 witnesses and selected P94A witnesses for all three source primitive families, and proves none is a BadPair. A counterexample to old P93→new P94A faithfulness cannot simply be substituted into the different original P89→P94A map. Extra, genuinely nonreflecting comparisons remain to be found or excluded.

    1.4 The distinct P92B associator-naturality obstruction¶

    On the actual north C60 first three F45 stages, the selected P92B assocNaturality constructor has genuine proof evidence, whereas the original F55 associator-naturality source type is uninhabited, by the independently proved original no-go.

    Thus the original F55 → P92B proof-term structural φ map is not surjective at that exact typed slot and no total function reconstructing old original F55 evidence from all selected P92B evidence of that slot can exist. This rules out a naive global inverse-on-witnesses argument, but by itself does not show noninjectivity of the original P89→P94A four-class map.

    The initial GK5AQ Lean attempt used ¬(Selected → Original), which is ill-typed because Selected → Original : Type and Lean's negation requires a Prop. The corrected exact-source definition uses ¬ Nonempty (Selected → Original); it compiled without changing the mathematical obligation or relying on sorryAx.
