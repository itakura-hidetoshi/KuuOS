    追加した観測：最大strict-only枝のraw chain左右経路¶

    元の真正依存証拠 SelectedContextualEighteen W l r J N の上に、SelectedStrictChainSide（left／right）と、raw chainの外側から内側へ進む左右経路と最大非自明strict-only非結合木との対 SelectedStrictBranchPath = List SelectedStrictChainSide × SelectedStrictOnlyChainTree を独立に定義した。

    SelectedStrictBranchPathSummary は次の二成分を保持する：

    pure : Option SelectedStrictOnlyChainTree

    sites : List SelectedStrictBranchPath

    chainの左右が両方pureなときは一つの新たな最大joined枝を経路[]に記録する。それ以外では、左由来のすべての最大枝のアドレスにleft、右由来にはrightを先頭に付し、列を順序付き連結する。reverseおよび元whiskerLeft／whiskerRightはpure根を終了させるが、raw chain左右経路自体は変更しない。旧18D継承葉やraw strict単体からは非自明pure鎖を作らない。

    この観測の保存性を、真正旧selected19の全5比較構成子と、新selectedRawCongruentNineteenの全7比較構成子のそれぞれについて型付き証拠の帰納法で証明した。元のunitPrepend／unitAppendは真正inherited葉に隣接する単独strictの挿入・削除に過ぎず、strict-only鎖の左右位置の一般的同一視ではない。

    旧5構成子商と新7構成子商へそれぞれ独立したQuotient.liftを実装し、旧→新商射影に関する因子化を証明した。旧・新比較Type自体を同一視していない。

    真正18D証拠対：v5.78完全観測一致と新左右位置の相違¶

    任意に与えられた真正17D端点Nに対し、S = strict Nとして、元の真正18D構成子のみで同一N→N fiberの二証拠を定義した。

    A = chain (chain S S) (reverse S)

    B = chain (reverse S) (chain S S)

    両者は元の九観測、二本の完全なNat→Nat無限祖先塔・直接連続反転塔、完全ordered reverse-run、v5.70単位簡約非結合括弧、旧18D継承証拠の葉数・ordered根タグ・完全内部構文リスト、v5.74反転site列[0]、v5.75イベント語[rawReverse]、v5.76継承葉保持括弧reversed unit、v5.77最大strict-only枝形[joined leaf leaf]、さらにv5.78深度付き枝形[(0, joined leaf leaf)]まですべて一致する。無限塔は全次数の関数等式をfunextで確かめ、有限サンプルへ弱めていない。

    しかし新観測は次のとおり異なる：

    Path(A) = (none, [([left], joined leaf leaf)])

    Path(B) = (none, [([right], joined leaf leaf)])

    新左右経路観測は真正新7構成子商に降下するため、元の新19D商クラス不一致、二証拠を結ぶ真正新19D Type値比較不存在が従う。これを使って、任意に供給された真正17D端点NのN→N商におけるv5.78完全結合観測の非単射性、新左右経路を復元するdecoder不存在、真正商クラスを復元するdecoder不存在を証明した。単なるraw構文文字列不一致を商比較不能性の根拠としていない。
