    1. 宿題だった局所完全性¶

    v4.86では、真正元GK5CG保守的五セル値L₃(i),L₂(i)を両端とする新しい、元sourceとは別の六セル自由presentationを導入。v4.87では、その生六セル語の整数次数degreeを保持し、平行な語を次数一致で商化。v4.88では実元五セル構成子語の厳密不一致L₃(i)≠L₂(i)を使い、次数が端点ポテンシャル差で決まり、その商がthinになると証明した。

    v4.89で元六セル語の両方を添字とする別帰納Type SevenRewrite W l r c d を追加し、13種類の明示的局所書換え履歴を構成した。ただし商で等しい任意の平行六セル語間に、この13規則だけによるType値書換え証明が存在するとは未証明だった。

    v4.90では、その逆方向を形式証明した。 元sourceの実値の厳密不一致を条件として使い、全ての新六セル生証明語を、具体的な七セル局所書換え履歴で三形の正規語に送る。

    2. 反転・合成の型付き正規形書換え¶

    正規形はv4.88で定義した EndpointNormal 三形のみ：

    [ 1_w,\qquad p:l\Rightarrow r,\qquad p^{-1}:r\Rightarrow l. ]

    sevenInverseNormal は正規六セルの反転を、inverseId、refl、doubleInverse の七セル構成子を用いて正規語に送る。

    sevenComposeNormals は、型付き中間端点を保存したまま、三形同士の合成を局所書換えで正規化する。左／右単位、p;p⁻¹の右消去、p⁻¹;pの左消去のみが必要となり、l≠rから同方向p;p、p⁻¹;p⁻¹の結合可能性を排除する。後者の排除は定義の捏造や公理ではなく、依存型と元二端点不一致に由来する。

    sevenEndpointNormal_unique は、同じ始終点を持つ三形の正規六セル語が生の構文として厳密一致することを、既証明の端点次数と三形の全場合分けから証明する。全生六セル語が厳密等しいという意味ではない。

    3. 帰納的な全語正規化・履歴保存¶

    sevenRaw_existsNormalTrace は任意の新自由六セル語cについて次の型付き証拠を構成する：

    [ \boxed{ \exists d,\; \mathrm{EndpointNormal}(d)\;\land\; \mathrm{Nonempty}(\mathrm{SevenRewrite}(c,d)). } ]

    証明はcの4構成子refl、pentagon、symm、transに対する構造帰納である。帰納仮定で得た局所七セル履歴をcongrInv／congrCompに通し、反転／合成の局所正規化証明とSevenRewrite.transでつなぐ。次数商のEqを七セルの証拠として持ち込んでいない。

    sevenRaw_toSelectedNormalではv4.88の選択正規代表への具体的七セル履歴も証明する。代表選択はClassical.choose由来だが、実際の書換え履歴は定理上Nonempty (SevenRewrite ...)として保持される。

    4. 完全性と三層の権威境界¶

    二端点l≠rの条件下、任意の平行な生六セル語c,dについて、両者をそれぞれ正規化し、正規代表の厳密一致を経由して七セル履歴を合成する：

    [ \boxed{ \forall c,d:w\Rightarrow z,\quad \mathrm{Nonempty}(\mathrm{SevenRewrite}(c,d)). } ]

    sevenRaw_allParallel_existsRewrite がこの強い結果を証明。v4.89の全局所書換え次数健全性と合わせて sevenRewrite_complete_iff_degree により、

    [ \boxed{ \mathrm{Nonempty}(\mathrm{SevenRewrite}(c,d)) \;\iff\; \deg(c)=\deg(d). } ]

    さらにsevenRewrite_complete_iff_quotientはv4.87の選択した次数商でのhomMk c = homMk dとの必要十分を形式証明する。sevenRaw_equalityHistoryQuotientは

    [ (c=d){\mathrm{raw}} \;\Longrightarrow\; \mathrm{Nonempty}(\mathrm{SevenRewrite}(c,d)) \;\Longleftrightarrow\; ([c]=[d]){\mathrm{quot}} ]

    の各型を明示する。v4.89のsevenRewrite_noStrictInterpreterを再利用し、完全性が成立しても、新七セル書換え全体を元の生六セル証明語の厳密等式に戻す解釈は存在しないとsevenComplete_stillNoStrictReturnで証明した。

    5. 真正P77全raw添字への接続¶

    元GK5CG保守的五セルTypepentagonFinalConservativeLoopにおける、任意の真正最終raw index i と元の二端点L₃(i),L₂(i)を使用する。

    • pentagonActualSevenRewrite_allParallelComplete：任意の平行六セル生証明語に実Type値七セル書換え履歴が存在。
    • pentagonActualSevenRewrite_completeIffQuotient：この書換え存在と、選択次数商の等式が必要十分。
    • pentagonActualSevenRewrite_completeWithSourceObstruction：完全性と元五セル厳密等式への一般descent不能が同時に成立。

    元F55/P77/GK5CGには新しい六／七セル生成元を追加せず、元のcharge +1 no-goやv4.85五セル語不一致を上書きしない。新presentationでのType値比較成立と、旧sourceのEqは別問題である。
