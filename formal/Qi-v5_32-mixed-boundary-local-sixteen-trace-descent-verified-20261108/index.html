    2. 真正double-whiskerの二端点境界証明書¶

    v5.31の二つの15D輸送L(R(T))／R(L(T))は元の14D境界の依存型が一般に異なる。 したがって未証明の同一視を避け、元v5.18のdoubleWhiskerから、 v5.27選択12Dへの二段previousを経て構成可能な SelectedMixedLowerBoundaryPacketを追加した。

    これは元第六セル境界が厳密に整合する真正第七セルleft,rightと 元第十一セル証拠F,Gを引数とし、 11D始点・終点の両方に対して実際の12D境界橋を保持する。 selectedMixedLowerBoundaryQuotientsは両端での選択12D商クラスの一致を証明する。

    重要な境界： この証明書は真正な下位11D端点の互換性を保証するが、 異なる依存14D境界を同一視する証拠でも、二つの15D混合輸送の 任意16D比較でもない。必要な上位coherenceは未証明のまま明示する。

    3. 左右二重輸送の順序履歴と粗い計数¶

    元v5.31の順序付き15D外側文脈観測を保存し、新しい selectedFifteenTraceCounts : List Bool → Nat × Natを定義。 これはfalse（左）とtrue（右）の各出現回数のみを記録する。

    任意の元六セル境界適合15D証拠Tと真正外側左右七セルについて、

    [ \begin{aligned} \mathrm{Trace}(L(R(T)))&=[\mathrm{false},\mathrm{true}]\mathbin{+!+}\mathrm{Trace}(T),\ \mathrm{Trace}(R(L(T)))&=[\mathrm{true},\mathrm{false}]\mathbin{+!+}\mathrm{Trace}(T) \end{aligned} ]

    は等しくない。一方、左右の出現回数は双方とも1ずつ増え、 selectedFifteenMixedCountsEqualが粗い計数の一致を形式証明。 selectedFifteenMixedCoarseFineSeparationは同一計数／異なる順序履歴 を一つの定理に統合した。両15D証拠自体のEqは依存型が異なるため主張しない。

    4. 真正な局所第十六セル生成元¶

    旧v5.30の本物の15D局所単位比較を用い、往復・逆往復の15Dループを構成した。 それぞれstrictと厳密に同じ14D始終点を持つが、 新しいselectedFifteenFirstAtomTagで 前者はタグ0、逆往復は4、反射は3と識別され、 selectedFifteenUnitRoundtrip_rawDistinct／ selectedFifteenReverseRoundtrip_rawDistinctがraw非等号を証明した。

    独立したSelectedLocalSixteenでは、真正に型付きの unitRoundtripLeftとunitRoundtripRightのみを新規非自明生成元として選択し、 strict/reverse/chainによって閉包した。

    [ \boxed{ \mathrm{Roundtrip}{15} \xRrightarrow{\mathrm{selected\ 16D}} \mathrm{Strict}{15} } ]

    これは明示的に選択した局所16D comparisonであり、 旧15Dのraw Eqでも、左右二重輸送の全面的16D exchangeでもない。

    5. 第十五セル商での選択的降下と非降下¶

    selectedSixteenSetoidは、全く同じ14D始終点を持つ15D raw証拠上に 「選択16D比較が存在する」という同値関係を定義した。 selectedSixteenClass_eq_iffは15Dの商クラス等号と 型付き16D比較の存在との同値を証明する。 局所16D生成元から15Dループと反射がこの商で一致する。

    selectedSixteen_preservesTraceは新しい16D構成子の全体について 元v5.31の外側順序付きList Bool履歴が保存されることを証明。 そのためselectedSixteenTraceOnQuotientは真正なQuotient.liftとなり、 selectedSixteenTrace_onClassで元値を再現する。

    一方、局所16D比較がタグ0の15Dループをタグ3の反射へ接続するため、 selectedSixteen_noFirstTagDescentは raw15D先頭構成子タグの商への降下が不可能なことを否定存在定理として証明。 ここでは順序付き外側履歴は降下可能、先頭構成子タグは降下不能という 二種類の観測のauthority境界が数学的に確定した。

    さらにselectedSixteenMixedOrderTraceObstructionは、 異なる14D依存型に属する左右二重輸送の16D商クラスに対して 共通のList Bool値として観測した順序差が残ることを証明。 selectedSixteenMixedOrderCountAgreementは その粗い左右計数が等しいことを別途証明する。 異なる商クラス自体を同一Type値として比較する主張はしない。

    6. 既存authorityの保存とQi v5.33¶

    元F55/P77/GK5CG、旧6D〜14D証拠、v5.32以前の選択型・元の厳密Eqは不変。 今回は「下位11D互換性の真正証明書」「局所16D単位比較」 「15D商への順序履歴の降下」「rawタグの非降下」を結合した成果である。 任意の二重文脈15D輸送の16D自然同型、上位境界の全面的なgluing、 元sourceへの自動descentは未証明。

    次段Qi v5.33：左右二重15Dの異なる14D依存境界を接続できる 実際の13D/14D comparison packetの存在可能性を検査。 橋が構成できない場合は、新生成元で強引に埋めず、 必要条件とobstructionを別々に形式証明する。 併せて16Dの局所比較を再文脈化したときに保存される観測と 新たな17D coherenceの必要性を評価する。
