    2. 独立GK5CC — 任意有限長・型付き代入鎖の真正RingHom構成¶

    元GK5BW／BX／BZ／CA／CBを型付き継承。任意の変数型族α : Nat → Type uと、各段の真正整数多変数多項式代入steps i : α i → MvPolynomial (α (i+1)) Intを用いる。

    nativeGK5CCTypedChainHom steps start length :
  MvPolynomial (α start) Int →+*
  MvPolynomial (α (start + length)) Int

    長さ0ではRingHom.id、長さlength+1では型付きnativeGK5CCStepSubstitutionHom (steps (start+length))を直前までの鎖に合成する。変数の型も個数も途中で変化してよく、同一型への単純な反復写像に退化させない。

    これを元の大域ZMod L_sと本物の互換局所R_sのMvPolynomial.eval₂Homへ合成する。全有限長について、後続1段の大域／局所逐次評価、CRT環同型の厳密RingHom自然性、任意有限被覆の大域／局所制限RingHom自然性、三段u⊆t⊆sの全体RingHom可換性が証明された。初期変数を任意非単射f : σ → α startで再分類しても三段図式は可換。終端zs : α(start+length)→Intは元整数環で代入鎖を評価してからZMod L_sへ射影する値と一致する。法0、空被覆、空変数、負係数、非互いに素を排除しない。

    3. Qi v4.47 — genuine north signed C60と元F55 Type境界¶

    各段の変数型をFin (arity i)とし、arity : Nat→Natは任意とする。元のfivefoldGK5BZNorthSignedCoordinatesは各終端変数に、元GK5BQのnativeGK5BQClearedNumerator d (indices v) values : Intを符号付きのまま割り当てる。新しい元F55 TypeソースやnatAbs代理は作らない。

    任意有限長の真正代入鎖について、元Int評価・大域ZMod L_s評価・gcd互換局所CRT Subring評価・CRT環同型・一段／三段被覆制限・任意非単射初期変数再分類を型付きLean定理で接続する。

    二つの真正元F55 Type証拠（primitive P=1とdouble inverse＋元右単位P=X²）は、同じ数値的有限CRT鎖の自然性を満たしても、元original→phi構造的seamの判定はそれぞれ存在／不存在となる。既存条件2≤dおよびL_s ∣ d!で保証されるCRT零は、元のP92B整数深度多項式についての条件付き算術定理に限定され、任意の外側代入多項式の零を意味しない。数値gluingからF55 Type源、P77等号、P94A四セル、無条件P89反射、普遍GK5AY seam、W=1→seamは導かない。
