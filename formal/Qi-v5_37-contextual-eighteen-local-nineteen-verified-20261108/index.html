    2. 真正18Dの独立文脈閉包¶

    新規SelectedContextualEighteenは、v5.35の元SelectedLocalEighteenのType値証拠を inherited構成子として保存する。 oldEighteenToContextual_injectiveはこの埋込みの単射性をLean4で証明している。

    残るwhiskerLeft、whiskerRightは真正SevenRewriteとContextFrameElevenの 依存添字が一致する場合にだけ許される。strict／reverse／chainを併せた 6構成子すべてについて、

    selectedContextSeventeenTrace l r J =
  selectedContextSeventeenTrace l r N

    をselectedContextualEighteen_preservesSeventeenTraceで証明した。 これは粗いイベント計数ではなく、List Boolの順序付き完全履歴である。

    新しいselectedContextEighteenSetoidは、厳密同じ16D端点を共有する 平行17D生証拠を、選択18Dの具体的な比較TypeのNonemptyで商とする。 selectedContextEighteenClass_eq_iffは商クラスの等号と実際の18D比較の存在を同値にし、 selectedContextEighteenTraceOnQuotientはQuotient.liftで完全な履歴を商へ降下させる。 これはv5.36の局所18D商とは別の選択商であり、同じ元証拠のraw Eqを主張しない。

    3. 真正型付き局所19D単位比較¶

    SelectedContextEighteenTraceではなく、正確な定数名 selectedContextEighteenTraceで生18D証拠自体の外側文脈履歴を観測する。 inherited／strictは空履歴、左右whiskeringは順序付きfalse／trueを前置し、 reverseは履歴を保存、chainは履歴リストを連結する。

    新しい独立SelectedLocalNineteenは以下の5種類の構成子のみを持つ：

    • strict：同一の真正raw18D証拠の反射。
    • unitPrepend：任意の真正旧18D証拠 M : SelectedLocalEighteen W l r J N に対して chain (strict J) (inherited M) と inherited M を、同一17D端点内で比較する。
    • unitAppend：chain (inherited M) (strict N) と inherited M の同型の局所比較。
    • reverse／chain：その型付き局所比較だけの反転・合成。

    selectedLocalNineteen_preservesEighteenTraceは上記5構成子の構造帰納により、 始終点の完全な順序付きraw18D外側履歴が等しいことを証明する。 selectedNineteenSetoid・selectedNineteenClass_eq_iffで真正同一17D fiberの 19D証拠商を定義し、selectedNineteenTraceOnQuotientで完全履歴を Quotient.liftとして降下させた。

    4. 局所19D商でのrawタグ非降下¶

    左側の具体的critical pair A = chain (strict J) (inherited M)、B = inherited Mは 新しい選択19D比較Typeで比較可能なので [A]₁₉=[B]₁₉ である。 しかし生の18D構文先頭タグは

    selectedContextEighteenTopTag l r A = 5
selectedContextEighteenTopTag l r B = 0

    となる。 selectedNineteenUnitPrepend_rawDistinctは A ≠ B を、 selectedNineteen_noRawEqualityInterpreterは選択19D比較をraw Eqへ解釈できないことを、 selectedNineteen_noTopTagDescentは生の先頭タグを忠実に再現する商上関数が存在しないことを形式証明した。

    したがって同じ局所19D商で、

    • 順序付きの外側文脈履歴は降下可能。
    • 生18Dのトップ構成子タグは降下不能。

    この両立が数学的に確定している。

    5. authority境界・限界¶

    • v5.36のSelectedOuterSwapClosureは共通List Bool観測空間上の隣接交換商であり、今回の18D/19D証拠商とは別の同値関係。
    • 観測swapでLR/RLが一致しても、依存型の異なるraw17D/18D証拠の同一視にはならない。
    • 真正下位12D〜14D比較パケットだけでは異なる高次fiberの端点同一性は導けず、v5.34のtrace保存型高次gluing gate障害も解除されていない。
    • 新しい19D単位比較は厳密同一17D端点の局所生成元であり、任意の混合19D交換・全面的Gray coherenceを主張しない。
    • 元証拠、旧定理の仮定、Lean/mathlib pin、public root107、保護#1558は不変。

    6. 次段Qi v5.38¶

    • 真正18D左右文脈の二重transportを別々の依存fiberに保持して構成する。
    • 各fiberの19D商から共通観測List Boolおよび有限swap商への写像を、元の証拠の履歴を失わずに接続する。
    • source-level比較へ進むための追加の境界同一性／transport証拠を必要十分条件として検討し、不足時には具体的obstructionを提示する。
    • 元raw Eq、異種依存fiberの無条件接合、弱い仮定への置換をしない。
