    全次数連続反転数：元依存Typeへの定義と商への保存¶

    新定義 selectedContextEighteenTopRunLength は、生の外側に連続して現れるraw reverseの長さを再帰的に数える。外側がchain・strict・inherited・whiskerの場合は0である。

    selectedContextEighteenConsecutiveRunCount l r d A は、長さd+1の直接連続したraw reverse部分列の出現数を元18D証拠Aで構造再帰により数える。reverse Aのとき、内側の計数に if d ≤ topRunLength(A) then 1 else 0 を加える。chainは左右計数の和、whiskerは内側の計数を保存し、元のType値と証明履歴を失わない。

    このNat全次数の計数について、それぞれ別個の機械的構造帰納法で：

    1. 元SelectedLocalNineteenの5構成子すべてに対するtop-run lengthとrun-countの保存、
    2. 新SelectedRawCongruentNineteenの7構成子すべてに対する保存（rawReverseで帰納仮定とtop-run length保存を併用）、
    3. 旧selected19商と新7構成子商の別々のQuotient.liftおよび旧→新projectionとの因子化、

    を証明した。旧19D Type比較と新19D Type比較は別のpresentationのままであり、片方をもう一方と同一視していない。

    さらにd=1では、今回のrun-countが既存v5.53のAdjacentReverseCountと元18D Type値上で完全一致することを構造帰納法で検証した。低次数と既存の真正観測の対応を、単なる命名だけではなく明示的な証明にしている。

    具体的な全n反例族：全祖先塔の一致と次連続長の障害¶

    任意のn : Natと真正17D端点Nに対し、元のSelectedContextualEighteen W l r N N上でNat.recによりraw reverse反復R^pを構成し、S = strict N、gap(X) = chain X Sとして、

    A_n = R^(n+4) (gap (R^(n+2) S))    -- 連続ラン [n+4,n+2]
B_n = R^(n+3) (gap (R^(n+3) S))    -- 連続ラン [n+3,n+3]

    を真正Type値として定義した。定理では、次の等式を全自然数nと全次数dについて個別に証明している。

    ∀ k : Nat, C_k(A_n) = C_k(B_n)      -- 全無限祖先塔（Nat → Nat）
Trace(A_n) = Trace(B_n)
TopReverseFlag(A_n) = TopReverseFlag(B_n)
AdjacentReverseCount(A_n) = AdjacentReverseCount(B_n)
RunCount_d(A_n) = RunCount_d(B_n)    (d ≤ n+2)
RunCount_(n+3)(A_n) = RunCount_(n+3)(B_n) + 1

    両方のrun-countの明示式は、(n+4-d)+(n+2-d)と(n+3-d)+(n+3-d)（Natの切断減算）。d≤n+2で一致し、d=n+3で左1・右0となる。run-countの添字dが長さd+1を表すため、長さn+3以下では一致し、長さn+4で初めて相違する。

    全塔一致は、strict chainの挿入が真正祖先塔の各座標を変えないこと、raw reverseを同じ回数だけ反復した証拠間の全座標一致を保存すること、合計反転回数(n+2)+(n+4)=(n+3)+(n+3)という証明を接続している。有限サンプリングから無限への帰納的飛躍はない。v5.60の橋渡しで旧八観測を、さらにC_6によって九番目を一致させる。

    違いは新商に独立に降下済みのRunCount_(n+3)が証明するため、selectedRawCongruentClassの不一致および元証拠対に対する真正新19D Type比較の不存在を導いた。

    exact fiberへの輸送と非単射定理の範囲¶

    任意の異端点fiberの非空性を仮定で追加する代わりに、実在する元証拠M : SelectedContextualEighteen W l r J Nが供給された場合のみ、chain M A_n／chain M B_nを同じJ→N fiber内へ構成した。九変量・全祖先塔・短い連続ラン計数の等式、および次の計数の差1が保存されることを明示証明している。

    真正新商上の結合観測は

    Obs_n(q) : (selectedRawNineObservationValue × (Nat → Nat))
           × (Fin (n+3) → Nat)
Obs_n(q) := (NineFullTower(q), i ↦ RunCount_i(q))

    であり、既存九成分と全自然数祖先塔、および短い連続ラン数を同時に読む。与えられた実在Mの同一fiberで、このObs_nは非単射、次計数RunCount_(n+3)の全域decoderおよび商クラス全復元decoderは存在しない。指定された任意のJ→Jでは本来のstrict Jから具体的な同一fiber反例を得る。

    これは、任意の有限個の連続長計数＋全無限祖先塔を加えても、この形の真正商観測では完全識別できないという一様な結果である。一方、全自然数dのrun-countを同時に観測した場合の単射性については、今回の証拠対では次の計数で区別できるため、結論を出さない。

    未認証境界と次段Qi v5.69¶

    全run-count塔(Nat → Nat)と全祖先塔(Nat → Nat)を同時に持つ真の結合観測が、真正新商を完全識別するかは未認証（NO_DATA）。今回の[n+4,n+2]対[n+3,n+3]はそれぞれn+3次数のrun-countが異なるため、全run-count塔の反例に転用してはならない。次段は、全run-count塔の非単射性を示す新しい真正証拠対の探索、または限定されたfiber／構文クラス上での条件付き忠実性を調べるのが正確である。

    任意異端点fiberの非空性、異fiber whiskering、20D gluing、全WORLD大域貼合、全商分類および制度的権限も依然NO_DATA。元18D依存Type値、独立する旧selected19／新7構成子19D Type比較、公開root107、固定Lean/mathlib、保護#1558 Draft／OPEN／未マージを維持する。append-only／tighten-only／overwrite-forbidden／same-root。
