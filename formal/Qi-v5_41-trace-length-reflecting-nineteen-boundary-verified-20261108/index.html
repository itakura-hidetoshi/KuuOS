    2. 元の真正RL 18D証拠から作る非定数の証拠列¶

    真正元18D証拠 M の左右二重輸送を、それぞれ異なる依存17D端点fiber内の X = selectedEighteenLeftAfterRight(M)（LR）、 R = selectedEighteenRightAfterLeft(M)（RL） として保存する。元の証拠値を同一視せず、RL fiberで旧chain・reverse構成子だけによって

    P_R(0)   = R
P_R(n+1) = chain (chain P_R(n) (reverse R)) R

    を定義する（selectedMixedRightTracePower）。 selectedMixedRightTracePower_lengthが len(Trace(P_R(n))) = (2*n+1) * len(Trace(R)) をLean4で証明する。RL真正二重輸送の履歴長は少なくとも2（selectedMixedRightSeed_tracePositive）なので、nの異なる証拠列は少なくとも履歴長で識別できる。これは元の異fiber証拠Eqではない。

    3. 長さの単射符号化と実際の19D境界¶

    指定LR証拠 X の履歴長を base として、 selectedMixedLengthCode base n = if n = base then 0 else n + 1 を定義し、selectedMixedLengthCode_injectiveで自然数上の単射性を証明する。

    selectedMixedLengthRawTransport M X'は、LR source証拠 X' の外側履歴の長さを符号化し、RLの真正証拠列 P_R(code(length(Trace(X'))))へ送る。指定LR証拠 X は指数0に送られるため、像は元の真正RL証拠 R に一致する（selectedMixedLengthRawTransport_chosen）。

    selectedMixedLengthBoundaryはv5.39のSelectedMixedNineteenBoundaryの実際のinhabitantである。source側の真正SelectedLocalNineteen比較は全ordered traceを保存するため、sourceの長さ符号が一致し、像のraw値が一致する。これによりlocalTransportを輸送先の真正SelectedLocalNineteen.strict Type値証拠で構成できる。追加公理や無条件20D交換は使わない。

    selectedMixedLengthAnchoredは指定LR像とRL実証拠の間の真正19D比較も構成する。この局所的anchored比較から指定19D商クラス方程式と指定点のswap観測一致が得られる。ただし全sourceにわたるswap観測の自然性とは別である。

    4. 厳密に証明できた反映と、未証明の忠実性¶

    selectedMixedLengthRaw_reflectTraceLength： 輸送先で二つの像が真正19D比較を持てば、両sourceの外側履歴長は一致する。証明はRL証拠列の (2*n+1)*len(Trace(R))、正のRL種長、自然数上の単射符号化に依拠する。

    selectedMixedLengthDescend_reflectTraceLengthは、この反映を本物のQuotient.liftで作った異なる19D商間の写像へ降下させる。 selectedMixedLengthDescend_separatesByTraceLengthは、sourceの長さが異なる任意の二商クラスを像で同一視できないことを証明する。

    特に、指定LR真正証拠 X と元のchain (chain X (reverse X)) X は同一LR fiber内にあり、後者の外側履歴長は3倍。したがって selectedMixedLengthDescend_chosenVsRoundtripが、実際に存在する二クラスの像の非等号を証明する。v5.40の定数境界とは異なり、この境界は19D商上で非定数である。

    未認証（NO_DATA／obstruction）： 同じ履歴長で内容が異なる元19D比較をすべて反映するSelectedMixedNineteenFaithfulBoundary.reflectLocalの具体的inhabitant、raw18D全証拠の単射、完全ordered trace全体の反映、全域のswap自然性、元の異依存fiber高次交換／20D gluing。長さの反映だけからこれらへ大域化しない。

    5. CI失敗・修正の構造理由¶

    最初の定理CI #42476709502では、sectionの暗黙の従属引数を含む再帰定義を明示的に再呼出しした際に、Lean4がl : WをRL raw18D証拠引数として扱う型不一致が発生した。これが長さ補題の基底・帰納ケースのdefinitional equalityに波及し、失敗した宣言のsorryAx診断も生じた。

    旧sourceの定義や仮定を変えず、selectedMixedRightTracePowerを同じ真正chain/reverse/chain証拠列を作るNat.recの式へ正規化した。基底ケースはsimp [selectedMixedRightTracePower]で自然数の単位積を明示的に整理した。途中CI #42477098068はHEAD更新でキャンセルされ、認証根拠に採用しない。最新HEAD 1979dd65...のCI #42477185958で全9,093ジョブ成功し、15宣言でsorryAxなしを確認した。公式Pinned Lean配布のHTTP 504があっても検証条件を弱めない。

    6. 権威境界と次段¶

    Lean4で証明済み： 非定数のanchored LR→RL境界transportの実在、元の真正19D Type値比較の保存、19D商降下、指定点でのswap観測一致、全商クラスに対する履歴長の反映、指定LR証拠と3倍roundtripの像の分離。

    未認証： 同一長さ内の証拠区別をすべて保存する忠実性、全域swap自然性、元の異fiber20D交換セル。証明可能性の余地と既証明の不可能性を混同せず、obstructionを保持する。

    次段Qi v5.42： この長さ符号化が潰す可能性のある同長異履歴のfiberを調べ、元19D比較反映を実際に構成できる条件と、全域swap観測の互換性を別々に探る。証明できない部分はNO_DATAのまま残す。
