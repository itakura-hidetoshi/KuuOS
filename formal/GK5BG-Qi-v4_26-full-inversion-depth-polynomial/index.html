    F112-P94D3GK5BG／Qi v4.26 — 反転深さ生成多項式とP94A四セル障害¶

    元F55原始originalの選択P92Bsymm入れ子深さ分布を、MathlibのPolynomial Intそのものとして定義する：

    P(original(f))         = 1
P(refl(r))             = 0
P(assocNaturality(...))= 0
P(symm(u))             = P(u) * X
P(trans(u,v))          = P(u) + P(v)
P(horizontal(u,v))     = P(u) + P(v)
P(F45/F54 context(u))  = P(u)

    真正P93C全16構成子および選択P94A全19構成子のType値四セルについて P(u)=P(v) を帰納的に証明した。これには旧P89のoriginal両端、水平・縦貼合、interchange、P94A追加horizontalUnit／leftContextUnit／rightContextUnitが含まれる。

    既存の別々の整数／自然数不変量は、Mathlib Polynomial.evalによる正確な特殊化として次の全称定理で一致する（自然数は必要箇所で整数へcast）：

    P_f(1)  = N_f  (GK5BB unsigned original-wrapper count)
P_f(-1) = S_f  (GK5BE signed original-wrapper grade)
P_f(2)  = W_f  (GK5BF inversion-depth weight)

    既存GK5AJの真正元P77→選択P93C四セル移送と新しい多項式保存則を結び、P(phi(f))が実際のP77元F55四セル商上へ Polynomial Int値としてQuotient.liftされることを証明。単なるProp（存在性）や三数値shadowだけの降下ではない。

    元の局所直接seam P94A(original(f),phi(f)) が実在すれば、P(phi(f))=1 が必要となる。この多項式必要条件の十分性は証明していない。

    2. 同一北C60 Homにおける局所seam正負の多項式分離¶

    真正北C60のpentagon原始F55証拠pと、元F55二重反転c:=symm(symm(p))は、同一の元F54 long→short Homに属する。

    P(phi(p)) = 1
P(phi(c)) = X^2
P(original(c)) = 1
N(phi(c)) = S(phi(c)) = 1
W(phi(c)) = 4

    pの直接局所seamはP94A.reflで実在するが、cの直接seamは多項式保存則に反するため不存在。さらに同じHom内の元P77商クラスで、二つのPolynomial Int値が異なると証明している。旧N=S=1という弱い必要条件の十分性を否定したGK5BFを、値全体の比較に強化した。

    3. 三数値評価がすべて同じでも異なるP92B証拠¶

    元F55の真正identity wrapperを使い、同じF54 endomorphism route上の二つの実際の選択P92B Type-valued 3証拠A,Bを構成した。それらの生成多項式は

    P_A(X) = X^3 + 2
P_B(X) = 2 X^2 + X

    であり、同時に

    P_A(1) = P_B(1) = 3
P_A(-1) = P_B(-1) = 1
P_A(2) = P_B(2) = 10
P_A(0) = 2  !=  P_B(0) = 0

    が成立。よってN,S,W三数値観測が一致しても多項式全体が異なり、P94Aの全19構成子保存則から¬ Nonempty(P94A(A,B))をLean4で証明した。これらはあくまでも選択P92Bエンドループであって元F55original→phi局所seamの反例と取り違えない。
