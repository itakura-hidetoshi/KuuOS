    独立観測：strict-only鎖の最大非結合枝形¶

    元の真正 SelectedContextualEighteen W l r J N Type値上で、SelectedStrictOnlyChainTree（leaf、joined）を独立の自由構文として導入した。SelectedStrictOnlyBranchSummary は次の二成分を持つ。

    pure : Option SelectedStrictOnlyChainTree
branches : List SelectedStrictOnlyChainTree

    pureは証拠全体がraw strictとraw chainだけで構成されている場合の非結合構文木、branchesは真のraw証拠の各位置に現れる最大strict-only非自明鎖を順序付きで保持する。純粋なstrict単体は枝イベントとして数えない。chainにおける二つのpure木の連結は一つの新たな最大joined木を作り、いずれかがpureでない場合は既存branches列を連結する。元のreverse・whiskerLeft・whiskerRightはpure根を終わらせるが、内部枝形は保持する。inherited(old18)は新しいstrict-only枝を作らない。

    この定義が許される重要な理由は、元の旧selected19単位規則unitPrepend・unitAppendが、真正継承葉の直前・直後のraw strict単体だけを挿入／削除し、strict-onlyなchain(strict,strict)の結合形までは同一視しないことにある。旧selected19全5構成子、新selectedRawCongruentNineteen全7構成子に対する保存性を真正型付き比較証拠の帰納法で個別に証明した。新側のrawReverse・rawChainRight・rawChainLeftでもそれぞれのsummary変換との互換性を確認した。

    旧五構成子商・新七構成子商にそれぞれ独立したQuotient.liftを実装し、旧→新商射影との因子化も証明した。元証拠Type・比較Typeの上書きや新公理追加はない。

    全v5.76観測一致でも残る真正証拠対¶

    実在する任意の17D端点Nに対し、真正contextual18D Type値の構成子のみでN→Nの二つの証拠を構成する。

    S = strict N
A = reverse (chain (chain S S) S)
B = reverse (chain S (chain S S))

    両者で、元九観測、二本の全無限Nat→Nat祖先塔・直接連続反転塔、完全ordered reverse-run列、v5.70単位簡約非結合raw括弧、旧18D継承葉数（0）、ordered旧18D根タグ列・完全内部構文リスト（ともに空列）、v5.74 reverse-site inherited count列（ともに[0]）、v5.75 orderedイベント語（ともに[rawReverse]）、v5.76継承葉保持括弧（ともにreversed unit）のすべてが一致する。無限関数の一致には各Nat次数の等式とfunextを実際に使っている。

    一方、新しいstrict-only summaryは：

    Summary(A) = (none, [joined (joined leaf leaf) leaf])
Summary(B) = (none, [joined leaf (joined leaf leaf)])

    という二つの異なる自由非結合木になる。これは元の真正新七構成子商上で保存される不変量なので、商クラスが実際に異なり、両証拠を結ぶ真正新19D比較Type値は存在しない。単なるraw文字列の違いを商の違いと取り違えていない。

    従って、v5.76までの全観測をまとめた実新商観測selectedRawCongruentFullV576QuotientObservationは、真正に与えられた各17D端点N→N商上で非単射である。新summaryのdecoderと商クラス全体の逆decoderの存在も否定した。

    証明の境界と次段 Qi v5.78¶

    今回の非単射性は、真正17D端点Nにより構成された同一端点N→Nの元18D証拠fiberに限る。異端点J→Nfiberの任意の非空性や非単射性を無条件には主張しない。新strict-only枝形観測を加えた後の全商クラスの分類・完全復元・単射性も未認証（NO_DATA）。今回の二証拠は新観測で区別されるので、次段の反例に流用できない。

    20D gluing、WORLD横断降下、哲学的同一性、制度的・実行権限はいずれも未認証。append-only／tighten-only／overwrite-forbidden／same-rootを維持する。
