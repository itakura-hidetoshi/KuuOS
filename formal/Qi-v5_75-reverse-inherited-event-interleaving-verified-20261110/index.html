    Qi v5.75 — 完全反転位置観測の先に残るraw反転／旧18D継承イベント順序の障害（Lean4形式証明・公理監査）¶

    新しい独立観測E：真正rawイベントの交錯順序¶

    真の SelectedContextualEighteen W l r J N 証拠に構造再帰し、SelectedReverseInheritedEvent という独立の二値構文を定義する。元Type値の同一視・型変更ではない。

    inherited old18      ↦ [inherited]
strict N             ↦ []
whiskerLeft/Right A  ↦ E(A)
reverse A            ↦ rawReverse :: E(A)
chain A B            ↦ E(A) ++ E(B)

    旧selected19の全5構成子、新selectedRawCongruentNineteenの全7構成子で保存性を個別に形式証明。新rawReverseと両rawChainの文脈閉包にも整合し、旧商・新商それぞれに独立にQuotient.liftで降下する。両者が元旧→新projectionを通じて整合することを証明した。旧新19Dの比較Typeは相互に同一視しない。

    v5.74の完全観測一致と真正商の不一致¶

    任意に実在する元17D端点Nに対し、真正元contextual18Dの構成子で同じN→N fiberの二証拠を作る。

    R = reverse (strict N)
I = inherited (SelectedLocalEighteen.strict N)
A = chain R I
B = chain I R

    v5.73までの元九観測、全Nat次数の祖先塔・全Nat次数の直接連続反転数塔、完全ordered反転ラン列、単位簡約非結合raw括弧形、旧18D継承葉数1、旧18D根タグリスト[strict]、完全内部旧18D括弧リスト[oldStrict]がすべて一致する。さらにv5.74のordered反転位置継承葉数リストも両者[0]で一致する。

    しかし、新しい独立観測はE(A)=[rawReverse,inherited]、E(B)=[inherited,rawReverse]で相異なる。Eは実際の新7構成子商に降下しているため、両者の新商クラスは等しくなく、真正な新19D比較Typeも非空ではない。前段全観測を新site列まで合わせた関数 selectedRawCongruentDoubleBracketCountRootInnerSitesObservation は、各真正N→N商で非単射。イベント列と商クラスの全域decoder不存在も証明した。

    証明範囲は真正同一端点N→Nに限定される。任意のJ→N異端点fiberの非空性・同様の非単射性は今回の定理からは主張しない。元の証拠を破棄したり、raw構文の見かけ上の違いだけで商クラス不一致を推測したりしていない。

    初回Lean4失敗と修正経路¶

    初回exact-source CI #42722358470 はselectedReverseInherited_witnessRootInnerObservedEqのrfl一箇所で失敗。全観測の2本のNat→Nat関数を、raw鎖中のNat加算順が違うのに定義上同一としたことが原因だった。定理の仮定や元証拠には触れず、全次数の独立補題selectedReverseInherited_witnessAncestorTowerEq・selectedReverseInherited_witnessRunTowerEqを追加し、funextとProd.extにより真の外延的等式へ修正した。

    論理的境界と次段Qi v5.76¶

    この結果はv5.74完全観測の局所非単射性であり、v5.75の新イベント語まで追加した後の全商クラス分類・単射性は未認証（NO_DATA）。元old18D内部のType値全体の完全な再構成も証明していない。次段では新イベント語まで一致する真正証拠対があるか、あるいは構文を制限した部分に条件付き忠実性が成立するかを調べる。
