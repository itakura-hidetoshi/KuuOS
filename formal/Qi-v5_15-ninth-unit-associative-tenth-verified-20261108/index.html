    1. 九セル自由合成の単位律・結合律を独立第十セルとして補完¶

    Qi v5.14で検証済みの第十セル比較MixedInterchangeTenCellは、元P/M消去順序の交換のみを新原始とし、自由九セル合成の単位・結合律はまだ証明していなかった。

    今回、旧第十セル証拠すべてをpreviousで保持する独立Typeを構成した。

    MixedUnitAssocTenCell W l r alpha beta

    新規比較生成元はちょうど三種類：

    • 左単位：leftUnit alpha — chain (refl q) alpha と alpha の型付き第十セル
    • 右単位：rightUnit alpha — chain alpha (refl q') と alpha の型付き第十セル
    • 結合則：assoc alpha beta gamma — chain (chain alpha beta) gamma と chain alpha (chain beta gamma) の型付き第十セル

    残りは厳密な証拠のstrict、旧証拠previous、第十セルの向き反転・連鎖、九セル反転・連鎖、八セルの逆向き・連鎖・whisker・合成文脈の型付き閉包。新文法は全15種類の構成子を持つ。

    mixedUnitAssocTenCell_strictlyNewは、旧第十セル文法では比較不能だった真正元九セル反射2個の連鎖 vs 反射1個を新leftUnitで比較できることを示す。旧文法への普遍比較復元（mixedUnitAssocTenCell_noPreviousInterpreter）と生九セルstrict Eqへの普遍昇格（mixedUnitAssocTenCell_noRawEqualityInterpreter）はそれぞれ反証済み。

    2. 旧九セル自由chain不変量の降下不能性¶

    前段Qi v5.14でQuotient.liftへ降下していたNat値tenthResidualNineChainChargeは、自由九セルchain構文ごとに+1を数えていた。

    [ Q_{\mathrm{chain}}(1_9;1_9)=1,\qquad Q_{\mathrm{chain}}(1_9)=0. ]

    新第十セルのleftUnitにより両証拠は同一商クラスになった。このため、元の全生九セル証拠に同じ値を返す旧Qの忠実な新商への降下は存在しない。これはmixedUnitAssocTenthClass_noOldChainChargeDescentで形式証明した。

    旧比較の新商への降下はmixedInterchangeTenthClass_descendsToUnitAssoc、選択商の厳密な粗化はmixedUnitAssocTenthClass_strictlyNew。元証拠を消したわけではなく、観測量の許容範囲が選択した比較法則に依存することを証明した。

    3. 新たなP/M独立出現回数の完全な保存と真正降下¶

    元の九セルmixedCancelNinePrimitiveTraceは、真正な旧P消去と新M消去のイベントをtrue/falseで区別する。新観測量を

    [ N_P(\alpha)=#{\mathrm{true\ in\ trace}(\alpha)}, \qquad N_M(\alpha)=#{\mathrm{false\ in\ trace}(\alpha)} ]

    とした。

    mixedInterchangeTenCell_preservesCancellationCountは前段第十セルの全12構成子、mixedUnitAssocTenCell_preservesCancellationCountは新文法の全15構成子について、任意isP : Boolの保存則を構造帰納法で証明している。

    [ \alpha\Rightarrow_{10}\beta \Longrightarrow N_P(\alpha)=N_P(\beta)\ \land\ N_M(\alpha)=N_M(\beta). ]

    mixedUnitAssocTenthPCountとmixedUnitAssocTenthMCountは、実際のQuotient.liftによる二つの別個のNat値商観測者であり、代表元上の値もLeanで計算した。単に自由語の同じ書き方でしか成立しない宣言ではない。

    4. 単位・結合補完後にも残る二つの独立障害¶

    真正元のP消去およびM消去をそれぞれ往復させた生九セルループを構成した。

    [ \begin{aligned} \lambda_P&=\mathrm{Pcancel};\mathrm{reverse}(\mathrm{Pcancel}), &(N_P,N_M)(\lambda_P)&=(2,0),\ \lambda_M&=\mathrm{Mcancel};\mathrm{reverse}(\mathrm{Mcancel}), &(N_P,N_M)(\lambda_M)&=(0,2). \end{aligned} ]

    対応する各元八セル端点上の反射九セル1_9は(0,0)。したがって、 ninthOriginalPentagonLoop_noUnitAssocComparisonとninthOriginalMixedLoop_noUnitAssocComparisonで、各往復ループと対応する反射九セルとの新第十セル非比較性を形式証明。両者は別々の元八セル端点に置かれているため、両ループ相互の直接比較不能を主張しているのではない。

    これよりmixedUnitAssocTenCell_notGloballyThinでこの選択第十セルpresentationのglobal thinnessを否定した。元八セル側の自由chain由来の2対0非比較もmixedUnitAssocTenCell_retainsEighthObstructionで引き続き保存している。

    射程： 九セルの逆向きreverseを持っていても、対応する逆元消去の第十セル比較を今回新規追加したわけではない。後続のgroupoid-completionの可能性は排除しない。

    5. 真正第十一セルcritical overlap候補¶

    旧v5.14 P/M交換と新leftUnitを重ねると、次の二経路はまったく同じ生九セル始点・終点を持つ。

    [ \begin{aligned} \Theta_{E U} &=(\mathrm{exchangePM\ in\ left\ context});\mathrm{leftUnit},\ \Theta_{U E} &=\mathrm{leftUnit};\mathrm{exchangePM}. \end{aligned} ]

    真正な型付き十セル証拠はそれぞれ pmLeftUnitCriticalExchangeThenUnitとpmLeftUnitCriticalUnitThenExchangeで明示構成した。

    新しい生十セル構文tracemixedUnitAssocTenRawTraceにより、値はそれぞれ[false,true]と[true,false]。pmLeftUnitCriticalRawTenGapで生のType値としてstrict不等であることをLean4で証明した。

    これは第十一セル比較の候補を局所的に特定したものである。第十一セルの不存在・必然性・唯一性を証明したわけではない。

    6. 元P77/GK5CG真正証拠境界¶

    pentagonActualNineUnitAssocTenthCompletionは任意の真正P77 final raw indexについて、元GK5CG long/short Type値から九セル左単位第十セルを実現すると同時に、元PentagonAdjoinedSixCellEqualityInterpreterの不存在を保持した。

    元F55/P77/GK5CG、旧六・七・八・九・十セル定義、公理・固定toolchainは一切変更しなかった。新商等号を元sourceのstrict等号には昇格させない。

    7. 次段Qi v5.16¶

    優先する第十一セル候補は、今回構成した交換→単位と単位→交換の二つの生十セル経路を結ぶ、独立した型付き比較とする。新比較後に、元十セル構文のどの履歴が商へ降下しなくなり、何が残るかを再度証明する。
