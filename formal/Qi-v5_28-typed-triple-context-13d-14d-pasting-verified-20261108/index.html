    2. 元の第七セルを三回重ねる、二つの貼り合わせ¶

    元の六セル境界が厳密に合う三つの独立した第七セル証拠

    [ u:a\Rightarrow b,\quad v:b\Rightarrow c,\quad t:c\Rightarrow d ]

    および真正の元第七〜第十一セル証拠値F : ContextFrameEleven W l r d eを固定する。 元第十一セルへのcontextFrameLeftを三回適用することで

    [ X=L_u(L_v(L_t(F))) ]

    を構成する。次の二つの元第七セルの括弧付け履歴は別々に保持する：

    [ Y_L=L_{(u\circ v)\circ t}(F), \qquad Y_R=L_{u\circ(v\circ t)}(F). ]

    selectedLeftTripleInnerPasting はX\to Y_R、selectedLeftTripleOuterPastingはX\to Y_Lの具体的な元選択12D証拠を作る。右文脈についても独立にselectedRightTripleOuterPastingとselectedRightTripleInnerPastingを構成。各証拠はv5.27の実際のcompLeft/compRightを使い、必要な箇所ではwhiskerLeft/whiskerRightによって前後文脈へ運ぶ。

    重要なauthority境界として、Y_LとY_Rを元の生の第十一セル証拠としてEqに置き換えてはいない。両者はそもそもSevenRewrite.transの括弧付けが異なる。

    3. 新しい第十二セル生成元を追加しない、型付きrebracketing¶

    selectedLeftTripleRebracketは、真正の既存12D証拠のreverseとchainから

    [ \boxed{Y_L\xRightarrow{\;12\;}Y_R} ]

    を組み立てる。右文脈も同様である。この12D橋は元の選択12Dの反転・合成から導出され、別の12D associator生成元ではない。

    二つのパスは、左では

    [ P_L:X\to Y_R,\qquad Q_L:X\to Y_L\to Y_R ]

    であり、右でもP_R,Q_Rを型付きで構成する。 ここでQ_LにはX\to Y_L\to X\to Y_Rという明示的な戻り道が含まれる。これは真正の12D文脈経路履歴であり、単に第七セル構文の結合則を仮定しているわけではない。 selectedLeftTriple_rawDistinctとselectedRightTriple_rawDistinctは、両経路の生の12D証拠値が一致しないことを証明した。

    4. 独立選択第十三セルと元v5.23の保持¶

    SelectedTriplePastingThirteen W l r P Qを、始終点が一致する実在v5.27選択12D経路の間の新規比較Typeとして構成する。新しい局所比較は、真正三連の左・右文脈の2系列に限るtripleLeft/tripleRightである。strict/reverse/chain/prepend/append/associatorの型付き構文閉包も明示した。

    originalFramedTwelveToSelectedは旧v5.23の真正framed12D値をv5.25・v5.27の2段のpreviousで保持し、originalThirteenToTripleは実際のCompositionalWhiskerThirteen証拠値を新TypeのinheritedOldに保持する。いずれの生証拠埋込みも単射を形式証明。

    selectedTripleLeft_higherWitnessとselectedTripleRight_higherWitnessは、選択13D比較の存在と元の12D生経路の非等号を同時に証明する。 selectedTripleLeft_noRawEqualityInterpreterは、当該選択比較をP=Qの元raw証明と読む万能解釈ができないことを示す。

    5. 条件付き選択第十四セル¶

    SelectedTriplePastingFourteenを、平行な新13D比較証拠間の別の選択比較Typeとして構成。三連文脈の局所的なtripleLeftUnit・tripleRightUnitは、同じ13D証拠の前後にstrictを貼った二通りの生13D経路を比較するための明示的な選択生成元であり、元のraw13D Eqではない。

    selectedTripleLeftFourteen_conditionalCubeと右側の同名定理は選択14D比較の存在と、生13D経路の非等号を同時に示す。selectedTripleLeftFourteen_noRawEqualityInterpreterは14D証拠が元13Dの厳密Eqを意味しないことを証明。

    originalFourteenToTripleはv5.23で既証明のSelectedCompositionFourteen証拠をinheritedOldにそのまま保持し、raw証拠埋込みの単射性を証明する。新しい三連13D比較と旧v5.23の全14D比較が自動的に相互交換可能・自然同型であるとは主張していない。

    6. 初回Lean失敗の型的原因と無弱化修正¶

    初回Leanでは、右側のselectedRightTriple_rawDistinctおよび右側のtripleRightThirteenUnit_rawDistinctのcases hが、元第七セルの依存添字に関してF.1 = F.s.trans uを要求し、Dependent elimination failedとなった。

    追加のselectedTwelfthFirstAtomTagおよびselectedThirteenFirstAtomTagは、元の生証拠の構成子列の先頭原子的タグをNatへ送るraw証拠観測である。chainに対しては左側の証拠をたどり、真正のcompLeft/compRightとwhiskerLeft/whiskerRight、13Dのstrict/tripleLeft/tripleRightなどを別々の有限値で識別する。等式があったと仮定した場合にcongrArgで非依存型Natの矛盾を導くので、元の依存添字を不正に消去する必要がない。

    修正はこの2種類のタグ定義と該当非等号の証明本体、#print axioms監査追加に限る。元の三連12D構成、独立13D/14D生成元・仮定を弱めず、最終exact-source CIはすべてSUCCESS、sorryAxなし。

    7. 次の研究境界¶

    Qi v5.29では、今回の13D局所比較が任意の12D経路の前後貼り合わせ、および元v5.27の左右文脈作用とどの条件で自然に整合するかを探る。新たな14D coherenceを追加する場合も、元のType値証拠と旧v5.23選択14Dを保持し、互換条件、obstruction、別presentationのauthorityを明示する。

    今回の結果は元の第七セル構文の厳密結合則、旧raw第十一〜十四セル証拠のEq、全高次coherenceの完成を主張しない。 append-only／tighten-only／overwrite-forbidden／same-root。
