    2. 元F77からP94Aまでの真正7層4-cell証拠¶

    元F55証拠の真正P77 vertical 4-cellを、P80→P85→P86→P87→P89→P93C→P94Aの7個のoldコンストラクタによりraw P92B.original 端点のP94A証拠へ完全に埋め込む。nativeGK5BCP77_to_rawP94 は、任意の依存型source first,last,r,s と元P77 w : P77(f,g) を受けて、P94A(original(f),original(g)) という実際のType値証拠を返す。

    これにより、元P77の真正 rightUnit(f) : P77(trans(f,ident(s)),f) を選択P94A raw四セルへ写し、さらに指定された子seam original(f)→φ(f) と選択P94A verticalRightUnit(φ(f)) の逆を合成する：

    original(trans(f, ident(s)))
  -- [P77.rightUnit through seven genuine .old embeddings] --> original(f)
  -- [given local SeamAt(f)] --> φ(f)
  -- [symm(P94A.verticalRightUnit(φ(f)))] --> trans(φ(f), refl(s))
  = φ(trans(f, ident(s)))

    これはGK5BBで不可能と証明された original(trans(f,g))→trans(original(f),original(g)) というraw split shellを一度も使わない。また不存在の元F55 ident seamも要求しない。左単位についても同型の真正構成を証明。

    3. 一般的な局所seam存在の同値とP77軌道¶

    • nativeGK5BCRightUnitSeam_nonempty_iff：Nonempty SeamAt(trans(f,ident(s))) ↔ Nonempty SeamAt(f)。
    • nativeGK5BCLeftUnitSeam_nonempty_iff：Nonempty SeamAt(trans(ident(r),f)) ↔ Nonempty SeamAt(f)。
    • nativeGK5BCSeam_transport_P77：元P77の真正四セル f→g があれば、raw P94Aでoriginal端点を移し、GK5AJで実際に得られる選択φ端点P93C 4-cellの逆と組み合わせ、SeamAt(g)からSeamAt(f)を構成。
    • nativeGK5BCSeam_nonempty_iff_P77：任意の元P77四セルで結ばれた元F55証拠2つにおける、個別直接seam存在の正確な同値。
    • nativeGK5BCAssoc_seam_nonempty_iff：元P77の結合律4-cellに沿って、異なる括弧構造の元F55合成の個別seam存在を同値化。

    ここで元P77の4-cellを選択側P94Aの全域正規化と同一視しない。個別の元P77 source証拠の実在する領域だけで比較を移す。

    4. 北C60の肯定例とGK5BB無条件no-goの同時成立¶

    真正北四段pentagon原始証拠 p := nativeGK5AGNorthOriginalCell と、元F54短経路の ident(s) との元F55合成 c := trans(p,ident(s)) を取る。元pのraw originalと再帰φは定義上一致し、P94A.refl seamを無条件に持つ。上の右単位構成を適用すると、nativeGK5BCNorthRightIdentityDirectSeam : P94A(original(c),φ(c)) を無条件に構成。

    同じ真のcについて、GK5BBにより¬ Nonempty(RequiredShell(c))、つまりraw original(c)→trans(original(p),original(ident(s))) のsplit 4-cellは不存在。従ってNonempty SeamAt(c)は真で、Nonempty RequiredShell(c)は偽：強い局所shellが個別seamの必要条件ではないことを具体的に証明した。

    さらにraw original(c)とφ(c)は元のType値付き3-cell構文として不等であるが、wrapper数は双方1。P94A四セルの実在と構文不等は矛盾しない。

    global obstructionは維持： 真の元F54経路を持つ北C60では、GK5BBによって¬ Nonempty NativeGK5AYOriginalPhiSeam northFirst northLast、¬ Nonempty NativeGK5BAConstructorShellKit (.pentagon .north) Site Site。特定cへの直接seamを構成しても、全元F55証拠にわたる一様seamや不可能なident bridgeを導かない。元P89 source class mapの無条件faithfulness/nonfaithfulnessも不変。
