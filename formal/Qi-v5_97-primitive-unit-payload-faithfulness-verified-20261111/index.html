    2．本当の原始unit葉と条件を限定した理由¶

    v5.97は既存の元依存型SelectedLocalEighteenの値について、元v5.73の内部括弧が厳密にoldUnitLeftまたはoldUnitRightであるというselectedV597OriginalPrimitiveUnitを定義した。これは元unitLeft／unitRight生成子単独の条件であり、元のreverseや非結合chainを外側に持つ1-unit証拠は含まない。新しい18D生成子や全域商は導入しない。

    この条件が満たされる本当の元証拠M:J→Nは、真正元unit数が厳密に1であり、元v5.92の完全型付き履歴が

    History(M) = [⟨J, ⟨N, M⟩⟩]

    とその証拠自身を含むことをLean4で証明。ここで元のbefore/F/G/C/afterは単なるタグに置換されず、Sigmaの最内層に格納された元の実証拠値の一部として保存される。型付きの真のraw17D始終端J,Nを勝手に識別・移送しない。

    3．二重Sigmaの等号反映と局所忠実性¶

    同じ本当のJ→N依存型を固定したうえで、

    M : SelectedLocalEighteen W l r J N
Atom(M) := ⟨J, ⟨N, M⟩⟩

    とすると、Atomの単射性を本当の二重Sigma構成子の等号から証明。Lean4では外側Sigma.mk.inj_iffによる依存等号HEqを同一型へ戻し、内側Sigmaについて再び同様に元の真正旧18D証拠等号を回収した。

    その結果、M,Lがともに単独unit葉で同じ真正J→N fiberに属する場合、

    History(M) = History(L) ↔ M = L
(Bracket(M) = Bracket(L) ∧ History(M) = History(L))
  ↔ M = L

    を形式証明した。さらにM ≠ Lなら元の完全型付き履歴も異なる。これはprimitive単独unit葉に限った忠実性であり、すべての一個unitの元証拠へ無条件に拡張していない。

    4．strict配置族への条件付き移送¶

    真正元のstrict前置Prefix(m,M)・後置Suffix(n,L)では、任意のm,nでも元v5.92の完全型付きunit履歴は保存される。v5.95の履歴等号反映を既証明のprimitive局所忠実性につなぎ、

    History(Prefix(m,M)) = History(Prefix(n,L)) ↔ M = L
History(Suffix(m,M)) = History(Suffix(n,L)) ↔ M = L
History(Prefix(m,M)) = History(Suffix(n,L)) ↔ M = L

    を証明。これは元のsourceのraw等号を復元するのであって、異なるstrict追加数・配置のpadding後raw証拠の等号を推論するものではない。同じnで同方向のpaddingを用いた場合に限り、元等号からpadding後raw等号が成立することを別途確認した。

    元の内部括弧まで一致し、かつ元primitive型付き履歴が一致している場合には、v5.96の正unit数・mixed orientationの定理を使い、padding後の括弧一致と異raw値が同時成立しないことを形式証明した。

    5．限定された不存在命題とNO_DATA¶

    新しい存在Propは双方がprimitive unit単独葉であること、元の完全型付き履歴が一致すること、元内部括弧も一致すること、かつ元raw値が異なることを要求する。

    この指定された限定Propは不可能と形式証明された。ただしv5.93のselectedV593OneUnitSourceCollisionExistsは単独葉や履歴一致を仮定しない。元のreverse／chainでunit葉が包まれる場合、またはtyped payload履歴が異なる場合の同指紋・異raw元源の存在・不可能性は引き続き NO_DATA である。primitive局所結果を元依存型全域へ昇格させず、異fiber gluing、旧新19D商全域同値、WORLD／20D降下・権限も未認証。

    • 初回CI #42964616845 FAILURE：二重Sigma単射のsigma_mk_injectiveに暗黙の端点引数を明示して型不一致2件。primitive葉以外の元構成子に対する大域的simpで、深い依存型正規化のwhnfがタイムアウト3件。

    • 最終CI #42965793931 SUCCESS：外・内の二重Sigma.mk.inj_iffからHEqを得てeq_of_heqする、明示型付き証明へ修正。新規Leanファイルの証明手順だけ修正し、元17D／18D／19D Type、すべての新定理文、元unit payload定義、比較規則、Lean/mathlib固定を変更せず、公理追加・sorryによる回避もなし。失敗CIの公理出力は認証根拠としない。

    7．次段Qi v5.98候補¶

    厳密に限定したprimitive unit葉の局所忠実性から出発し、元のreverse・chainで構成する1-unit断片で、元の型付きpayload履歴と内部括弧指紋から元raw証拠を復元するための依存型中間端点に関する補助条件を明示する。条件が成立しない枝はobstructionとして残す。元v5.93の無条件同指紋・異raw source存在または全域不可能性を証明したと主張しない。
