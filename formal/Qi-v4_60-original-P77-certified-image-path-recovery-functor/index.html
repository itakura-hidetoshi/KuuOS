    1. 正本の構造とauthority境界¶

    Qi v4.53の真正FivefoldEdge有向5辺e01/e12/e23/e04/e43からの自由経路圏FivefoldFreePathCategoryと、Qi v4.54で元F55/P77の真正型付き四セルを元GK5CG conservative Type値5-cellの存在証拠によって商にした元target圏を保持する。

    Qi v4.57のFivefoldP77ImagePointは、元P77商クラスと本物の元有限経路による到達可能性の証拠をHomに持つ。Qi v4.58はこのsource→certified imageが実際のMathlib圏同値であることを示した。v4.59はchargeがゼロでも元target全体には未到達な真正P77証拠が存在することを証明している。

    今回の復元は証拠付き像に限定される。数値charge、P94A shadow、C60物理EdgeやRingHom等号から元F55/P77のType値四セル・五セルを生成するものではない。

    2. 元P77商像Homの唯一の経路正規形¶

    像Hom A : FivefoldP77ImageHom ... X Y に対して元の到達証拠を使用し、fivefoldP77ImageRecoverPathが

    [ w_A:\operatorname{Quiver.Path}(X.vertex,Y.vertex) ]

    を選び、fivefoldP77ImageRecoverPath_specで真正元P77商targetにおける正確な評価

    [ F_{\mathrm{P77}}(w_A)=A.val ]

    を形式証明する。さらにfivefoldP77ImageRecoverPath_uniqueにより、同じ元P77商クラスを評価で与える元型付き有限経路は唯一である。これはv4.55の真正Faithfulから証明し、chargeから経路を推測するわけではない。

    Classical.chooseでProp値到達証拠の存在からpathを選ぶため、復元関手は非計算的である。実行可能なアルゴリズムとしての証拠抽出や、全target上の計算を主張しない。

    3. 真正Functor、恒等射・合成、両方向の復元¶

    fivefoldP77ImageRecoverPath_idとfivefoldP77ImageRecoverPath_compは

    [ w_{\mathrm{id}_X}=\mathrm{nil}X,\qquad w{A\circ B}=w_A\circ w_B ]

    を元の依存型端点・元P77商合成に沿って証明する。これからMathlibの実際のFunctor

    [ \operatorname{Recover}: \operatorname{Im}(F)\longrightarrow\mathcal P_5 ]

    （fivefoldP77ImageRecoveryFunctor）を構成した。

    fivefoldP77ImageRecovery_left_obj/mapとfivefoldP77ImageRecovery_right_obj/mapは、source→image→sourceとimage→source→imageがそれぞれの元対象と全Homに対して厳密に恒等となることを証明する。これは関手の対象・Hom作用ごとの等式であり、v4.58のchoice依存のEquivalence.inverseとの定義的等号を新たに主張していない。

    さらにfivefoldP77ImageHomPathEquivは、各型付き端点で

    [ \operatorname{Quiver.Path}(X.vertex,Y.vertex) \simeq \operatorname{Hom}_{\operatorname{Im}(F)}(X,Y) ]

    という真正Type値Equivを構成する。これは数値chargeの同値ではない。

    4. 元GK5CG chargeと経路長の関手的整合¶

    fivefoldP77ImageRecoverPath_charge_lengthは全ての証拠付き像Homについて

    [ Q(A.val)=\bigl(\operatorname{length}(w_A):\mathbb Z\bigr) ]

    を証明する。fivefoldP77ImageRecoverPath_comp_chargeは実際の像Hom合成において、復元した元経路を合成してから測った長さと元chargeを照合する。

    fivefoldP77ImageRecoverPath_zero_charge_endpointsにより、像Homのchargeが0なら復元経路の長さは0で、元型付き端点が一致する。これは像に既に所属する場合の主張であり、元P77全targetのchargeだけから到達性を推論しない。

    5. 全元P77 targetへの回収不可能性¶

    fivefoldP77NoGlobalHomRecoveryは、全ての元P77保守的商クラスに対し、そのクラスを厳密に評価で再現する型付き元有限経路を返す全域sectionが存在しないことを証明する。

    反例はQi v4.59で構成した真正元P77四セル

    [ z_0=e_{01}^{-1}\circ U\circ L^{-1}:1\to0, \qquad Q(z_0)=-1+3-2=0 ]

    である。元有向自由経路ではchargeが長さなので、もし評価でz_0を与える元経路があれば長さは0となり、端点1\ne0に矛盾する。

    このno-goは指定された元P77商ターゲットへの正確な評価を保つ復元についてのもので、無関係な別の圏同値一般を否定するものではない。

    6. Leanエラー修正の構造理由¶

    初回CIでは、像対象のラッパーとFunctorのHom式を混ぜたcalcにおいて、LeanのTrans Eq Eqの中間型が合致しなかった。二回目CIでは、元Quiver.Path.compが文字どおりのカテゴリー合成記法とは一致せず、rw [Functor.map_comp]のパターン認識が失敗した。

    元v4.57の検証済み証明と依存シグネチャを参照し、恒等射は元商クラスへの真のmap_id、合成則は元商クラスでの明示的map_comp等式連鎖に変更した。17宣言の定理命題・元P77/五セルauthority・公理境界・元数学的仮定を一切弱めず、3回目CIで固定Leanによる全10,257ジョブ成功を得た。

    7. 次の研究境界¶

    確定：真正元P77 source-certified像の各Homについて、本物の型付き有限経路を非計算的に一意復元し、Functor・Hom Equiv・charge=lengthを保存できる。全元P77 targetへは正確な評価を保持した全域sectionを延長できない。

    次の焦点（Qi v4.61）：復元とv4.58既存の準逆Functorとの具体的な自然同型、元型付き五角形の上経路／下経路の復元正規形、元P77全targetへの部分的なextension/descentの正確なobstruction。元F54/F55/P77/P94A・真正C60・北C60 CRTは別authorityとして保持する。
