    2. 独立GK5BZ — 多変数整数多項式・真正有限CRT環同型の自然性¶

    前段GK5BWで、任意有限添字集合s、任意自然数法mᵢ、そのLₛ=Finset.lcm s mに対して、元のgcd重なりで互換な局所ZMod依存積のSubringRₛと大域ZMod Lₛの真正環同型Φₛ : ZMod Lₛ ≃+* Rₛを証明済み。GK5BXは被覆包含u⊆t⊆sに沿う大域制限qₛₜ、局所制限ρₛₜについてRingHomの恒等・合成・自然性を証明した。GK5BYは一変数Polynomial Intの評価にこれらを接続した。

    GK5BZでは任意の変数型σに対する真正MvPolynomial σ Intを使う。具体的な有限変数はσ=Fin nであり、n=0も含む。固定mathlib MvPolynomial.eval₂HomとMvPolynomial.ringHom_extから大域・互換局所の双方へ真正な多変数評価RingHomを構成し、加法・乗法、係数・変数を保持する。

    Φₛ (P(xs)) = P(Φₛ ∘ xs)
qₛₜ (P(xs)) = P(qₛₜ ∘ xs)
ρₛₜ (P(as)) = P(ρₛₜ ∘ as)

    これらを環準同型の等式として証明し、三段被覆u⊆t⊆sについて二段制限・直接制限・CRT再合成が可換となる定理も形式化した。任意の元符号付き整数変数zs:σ→Intについて、最初に整数環上で多変数評価してからZMod Lₛへ射影する操作と、各整数を射影後に多変数評価する操作は同値。有限変数Fin nの系も含む。

    互いに素性・非零性・正値・支配的局所法・非空被覆・多項式次数・階乗整除は、これらの多変数自然性の前提ではない。ZMod 0 = ℤおよび空の変数集合・空の被覆も含む。

    Lean4修正記録¶

    初回LeanエラーはMvPolynomial.ringHom_extのC／Xゴールで、評価・合成写像の簡約が不足していた。固定mathlibのMvPolynomial.eval₂Hom_C／eval₂Hom_X'／RingHom.comp_applyを使って明示展開した。最後の三段図式の不要なcongr 1を、既証明等式に対するcongrArgへ修正。中間のCI選別成果物欠落は定理の数学的障害ではなく、次ランで選別を成功させてLeanを再検証した。新規有限変数の符号付き評価系も追加し、最終CIで新規16定理すべてsorryAxなし。定理の前提や結論を弱めず修正した。

    3. Qi v4.44 — 真正北C60の元符号付き整数多変数値とF55の境界¶

    元GK5BQの真正符号付き整数分子N(d,j,v):Intを、それぞれ独立の有限変数i:Fin nに対してN(d,indices(i),values)として代入する。任意のQ:MvPolynomial (Fin n) Intをこの元値に評価した結果と、ZMod Lₛ上での多変数評価およびGK5BWの互換局所剰余Subringでの評価は一致する。加法・乗法、任意一段・二段被覆制限も真正Lean等式で成立。絶対値代理natAbsは使わない。

    実際の元F55 Type証拠は、primitive原証拠（元P92B整数多項式値P=1）と、double inverse＋F55右単位の別証拠（元P92B整数多項式値P=X²）をそれぞれ保持する。両者とも数値的な有限多変数CRT自然性を持ち、既証明の明示的条件2≤d・Lₛ∣d!の下で、部分被覆uの元整数深度多項式のCRT零証明書も共有する。しかし元original→phiの構造的seamは前者で存在、後者で不存在。同じ型付き定理でこのobstructionを区別して保持する。

    重要：最後のCRT零は既存の元P92B整数深度多項式についての条件付き定理である。任意の外側多変数多項式Qが零になるとは主張しない。また数値的多変数gluingは元F55 Type証拠やP77商類等号、P94A四セル、GK5AY全域seam、P89無条件反射、W=1→seamを再構成しない。元F54二Nat・二圏・Blocks、元F55 Type値履歴、真正第五Dart北C60物理gauge、条件付きP89障害を別authorityとして維持する。

    4. 次段階（研究計画、未形式化）¶
