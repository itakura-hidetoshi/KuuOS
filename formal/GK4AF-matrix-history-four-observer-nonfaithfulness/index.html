    1. 真正F54 Type値履歴を保存する非可換整数2×2行列値¶

    行列不変量のLeanソースは、完全依存型の元F45二圏・四Blocks・両Nat depth・実C60葉を失わず、全ての真正F54RotationEdge、中間木を保持したRotationChain、原DepthRotationRouteの5構成子を行列値へ写す。

    値域NativeGK4AFMatrix=(Int×Int)×(Int×Int)には、実行列積と単位行列を明示的に定義し、4つの整数多項式等式によって積の結合律を、別に左右単位をLean4で証明した。

    C : original double-Nat cast = [[1, 1], [0, 1]]
F : actual forward rotation = [[1,-1], [0, 1]]
R : actual backward rotation = [[1, 0], [1, 1]]
I : genuine chain identity = [[1, 0], [0, 1]]

C * F = I      -- true F54 assoc comprises one cast then one forward
B := F * R     -- genuine two-edge original physical backtrack

    F54.assocの像が厳密にIとなる点が重要。元F55のpentagon両辺はI、disjointSquare両辺は実前進回転F*F。元P92Bのassociator-naturalityは元u,v,wの順序を変えず、既存の結合律とC*F=Iで検証する。

    その上で元F55全9構成子、元P92B全9構成子（本物のassocNaturalityを含む）、F54構造seam全14構成子、拡張比較全3構成子に対する保存性を、各々の元Type値証拠上で証明。元P92B証拠存在商Qと別の独立構造比較商SのそれぞれへQuotient.liftを構成、元Q→S正準比較の可換性とSの真正合成・単位における行列値の乗法性を形式化する。観測の一致から元のP92B Type値3-cellを作ることはない。

    2. 真正四成分kernelの残余非忠実性を決定¶

    真の反例と比較写像のLeanソースでは、元F54の真正局所回転rot:LocalRotation p before after、真正B := nativeGK4FBacktrack rotとC := nativeGK4WCastRoute beforeから、同一F45型付き自己Homの本物の2経路を構成する。

    u = C ; B ; B ; C
v = B ; C ; C ; B

    元GK4AEの四成分観測は双方で完全に一致：

    O_AE(u) = O_AE(v) = (false, ((-2, 2), -2))
    -- grade=false, castCharge=-2, backwardCount=2, moment=-2

    しかし新しい整数行列評価は厳密に異なる：

    M(u) = [[ 0,-1],[1,1]]
M(v) = [[-1,-1],[3,2]]

    両者の左上成分がそれぞれ0と-1なので、元Qおよび独立構造商S上の行列値保存により[u]_S ≠ [v]_SとLean証明。一方、真正第二K_AE比較では四成分観測値一致が像の一致と必要十分なのでF_AE([u]_S)=F_AE([v]_S)。従って、真正S→K_AE比較関手は元F54局所回転が実在する任意の自己Homで非忠実。実C60北側六角形northHexagonNativeLeftRotationにも無条件で特殊化した。

    この結論は、GK4ACの別のNat≃Fiber(K_AA→K_X,[R_0])、GK4ADのS→K_AA非忠実性、GK4AEのK_AE→K_AA非忠実性のそれぞれと両立するが、商のQ、S、K_AE、K_AA、K_Xを同一視してはいない。

    3. CI不成功からのLean記法修正とexact-source検証¶

    初回CI #41182235164では、新規行列不変量1ファイル目（実積結合律・全9/9/14/3構成子保存・元Q/S降下）はコンパイル成功、2ファイル目の商類相異証明2件のみが不成功だった。原因は、LeanのcongrArg (fun M => M.1.1)で得た算術矛盾が、まだタプル射影のままでomegaに渡ったため。「行列左上成分0=-1」の型付きdefinitional unfoldingが算術戦術の前提へ渡っていなかった。

    最終修正では該当2か所へ

    have hentry := congrArg (fun m : NativeGK4AFMatrix => m.1.1) hv
change (0 : Int) = (-1 : Int) at hentry
omega

    を採用。両変更Leanファイル全文・imports・元F54/元P92B/structural比較のdependent signatures・pinned Lean/mathlibを照合し、修正版HEADで3751/3751 SUCCESS、Governance全5/5 SUCCESS、sorryAxなし、warning/error 0/0を得た。古いLean証明を上書きせずappend-only。

    4. 次のGK4AGの研究境界（未証明）¶

    既存真正四成分O_AEと新しい行列値Mを組み合わせる別の第二観測kernel商K_AGを構成し、真正S→K_AG→K_AE比較・忘却関手を厳密化する候補がある。ただし行列値と四成分値が等価・完全忠実であるとは推論せず、S→K_AGの残余障害を別途調べる。元P92B Qの結合律・左右単位、歴史的完全型付き同値、真正14D無条件Countable、19D filler、global strict n、hyperdescentは引き続き未証明。
