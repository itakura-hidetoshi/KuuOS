    Qi v5.84 — 右whiskeringのguard付き局所忠実性と2源内部括弧obstruction（Lean4形式証明・公理監査）¶

    2. 元18D Type上の右側3枝と成立条件¶

    真に供給されたF G : ContextFrameEleven W l r c d、after : SevenRewrite W l r d e、元17D端点Nを用いて、右側のみN' = whiskerRight F G N afterとする。さらに別途実際に供給されるM : SelectedLocalEighteen W l r N' N'を必要条件とする。任意のMやafterの存在を生成・推定しない。

    新SelectedV584RightGuardedFragmentから元の依存SelectedContextualEighteen W l r N' N'への埋め込みは、(1) v5.82自由pure strict/reverse/raw-chain部分の像、(2) reverse (inherited M)、(3) reverse (whiskerRight F G (strict N) after)の3枝のみを取る。左側v5.83のfiberと右側fiberを型として同一視しない。

    独立selectedContextEighteenWhiskerPlacement観測は、それぞれselectedPureStrictReverseRawValue A、reversed (source (selectedLocalEighteenInnerBracket M))、reversed (right strict)である。これらの排他性に基づくselectedV584RawValue_injective、元18D上の観測等式、埋め込みの単射性をLean4で証明。

    3. 独立した旧新19D比較と完全観測¶

    前節の指定3枝A,Bに限り、旧5構成子商と新7構成子商それぞれで[embed A] = [embed B] ↔ A = Bを定理化。また元旧SelectedLocalNineteenと元新SelectedRawCongruentNineteenという別々の比較TypeのNonemptyが、それぞれA = Bと同値であることを別証明し、この限定像上でのみ比較可能性の同値を得る。

    SelectedFullV581QuotientObservationValueの旧v5.80全座標（元九観測・二本の全Nat→Nat無限祖先／run塔など）とv5.81配置木の直積を減らさず、当該3枝の真正新商クラス上で観測の等号反映を証明した。全18D商全体の忠実性や、旧新19D比較Typeの同一性は未証明。

    4. 2つの元旧18D証拠の分離条件¶

    同一の右whiskered N'→N' fiberに、別個の真正旧18D証拠M,Lが両方供給されたときに限り、既に旧・新真正商へ別々に降下したv5.81配置観測を用いて次を証明。

    • 旧5構成子商クラス[inherited M] = [inherited L]なら、innerBracket(M) = innerBracket(L)。
    • 新7構成子商についても同じ必要条件。
    • 対偶：innerBracket(M) ≠ innerBracket(L)なら、旧・新両商クラスは不一致で、それぞれの元19D Type比較のNonemptyは成立しない。
    • さらに、reverse (inherited M)とreverse (inherited L)を1回のraw反転でguardした真正新商クラスも不一致。

    innerBracket(M) = innerBracket(L)から元Type値や商クラスの一致を導く逆方向は未認証。局所観測から無条件の大域貼合へ昇格させない。

    5. 単位律による保存されたobstruction¶

    元のSelectedLocalNineteen.unitPrepend MとunitAppend Mを変更せず保存。右同一fiberでも、raw 18D構成子で異なる chain (strict N') (inherited M)／inherited M、またchain (inherited M) (strict N')／inherited Mは、元旧19D商および独立新19D商ではそれぞれ同一クラスになる。新しいselectedV584Right_unguardedAppendOldNewとselectedV584Right_unguardedAppendRawDistinctは、後者のraw不一致と商同一の両方を証明。

    したがって未保護のinherited葉を自由追加した無制限の忠実な分類は、この構成からは得られない。これを障害として明示し、元の単位生成元や仮定を弱めていない。

    7. 未認証項目とQi v5.85への境界¶

    任意の元18DM,LやSevenRewriteの居住性、innerBracket観測一致からの逆方向、異なる左／右fiberの同一視・輸送、任意のraw結合・guard閉包、旧新19D Typeの大域同値、全商分類、WORLD横断降下、20D gluing、制度的／実行権限は未認証（NO_DATA）。

    次段v5.85候補は、同一依存fiber内で旧18D内部括弧観測が等しいが別の元Type証拠の識別可能性／不足観測量の検討と、追加guard下の条件付き閉包。差分とcompatibilityを残し、全域化しない。
