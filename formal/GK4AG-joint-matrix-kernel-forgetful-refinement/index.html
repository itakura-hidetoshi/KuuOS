    1. 元F54からの積観測は真正な非可換値¶

    積観測と独立Q/S降下のLeanソース：

    O_AG(r) = (O_AE(r), M(r))
NativeGK4AGValue := NativeGK4AEValue × NativeGK4AFMatrix
(u,A) ⋄ (v,B) := (nativeGK4AECombine u v, nativeGK4AFMul A B)
unit := (nativeGK4AEUnit, nativeGK4AFOne)

    元GK4AEの真正四成分は Bool × ((Int×Nat)×Int) で、積は順序momentに交差項を含む。元GK4AFの整数2×2行列は、真正F54 castDepths・前方向RotationEdge・逆方向RotationEdgeを、順序を保った行列積に写す。nativeGK4AGCombine_assoc・左右単位は二成分それぞれの既証定理から直接形式化し、値の可換化や行列のtrace/determinantへの圧縮を行わない。

    元F54依存型 DepthRotationRoute の合成・左右文脈での観測を証明し、実際の元P92B証拠存在商 Q と独立構造比較商 S に 別個にnativeGK4AGP92・nativeGK4AGStructuralを構成。Q→S比較との可換性、元P92B合成の観測積保存、元独立S合成の観測積保存、元F54全14構造seamとの整合を証明した。

    成分定理が保存する元Type値比較の範囲は、元F55全9構成子・元P92B全9構成子（真正assocNaturality含む）・独立構造seam全14・拡張構造比較全3。GK4AGはその正本証明を使うものであり、数値観測の一致から元P92BのType値3-cellを作らない。

    2. 新しい真正第二kernel商 K_AG¶

    真正第二kernel圏とS比較関手のLeanソース：

    K_AG(first,last) :=
    Q(first,last) / (q ~ r iff O_AG(q) = O_AG(r))

    NativeGK4SKernelClasses (nativeGK4AGP92Family p D E)として、元F54型付き境界にある真正元P92B証拠存在商Qの第二商を構成した。元Qそのものは圏公理が未証明なので、Qの結合律・単位律を仮定せず、GK4Sの到達可能観測値 image の合成を輸送し、値域の積の結合律・単位律からCategory (NativeGK4AGKernelStage ...)を証明。

    • nativeGK4AGComparisonFunctor : S ⥤ K_AG を元構造商SのMathlib圏から構成、各実型付きHomで 全射。
    • nativeGK4AGKernelValueFunctor を別の非可換積値圏へ構成し、各Homで 単射。これは第二商のkernel定義から出る忠実性であり、S→K_AG全域の忠実性ではない。
    • nativeGK4AGComparison_eq_iff はS比較で類が一致する必要十分条件を、真正元Sでの組観測一致に還元する。

    3. 真正忘却関手 K_AG→K_AE と狭義の精密化¶

    元四成分商への忘却関手と反例のLeanソース。

    新第二商 K_AG のクラスから、行列観測だけを忘れて旧四成分商K_AEへ写すnativeGK4AGForgetMatrixFunctorを真正Mathlib関手として構成。元P92Bの同じ実証拠類を表現元として用い、全Homで全射、真正単位・合成を保存し、次の比較図式が全Homで可換と証明：

         S  ─────F_AG────→  K_AG
      ╲                  │
       ╲ F_AE            │ U_AG,AE  (Hom-surjective)
        ╲                ▼
         └────────────→ K_AE

    本物の元F54局所回転 rot:LocalRotation p before after、二Nat cast自己経路C、実前後方向backtrackBから、GK4AFで既証の真の依存型自己経路を再利用：

    u = C; B; B; C
v = B; C; C; B
O_AE(u) = O_AE(v) = (false,-2,2,-2)
M(u) = [[ 0,-1],[1,1]]
M(v) = [[-1,-1],[3,2]]

    したがって：

    F_AG([u]_S) ≠ F_AG([v]_S)
U_AG,AE(F_AG([u]_S)) = U_AG,AE(F_AG([v]_S))

    すなわち、真正K_AG→K_AEは 局所非忠実で、真正C60北側六角形 northHexagonNativeLeftRotation でも無条件のHom非単射をLean4で証明。GK4AFが証明したS→K_AEの残余非忠実性を、この行列成分が具体的に修復して分離する。ただし残りすべてのS非同値類が区別できるとまでは推論しない。

    4. 厳密な権限境界と次段階¶

    S→K_AG の全域忠実性は 未証明。nativeGK4AGComparison_injective_iff_joint では、任意の固定型付きHomで

    Function.Injective (S → K_AG)
    ↔ Function.Injective (S → NativeGK4AGValue)

    という局所必要十分条件だけを証明した。値域は観測の全値ではなく、実元F54から到達可能なimageである。元P92B Q の結合律・左右単位、歴史的完全型付き同値、真正14D無条件Countable、19D filler、global strict n、hyperdescentはすべて未証明として保持する。

    次候補GK4AH（未証明）：同じ組観測 (O_AE,M) を持つが独立構造Sで異なる真の元F54型付き経路が存在するか、存在しないとするための限定的な忠実性条件を、非可換表現・局所文脈・比較証拠の差から独立に検査する。

    5. Lean4修正履歴、exact-source receipt¶

    初回source HEAD b9d9dabb2ce3e34ce07a8cae0c0d7846a2477a30・CI #41183588516では、最初の積観測Leanが成功する一方、二番目のnativeGK4AGKernelValue_composeでrw [nativeGK4AGKernelCompose_class]が失敗。原因はQuotient.inductionOn₂後のゴールが⟦q⟧と表示され、補題のnativeGK4SKernelClass ... qとの表層書換対象をLeanが認識しなかったこと。数学的な等式の破綻ではない。

    そのため、既存GK4AEの確定した商類合成の書き方に揃え、型付き境界と実観測familyを明示する

    (nativeGK4SKernelClass (nativeGK4AGP92Family p D E) t₁ t₂ q)
    (nativeGK4SKernelClass (nativeGK4AGP92Family p D E) t₂ t₃ r)) =
  nativeGK4AGCombine
    (nativeGK4AGKernelValue t₁ t₂
      (nativeGK4SKernelClass (nativeGK4AGP92Family p D E) t₁ t₂ q))
    (nativeGK4AGKernelValue t₂ t₃
      (nativeGK4SKernelClass (nativeGK4AGP92Family p D E) t₂ t₃ r))
