    1. 真正5辺の独立自由経路圏¶

    Qi v4.52の唯一のFivefoldIndex = FivePhase = ZMod 5とFivefoldEdge={e01,e12,e23,e04,e43}を再利用。既存Qi v3.1はFivePhase上に相生・相剋の別のQuiverを定義しているため、そのインスタンスを上書きせず、FivefoldPathVertexという位相を保持する別のwrapperに、端点等式を含むFivefoldPathArrowを構成。

    標準MathlibのFivefoldFreePathCategory := Paths FivefoldPathVertexは真正自由経路圏。上三辺e01≫e12≫e23と下二辺e04≫e43は、同じ0→3にあるが長さ3・2で非等号と形式証明。既存Qi v3.5/GK5Xの全whole NatIso pentagonには変更しない。

    2. 全有限経路を元P77四セルの真正Type値付き証拠へ評価¶

    任意の元F54の2カテゴリー、2つのNat深さ、Blocks、元F55合成可能四項組f,g,h,kに対し、fivefoldArrowOriginalP77は各矢印を旧Qi v4.52の真正NativeF55RawVerticalFourCellへ写す。特に逆向きのe04/e43で既存元証拠のsymmを保持する。

    fivefoldEvaluateP77はQuiver.Path.recによる元P77四セルの実際の証拠構文値への全有限長評価。空経路をP77.refl、末尾辺追加をP77.transとして、元F55証拠の型付き始終端を維持する。元P77四セルの生構文自体をstrictなCategoryと偽っておらず、商や数値shadowへ替えない。

    3. 新規中心定理¶

    ∀ typed finite path w,
  assocCharge(fivefoldEvaluateP77 f g h k w) = (w.length : ℤ)

    この定理を元P77の真正assoc・symm・trans・左右whiskeringの固定されたチャージ再帰から証明。結果として、 - 評価後の元P77四セル証拠の等号 ⇒ 元経路の長さの等号。fivefoldEvaluateP77_eq_implies_length。 - 長さが同一端点経路を識別するという明示条件LengthInjectiveがあれば、P77評価も単射。fivefoldEvaluateP77_injective_of_length。この条件そのものの一般的な無条件成立を主張していない。 - 二つの実五角形経路は元P77評価後も3対2の異なる整数チャージと異なるType証拠値を持つ。fivefoldFreeTwoEvaluations_charge、fivefoldFreeTwoEvaluations_ne。 - GK5CGの保守的五セルは整数チャージを保存するため、評価後の両経路間に保守的5-cellは存在しない。fivefoldFreeTwoEvaluations_noConservativeFiveCell。

    4. 同じ自由経路のC60物理辺トレース¶

    fivefoldFreePhysicalTrace frame v pathは、元の真正C60五角形(.pentagon v)・任意局所ゲージframeで、各生成辺が選ぶ本物のEdge.aroundを保存するListへ任意有限経路を写す。空経路は空列、consでは実辺1本追加。元物理ダートの接続正当性はQi v4.52のfivefoldPhysicalEdge_joinsから継承。

    (fivefoldFreePhysicalTrace frame v path).length = path.length

    とLeanで証明。元P77四セル評価のchargeと物理実辺数は同じ原自由経路に関して数値的に一致するが、P77四セルや物理Edgeを等しいTypeとはしない。

    5. Lean4修正履歴と検証範囲¶

    初回CI #41935315502では、固定mathlibQuiver.Path.recのconsstepは(path,edge,IH)の3明示引数だが、当初誤って4引数として実装したため型不一致。後続rfl・rwエラーもこの根本原因の伝播。固定mathlib Mathlib/Combinatorics/Quiver/Path.lean・Mathlib/CategoryTheory/PathCategory/Basic.lean、既存GK5CF/CG、Qi v4.52ソース全文を照合し、stepの3引数化、完全指定のNativeF55RawVerticalFourCell.trans、証明チャージのchangeによる関数適用正規化で修正。仮定・結論を一切弱めず、外部公理・sorryなし。最終CI #41935914077は10,250 / 10,250成功、14監査すべて標準公理の範囲。

    数学的な限界：現段階のfivefoldEvaluateP77は元P77生構文へのproof-valued path evaluatorであり、元P77を無条件strict圏とする関手ではない。新しく定義したFivefoldFreePathCategory自体は正真正銘のMathlib自由圏。保守的5-cellによる商を明示した真正target Category／faithful functorの無条件成立や、元P94Aでの5-cell、数値CRTからの元証拠復元、Gray全体・無制限高次descentを主張しない。

    次研究：GK5CG保守的5-cellによる元P77四証拠の商をstrict target Categoryとして定義し、全有限経路の評価をその商へ実際にfunctorialに降下させる。その上でfaithfulnessの必要十分条件と、チャージが検出できない追加のobstructionを追う。元のFivefoldIndex・FivefoldEdge・original F54/F55・Qi v4.51 signed CRTを保全。
