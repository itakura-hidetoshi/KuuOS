    1. 本当に同じ自由六セル始終点を持つ四頂点¶

    Qi v5.08で構成・区別された元四重五角形の七セル履歴を

    • H₃ := sevenFourfoldInversePentagonThree l r（結合子3回）
    • H₂ := sevenFourfoldInversePentagonTwo l r（結合子2回）

    と置く。Qi v5.06/v5.07の真正混合残差の二履歴を

    • M₁ := sevenMixedResidueFirst (long := l) (short := r) r
    • M₂ := sevenMixedResidueSecond (long := l) (short := r) r

    と置く。

    SevenRewrite.congrCompによって次の四頂点を構成する。

    NW = H₃ ⊗ M₁         NE = H₂ ⊗ M₁
SW = H₃ ⊗ M₂         SE = H₂ ⊗ M₂

    各値は 実際の元SevenRewrite Typeの値 であり、新しい比較に合わせて自由六セル始終点を後付けで同一視していない。 NW = fourfoldMixedResidueFirst l r、SE = fourfoldMixedResidueSecond l r はQi v5.09の真正値を再使用する。

    2. 新しい一原始生成元と旧比較の局所合流¶

    次の四つの比較を、添字付きPentagonAssocEightCellと既存MixedResidueEightCellで構成する。

           NW ── P(new) ──> NE
        |                 |
      M(old)            M(old)
        |                 |
        v                 v
       SW ── P(new) ──> SE
    • 北辺 fourfoldMixedCriticalNorth：実際のfourfoldPentagonと旧反射比較をcompositeContextで結合。
    • 西辺 fourfoldMixedCriticalOldWest：元mixedResidueと旧反射比較だけで構成。
    • 東辺 fourfoldMixedCriticalOldEast：同じ旧mixedResidueで構成。
    • 南辺 fourfoldMixedCriticalSouth：同じ一種類の新fourfoldPentagonで構成。

    fourfoldMixedCriticalNorth_noOldとfourfoldMixedCriticalSouth_noOldは、旧文法での北辺・南辺比較の不存在を証明する。証明はQi v5.09の既証明対角線不可能性fourfoldMixedResidue_noPreviousと、旧東辺・西辺を合成した導出であり、追加仮定でも新公理でもない。

    fourfoldMixedCriticalLocalDiamondは四辺の具体的な型付き証拠と二つの旧比較不存在をまとめて証明。fourfoldMixedCriticalClassDiamondは新しく選択した七セル履歴商の四頂点が同一クラスになることを証明する。元七セルType値のstrict Eqは主張しない。

    二つの実際の八セル完成経路

    fourfoldMixedCriticalPThenM l r
fourfoldMixedCriticalMThenP l r

    はどちらもPentagonAssocEightCell W l r NW SEを持つ。

    3. 残る高次obstructionの正確な意味¶

    mixedResiduePrimitiveTraceは旧八セル生証拠に現れる本来のmixedResidue生成元だけを順番に記録する。 pentagonAssocPrimitiveTraceは、新八セル生証拠においてfourfoldPentagonをtrue、旧mixedResidueをfalseとして記録する。旧反射比較などの他の生成元から、架空の新しい原始比較イベントを作らない。

    実際に

    pentagonAssocPrimitiveTrace (fourfoldMixedCriticalPThenM l r)
  = [true, false]
pentagonAssocPrimitiveTrace (fourfoldMixedCriticalMThenP l r)
  = [false, true]

    をrflで検証し、fourfoldMixedCriticalRawEightGapで

    [ \boxed{ \mathrm{PThenM}(l,r)\ne\mathrm{MThenP}(l,r) } ]

    を生の自由八セル証明Typeのstrict Eqとして証明した。

    これは「七セルの二分岐は新商で局所合流する」が「その二つの八セル証明自体はstrict Eqでない」ことを意味する。ここから九セル比較が存在しない、あるいは全てのモデルで高次coherenceが不可能とは導けない。イベント順序traceが将来の九セル比較の不変量であるとも仮定しない。

    4. 降下する観測量・source境界¶

    fourfoldMixedCriticalParityCompatibilityはv5.09の全構成子保存定理から

    [ V_2(NW)=V_2(SE),\quad R_2(NW)=R_2(SE),\quad U_2(NW)=U_2(SE) ]

    を導く。Qi v5.09のQuotient.liftによる三観測の降下はそのまま保持される。他方、旧結合子指紋 Phi はv5.09の新七セル商では降下しないままである。観測降下、元証拠履歴、独立八セル値、将来の九セル比較問題を区別する。

    元F55/P77/GK5CG定義、全独立presentation、既存MixedResidueEightCell、元PentagonAssocEightCell、元七セル商、Lean/toolchain/workflowは変更なし。追加は新規Leanファイル1件とKuuOSFormalへのimport 1行のみ。
