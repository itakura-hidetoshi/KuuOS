    1.1 Why the exact provenance grade is stronger than GK5AP¶

    GK5AP established minimal counts for a particular normalization: every selected P94A 4-cell normalizing a genuine left-context identity must use leftContextUnit at least once; the right case is symmetric. The minimum is one, even if both other selected units are available.

    GK5AR now proves a universal mod-two provenance law for each of the all nineteen actual proof-relevant P94A four-cell constructors. Write I_L for GK5AP's leftContext/precompose observer and I_R for its rightContext/postcompose observer on raw P92B proof histories. Write N_L(w) and N_R(w) for the EXACT natural-number occurrence counts of the two selected context-unit 4-generators in a P94A proof term w (not numerical C60 shadows).

    For every genuinely typed four-cell w : P94A(f,g):

    (N_L(w) mod 2, N_R(w) mod 2)
  = (I_L(g) - I_L(f), I_R(g) - I_R(f)) in (ZMod 2) × (ZMod 2).

    These endpoint-difference identities are the Lean theorem NativeF55P94UnitFourCell.gk5arContextParity_normalForm. They are the actual selected P94A proof-term provenance; no raw F55 or original P89 proof terms were erased or identified.

    The proof handles all constructors: old P93, reflexivity, symmetry, vertical composition and units/associativity, both whiskers and both contexts, F54 pre/post route actions, both horizontal contexts, genuine interchange and the three explicit P94A unit primitives.

    In particular, for any two P94A certificates w₁,w₂ with the same dependent P92B 3-cell source and target:

    N_L(w₁) mod 2 = N_L(w₂) mod 2
N_R(w₁) mod 2 = N_R(w₂) mod 2

    This is gk5arContextParity_rigid: different higher histories have the same grade, not the same raw proof term.

    Original selected P94A unit normalization N_L mod 2 N_R mod 2
    leftContext(refl u, later) → refl(leftContext u later) 1 (odd) 0 (even)
    rightContext(earlier, refl v) → refl(rightContext earlier v) 0 (even) 1 (odd)
    horizontal(refl u,refl v) → refl(horizontalRoute u v) 0 (even) 0 (even)

    All possible certificates for each true source/target have those parities, independent of additional P93 evidence or arbitrary use of other P94A generators. This strengthens GK5AP/GK5AO, not by asserting a strict higher category, but by certifying the source-provenance grade of every derivation.

    Important boundary: GK5AO proves the horizontalUnit primitive has minimum count one, but GK5AR does not prove a mod-two rigidity theorem for horizontalUnit count. Only the two context-unit counts have the displayed mod-two rigidity.
