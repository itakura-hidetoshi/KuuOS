    真正18D証拠と同一観測・異なる四連続反転数¶

    前段Qi v5.66で得た3連続反転数は、新7構成子商で独立に保存される。今回の新反例は、その数までも一致させている。真正17D端点Nについて元のSelectedContextualEighteen W l r N Nの本来のstrict、reverse、chainだけを使い、

    S := strict N
D := reverse (reverse S)
T := reverse D
gap(X) := chain X S
A := reverse (reverse (reverse (reverse (gap D))))
B := reverse (reverse (reverse (gap T)))

    と定義した。Aは外から4連続＋gap＋2連続、Bは3連続＋gap＋3連続という構文上の異なる履歴であり、双方ともraw reverse節は計6個。次を元Type値で証明した。

    ∀ n : Nat, C_n(A) = C_n(B)
Trace(A) = Trace(B)
TopReverseFlag(A) = TopReverseFlag(B)
AdjacentReverseCount(A) = AdjacentReverseCount(B) = 4
ConsecutiveTripleCount(A) = ConsecutiveTripleCount(B) = 2
ConsecutiveQuadrupleCount(A) = 1
ConsecutiveQuadrupleCount(B) = 0

    gapはstrict identityをchainで入れるが全次数C_nを変えない。gapの位置をraw reverse一個だけ移すときも全自然数次数の等式を維持することを証明し、その外側に三つのraw reverseを重ねてA/Bの全塔一致を導出した。したがって、有限個の祖先サンプルから無限への推測ではない。v5.60のC₁〜C₅橋渡しから、元の8観測の一致と第9のC₆一致を導き、完全ordered traceとtop flag、隣接反転、三連続反転も一致させた。

    独立した四連続反転数と商への降下¶

    新たに元18D証拠へselectedContextEighteenTopTripleReverseFlagとselectedContextEighteenConsecutiveQuadrupleCountを追加定義。後者はraw reverseの子が最上位に三つの即時reverseを持つ場合のみ1を加え、chainでは左右の部分木の数を加算し、whiskerLeft／whiskerRightでは内側の数を保持する。元selected19の全5構成子と、新raw congruenceの全7構成子における保存を別々に構造帰納法で証明した（rawReverseは別途保存したtop-triple flagを使用）。

    元商・新商それぞれでQuotient.liftによる真の商不変量を定義し、旧商から新商へのprojectionで因子化することも証明。四連続数の1対0から、A/Bの新商クラスは相異なり、型付き新19D比較値は存在しない。比較生成元を付け足して結論を得たのではなく、既存の7構成子を保持した。

    真正の同一fiberへの輸送と10番目を越える障害¶

    実際にM : SelectedContextualEighteen W l r J Nが与えられた場合に限り、chain M Aとchain M Bを元と同一のJ→N fiberへ構成する。九観測、全Nat→Nat祖先塔、三連続反転数はなお一致し、四連続反転数の差1が残る。

    既存の真の商写像selectedRawCongruentNineFullTowerObservationと、新商の独立した三連続計数を組み合わせ、

    Obs_(9+infinity+triple)(q) =
  (selectedRawCongruentNineFullTowerObservation(q),
   selectedRawCongruentConsecutiveTripleOnQuotient(q))

    を定義。実際のMを供給したfiberでこの商観測は非単射、四連続数decoderと全商クラスdecoderは存在せず、J→Jのstrict raw証拠による明示例も存在する。前段v5.66の反例を流用せず、三連続計数まで一致する新証拠対を構成している。

    未認証境界と次段の検討¶

    この定理から、新たに四連続反転数を観測へ追加したときの完全識別性は導けない。その段階は未認証（NO_DATA）。次段では反転連続長一般kの不変量について構造再帰・商保存と、[k,k−2]対[k−1,k−1]（k≧4）の同型の障害が本当に成立するかを具体的に検証できるが、現段階で全kの定理を主張しない。

    任意の異端点fiberの非空性、異fiber whiskering、20D gluing、全WORLDの大域貼合、全商の完全分類、制度的な行為権限は未認証。元18Dの真正依存Type値、旧selected19と新7構成子商の区別、root107、固定Lean/mathlib、保護#1558 Draft/OPEN/未マージを維持。append-only／tighten-only／overwrite-forbidden／same-root。
