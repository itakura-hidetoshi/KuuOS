    1. 数学的対象：五つの真正二分括弧付け¶

    v4.82は任意の有限型付き二分木の評価が、元の順序付き真正DirectNormalChainを右foldしたものと全域観測で一致することを証明済みである。

    v4.83では4つの任意の真正型付き部分木A,B,C,D₄（各部分木は任意有限長・空木も可）について、5つの異なる元Type値二分木を定義する。

    V0 = (((A B) C) D₄)
V1 = ((A (B C)) D₄)
V2 = (A ((B C) D₄))
V3 = (A (B (C D₄)))
V4 = ((A B) (C D₄))

    各部分木の中間Family・部分StateはDirectNormalBracketTreeの依存型添字で実際に一致している。葉は元のFrontNormal、再括弧付けrouteとScheduleは実際の構成子のまま保持される。次数・長さだけの抽象ペンタゴンや商で代替しない。

    2. 元の順序付き鎖での五辺の厳密整合性¶

    5つの真正局所回転は以下の有向辺を与える。

           V0 → V1 → V2 → V3
        ╲             ↑
         →  V4  ─────┘

    pentagonFlatten01、pentagonFlatten12、pentagonFlatten23、pentagonFlatten04、pentagonFlatten43は、各辺で元の順序付き有限鎖そのものの厳密等式を証明する。証明の核は既存のbracketNode_assoc_flatten（その根拠はv4.81のdirectChainAppend_assoc）と、元の左右部分木コンテキストへのcongrArgである。元のsource chainは削除・再構成・商化しない。

    2つの異なる経路から得た端点の元鎖等式はpentagonFlatten_longとpentagonFlatten_shortとして別々に保存する。ここでの厳密等式は鎖の構成子レベルに限るので、評価後のFrontNormal route語の厳密結合則は主張しない。

    3. 2経路の全域観測整合性¶

    5辺でbracketSameChain_observedをそれぞれ適用し、全forward／backward raw index、および元source-witness Type値pullbackの同値を個別に証明する。

    • pentagonLong_observed：3辺 V0→V1→V2→V3 の観測証明を合成。
    • pentagonShort_observed：2辺 V0→V4→V3 の観測証明を合成。
    • pentagonTwoPaths_forward、pentagonTwoPaths_backward、pentagonTwoPaths_pullback：2経路を独立した証明項として、同一の全域端点観測命題の2件の証明を明示する。

    この数学的な意味は観測レベルの五角図式可換性である。PlanObservedEqの証明が同じ命題を確立することを、元五セルの2経路の合成そのものに関するhigher equalityと混同しない。五セル合成によるpentagonatorの存在は導かれない。

    4. 真正GK5CG元五セル・source・compatibility・障害¶

    • 五辺のpentagonEdge**_rawSquareとpentagonEdge**_rawLoopが、双方の元GK5CG五セルType値を持つraw squareと非自明であり得るloopを5辺ごとに保持する。選択五セル値の同一視・各loopの充填はしない。
    • pentagonEndpoint_rawSquare、pentagonEndpoint_rawLoopは共通端点に対する元Type値を別途保持する。五辺の五セル合成を作ったという主張ではない。
    • pentagonEndpoint_path、pentagonEndpoint_certified、pentagonEndpoint_certify_rawは元Quiver.Path、真正source-certified P77 partial Hom、各側の元raw比較を保持する。source witnessがsubsingletonである、任意の未存在source証拠を作れる、とは仮定しない。
    • pentagonEndpoint_allCompatible_iffとpentagonEndpoint_obstructed_iffは両端点の全Plan compatibility／障害を共通の最終因子木に還元する。途中の任意refinementを横断する障害の一律不変性を主張しない。

    6. 次の研究境界 — Qi v4.84候補¶

    真正五角形の観測可換性は完了。一方で元五セルについてのhigher coherenceが成立するかは別である。次段階ではまず、既存GK5CG五セルの合成演算が、五辺のraw square／loopの値について元のsource/target Typeと合成可能性を持つかを検査する。そのうえで合成が構成できる範囲に限り、3辺経路と2辺経路の元Type値合成証明書を別々に定義し、一致または一致を妨げるobstructionを正確に形式化する。

    観測同値だけから充填やloop自明性を推論せず、strict 空中心・独立Kuu＝presentation・same-root・append-only・tighten-only・obstruction-aware descentを継承する。
