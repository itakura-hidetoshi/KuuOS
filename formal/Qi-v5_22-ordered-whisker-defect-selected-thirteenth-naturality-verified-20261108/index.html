    1. 順序付き履歴の真正defect証明書¶

    元第十セル MixedUnitAssocTenCellの生の順序付きBool履歴 mixedTenWhiskerRawTraceを保持する。 新しい OrderedWhiskerDefect(source,target) は、 whiskerPrefix : List Boolと真正等式 exact_target : target = whiskerPrefix ++ sourceを持つ別Typeの証明書。

    二つの実際のdefect A : OrderedWhiskerDefect(a,b)、 B : OrderedWhiskerDefect(b,c)の連結は

    [ \boxed{ \operatorname{prefix}(B\circ A) =\operatorname{prefix}(B)\mathbin{+!+}\operatorname{prefix}(A) } ]

    という後から適用した操作の前置順序になる。 orderedWhiskerDefectId、 orderedWhiskerDefectComp、 orderedWhiskerDefectComp_prefix、 orderedWhiskerDefect_lengthを構成・証明。 rwで依存した証明書そのもののindexを変えることを避け、 congrArgにより型を保ったままリスト等式を合成する。

    元の真正左／右whiskeringでは

    [ \begin{aligned} \operatorname{Trace}{10}(L(\xi)) &= [\mathrm{false}]\mathbin{+!+}\operatorname{Trace}{10}(\xi),\ \operatorname{Trace}{10}(R(\xi)) &= [\mathrm{true}]\mathbin{+!+}\operatorname{Trace}{10}(\xi). \end{aligned} ]

    二重適用した真正元第十セルでは

    [ \boxed{ \begin{aligned} \operatorname{Trace}{10}(L(R(\xi))) &= [0,1]\mathbin{+!+}T,\ \operatorname{Trace}{10}(R(L(\xi))) &= [1,0]\mathbin{+!+}T. \end{aligned} } ]

    doubleWhiskerDefect_orderedValuesはこの厳密な生履歴を証明し、 doubleWhiskerDefect_notCommutativeで順序列の非等号を証明。 一方、長さはともに2+T.lengthで、 doubleWhiskerDefect_lengthCollisionは同じNat計数では 左右順序を区別できないことを明示する。 doubleWhiskerDefect_actualFrameOrderはこれを実元第十一セル framed packetに接続する。traceは商で消去しない。

    2. 元第十二セルの両方向の真正二重whiskering¶

    任意の旧v5.17実在第十二セル証拠

    [ T : \mathrm{MixedExchangeInverseTwelveCell}(H,K) ]

    と、型付き第七セル文脈before,afterを入力する。 旧第十二セル自体が持つ真正whiskerLeft／ whiskerRight原始だけから、二つの別fiberの型付き証拠を構成：

    originalTwelfthRightThenLeft = whiskerLeft before (whiskerRight T after)、

    originalTwelfthLeftThenRight = whiskerRight (whiskerLeft before T) after。

    この両者は同じ元旧十二セルTypeの平行証拠ではない。 元第七〜第十一セルの括弧付けと元十セル履歴が違うので、 暗黙のEq-rec・証拠捏造・元の証拠型の変更を行わない。

    各々を元v5.18 FramedElevenへpackし、 framedTwelfthRightThenLeft／ framedTwelfthLeftThenRightで 既存FramedDoubleWhiskerTwelveCell.previousへ移す。

    3. 真正framed自然性squareと二つの非同一12D経路¶

    旧第十二セルT:H⇒Kの各二重whiskeringと、 v5.18の真正doubleWhiskerを四辺に置く。 次の2つのframed第十二セル合成証拠が、 同じ始終点を正確に持つ。

    [ \begin{aligned} P_{\mathrm{upper}} &: L(R(H)) \xRightarrow{\mathrm{old}(T)} L(R(K)) \xRightarrow{\mathrm{doubleWhisker}(K)} R(L(K)),\ P_{\mathrm{lower}} &: L(R(H)) \xRightarrow{\mathrm{doubleWhisker}(H)} R(L(H)) \xRightarrow{\mathrm{old}(T)} R(L(K)). \end{aligned} ]

    framedWhiskerSquareUpperRouteと framedWhiskerSquareLowerRouteを 元の真正型付き構成子だけで実装した。

    framedWhiskerSquareRoutes_rawDistinctにより (P_{\mathrm{upper}}\ne P_{\mathrm{lower}})を 旧framed十二セルの生構文として証明。 同一framed端点は生十二セル証明値の一致を意味しない。

    さらにframedWhiskerSquare_noInheritedDiagonalは、 任意の元第十一セルH,Kに対し、

    [ \boxed{ \neg\operatorname{Nonempty}! \left(\mathrm{FramedInheritedTwelfth} (L(R(H)),R(L(K)))\right) } ]

    を、元の完全spine観測と互いに異なる[0,1]対[1,0]traceから 証明した。旧同一fiber第十二セルによる対角比較は 旧第十二セル証拠Tが存在しても成立しない。 元第八セルsource/targetの真正EightCell.associate比較は この障害とは独立に存在する。

    4. 新しい選択第十三セルの最小生成元¶

    新しい別presentation SelectedWhiskerNaturalityThirteenを定義。 新規局所生成元はnaturality一種類のみで、 全元第十二セルTと文脈before/afterから (P_{\mathrm{upper}}\Rrightarrow P_{\mathrm{lower}}) を生成する。ほかはstrict・reverse・chainという 形式的比較閉包だけ（計四構成子）。

    selectedWhiskerNaturality_relativeNecessityは、 新選択13D比較の存在と、元framed12Dのraw非等号を同時に証明。 selectedWhiskerNaturality_boundaryAndObstructionは 元第八セルの両端の真正compatibility、13D選択比較の存在、 旧第十二セル対角比較の不存在を同時に与える。

    originalExchangeRightCancellationThirteenCompletionでは、 実在する元v5.17 MixedExchangeInverseTwelveCell.cancelExchangeRight （十一セル逆元往復から反射への非自明な真正12D比較）を使い、 13D生成元が本当にinhabitedであることを示す。

    selectedWhiskerNaturality_noRawEqualityInterpreterにより、 新13D比較のすべてを元のframed第十二セル厳密Eqに送る 万能な解釈関数は存在しないとLean4で証明。

    注意：これは選択13D presentationへの局所比較の追加であって、 元F55/P77/GK5CGに第十三セルがもともと存在した証明でも、 任意の旧高次coherence／thinness／全商からのraw履歴復元でもない。

    5. 初回・第2回Lean記法エラーの構造的修正¶

    初回CI #42432518822： prefixはLean4の記法宣言用予約語であり、structure field名に直接 使用するとパーサが失敗し、下流で未知fieldやsorryAx診断が連鎖した。 元定理を弱めず、whiskerPrefixへ名前を統一した。

    第2回CI #42432813355： rw [A.exact_target]が依存したB : OrderedWhiskerDefect b cの 添字bまで書換えようとして、不正なmotiveを生成した。 rw [D.exact_target]もDのindex依存に同様の問題。 congrArgを用いて必要なList Bool等式だけを作用させ、 元の依存証明書の型を不変に保つ修正を行った。

    第3回CI #42433184371は全10,335 Leanジョブと Governance30ジョブSUCCESS。全26宣言の公理監査は標準だけで sorryAxなし。従って失敗段階のsorryAx表示は 未解決構文・型エラーの診断であり、新しい公理による穴埋めではない。

    6. 数学的authority境界と次段階¶

    Qi v5.22は、元証拠の順序付きdefect、非同一12D自然性経路、 選択13D最小比較の存在を切り分けた。 第八セルcompatibleから旧fiber Eqを導かず、 FramedInheritedTwelfthとFramedDoubleWhiskerTwelveCell、 新SelectedWhiskerNaturalityThirteenの三つのauthorityを混同しない。

    Qi v5.23の候補： 新13D自然性の strict/reverse/chainを越えた、元第十二セルの合成との 互換性・二重whiskeringの3つ以上の文脈を含む critical cube／選択14D obstructionの構成。 元Typeの保存、局所可降下性、商情報損失を引き続き区別する。

    append-only／tighten-only／overwrite-forbidden／same-root。 公開root107、固定Lean/mathlib pin、保護PR #1558を変更しない。
