    2. 四変量の真正19D商観測¶

    従来の三変量 I₃=(length(Trace),ActiveChain,ReverseCount) に、v5.44で証明済みの LeftNestedCount を追加した。

    I₄(q) = (I₃(q), LeftNestedCount(q))

    selectedLocalNineteen_preservesFourは既存比較5構成子の保存を示し、selectedNineteenFourObservationは各厳密な17D dependent endpoint fiberの19D商へ降下する。selectedNineteenFour_onClassとselectedNineteenFour_eq_iffで生18D値との計算則と成分同値を証明。四変量を元のType値証拠Eqへ昇格させていない。

    3. 四変量を区別する真正LR→RL型付き境界¶

    入れ子のNat.pairと既存selectedMixedLengthCodeによりselectedMixedFourCode_injectiveを証明。真正RL証拠の既存列selectedMixedRightTracePowerへ四変量の単射符号を送るselectedMixedFourRawTransportを構成。元LRの真正SelectedLocalNineteen証拠を入力とし、targetのstrict比較を返すselectedMixedFourBoundary.localTransportも実装した。selectedMixedFourAnchoredは指定LR証拠と真正RL証拠の接続を保持する。

    この具体的な輸送の商降下についてのみ、Lean4で

    descend_four(q₁) = descend_four(q₂) ↔ I₄(q₁) = I₄(q₂)

    をselectedMixedFourDescend_eq_iff_observationとして証明した。これによりv5.44の真の括弧付け異証拠対は今回の新境界で分離される（selectedMixedFourDescend_separatesAssoc）。ただし source と target で四変量の数値が全域で一致することや、一般の19D比較反映は主張しない。

    4. 同一四変量でも異なる真正19D証拠¶

    新しいraw18D不変量selectedContextEighteenReverseLeftCountは、chainの左辺の先頭構成子がreverseである節点を数える。旧SelectedLocalNineteenの5構成子がこれを保存することを証明し、selectedNineteenReverseLeftOnQuotientで商へ降下した。

    任意の真正18D証拠X : J → Nの同じ依存fiber内で、

    A(X) = chain (chain (strict J) (reverse (strict J))) X
B(X) = chain (chain (reverse (strict J)) (strict J)) X

    を構成。これらは完全ordered exterior traceが等しく、四変量I₄も同じだが

    ReverseLeftCount(B(X)) = ReverseLeftCount(A(X)) + 1

    となる。selectedNineteenStrictReverse_classDistinctは元の真正19D商クラス[A(X)]₁₉ ≠ [B(X)]₁₉を証明。selectedNineteenStrictReverse_noLocalはその間の真正SelectedLocalNineteen Type値比較が存在しないことも証明した。selectedNineteenFour_notInjectiveは任意のinhabited raw18D exact fiberで四変量観測の非単射性を示す。

    この証明を真正LR二重輸送の原証拠に適用して、四変量境界の像が両者を同一視すること、具体的境界が非単射であり全19D比較の反映証明書を持たないことをそれぞれ証明した。selectedMixedFourAnchored_chosenSwapは指定点のcoarse swap観測のみを保証する。

    5. 権威境界・次段¶

    認証済み： 四変量の19D商上観測、型付き非定数anchored LR→RL境界の実構成、像Eq iff source四変量Eq、v5.44の括弧付け対の識別、第五不変量ReverseLeftCount、同一完全trace・同一四変量・異なる真正19D商クラスという反例、この具体的四変量境界の非忠実性。

    未認証／NO_DATA： 別の忠実LR→RL境界の存在・不存在、全域swap自然性、異なる元Type値の生Eq、無条件20D交換・gluing。観測等値を元の証拠同一性に固定しない。特定の境界の非単射性から一般的な不可能性を推論しない。

    次段Qi v5.46： 第五不変量ReverseLeftCountを追加した観測と、より強い数値的符号化の境界輸送を検討する。残る証拠履歴や自然性条件を独立して検証し、未認証部分はNO_DATAで保持する。
