    2. 独立GK5CD — 依存型の連結とCRT RingHom自然性¶

    前段GK5CCの真正型可変代入鎖 T(start,length) は、各段 α i → MvPolynomial (α (i+1)) Int を実在するRingHomへ移し、その有限長の型付き合成を作る。GK5CDは任意start,left,rightについて、前半T(start,left)と後半T(start+left,right)の合成にNat.add_assocの型移送を施し、単一鎖T(start,left+right)と厳密なRingHom等式で等しいことを証明した。

    型付き等式： transport(Nat.add_assoc start left right, T(start+left,right) ∘ T(start,left)) = T(start,left+right)。

    長さ0の左右分割でも同一値を保持する。左側が0のとき終端添字start+(0+right)とstart+rightは定理的には等しいが、依存型としては無断同一視しないため、補題内で0+rightを明示的に保持する。

    この結果を大域ZMod L_s・元のgcd互換局所SubringR_sで評価するRingHomへ接続。実際のGK5BW CRT RingEquiv、GK5BX被覆制限、三段u⊆t⊆sでのCRT可換性、任意非単射初期変数再分類、元signedInt評価後の剰余一致を導出。法0・空被覆・負係数・非互いに素法・変数型変動を排除しない。

    3. Leanエラーの構造理由と修正¶

    初回CI #41878040482では、連結定理の後続ステップでNat.add_assocの依存型輸送とRingHom.compの交換が未解消であり、左区間0の補題においてα(start+right)とα(start+(0+right))を暗黙に同一視した型不一致も検出された。

    新規ソース全文・依存元GK5CCの再帰的型付きRingHom・Lean4のtransportを照合し、nativeGK5CDTransportStepを等式帰納法cases h; rflで証明。後続の合成に明示的に使用し、左零区間は型添字を0+rightと記述して正確性を保持した。中間CIでは連結本体の公理監査からsorryAxが消え、最後に全13定理のexact-source Leanと公理監査が成功した。数学的連結主張の仮定や射の等式を弱めていない。

    4. Qi v4.48 — 真正北C60 signed numeratorとType authority境界¶

    元fivefoldGK5CCNorthFiniteChainHom arity steps start lengthの各段は実際のFin (arity i)多変数整数多項式を変数として扱う。Qi v4.48は任意分割の真正代入鎖をそのままRingHomにし、終端変数へ元GK5BQ符号付きnativeGK5BQClearedNumeratorを代入。大域ZMod L_s、真正compatible-local Subring、CRT RingEquiv、被覆一段／三段塔、元整数評価の可換性を10定理で証明した。

    境界： 元F55のprimitive原Type証拠P=1とdouble inverse＋右F55単位P=X²について、original→phi seamの存在／不存在が異なることは先行の独立・Qi形式証明で確立された別authority。Qi v4.48で新たに別のF55 sourceやhigher cellを構築したという主張ではない。数値合同やCRT gluingから元F55 Type、P77等号、P89無条件反射、P94A四セル、普遍GK5AY seam、W=1→seamは導かない。既存2≤d・L_s∣d!で保証された零証明は元の整数深度多項式だけであり、任意外側代入多項式が零になるとは主張しない。
