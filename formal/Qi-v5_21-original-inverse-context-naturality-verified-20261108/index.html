    1. 真正inverseContextは別fiberへの型付き作用¶

    v5.20のTraceFaithfulHigherTowerは固定された元の六セル添字 c,dに対し、元第八セルcompatibleに追加して全上位証拠Typeへの 依存関数と第十セル順序履歴保存を要求する。

    Qi v5.21では、新たに元のFramedElevenに直接作用する

    inverseContextTransportFrame : FramedEleven W l r → FramedEleven W l r

    を構成。内部では実際に既存の元構成子を使用する。

    次元 入力 → 出力
    六セル c : w→z → SixCell.symm c : z→w
    七セル s → SevenRewrite.congrInv s
    八セル q → PentagonAssocEightCell.inverseContext q
    九セル alpha → MixedCancelNineCell.inverseContext alpha
    十セル xi → MixedUnitAssocTenCell.inverseContext xi
    十一セル H → MixedExchangeUnitElevenCell.inverseContext H
    十二セル T → MixedExchangeInverseTwelveCell.inverseContext T

    すべて原型のType値のまま構成・添字付けされ、 偽の元六セル等号、EightCell(s, congrInv s)、 商の強制的復元のいずれも仮定しない。 inverseContextTransportFrame_onRawは旧十一セル値を再パックした結果を、 本物の元十一セルinverseContextと定義上の等号で結ぶ。

    2. 履歴保存と逆文脈の二段反復¶

    元第十セルの完全ordered witness traceについて

    [ \boxed{ \mathrm{Trace}{10}(\mathrm{inverseContext}(\xi)) =\mathrm{Trace}{10}(\xi) } ]

    を証明した（inverseContextTransportFrame_preservesTrace）。 二回適用した場合の履歴保存も inverseContextTransportFrame_twice_preservesTraceで証明。

    ただし、自由六セルにおけるsymm (symm c)を cと生の厳密な等号で同一視していない。 反転操作の意味と、元raw構文の強制的簡約は別である。

    3. 旧第十二セル証拠の自然性と比較の降下¶

    inverseContextOldTwelfthは実在する旧 MixedExchangeInverseTwelveCell H Kの証拠値を 既存原始inverseContext Tで輸送し、新しい下位fiberで FramedInheritedTwelfthを構成する。

    inverseContextInheritedTwelfthは、 そのstrict / previous / reverse / chainの 全4構成子に関する帰納法で閉じる。よって旧比較の存在は inverseContextで保たれ、inverseContextInheritedTwelfth_toFullにより 元v5.18 framed第十二セルへ追加の商同一視なしに埋め込まれる。

    これは旧比較のみの自然性である。v5.18で追加した doubleWhisker原始の全体に対する任意context自然性を 新しい公理として仮定したり、一般的に証明したりはしていない。

    4. 生の非恒等性と固定fiber towerのauthority障害¶

    originalReflexiveElevenFrameは任意の元値w : Wについて、 元の六セルrefl w、七セルrefl、 真正の八・九・十・十一セル反射の既存原始だけから作られる 実際にinhabitedな型付き証拠値である。

    入力と輸送後は、元六セルのsourceの最外コンストラクタが

    [ \boxed{ \mathrm{refl}(w)\quad\text{対}\quad \mathrm{symm}(\mathrm{refl}(w)) } ]

    と異なる。この差をframeSourceSixInverseTagで 依存型を壊さず観測し、次を証明：

    • inverseContextFrame_nonidentityAtRefl：任意の元反射六セル添字上の実十一セル証拠について、raw framed packetは厳密に異なる。
    • originalReflexive_inverseContext_nonidentity：実在する具体的反射十一セルで、非同一性と旧第十セル順序履歴の同一性を同時に証明。
    • inverseContextFrame_notFixedSixTower：v5.20の固定六セル添字を保つ任意towerからは、この逆contextの生packetを出力できない。

    この不可能性は歴史の長さだけでなく元六セルsource添字に由来する。 新しいcontextの輸送は実在するが、既存の固定fiber塔に 無条件に取り込めるものではない。

    5. 左右whiskeringとの厳密な対照¶

    originalLeftWhisker_tracePrefix、 originalRightWhisker_tracePrefixが元の十セルコンストラクタについて

    [ \begin{aligned} \operatorname{Trace}{10}(\operatorname{whiskerLeft}(\xi)) &=\mathrm{false}::\operatorname{Trace}{10}(\xi),\ \operatorname{Trace}{10}(\operatorname{whiskerRight}(\xi)) &=\mathrm{true}::\operatorname{Trace}{10}(\xi). \end{aligned} ]

    を定義上の等号で証明。 有限リストの長さの差より、いずれも元の順序履歴には 等しくならない（originalLeftWhisker_traceObstruction／ originalRightWhisker_traceObstruction）。 これは商や任意補助traceを使った仮定ではなく、 元コンストラクタの真正構文に対する結論である。

    従ってinverseContextは履歴を保つ非恒等境界作用、 左右whiskeringは履歴に新しい構造を追加する非保存文脈作用 として区別される。

    6. authority・研究frontier¶

    元source／witnessを別のpresentationへ移すことと、 その元sourceのstrict Eqを証明すること、 異なる文脈間の新しい高次interchangerを存在証明することは 別の数学的義務である。

    今後のQi v5.22では、真正の両側whiskeringを伴う 新しいtrace-defect付きtransportの条件付き合成と、 元第十二セルを保つ独立naturalityの可能性を検討する。 第八セルの比較証拠を元のraw source Eqに昇格させず、 選択商・source authority・残存obstructionを独立に扱う。
