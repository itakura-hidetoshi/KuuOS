    F112-P94D3GK4AL — 真正忘却ファイバーの可算性と条件付き有限行列正規形¶

    2026-10-31 JST／canonical main。元F45の任意の完全依存型Homに対し、真正第二商 K_AI → K_AG の各ファイバーの可算性を、既存GK4AJの第二行列単射からLean4形式化した。GK4AKで得た任意大有限下界と矛盾せず、両者を一つの真正ファイバーに結び付ける。GK4AKのroot README／ROADMAP未同期分も、本GK4AL文書PRで合わせて同期する。

    2. すべての真正型付きファイバーの可算性¶

    真正ファイバーの可算性Leanは元の型付き木first, lastと、任意の旧K_AG類qに対して定義済みの本当の従属型

    Fiber(q) := {z : K_AI(first,last) // U_AI,AG(z) = q}

    から、元GK4AH第二整数行列M_AH(z)への単射を作り、

    Countable Fiber(q)

    をLean定理nativeGK4ALFiberCountableとして証明する。行列型NativeGK4AHMatrix=(Int×Int)×(Int×Int)は可算。GK4AJのnativeGK4AJFiberMatrix_injectiveを直接使うため、LocalRotation、実F54単位律や元Qの圏公理は不要。さらにnativeGK4ALKernelHomCountableにより、任意の元F45型付きHomのK_AI全Hom自体が可算である。

    nativeGK4ALAttainedMatrixSetは実際に到達する第二行列値の集合（Set.range）。nativeGK4ALFiberAttainedMatrixEquivは次の正確な同値を再利用して証明する。

    Fiber(q) ≃ { M : NativeGK4AHMatrix //
             M ∈ Set.range (nativeGK4AJFiberMatrix first last q) }

    これは全整数行列が到達することを意味しない。観測値を単なる自由な整数4組と同一視しない。

    3. GK4AKとの結合：任意の有限下界を持つ可算ファイバー¶

    真正有限族・正規形条件Leanは、元F54真正LocalRotationを固定し、GK4AKの

    W_k(j) = B^(6j) ; C ; B^(12(k-j)) ; C ; B^(6j)
0 ≤ j ≤ k

    を再利用する。これらは単一の旧観測類q_kに忘却されるが、第二行列から

    L(M_AH(W_k(j))) = 8 - 192 * (k - j)
L([[a,b],[c,e]]) = 4*b + 2*e - 2*a - c

    という整数線形decoderで添字を復元できる。従って任意kについて本当の到達行列集合への

    Fin(k+1) ↪ NativeGK4AHMatrix
Fin(k+1) ≃ {M // ∃ j : Fin(k+1), M_AH(W_k(j)) = M}

    を作る。ここでの同値は構成された有限部分族に対してのみであり、全ファイバーとの同値を無条件に主張しない。

    主定理nativeGK4AL_arbitrary_finite_countable_fiberは

    ∀ k : Nat, ∃ q_k : K_AG(before,before),
  Countable (Fiber(q_k)) ∧ Nonempty (Fin(k+1) ↪ Fiber(q_k))

    を、真正元F54の型付き源経路から証明。さらにnativeGK4ALPhysicalNorth_arbitrary_finite_countable_fiberは真のC60北側六角形に無条件で特殊化する。

    4. 「有限族が全体を尽くす」と言えるための正確な障害¶

    nativeGK4ALFamilyCovers rot kは、選んだFin(k+1)経路族が実際のFiber(q_k)へ全射であるという追加命題として定義する。Lean定理nativeGK4ALFamilyCovers_iff_matrixCoverは、次の必要十分条件を証明する。

    FamilyCovers(k) ↔
  ∀ z : Fiber(q_k),
    ∃ j : Fin(k+1), M_AH(z) = M_AH(W_k(j))

    この条件は第二行列のファイバー内単射により厳密に成立し、逆向きも失われない。被覆条件そのものは証明していない。その仮定が与えられた場合に限り、nativeGK4ALExactFiniteFiberEquivOfCoverは

    FamilyCovers(k) → Fin(k+1) ≃ Fiber(q_k)

    を返す。従って、ファイバー全体のexact cardinalityや構成族の網羅性は現段階では未知のままである。

    5. 境界／次候補¶

    • 今回の定理は「各ファイバーは高々可算」かつ「サイズはファイバー間で一様に有限有界ではない」という両立する二主張である。異なるkのターゲットq_kはGK4AKで相異なることも証明済み。一つの固定ファイバーが無限であることは今回の結論ではない。
    • S→K_AIの全域忠実性、全整数行列の到達可能性、q_kファイバーの正確な元数、元P92B Qの結合律・左右単位、歴史的完全型付き同値、真正14D無条件Countable、19D filler、global strict n、Gray圏およびhyperdescentは未証明。
    • 次候補GK4AM（未証明）：固定した真の旧類qについて無限個の元F54真正経路を同時に載せられるかを検討し、有限族の非網羅性の証人または到達値の具体的制限を探す。有限下界の非一様性から単一無限ファイバーを推論しない。
