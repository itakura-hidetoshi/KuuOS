    数学的構成と独立した商不変量¶

    v5.65は全祖先塔とordered trace/topからadjacent reverseを復元できないことを証明したが、その証拠対はadjacentを含む既存九変量に対する反例ではない。v5.66では新しい証拠対を直接構成した。

    同じ元17D端点Nについて、元のSelectedContextualEighteen W l r N Nの本来のstrict、reverse、chainだけで

    S   := strict N
R   := reverse S
gap(X) := chain X S
A   := reverse (reverse (reverse (gap R)))
B   := reverse (reverse (gap (reverse R)))

    と定義する。両者はraw reverse節4個を持つが、Aは3連続＋gap＋1、Bは2連続＋gap＋2という異なる構文配置を保持する。

    v5.59の真のC_n（C₀=1は形式seed）に対し、gapにstrictを足しても全次数計数が不変、raw reverseの再配置でも帰納的に一致することを証明。従って、

    ∀ n : Nat, C_n(A) = C_n(B)
Trace(A) = Trace(B) = []
TopReverseFlag(A) = TopReverseFlag(B) = 1
AdjacentReverseCount(A) = AdjacentReverseCount(B) = 2

    が本来の真正18D証拠に成立。C₁〜C₅と元の反転総数・祖先pair/triple/quadruple/quintuple計数のv5.60橋渡しを用い、既存の全八raw観測の同時一致、さらに第九C₆の一致を形式証明した。

    これとは別の新しい情報として、二つの即時raw reverseが頂点にあるかを調べるselectedContextEighteenTopDoubleReverseFlag、およびその再帰による直接三連続raw反転数selectedContextEighteenConsecutiveTripleCountを元Type値へ追加定義。後者は元selected19の5構成子・新7構成子でそれぞれの保存を構造帰納法で証明し、旧商・新商へ独立にQuotient.liftで降下、旧商→新商のprojectionとも因子化する。

    この真正新商不変量だけが二つの元証拠で

    ConsecutiveTripleCount(A) = 1
ConsecutiveTripleCount(B) = 0

    と異なるため、新商クラスは一致せず、型付き新19D比較値も存在しない。

    同一fiberへの輸送・真の無限結合観測¶

    元の真正M : SelectedContextualEighteen W l r J Nが与えられたときだけ、chain M Aとchain M Bをその元と同じJ→N exact fiberに構成した。元八観測・C₆・全てのCₙは右合成により一致したままで、三連続反転数の差は1のまま残る。

    既存の真の新商観測selectedRawCongruentNineObservationと、全自然数次数の真正selectedRawCongruentFullTowerObservation : Quotient → (Nat → Nat)の積

    [ \mathrm{Obs}{9+\infty}(q) = \bigl(\mathrm{Obs}{9}(q),(n\mapsto C_n(q))\bigr) ]

    を新たな独立の商写像selectedRawCongruentNineFullTowerObservationとして定義した。これは有限打切りではなく全Nat→Nat関数であり、adjacentを含む既存九変量すべて＋無限塔を同時観測している。

    形式証明された結果は、指定された実在Mのある同一fiberにおいて、この写像は非単射、三連続反転数を全域に復元するdecoderは存在せず、全クラスdecoderも存在しないこと。指定J→Jには本来のstrict Jがあるため、実在する証拠を用いた無条件のendomorphism版も成立。

    未認証境界・次段¶

    今回の結果は「全祖先塔＋既存九観測」が新商の完全復元を与えないという具体的な形式定理である。ここへ新しい三連続反転数を加えた十番目の観測で全商クラスが復元できるかは依然NO_DATA。この特定反例を十番目の観測の非単射性として再利用してはならない。

    同様に、任意異端点fiberの非空性、異fiber whiskering、20D gluing、全WORLDの大域貼合、制度的実行権限は未認証。元selected19商／新7構成子商は別のpresentationとして維持し、v5.51で証明済みの旧LeftNestedCountや元19D正規代表の非降下障害も保持する。
