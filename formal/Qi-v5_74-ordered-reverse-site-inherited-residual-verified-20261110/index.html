    新しい独立観測と保存性¶

    真正 M : SelectedContextualEighteen W l r J N のraw構成子に構造再帰し、各 reverse A の直下の元証拠 A に存在する真正 inherited(old18) 葉の個数を記録する。新定義は selectedContextEighteenReverseSiteInheritedCounts。その動作は：

    inherited old18    ↦ []
strict N           ↦ []
whiskerLeft/Right A↦ SiteList(A)
reverse A          ↦ InheritedLeafCount(A) :: SiteList(A)
chain A B          ↦ SiteList(A) ++ SiteList(B)

    単に反転総数や継承葉総数を読むのではなく、raw反転の位置ごとの条件付き継承数を順序付きで保存する。新しい値は旧18D本体の代用や元Type値の同一視ではない。

    • 元の SelectedLocalNineteen 5構成子すべてで保存を形式証明した。特に旧 unitPrepend・unitAppend はraw strictの挿入・削除のみで反転位置列に影響しない。
    • 独立 SelectedRawCongruentNineteen 7構成子すべてで保存を形式証明。新 rawReverse に対しては既存v5.71の継承葉数保存と再帰的な反転位置列の保存を両方使用し、元の型付き比較を忠実に追った。左右の rawChainRight／rawChainLeft も順序付きリスト連結と互換。
    • 旧商・新商に独立して Quotient.lift で降下し、元の旧→新projectionへの因子化を証明。比較規則の上書きや追加公理は行っていない。

    真正同一fiberでの全旧観測一致と新しい障害¶

    任意の真正17D端点 N について、元 SelectedContextualEighteen の厳密な依存構成子だけで以下を作る。

    R = reverse (strict N)
I = reverse (inherited (SelectedLocalEighteen.strict N))
A = chain R I
B = chain I R

    両者は真正 N→N の元raw18D Type値である。既存九観測、全次数の祖先塔 Nat→Nat、全次数の直接連続反転数塔 Nat→Nat、完全ordered raw反転ラン列、単位簡約したraw18D非結合括弧構造、inherited葉数（両方1）、順序付き旧18D根タグ列（両方 [strict]）、さらにv5.73で加えた完全ordered内部旧18D非結合構文リスト（両方 [oldStrict]）**まで一致する。

    新たな反転位置列だけは S(A)=[0,1]、S(B)=[1,0] で異なる。この列は真正新商へ降下するため、実際の新7構成子商クラスが相異なり、両者の真正Type値新19D比較も存在しない。単なるraw構文の文字列不一致を商不一致と取り違えていない。

    さらに、元の真正 M:J→N が実際に供給された場合だけ、chain M A と chain M B を同じexact dependent fiber J→N に構成する。全従来観測は一致し、新反転位置列の相違は同じprefixのList消去則によって残る。よって拡張前のv5.73結合商観測はそのfiberで非単射、反転位置列のdecoderおよび商クラス全体のdecoderは存在しない。指定 J→J に対しては真正 strict J を使った具体例も得た。勝手に異端点fiberを非空と仮定していない。

    論理的な境界・次段¶

    新しい列を追加しても、全商クラスの一般分類・完全復元は証明していない。今回の反例対は新反転位置列そのもので区別されるため、その新観測を加えた場合の非単射性の証明に流用できない。
