    1. 型付き十一セル逆元往復の二方向¶

    v5.16で導入した唯一の新規第十一セルの交換原始を

    [ \Xi\colon\Theta_{EU}\Longrightarrow\Theta_{UE} ]

    とする。Thetaは元のQi v5.15で生成された二つの生の第十セル型付き証拠であり、 両者のstrict raw Eqは以前から偽である。

    第十一セルでの反転・連鎖により、真正の左右往復

    [ \begin{aligned} L_R&=\Xi\star\Xi^{-1} \colon\Theta_{EU}\Longrightarrow\Theta_{EU},\ L_L&=\Xi^{-1}\star\Xi \colon\Theta_{UE}\Longrightarrow\Theta_{UE} \end{aligned} ]

    をそれぞれ構成した。

    対応Lean API：

    • twelfthOriginalExchangeRightLoop／twelfthOriginalExchangeLeftLoop
    • twelfthOriginalExchangeRightRawGap／twelfthOriginalExchangeLeftRawGap

    どちらのループも各元端点におけるmixedExchangeUnitElevenCell_reflとはraw 11Dで厳密に異なる。第十二セルを設けてもそのraw Eqは書換えない。

    2. 最小の独立第十二セルpresentation¶

    MixedExchangeInverseTwelveCellは、同じ元の第十セル始終点 xi zeta の二つの生第十一セル値 H K を比較する、新たなType値文法である。

    追加したprimitiveは四種類に限定する。

    1. cancelExchangeRight：L_Rと右端点の第十一反射証拠を比較。
    2. cancelExchangeLeft：L_Lと左端点の第十一反射証拠を比較。
    3. whiskerLeftStrict：whiskerLeft before (strict rfl)と、whisker済みの元第十セル証拠のstrict rflを比較。
    4. whiskerRightStrict：右whiskerについて同じ整合を要求。

    その他十五構成子は、strict／reverse／chainおよび既存第十一セルの反転・連鎖・十セル反転と合成・九セル文脈・左右whiskering・inverse/composite文脈への型付き閉包だけである。計十九構成子。

    選択されたSetoid mixedExchangeInverseTwelfthSetoid と商mixedExchangeInverseTwelfthClassについて、比較可能性とクラス一致の必要十分条件を証明した。 元の左右往復は選択商では対応する反射と一致するが、raw eleventh witnessの同一性には戻らない。

    mixedExchangeInverseTwelfthClass_noRawRetractionにより、この選択商から全生第十一セル証拠への左逆復元は存在しない。

    3. 左右whiskeringの本物の局所critical pair¶

    twelfthLeftWhiskerStrictCriticalとtwelfthRightWhiskerStrictCriticalは、いずれも以下を同時に示す：

    • whiskerした第十一反射のraw証拠と、whisker済み第十セル上の新しい反射証拠はstrict Eqで異なる。
    • しかし二つの証拠は新設の型付き第十二セルで比較できる。

    既存の第十二セル比較をwhiskerした後で、これらのstrict整合generatorを連鎖することにより

    • twelfthLeftWhiskeredCancellation
    • twelfthRightWhiskeredCancellation

    を構成した。これは単なる同型視や下位証拠の書換えではない。

    未解決境界：「左whiskerしてから右」と「右whiskerしてから左」は、下位のraw ninth/eighth/ten証拠インデックスまで一致するとは限らない。二重whiskerのinterchangerを無条件に設けると、未証明の局所compatibilityを捨てるため、今回は導入しない。

    4. 生第十一セル履歴に残る独立不変量¶

    eleventhTenSymmEventCountを元の第十一セル証拠について構造再帰で定義する。

    [ N_{\mathrm{tenSymm}}(H) =#{\text{original eleven-cell tenSymm wrappers in }H}. ]

    単位・反転・whiskeringによる再包囲は元の構成子の出現回数を適切に保存し、tenSymmだけが1を加える。連鎖・合成の下では加法的である。

    mixedExchangeInverseTwelveCell_preservesTenSymmCount は全十九第十二セル構成子を構造帰納法で覆い、選択比較

    [ \Omega\colon H\Rrightarrow K \quad\Longrightarrow\quad N_{\mathrm{tenSymm}}(H)=N_{\mathrm{tenSymm}}(K) ]

    を形式証明する。

    さらに mixedExchangeInverseTwelfthTenSymmCount が本物のQuotient.liftであり、代表元評価式も検証された。

    特に元の実在する十セルcritical witness pmLeftUnitCriticalExchangeThenUnit について、 twelfthOriginalTenSymmStrictLoopと対応する第十一反射の値は

    [ \boxed{ N_{\mathrm{tenSymm}} \bigl(\mathrm{tenSymm}(\mathrm{strict\;rfl})\bigr)=1, \qquad N_{\mathrm{tenSymm}}(\mathrm{strict\;rfl})=0. } ]

    したがって二つは新しい第十二セルによって比較不能であり、商のクラスも異なる。 mixedExchangeInverseTwelveCell_notGloballyThinにより、選択第十二セルはglobal thinにならない。

    この非比較は今回選択した第十二セル文法に相対的であり、任意の高次圏における一般不可能性を宣言するものではない。

    5. 元の証拠とauthority境界¶

    mixedExchangeInverseTwelveCell_retainsOriginalTenthObstructionsは、v5.16の本物の十セル往復で残った独立計数 (2,0)対(0,0)、(0,2)対(0,0) に基づく旧第十一セル比較の不存在を保存する。第十二セルの追加は旧十一セル構成子を増やさない。

    pentagonActualOriginalExchangeTwelfthCompletionは、任意の真正P77 final raw indexで、元GK5CG長短五セルType値を供給し、新たな十二セル存在と、元PentagonAdjoinedSixCellEqualityInterpreter不存在を同時に構成する。

    保存原則：append-only／tighten-only／overwrite-forbidden／same-root。新presentationでの比較を旧raw証拠の同一性、普遍的coherence、higher authorityの昇格へ読み替えない。

    6. 次段Qi v5.18¶

    研究課題は、元のwhiskering済みraw境界を忘れずに

    [ (\mathrm{left}\circ\mathrm{right})\quad\text{対}\quad (\mathrm{right}\circ\mathrm{left}) ]

    の局所インデックス付きinterchanger候補を構成することである。 まず十・十一セル境界が一致する場合と一致しない場合を分け、十一セル／十二セルの二経路のcritical overlapを調べる。必要な比較だけを局所追加し、より低次の元証拠、保存観測量、残存obstructionを継続追跡する。
