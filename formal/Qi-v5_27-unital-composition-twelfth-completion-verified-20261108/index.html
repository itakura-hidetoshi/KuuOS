    2. 最小の選択的文脈補完¶

    新たな独立Type SelectedUnitalCompositionTwelve W l r F G は、v5.25のContextClosedFramedTwelveの真正生証拠をpreviousへそのまま格納する。既存構文の変更は一切ない。

    strict/reverse/chain、元第七セルの境界適合的whiskerLeft/whiskerRightは新presentation側でも保持する。そのうえで、型付き第十二セル比較生成元は次の4種類だけを新設した：

    • unitLeft：元第七セルrefl cで左whiskeringした元packetと元packetとの比較。
    • unitRight：元第七セルrefl dで右whiskeringした元packetと元packetとの比較。
    • compLeft：左文脈を2回逐次適用したpacketと、元SevenRewrite.transで合成した文脈を1回適用したpacketとの比較。
    • compRight：右文脈の逐次適用と、元SevenRewrite.trans合成文脈の適用との比較。

    いずれも元第六セル境界c,dと真の元第七〜第十一セルType値を添字として保持する。既存の第六〜第十四セルの構成子に単位・合成法則を密かに追加したのではなく、新たに選択した比較presentationのみに法則を導入した。

    IsSelectedUnitalCongruenceとselectedUnital_leastは、元v5.25比較とこの4種類の局所生成元を含む同値関係・左右文脈閉包に関して、新比較が最小の関係であると証明する。最小性は指定した生成規則に関するもので、任意の外部coherenceまで含む万能的最小性ではない。

    3. 新しい境界付き商における厳密な単位則と合成則¶

    元第六セルの正確な境界c,dごとにselectedUnitalBoundarySetoidを構成し、商をQ_{27}(c,d)と表す。元第七セルの文脈u:b→c、v:d→eに対して、元の真のwhiskeringを使った

    [ L_u:Q_{27}(c,d)\to Q_{27}(b,d),\qquad R_v:Q_{27}(c,d)\to Q_{27}(c,e) ]

    が新比較に関してwell-definedであることをQuotient.liftで証明した。

    selectedUnitalLeft_unit・selectedUnitalRight_unitはすべての商の点xについて

    [ \boxed{L_{\mathrm{refl}}(x)=x,\qquad R_{\mathrm{refl}}(x)=x.} ]

    selectedUnitalLeft_comp・selectedUnitalRight_compは型付きの合成可能な二つの元第七セル文脈について

    [ \boxed{L_u(L_v(x))=L_{u\cdot v}(x),\qquad R_v(R_u(x))=R_{u\cdot v}(x).} ]

    を証明した。さらにselectedUnital_actions_commuteは、v5.18の元doubleWhiskerから来る真正旧比較証拠を二重に包含し、左右反対側の作用の交換則を維持する。

    これらは選択商上の等式であり、元の生FramedEleven値のEqではない。

    4. 元証拠の保存と、従来の履歴長の非降下¶

    selectedUnital_previous_injectiveは旧v5.25の生の十二セル証拠値の新Typeへの埋込みが単射であることを証明する。一方、contextToSelectedUnitalは旧v5.25商から新v5.27商への自然な写像を構成するが、この商写像は単射ではない。

    実在する元MixedExchangeUnitElevenCell.exchangeUnitからContextFrameEleven証拠を作り、反射左文脈の前後で元raw第十セルのwhisker総履歴長が1増えることを用いると、

    [ \operatorname{contextClosedClass}(L_{\mathrm{refl}} F) \ne\operatorname{contextClosedClass}(F) \quad\text{but}\quad \operatorname{selectedUnitalClass}(L_{\mathrm{refl}}F) =\operatorname{selectedUnitalClass}(F). ]

    したがって、新商から全raw packetの旧長さcontextTraceLengthを再構成する観測写像は存在しない：

    [ \boxed{\neg\exists\, O:Q_{27}\to\mathbb N\;\; \forall F,\ O([F])=|\mathrm{Trace}_{10}(F)|.} ]

    selectedUnital_contextQuotient_notInjectiveとselectedUnital_noLengthDescentでそれぞれ証明した。 元の生packetの履歴は削除されず、選択商からの読み出しに関してのみ区別が失われる。

    5. 三つの元観測量は保存され、tenSymm障害は残る¶

    従来の真正元第十セル関連三計数

    [ C(F)= (\mathrm{oldTenthCount}(F), \mathrm{unitTenthCount}(F), \mathrm{tenSymmCount}(F))\in\mathbb N^3 ]

    に対し、selectedUnital_preservesCountsは新第十二セルの全10構成子を帰納して保存を証明する。selectedUnitalEventCountsは新商からこの三つ組への実際のQuotient.liftを構成する。

    selectedUnital_retainsTenSymmObstructionは元v5.18のtenSymm critical loopとその反射packetの間に新比較が存在しないと証明した。これにより補完は全packetを無条件に同一視しない。ただし三計数が全新比較を完全分類するという逆方向は未証明。

    6. authority境界・次の課題¶

    本結果は、元第七セル・第十一セル証拠から導いた独立の選択第十二セルpresentationにおける定理である。元F55/P77/GK5CGの同一視、既存6D〜14Dのraw Eq、v5.22/23の選択13D/14Dとの全面的自然性、任意高次cubeのcoherence、汎用的な完全正規化は主張していない。

    次のQi v5.28では、新商上で同側合成法則が複数の括弧付け・三連文脈の貼り合わせと整合するか、旧13D/14Dの選択比較へ移送できる条件は何か、さらに一段上の証拠履歴を保持しながら調べる。
