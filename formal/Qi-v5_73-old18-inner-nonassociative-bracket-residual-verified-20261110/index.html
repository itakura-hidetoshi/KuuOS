    Qi v5.73 — inherited旧18D内部の非結合的括弧構造が残す識別障害（Lean4形式証明・公理監査）¶

    2. 真正旧18D証拠からの独立した非結合的内部構文観測¶

    元の依存Type SelectedLocalEighteen は strict、unitLeft、unitRight、reverse、chain の5構成子を持つ。独立の SelectedInheritedOldInnerBracket は、これらをそれぞれ oldStrict、oldUnitLeft、oldUnitRight、単項 oldReversed、二項 oldJoined に写す、結合則を課さない構文木である。これは本来の依存Type値を同一視する商ではなく、本来の値の独立観測である。

    新 selectedContextEighteenInheritedInnerList は、真正contextual18D raw証拠の inherited(old18) 葉で内側のold18D構文木を読み、順序付きListにする。raw strict は空列、raw reverse／whiskerは内側の列を保持し、raw chain A B は列を順序付き連結する。

    • 元 SelectedLocalNineteen の5構成子すべてでこの列が保存される。特に元 unitPrepend／unitAppend はcontextual raw strict を除くだけで、継承された真のold18D証拠を変更しない。
    • 独立 SelectedRawCongruentNineteen の7構成子すべてで保存。raw reverseと左右raw chainにおける型付き保存を帰納法で証明。
    • 旧・新の別々の真正商へ Quotient.lift し、旧→新projectionを通じた因子化も証明した。比較生成元の増設や元Typeの書換えはない。

    3. 既存全観測の一致と新障害の実例¶

    任意の真正17D端点 N の元old18D N→N fiberで、次の実際のType値を構成する。

    s    := old18.strict N
Aold := old18.chain (old18.chain s s) s
Bold := old18.chain s (old18.chain s s)
A    := contextual18.reverse (contextual18.inherited Aold)
B    := contextual18.reverse (contextual18.inherited Bold)

    Aold、Bold のold18D最外構成子はともに chain、内部の strict 原子はどちらも3個。しかし非結合的old18D構文木は ((s∘s)∘s) と (s∘(s∘s)) で異なる。

    元の真正contextual18D A、B について、従来の九観測・全自然数次数の祖先塔 Nat→Nat・全直接連続反転数塔 Nat→Nat・完全ordered raw逆転ラン列・raw18D単位簡約非結合括弧・inherited葉数（双方1）・その最外構成子の順序付き列（双方 [chain]） が完全一致することを形式証明した。

    その一方で、新しい真のold18D内部括弧リストは [oldJoined (oldJoined s s) s] 対 [oldJoined s (oldJoined s s)] と異なる。このリストは真正7構成子商へ降下するため、真正新商クラスは相異なり、型付き新19D比較も存在しない。

    さらに実在する元 M:J→N を明示的に受け取った場合に限り、chain M A、chain M B を同じexact dependent fiberに構成し、全旧観測とv5.72根タグ列が一致したまま、新しいold18D内部括弧列は共通prefixのList消去によって異なるままと証明。よって、その実在するfiberにおける結合商観測の非単射、inner-bracket decoder不存在、全商クラスdecoder不存在、真正 strict J を与えるJ→J例を得た。異端点fiberの任意非空性は仮定しない。

    5. 論理境界と次段¶

    SelectedInheritedOldInnerBracket は旧18D構成子の内側の形状を読むが、unitLeft や unitRight の依存添字・元の before/F/G/C/after 証拠値をそのまま復元するものではない。同じ自由構文木を持つ異なる元旧18D Type値の識別性、全新商クラスの分類、全証拠Type値の再構成はNO_DATA。

    次段Qi v5.74では、この内部構文木まで追加した結合観測について、真正同一fiberの新たな識別障害または制限した構文クラスでの忠実性を検証する。今回の証拠対は内部構文木で区別されるため、そのまま次段の非単射反例に流用しない。
