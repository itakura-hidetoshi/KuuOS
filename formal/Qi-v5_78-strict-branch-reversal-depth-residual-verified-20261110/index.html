    新しい独立観測：最大strict-only枝のraw反転祖先深度¶

    v5.77のSelectedStrictOnlyBranchSummaryはpureなstrict-only非結合枝形の順序を保持するが、各枝の外側に存在するraw reverseの祖先個数は記録しない。v5.78では、元の真正依存SelectedContextualEighteenの構造再帰から、次の別の観測を定義した。

    SelectedStrictBranchDepthSummary: - pure : Option SelectedStrictOnlyChainTree - sites : List (Nat × SelectedStrictOnlyChainTree)

    chainは両子がpureなら一つの最大非自明joined枝と深度0を作り、それ以外では枝位置列を左右順に連結する。reverseはその内側の全枝の深度を1増す。whiskerLeft／whiskerRightはpure根を終えるがraw反転深度を増さない。inherited(old18)とraw strict単体は非自明strict-only枝を作らない。

    本観測は元旧selected19の全5構成子、独立新selectedRawCongruentNineteenの全7構成子で保存されることを実Type値比較の帰納法で個別に形式証明した。旧単位規則unitPrepend／unitAppendが挿入するのは真正inherited葉に隣接するraw strict単体であり、非自明pure strict-only chainではない。

    旧5構成子商と新7構成子商のそれぞれへ独立したQuotient.liftを構成し、旧→新商射影に関する因子化も証明した。元18D証拠、旧新比較Typeそのものには変更を加えていない。

    v5.77全観測一致の新しい真正18D証拠対¶

    任意に与えられた真正17D端点Nに対しS = strict Nと置き、同一N→N依存fiber内で以下を元の構成子のみから定義する。

    • A = chain (reverse (chain S S)) S
    • B = chain (reverse S) (chain S S)

    両者のraw strict葉数は3、raw chain数は2、raw reverse数は1。元九観測、両方の全無限Nat→Nat塔、完全ordered reverse-run列、v5.70単位簡約括弧、旧18D継承葉数・根・内部構文列（空）、v5.74反転site列[0]、v5.75イベント語[rawReverse]、v5.76継承葉保持括弧reversed unitの値が全一致する。無限塔の同値性は各次数の証明とfunextを使う。

    さらにv5.77で追加した最大strict-only枝形summaryも双方(none, [joined leaf leaf])で一致する。従ってv5.77までの全商観測selectedRawCongruentFullV577QuotientObservationが一致することを、実商上で形式証明した。

    しかし、新summaryの最大枝は次のように異なる。

    • Depth(A) = (none, [(1, joined leaf leaf)])
    • Depth(B) = (none, [(0, joined leaf leaf)])

    左の枝はraw reverseの内側、右の枝はraw reverseの外側である。新summaryが新7構成子商へ真正に降下するため、新商クラス不一致、真正新19D Type値比較の不存在が従う。これを用い、任意の実在するNのN→N商上でのv5.77全観測の非単射性、新深度情報decoder・商クラスdecoderの不存在をLean4形式証明した。

    単なるraw証拠文字列の差ではなく、独立に降下した商不変量によって比較不能性を示している。

    有効範囲・未認証事項と次段¶

    証明されたのは真正17D端点Nが供給される同一N→N fiberでの非単射性である。無条件の任意異端点J→N fiber非空性、全商クラスの分類、完全復元、20D gluing、WORLD横断降下、制度的・実行権限はいずれも未認証（NO_DATA）。

    次段Qi v5.79では、新しい反転祖先深度を全観測へ追加した場合の識別力や、raw chainの左右位置・より深い構造が独立の商不変量として残るかを、あらためて真正型付き証拠上で検証する。v5.78のA/Bは新しい深度観測により区別されるため、次段反例には再使用しない。

    append-only／tighten-only／overwrite-forbidden／same-root。
