    Qi v5.82 — 元18Dのpure strict/reverse/chain部分presentationにおける条件付き忠実性（Lean4形式証明・公理監査）¶

    2026年11月10日 JST。対象は、元の依存型SelectedContextualEighteenから明示的に構成される限定部分、旧5構成子SelectedLocalNineteenと別Typeの新7構成子SelectedRawCongruentNineteen、それぞれの真正商である。「空」「縁起」との哲学的対応は命名・解釈層に属し、形式証明は与えられた型・構成子・比較・商の局所的主張に限る。

    2．元の依存18D Typeに埋め込む限定構文¶

    SelectedPureStrictReverseTreeはstrict、reversed、joinedからなる自由な非結合構文木である。真正に与えられた17D端点Nごとに、再帰的なselectedPureStrictReverseEmbed Nでこれを元の真正SelectedContextualEighteen W l r N Nの元Type値へ送る。

    • strictは元のstrict N。
    • reversed Aは元のreverse (embed N A)。
    • joined A Bは元のchain (embed N A) (embed N B)。

    この限定presentationにはinheritedや左右whiskering構成子は現れない。したがって、旧19Dの本来の単位規則が消す「真正inherited葉に直接隣接したstrict」は存在せず、任意のraw strictを単位として消す新しい規則を仮定しない。任意の異端点J→Nの居住性も仮定しない。

    3．v5.81独立観測からの局所復元¶

    別定義selectedPureStrictReverseRawValueは、自由なstrict/reversal/chainの樹形をv5.81のSelectedWhiskerPlacementTreeへ読み取る。真正18D構成子への埋め込み後の実観測とこの値が一致することを元の依存Type上で形式証明した。

    selectedPureStrictReverseDecodeは全補助観測型上の関数として定義するが、その左逆性が証明されるのはこのpure部分の像上だけ。他のsource・left・rightを含む全構文に対する忠実復元器とは主張しない。結果としてこの部分上では元18Dへの埋め込みも単射である。

    4．旧5構成子と新7構成子の比較の一致範囲¶

    指定した真正N→N fiberの純粋部分で、Lean4で次をそれぞれ証明した。

    [embed N A]_(old 19D) = [embed N B]_(old 19D)  ↔  A = B
[embed N A]_(new 19D) = [embed N B]_(new 19D)  ↔  A = B

Nonempty (SelectedLocalNineteen (embed N A) (embed N B))
  ↔ A = B

Nonempty (SelectedRawCongruentNineteen N N (embed N A) (embed N B))
  ↔ A = B

    旧新のTypeとしての比較を同一視せず、この制限された像上の比較可能性の必要十分条件が同じことを証明した。旧・新商クラスの写像はそれぞれ単射で、旧→新射影もこの限定部分上では等号を反映する。全体商の一致や一般的な逆向き比較生成元の存在は主張していない。

    5．v5.81完全観測を保つ局所的な忠実性¶

    SelectedFullV581QuotientObservationValueは、それまでのSelectedFullV580QuotientObservationValueと、v5.81の独立して新商に降下済みのwhisker配置木との直積である。

    selectedRawCongruentFullV581QuotientObservationを真正7構成子商からこの直積へ構成し、上記pure fragmentで

    FullV581([embed N A]) = FullV581([embed N B])  ↔  A = B

    および合成写像の単射性を形式証明。従来の元九変量、二本の全Nat→Nat無限塔、ordered reversal run、元旧18D出典、strict-only枝観測などを減らすことなく、新観測を追加する構成である。

    境界：v5.81で作ったwhiskered真正18D反例では、この新観測を含まないv5.80完全観測が非単射だった。本v5.82は別の制限されたpure構文像の単射性であるため、それと矛盾しない。

    8．未認証の範囲と次段¶

    依然として任意の元18D証拠をpure部分へ簡約する定理、旧5構成子と新7構成子の大域的比較同値、全商の完全忠実分類、任意J→Nの居住性、WORLD横断降下、20D gluing、行為権限は未認証（NO_DATA）である。

    Qi v5.83の候補：元inherited葉またはwhiskeringを一つ以上含む部分presentationへ、どの補助履歴を保持すれば局所復元が拡張できるか、単位規則や元依存証拠の値を保存したまま探索する。対象部分の拡張と降下の証明条件を先に立て、未認証の全域化をしない。
