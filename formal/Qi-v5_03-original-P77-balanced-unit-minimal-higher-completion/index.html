    Qi v5.03 Lean全文 ・ 前段Qi v5.02正式記録

    1. v5.02から継承した真正障害¶

    Qi v5.02では、元の13構成子をもつSevenRewrite型の七セル履歴について sevenUnitStepCharge : SevenRewrite ... → ℤという符号付き整数Uを構成した。 左右単位則生成元を各+1、反転で負、型付き縦横合成で加法とし、 旧v5.01 UnitDiamondEightCellの全構成子で保存されることを証明した。

    同じ元のraw六セル始終点を持つ二つの真正三因子履歴

    sevenBalancedUnitInvisibleFirst w
sevenBalancedUnitInvisibleSecond w

    は次を満たす。

                             H_first       H_second
元三整数 (T,J,K)           (1,0,0)       (1,0,0)
第四整数 R mod 2          0             0
単位則整数 U              1             3
raw六セル始終点           同一          同一

    よって旧v5.01の比較全体でUが保存されるため、 UnitDiamondEightCell(H_first,H_second)は存在しない。 今回はこの証明済みの局所比較不能性だけを新しい独立presentationで補完する。

    2. 強い三因子障害の真正P77 sourceへの輸送¶

    v5.02のP77定理で輸送できていたのは、左右逆元消去を結んだ 二因子前駆例だった。前駆例は第四整数Rの偶奇が一致しても、 元三整数のTには1対0の差が残る。

    今回新たに

    sevenBalancedStrongSourceFirst c
sevenBalancedStrongSourceSecond c
sevenBalancedStrongSource_values c
sevenBalancedStrongSource_noPrevious c

    を構成した。任意の真正六セルsource証拠cに、 三角形critical pairによるT相殺を含む強い三因子履歴を 横合成したものである。

    両者はraw六セル始終点が完全一致し、元三整数とR偶奇が一致する。 その一方、整数Uは1対3で異なるため、旧八セルでは比較不能である。

    さらにpentagonActualStrongBalancedUnitCompletionWithSourceObstructionは、 任意の真正P77最終raw添字に対し、 pentagonAdjoinedSixCell_generatorを使ってこの強い証拠を輸送する。 旧GK5CG五セルのType値sourceとその証拠履歴は一切変更せず、 ¬ PentagonAdjoinedSixCellEqualityInterpreterを保持する。

    3. 独立BalancedUnitEightCell — 原始比較は1種類¶

    別の新Type値presentationとして

    inductive BalancedUnitEightCell (W : Type uSix) (l r : W) : ...

    を構成した。原始的に新しく追加した比較は1種類だけである。

    BalancedUnitEightCell.balancedUnit (w : W)

    その添字は元v5.02で証明済みの sevenBalancedUnitInvisibleFirst wと sevenBalancedUnitInvisibleSecond wの二つであり、 新しい根拠なしの一般比較・source strict Eqを追加していない。

    全旧UnitDiamondEightCell証拠はpreviousによって保存される。 残るreverse、chain、whiskerLeft、whiskerRight、 inverseContext、compositeContextは従来と同じ型付き文脈閉包だけである。

    旧presentationの定義、旧quotient、自由七セルraw文法、 元F55/P77/GK5CG sourceおよび証拠履歴は変更していない。

    4. 商の厳密な粗化と保存量の降下境界¶

    新選択商はbalancedUnitHistorySetoidと balancedUnitHistoryClassにより構成し、実際の BalancedUnitEightCell証拠をNonemptyで保持する。

    [H_first]_new  = [H_second]_new
[H_first]_old ≠ [H_second]_old

    旧v5.01 classの一致は新classの一致に降下するが、その逆の 普遍解釈は存在しないことを具体的な証拠で示した。

    今回は新balancedUnit生成元で整数Uが1→3に変化するので、

    整数Uは新商へ降下しない。
一方、U mod 2 と R mod 2 は両方新商へ降下する。

    次のLean定理を全新比較構成子についての帰納法で証明した。

    balancedUnitEightCell_preservesParity
balancedUnitEightCell_preservesUnitCountParity
balancedUnitHistoryClass_noIntegerUnitDescent

    真正な新商上でQuotient.liftを使い balancedUnitHistoryParityと balancedUnitHistoryUnitCountParityという 二つのBool値観測量を構成した。

    重要なのは、Uという整数値を強引に新商の代表元に依存した形で 定義していない点である。旧整数Uの非降下と残余偶奇の降下は分離している。

    5. 混合critical pairと限定局所合流¶

    新balancedUnitと既存の二つの比較生成元を横合成した 実際の型付き混合critical pairを構成した。

    • balancedUnit × identityDouble
    • balancedUnit × unitDiamond

    いずれも旧v5.01の比較ではU値の差が2のため不可能である。 新BalancedUnitEightCellでは唯一の新原始比較と 既存previous証拠のcompositeContextによって比較できる。

    限定BalancedUnitCriticalPeakは旧選択critical family、 この新原始比較、二種類の混合比較と型付き反転・連鎖・文脈を含む。 balancedUnitCriticalPeak_fillはその限定族の全構成子に 真正なType値比較を構造帰納的に与える。

    これは任意の平行七セル履歴の完全合流、大域thin性、 九セル構成の存在を意味しない。

    6. CIの確認と変更範囲¶

    新規Leanモジュール1件とformal/KuuOSFormal.leanの公開import1行のみを変更。 元のLean証明とsourceファイル、全旧presentationを上書きしていない。

    exact-source CI #42311449662では、固定Lean/mathlibと -DwarningAsError=true・-DsorryAsError=trueで KuuOSFormalと新モジュールのビルドが 10,302/10,302 SUCCESSとなった。 新40宣言の全#print axiomsに非標準公理やsorryAxはない。 変更警告・エラーなし、source/test-merge Git tree一致も独立確認済み。

    7. 未証明事項と次段Qi v5.04¶

    本段階では次の点を証明していない。

    • 任意の平行七セル履歴の比較可能性・障害の完全分類
    • R mod 2とU mod 2の同時一致からの無条件な比較存在
    • 九セル以上の大域thin性や元sourceのstrict Eqへの昇格
    • 全高次比較Type値を薄いPropへ縮約すること

    次のQi v5.04では、残った二つのBool値観測量の組 (R mod 2, U mod 2)で判別できない真正な比較不能例の有無を、 現行新presentationの全構成子を先に照合して調べる。 新原始生成元は具体的な非比較性が証明された場合に限り 別の独立presentationへ最小追加する。
