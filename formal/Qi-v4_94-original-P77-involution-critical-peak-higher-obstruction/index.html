    1. 前段階と新しい問題¶

    Qi v4.91では新しい八セルEightCell(H₁,H₂)を自由生成し、v4.92で局所zigzag／独立書換えの限定critical peakの合流と履歴商を構成した。Qi v4.93では、七セル結合・単位の三角形ピークを既存22八セル生成規則では埋められないことを整数sevenTriangleChargeで証明し、元のEightCellを変更せずに別TypeTriangleEightCellを導入した。

    v4.94はこの拡張でもなお残る、七セルのdoubleInverseとinverseLeft／inverseRightが重なる二つの新critical peakを具体的に扱う。

    2. 第二の独立した七セル整数不変量¶

    sevenInvolutionCharge は元の13構成子によるSevenRewriteの生の七セル履歴を入力し、doubleInverseだけを+1で数える。他の基本局所規則は0、七セル履歴symmは符号反転、trans・congrCompは加法、congrInvは値を保持する。

    [ \begin{aligned} J(\mathrm{doubleInverse}(c))&=1,\ J(\mathrm{symm}(H))&=-J(H),\ J(\mathrm{trans}(H,K))&=J(H)+J(K),\ J(\mathrm{congrComp}(H,K))&=J(H)+J(K),\ J(\mathrm{congrInv}(H))&=J(H). \end{aligned} ]

    eightCell_preservesInvolutionChargeは元v4.91の22八セル構成子すべてへの構造帰納により、この値が保存されることを証明する。

    さらに重要なtriangleEightCell_preservesInvolutionChargeは、v4.93で追加した左右三角形二生成元を含むすべてのTriangleEightCellについて同じ保存を構造帰納で証明する。

    [ \boxed{ Q:\mathrm{TriangleEightCell}(H_1,H_2) \Longrightarrow J(H_1)=J(H_2). } ]

    ここでJはv4.93のsevenTriangleChargeとは別の不変量である。前回の三角形補完で消えない新たなobstructionを検出する。

    3. 実際の二重反転／逆元消去critical peak¶

    任意の新六セル生語c:w⇒zについて、左右に対応する型付きの二つの重なりを扱う。

    左側： 生六セル語symm(symm c);symm c ⇒ refl wへの七セル比較。

    • sevenLeftDoubleInverseDirect c := inverseLeft (symm c)：直ちに逆元消去。
    • sevenLeftDoubleInverseVia c := trans (congrComp (doubleInverse c) (refl (symm c))) (inverseRight c)：先に二重反転を消去し、その後右逆元消去。

    右側： 生六セル語symm c;symm(symm c) ⇒ refl zへの七セル比較。

    • sevenRightDoubleInverseDirect c := inverseRight (symm c)。
    • sevenRightDoubleInverseVia c := trans (congrComp (refl (symm c)) (doubleInverse c)) (inverseLeft c)。

    sevenLeftDoubleInverse_chargeGapとsevenRightDoubleInverse_chargeGapでそれぞれ

    [ \boxed{ J(H_{\rm direct})=0,\qquad J(H_{\rm via})=1 } ]

    を形式証明。既存拡張での保存則から

    [ \boxed{ \neg\operatorname{Nonempty} \bigl(\mathrm{TriangleEightCell}(H_{\rm direct},H_{\rm via})\bigr) } ]

    が左右のピークで成立する（sevenLeftDoubleInverse_noTriangleEightCell／sevenRightDoubleInverse_noTriangleEightCell）。これは元の三角形八セル拡張の全構成子に対する証明済み非合流であり、単に証明書が見つからないという意味ではない。

    sevenLeftDoubleInverse_notStrictは生の七セル履歴そのものの厳密不一致も明示する。

    4. 新しく独立に付加した八セルType¶

    元のEightCellやTriangleEightCellは書き換えない。別のInvolutionEightCell(H₁,H₂):Typeを導入し、.previousにより旧TriangleEightCellを全て包含し、左・右の二重反転ピークの二つだけを新たなprimitive generator .leftOverlap・.rightOverlapとして追加する。残りは反転・連鎖・左右whiskering・六セル反転／合成文脈への閉包である。

    involutionEightCell_leftNewNotPreviousおよびinvolutionEightCell_rightNewNotPreviousは、以前の比較Typeでは空、新拡張では居住することを同時に証明。

    involutionEightCell_noPreviousInterpreterは、全新証拠を旧TriangleEightCellへ送る普遍関数が存在しないことを、Type値Pi型について正しく¬ Nonempty (∀ ..., InvolutionEightCell → TriangleEightCell)として証明する。involutionEightCell_noStrictInterpreterは新証拠から生七セル構文の厳密Eqへの戻りも不可能であると示す。

    5. 限定的critical peak族と商の厳密な区別¶

    InvolutionCriticalPeakは前版TriangleCriticalPeakの全証拠を包含し、上の左右二重反転ピークを付加し、反転・連鎖・前後whiskering・反転／合成文脈にのみ閉じる限定された9構成子の帰納Type。任意平行七セル履歴という無条件構成子を持たない。

    involutionCriticalPeak_fillでは帰納法により各P : InvolutionCriticalPeak(H₁,H₂)から実際のInvolutionEightCell(H₁,H₂)を構成し、involutionCriticalPeak_joinableが存在定理を与える。

    involutionHistorySetoidは比較存在から作る反射・対称・推移を満たすSetoid。選択商involutionHistoryClassについて

    [ [H_1]{\mathrm{inv}}=[H_2]{\mathrm{inv}} \iff \operatorname{Nonempty} \bigl(\mathrm{InvolutionEightCell}(H_1,H_2)\bigr) ]

    を形式証明する。旧triangleHistoryClassで成立する商の等号は新商へ降下し、逆方向の普遍的な復帰はできない。

    特にinvolutionHistoryClass_strictlyNewにより

    [ \boxed{ [H_{\rm direct}]{\mathrm{inv}} = [H{\rm via}]{\mathrm{inv}} \quad\land\quad [H{\rm direct}]{\triangle}\ne [H{\rm via}]_{\triangle} } ]

    がLean4で成立。高次比較可能性の増大を新旧商の厳密な非同値で確認した。

    6. 真正P77元sourceとの境界¶

    pentagonActualInvolutionOverlap_newVsTriangleWithSourceObstructionは任意の元P77最終raw添字iにおいて、元GK5CG保守的五セル値の真正指定二端点から六セルpentagon生成元cを選ぶ。

    同じ元source添字上で、新InvolutionEightCell比較は存在し、元TriangleEightCell比較は存在せず、元PentagonAdjoinedSixCellEqualityInterpreterも存在しないことを同時に証明する。

    これは元F55/P77/GK5CGの六／七／八セルsource構成子を追加したことではない。真正五セル値の厳密不一致と元電荷no-goはそのまま保持する。

    7. 検証境界と次の研究候補¶

    今回の定理はすべての平行な七セル履歴に対する高次coherence完全性ではない。二つの独立整数不変量と、各段階で必要と証明できた有限種類の局所生成元という区別を保持する。第九セルや元sourceへの無条件の降下も主張しない。

    次候補Qi v4.95：二つの整数不変量を同時に用いたobstruction判定、さらにinverseCompとassoc・単位の重なりの具体的peak分類。新拡張で消えない障害を確認してから最小限の新規則を判断する。
