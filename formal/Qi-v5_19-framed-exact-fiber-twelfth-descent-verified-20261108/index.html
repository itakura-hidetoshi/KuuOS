    1. 第十一セル証拠と生の下位境界を分離¶

    FramedElevenExactSpine W l rは、元のFramedElevenから 最上位の生第十一セル証拠Hだけを外し、元第六〜第十セルの 全ての依存したraw indexと元証拠を別のTypeとして保存する。 framedElevenExactSpine／framedElevenSpinePackで元packetを復元できることは framedElevenSpinePack_exactで証明済み。

    生のspine (S,T)について、真正のS = Tがあるときだけ

    [ \operatorname{transport}_{e}: \mathrm{ElevenWitness}(S)\longrightarrow\mathrm{ElevenWitness}(T) ]

    をframedElevenSpineTransportで構成する。 これはLeanの等式帰納法に基づく本当の型付き輸送であり、 v5.18の第八セルassociatorの存在をEqへ昇格させるものではない。

    2. exact-fiber降下の必要十分条件¶

    FramedExactSpineTwelfthは、下位spineの真正な等式と、輸送された 生第十一セル証拠間の元v5.17第十二セル証拠を保持する依存structureである。

    FramedExactFiberTwelfthLift F Gの存在は

    [ \boxed{ \exists e:S(F)=S(G),\quad \mathrm{MixedExchangeInverseTwelveCell} (\operatorname{transport}_{e}H_F,H_G). } ]

    これを、新しい原始を含まない独立文法 FramedInheritedTwelfth（strict／previous／reverse／chain、計4構成子） と比較した。previousは既存の元v5.17第十二セル証拠を丸ごと持つ。

    framedInheritedTwelfth_iff_exactFiberにより、このinherited-only文法に限って 新たな型付き比較の存在と上記exact-fiber条件が同値であると形式証明した。 framedExactFiberTransport_reverse／framedExactFiberTransport_chainで 等式輸送後の反転・連鎖を元第十二セル構成子から構成する。

    特に指定した元同一fiberの2つの第十一セル証拠H,Kについては

    [ \boxed{ \mathrm{InheritedFramedTwelve}(\mathrm{frame}(H),\mathrm{frame}(K)) \quad\Longleftrightarrow\quad \mathrm{OriginalTwelve}(H,K)\ \text{がinhabited}. } ]

    対応するframedExactFiberLift_onOriginal_iffと framedInheritedTwelfth_onOriginal_iffは、元Typeを改変せず証明している。 注意：完全なv5.18 framed第十二セル比較の全てがexact-fiberへ降下するとは主張していない。

    3. 本物の二重whiskeringは境界比較可能だがexact一致しない¶

    v5.18の元二重whiskering doubleWhiskerLeftAfterRightFrame／doubleWhiskerRightAfterLeftFrame には、第七セルrawの括弧付けの相違がある。 このsource/targetの両方には元のEightCell.associateによる真正第八セル比較が存在する。

    しかし、元第十セルのraw Bool履歴は

    [ T_L=[\mathrm{left},\mathrm{right}]\mathbin{+!+}T, \qquad T_R=[\mathrm{right},\mathrm{left}]\mathbin{+!+}T. ]

    したがってdoubleWhiskerExactSpineGapは、全ての元の型付き二重whiskering文脈 において生spineの厳密な等式が成立しないことを証明する。 doubleWhiskerEightCompatible_notExactSpineは、真正第八セルの 2つのcompatibleな境界証拠と、spineのstrict不一致を同時に構成する。

    元のv5.16 exchangeUnitを使う具体的な元critical pairでは

    originalDoubleWhisker_noExactFiberLift／originalDoubleWhisker_notInherited がexact輸送と旧比較だけの非存在を証明する一方、 v5.18の新doubleWhisker生成元ではframed比較が存在する。 framedDoubleWhisker_strictBeyondExactは、この選択framed商の拡大が 旧same-fiber第十二セルより本当に強いことを証明する。 framedDoubleWhisker_noUniversalExactTransportは全比較の普遍的同一fiber化を排除する。

    4. 完全spine観測の可降下性と商写像の非単射性¶

    旧比較のみで閉じたframedInheritedTwelfthSetoidとframedInheritedTwelfthClassを構成。 framedInheritedTwelfth_preservesSpineから、 完全なraw下位添字をType値で読み出す

    framedInheritedSpineObserver

    を真正のQuotient.liftで構成した。 これは新しいprimitiveのない商では完全spine観測が正しく降下することを示す。

    一方、framedInheritedToFullQuotientは、この旧商から v5.18の新しいFramedDoubleWhiskerTwelveCell選択商への 自然な商写像である。元critical pairは新商で一致するが、 旧商ではspine観測が異なる。従って

    [ \boxed{ \neg\operatorname{Injective} (Q_{\mathrm{inherited}}\to Q_{\mathrm{framed}}) } ]

    をframedInheritedToFullQuotient_notInjectiveでLean証明した。

    さらにframedExactSpine_noFactorThroughFullQuotientは、 旧商の完全spine観測が新商を経由して因子化できないことを明示する。 framedInheritedToFullQuotient_noLeftInverseで全左逆復元の不存在も示した。

    この非因子化がv5.19の中心的なobstructionである： 高次比較の追加によって新商へ降下した情報と、 もはや降下できない元source証拠履歴を区別する。

    5. 残存障害、元P77特殊化、authority境界¶

    元v5.17のtenSymm(strict rfl)とstrict rflの1対0障害は、 framedExactFiber_retainsTenSymmObstructionで保持する。 新しい商を構成しても無条件のglobal thinnessを導いていない。

    pentagonActualExactFiberObstructionは、任意の元P77 final raw indexの 真正GK5CG long/short五セルType値を使い、framed比較の存在と、 exact-fiber liftの不存在、および元PentagonAdjoinedSixCellEqualityInterpreter 不存在を同時に形式化する。元のF55/P77/GK5CG sourceの証拠を代替構成していない。

    運用原則：append-only／tighten-only／overwrite-forbidden／same-root。 独立空・strict空・選択商を無条件に同一視せず、 obstructionとauthorityの違いを明示する。

    6. 初回CIでのLean 4記法・型エラーの学習と修正¶

    初回CI #42427708052： 等式S=TはPropであり、SigmaのType側のindexとして 直接使用した記述に型不一致。さらに元P77特殊化に括弧余剰があった。 命題と仮定を変更せず、alignment : S=Tとその証拠に依存する comparison : ...をフィールドに持つFramedExactSpineTwelfthへ改めた。

    二回目CI #42428047003： 隣接した2つのLean文書コメントによる構文解析エラーのみ。 全41宣言の本体と公理依存が監査ログに現れる一方、 構文エラーが残るため正式検証とは認めず、余分なコメントを除去。 三回目CI #42428479556で 全10,332 LeanジョブとGovernance30ジョブがSUCCESS。 新41宣言の依存にsorryAx・追加非標準公理は存在しない。

    7. 次段Qi v5.20¶

    次はexact-equalityの条件を緩めずに、元の八セルassociatorを 第九／第十／第十一セルの具体的な型付きtransportで橋渡しできる局所条件と、 その条件が不十分な場合の新しいobstructionを分類する。 新framed比較の存在だけからEqや下位の旧source authorityを 導くことなく、各presentationの証拠を独立に保持する。
