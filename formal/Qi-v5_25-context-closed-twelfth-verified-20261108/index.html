    2. 元の境界と証拠を保つ独立presentation¶

    ContextFrameEleven W l r c dは、元第六セル境界 c,d を添字として固定し、 元第七〜第十一セル s,t,q₀,q₁,alpha,beta,xi,zeta,H をType値のまま保存する。 contextFramePackは既存 FramedEleven へ包装する。 左右の contextFrameLeft / contextFrameRight は、境界が合う元第七セル文脈を 元第十一セルの真正whiskeringへ渡す。異なる元fiberをEqで同一視しない。

    新しい ContextClosedFramedTwelve は、既存のfull framed第十二セル証拠を previousの引数にそのまま保持する。strict/reverse/chainに加え、 新たな文脈規則は境界適合的なwhiskerLeftとwhiskerRightの二つだけである。 旧6D〜14Dの構成子を変更していない。

    contextClosed_previous_injectiveは、旧raw第十二セル証拠値の埋込みの単射性を証明する。 これは商類の写像の単射性ではない。 IsTypedWhiskerCongruenceで旧比較を含む同値関係と同じ左右文脈閉包条件を明示し、 contextClosed_leastは新しい比較がそのようなすべての関係に含まれることを証明する。 この意味で、指定された型付き文脈規則に関する最小閉包である。

    3. v5.24の欠けた面を導出する¶

    v5.24の真正三重配置を、構成子の外側からの順序で F_LRR、F_RLR、F_RRLと書く。 旧presentationには F_LRR → F_RLR が存在したが、末尾不変量によって F_RLR → F_RRL は存在しなかった。

    新しい contextClosed_innerFace は次の証拠を実際に組み立てる：

    whiskerRight
  (contextFrameOfRaw (whiskerLeft before (whiskerRight H inner)))
  (contextFrameOfRaw (whiskerRight (whiskerLeft before H) inner))
  (previous (doubleWhisker before H inner))
  outer

    つまり、元のdoubleWhisker証拠一つと新しい右文脈閉包一回から欠損面を得る。 欠損面の存在そのものを特別な生成元として仮定していない。 contextClosed_fullTriplePathは旧外側交換面とこの新しい内側交換面を連結する。

    contextClosed_innerFace_strictExtensionが同時に証明する内容は

    [ \boxed{\operatorname{Nonempty}(\mathrm{New12}(F_{RLR},F_{RRL})) \quad\land\quad \neg\operatorname{Nonempty}(\mathrm{Old12}(F_{RLR},F_{RRL})).} ]

    旧不存在定理は取り消されない。異なるpresentationの比較能力を分離した結果である。 実在例には元の exchangeUnit と反射第七セル文脈を使う。

    4. 保持されるraw証拠と、新商で失われる区別¶

    旧商から新商への oldToContextClosedQuotient を構成する。 oldToContextClosedQuotient_notInjectiveは、上の実在する元exchangeUnit例で この写像が非単射であることを証明する。

    旧raw証拠の埋込みは単射だが、旧商で区別されていた二つのpacket類は新商で一致する。 contextClosed_noOldReflectionは、新しいすべての比較を旧比較へ戻す解釈を否定する。

    v5.24で旧商へ降下した末尾観測 I(F) = drop 2 (Trace10(F))についても、 contextClosed_noTailDescentが新商への降下を否定する。 元のpacketに保存した履歴が削除されたのではなく、新しい商だけからは その履歴を一意に読み出せないという情報損失である。

    5. 三つの元観測量と残る障害¶

    framedContextEventCountsは元からある三つの計数を組にする：

    [ C(F)=(\mathrm{oldTenthCount}(F),\mathrm{unitTenthCount}(F),\mathrm{tenSymmCount}(F)) \in\mathbb N^3. ]

    contextClosed_preservesEventCountsは新しい全構成子で保存を証明し、 contextClosedEventCountsは新商からこの三つ組への Quotient.lift を構成する。 contextClosed_retainsTenSymmObstructionにより、元のtenSymm critical loopと反射packetは 新しい比較でも接続されない。今回の補完は、すべてのpacketを無差別に同一視するものではない。 三計数が全比較を完全分類するという逆方向は未証明である。

    6. 境界ごとの商に降下する左右作用¶

    contextBoundarySetoidは、固定した元第六セル境界 c,d を持つpacket上で 新しい比較を用いる商を作る。 元第七セル before:b→c、after:d→eに対し、 contextClosedLeftActionとcontextClosedRightActionが

    [ L_{before}:Q(c,d)\to Q(b,d),\qquad R_{after}:Q(c,d)\to Q(c,e) ]

    を構成する。旧full商では失敗していた作用の降下を、明示した境界付き新商で実現した。 contextClosedActions_commuteは元のdoubleWhiskerを使い

    [ \boxed{L_{before}(R_{after}(x))=R_{after}(L_{before}(x))} ]

    を証明する。これは新商上の等式であり、元のraw証拠が同じという主張ではない。 同じ側の文脈合成則・単位則、全packetの正規形、旧13D/14D証拠の自動的拡張は未証明。

    7. 修正経緯と次の境界¶

    公開集約の全文再送によって意図しないimport差分が生じたため、その編集は Git blobを再利用して完全に戻した。最終定理PRは新規独立モジュール1件のみであり、 一時的な集約差分はmainへ到達していない。

    対象CI #42439346295の実際のLeanエラーは同値定理1件： ⟨Quotient.exact, Quotient.sound⟩という未適用関数の組では、独自Setoidが 期待するwrapper越しに推論されなかった。 全文と依存型を照合し、両方向に intro h を置いてそれぞれの補題を適用した。 定理文・仮定を変えず、差分はその証明本体だけ。 失敗時の下流 sorryAx 表示はこのelaboration失敗の回復項であり、修正後には一切残らない。

    次の実装課題は、保持済み公開集約への安全なimport追加と文書索引の同期。 次の研究候補は、同側の文脈合成・反射文脈作用を、保持されるraw履歴長などから調べること。 左右作用が交換するだけで、すべての関手法則や高次整合性が自動的に成立するとはしない。
