    v5.68からの新しい数学的条件：全二重無限観測¶

    v5.68では、元18D raw reverseの長さ別出現数RunCount_d（長さd+1の連続反転部分列数）が、旧selected19の5構成子と新7構成子のすべてで保存され、新・旧商へそれぞれQuotient.liftで降下することを証明済みだった。しかしv5.68の証拠対は、未観測の次次数RunCount_(n+3)で区別できるため、全次数のRunCountを同時に観測する反例ではなかった。

    今回は真の新7構成子商の観測を

    Obs_double(q) =
  (selectedRawCongruentNineFullTowerObservation(q),
   (d : Nat) ↦ selectedRawCongruentRunCountOnQuotient(d, q))

型：Quotient →
  (selectedRawNineObservationValue × (Nat → Nat)) × (Nat → Nat)

    と定義。ここで第1のNat→Natは全次数の祖先塔、第2のNat→Natは全次数の直接連続反転数塔である。有限prefixや有限サンプルには切り詰めない。

    真正18Dにおける順序付き反転ランの新しい独立不変量¶

    新規selectedContextEighteenOrderedRunListは、元SelectedContextualEighteenの構造再帰により直接連続するraw reverseの長さを生の出現順でList Natとして保持する。strictとinheritedは空列、whiskeringは内部履歴を保持、chainは左右列を連結する。reverseはその子のTopRunLength=0なら新たな先頭runを1として加え、正なら子の先頭runを1延長する。元18D Type値の代わりに任意の代理構文を導入して比較を増やすことはない。

    保存性は独立に確認した。

    1. 元のSelectedLocalNineteen 5構成子：unitPrepend／unitAppendを含めて順序付き列を保存。
    2. 新しいSelectedRawCongruentNineteen 7構成子：rawReverseでは新規ordered listの帰納仮定に加えv5.68で保存済みのTopRunLengthを使い、rawChainLeft／Rightではordered listの連結に対する合同性を証明。
    3. 旧・新商それぞれに対し真正Quotient.liftで同じ元Type値から順序付きラン列を降下。既存selectedRawCongruentProjectでの旧→新射影とも因子化。

    これは旧selected19商と新7構成子商を同一視する主張ではなく、それぞれ異なる比較presentation上で共通する元不変量が保存されるという形式的構成である。

    全祖先塔と全連続反転数塔が一致する真正証拠対¶

    真正17D端点Nに対してS=strict N、gap(X)=chain X S、R^kを元raw reverseのNat.rec反復として、

    A = R^3 (gap (R^2 S))    -- 順序付きrun [3,2]
B = R^2 (gap (R^3 S))    -- 順序付きrun [2,3]

    を、実在する同一N→Nの元18D依存Type値として構成。次をLean4で証明した。

    ∀ k : Nat, AncestorCount_k(A) = AncestorCount_k(B)
∀ d : Nat, RunCount_d(A) = RunCount_d(B)
Trace(A) = Trace(B)
TopReverseFlag(A) = TopReverseFlag(B)
AdjacentReverseCount(A) = AdjacentReverseCount(B)
NineObservation(A) = NineObservation(B)

OrderedRunList(A) = [3,2]
OrderedRunList(B) = [2,3]
OrderedRunList(A) ≠ OrderedRunList(B)

    任意の二ブロック長p,qに対し、RunCount_d(R^p(gap(R^q S)))=(p-d)+(q-d)（自然数の切断減算）という真正raw計数式を定理化した。この値はp,qの交換に不変なので、全てのdを同時に一致させる。

    祖先塔についても、strict-chain gapを除いても各次数の計数が不変である既証明を、反転反復の全次数保存と合成し、p+q=q+pによって全てのkを同時に一致させる。v5.60のC₁〜C₅橋渡し、完全ordered trace、top reverseと既存Adjacencyの一致から元八観測、さらにC₆で第九観測まで一致を確認した。

    一方、[3,2]≠[2,3]は新商へ独立に降下済みのordered list不変量で区別できる。したがって、真正新商クラスは不一致であり、両者を比較する新19D Type値証拠も存在しない。

    元の同一fiberへの輸送・非単射性・decoder障害¶

    M : SelectedContextualEighteen W l r J Nという元の真正証拠が実際に供給された場合に限り、chain M Aとchain M Bを元と同一J→N dependent fiberに構成した。全無限祖先塔、全無限run-count塔、元九観測は右連結で一致したまま、順序付きrun listは共通のOrderedRunList(M)を前置した二列になる。一般のList Natの左連結消去（prefix cancellation）を証明し、元の[3,2]≠[2,3]の差がこの同一fiber内でも消えないことを認証した。

    この結果から、実在する任意のMを持つ同一fiberの真の新商で：

    • Obs_double : Quotient → (Nine × AncestorTower) × RunTowerは非単射。
    • Obs_doubleから全域でordered raw-run listを復元するdecoderは存在しない。
    • 同観測から全ての新商クラスを復元するdecoderも存在しない。
    • 指定された元17D端点Jについて、元のstrict Jを用いたJ→Jの真正例が存在する。

    異端点fiberの任意の非空性、異fiberの比較や貼合は一切仮定していない。

    未認証境界・次段Qi v5.70¶

    今回認証されたのは、全祖先塔と全run-count塔を同時に持つ商観測が非単射であることであり、順序付きラン列を追加した次の観測が完全分類子になるという主張ではない。順序付きラン列が一致する別の真正元18D証拠対の探索、または限定された構文クラス／exact fiber上での条件付き忠実性が次段の候補となる。
