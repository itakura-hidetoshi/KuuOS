    2. GK5BX：一般有限互換CRT環の真の制限コヒーレンス¶

    GK5BWの真正環同型 Φ_s : ZMod(L_s) ≃+* R_s を使用する。有限被覆u⊆t⊆sの任意の自然数法（零法、互いに素でない法、空被覆を含む）について、各L_s=Finset.lcm s moduli。gcd上で互換な局所ZMod値の依存積SubringをR_sとする。

    • 真の有限LCM整除：L_t ∣ L_s。ここから大域制限q_(s,t):ZMod L_s →+* ZMod L_tを固定mathlibZMod.castHomで定義。
    • 真の局所互換Subring制限ρ_(s,t):R_s →+* R_tを構成。元のZMod値をそのまま部分被覆へ制限し、全pairwise gcd互換性、加法・乗法・単位元を保つ。
    • RingHom恒等・合成の文字どおりの等式：ρ_(s,s)=id、ρ_(t,u)∘ρ_(s,t)=ρ_(s,u)、q_(s,s)=id、q_(t,u)∘q_(s,t)=q_(s,u)。
    • 自然性の可換四角形：Φ_t ∘ q_(s,t) = ρ_(s,t) ∘ Φ_sをRingHomの等式として証明。さらにΦ_t⁻¹ ∘ ρ_(s,t) = q_(s,t) ∘ Φ_s⁻¹の値に対する逆自然性を証明。三段被覆の全体図式についても真正RingHom等式でコヒーレンスを確認。
    • 上記に新たな非零性・coprime・支配的法・非空被覆・元F55 Type sourceの存在仮定はない。適用対象は数値的CRT環であって、元F55 Type-valued seamの存在を構成しない。

    初回CIのLean4記法エラーはSubset.refl sをHasSubset.Subset.reflとして誤解決した3箇所に限られた。いずれも真正Finset包含証明fun _ hi => hiで修正し、定理の仮定・結論はそのまま保持。最終exact-source CIで11定理の公理依存にsorryAxなし。

    3. Qi v4.42：真正北C60の元符号付き整数値・三段自然性¶

    元GK5BQの真正nativeGK5BQClearedNumerator d j values : Intを符号付きのままZMod L_sへ埋め込み、GK5BWの元compatible CRT ringへ写す。前段Qi v4.41の一段自然性を、今回の二段被覆制限へ拡張した。

    • 真の元符号付きnumeratorの大域ZMod合同類は一段制限、二段制限後も元の整数から直接作った最終局所合同類と一致する。元compatible局所剰余環全体でも同じ等式が成立。
    • 一般整数多項式P : Polynomial IntについてP.natDegree ≤ dとL_s ∣ d!なら、全有限部分被覆t⊆sで既存のCRT零証明書が成立する。整除の移送は真のL_t ∣ L_sと除法の推移に基づく。
    • 真正元F55 Type sourceの二つの異なる値：primitive P=1とdouble inverse＋元F55右単位P=X²の元P92B整数深度多項式値それぞれに、同じ二段CRT ring制限自然性を適用。条件2≤d・L_s|d!の下、双方が部分被覆uでCRT零である一方、元original→phi構造的seamはprimitiveで存在し、double inverseでは不存在という既証明の元Type境界を同じ型付き定理に保つ。

    これらは元F55のType source・P77商類等号・P94A 4-cellの復元ではなく、元F55 Type履歴に結び付いた既存の整数値に対する数値的自然性である。真正北第五Dart物理C60・条件付きP89 BadPair反射を同一視しない。旧定理依存と独立Kuu→Qiのauthority境界を維持する。
