    2．真正同一raw17D fiberでの自然数族¶

    元の真正旧18D証拠 M : SelectedLocalEighteen W l r J N が本当に与えられた条件下で、元の構成子strictとchainだけを使用し、同じ型J→Nに入る2つの関数を定義した。

    Prefix(0,M)   = M
Prefix(n+1,M) = chain (strict J) (Prefix(n,M)) : J→N

Suffix(0,M)   = M
Suffix(n+1,M) = chain (Suffix(n,M)) (strict N) : J→N

    ここでは元のrawstrictを何度重ねてもchainの値を単位律で消さず、元証拠の真正の依存型indexを保持する。帰納法により全てのnについて、OriginalUnitCount(Prefix(n,M))=OriginalUnitCount(M)、OriginalUnitCount(Suffix(n,M))=OriginalUnitCount(M)を形式証明した。

    v5.92のselectedV592OriginalUnitHistoryは、真のunitLeft/right葉をそれぞれ元の証拠・raw17D始終端・before/F/G/C/after全データ付きで保持する。今回、History(Prefix(n,M))=History(M)=History(Suffix(n,M))を元の全旧18D Type上で証明。unit数や型付きunit payload履歴が同じだからといって元旧18D証拠が等しいわけではない。

    3．元の非結合内部括弧での区別と無限単射¶

    新selectedV594InnerStrictCountは、既存v5.73のraw内部括弧構文木を読む独立の自然数観測である。木のoldStrictを1、oldUnitLeft／oldUnitRightを0、oldReversedでは再帰的に保存、oldJoinedでは加算する。

    元のsource-inner-bracketをBracketと略記すると、

    StrictCount(Bracket(Prefix(n,M))) = n + StrictCount(Bracket(M))
StrictCount(Bracket(Suffix(n,M))) = n + StrictCount(Bracket(M))

    をLean4で帰納法により証明した。これをcongrArgによって元の真のraw証拠等号に作用させ、Nat → SelectedLocalEighteen W l r J NとしてPrefix族・Suffix族それぞれの単射性を証明した。従って、固定Mを与えた同一真正fiberで異なるm≠nなら、元の完全型付きunit履歴は同じだが、内部括弧指紋は異なり、元raw証拠は異なる。

    これは全Mについて同一fiberが無限に多くのraw証拠を含むという条件付き・構成的定理である。異なるfiber間の証拠を貼合せず、元19D商での同一性に拡張しない。

    4．真正unitLeft／unitRight固有の元パラメータを保持した具体例¶

    元v5.35の真正unitLeft before F G C after : J→Nと独立のunitRight before F G C after : J'→N'について、それぞれ元の本当の端点を用いて

    A = chain (strict J) U  : J→N
B = chain U (strict N)  : J→N

    を構成した。selectedV594ActualLeftOneUnitStrictPlacementGap／selectedV594ActualRightOneUnitStrictPlacementGapは左右を混同せずそれぞれ

    History(A) = History(B)
Bracket(A) ≠ Bracket(B)
OriginalUnitCount(A) = 1
OriginalUnitCount(B) = 1
A ≠ B

    を元の真正依存型のまま証明する。例はunitCount=1の同じJ→Nfiberにおける履歴衝突と括弧不一致であり、v5.93が要求した括弧一致・raw不一致の実例ではない。

    5．初回Lean4失敗と構造的修正¶

    初回CI #42918731813は、新規v5.94ファイル内の4件のLeanエラーでFAILURE。最初の2件（元167・184行）はrflが0+x=xを定義的等号とは扱わないことによる帰納法のzero分岐失敗。残る2件（元205・217行）はcongrArg後の関数適用(fun n => ... ) mが未簡約のままで、rwパターンに直接一致しなかったことによる。

    元v5.35の依存型構成子と添字、v5.73括弧観測、v5.89 unit数、v5.92型付き履歴、v5.93既存証明、新規Lean全文を照合。zero分岐はsimpa only [selectedV594StrictPrefix, Nat.zero_add]／Suffix対応に置き換え、単射証明ではcongrArg後の両側を具体的な型付き式へchange ... at hcで明示してから既存の補題でrwした。4件の証明手順だけを修正し、仮定・定理文・旧ファイル・Lean/mathlib固定値は不変更。

    修正後の両独立CIと公理監査はすべてSUCCESS、新規sorryAxなし。未完成の初回CIの公理出力は認証根拠として採用しない。
