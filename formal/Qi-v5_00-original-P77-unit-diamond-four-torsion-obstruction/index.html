    1. 問題設定と観測・推測の分離¶

    Qi v4.99では、真の七セル履歴上の第四整数R(H)=sevenIdentityBalance Hが、 独立IdentityEightCell商へ整数のままでは降下しないにもかかわらず、 R(H)%2は全高次比較構成子で保存され、 Quotient.liftによるBool値観測量identityHistoryParityが得られた。

    未解決だった問いは、 同じ生の六セル始終点を持つ二つの七セル履歴で、Rの偶奇が等しくても、 既存のIdentityEightCell構成子のいかなる合成でも比較できない具体例があるか、 というものである。

    本段階はその具体的反例を形式証明する。 一般の七セル平行履歴の大域的分類や、選択商のthin性までは主張しない。

    2. 四剰余観測量の定義¶

    不変量のもとになるsevenUnitTorsionWeight(H): ℤは、元の13構成子を持つ自由SevenRewrite Typeから再帰的に定義する。 基本生成元の重みは以下のとおり。

    七セル生成元 重み
    refl, leftUnit, assoc, inverseRight 0
    inverseId, inverseComp 1
    rightUnit, inverseLeft, doubleInverse 2

    symm Hでは符号を反転する。trans H KとcongrComp H Kでは加算し、 congrInv Hでは同じ重みを保つ。

    [ S(H):=\operatorname{sevenUnitTorsionResidue}(H) =\operatorname{sevenUnitTorsionWeight}(H)\bmod 4. ]

    Lean実装ではS(H): ℤを0から3の剰余代表として保持し、ZMod 4との暗黙の型同一視はしない。

    Sは既存の第四整数Rとは異なる。RはidentityDoubleで2だけ変化し、 Sはこれも含む全比較で不変となる。

    構成子の重みを法2に落とすとS(H) % 2 = R(H) % 2となる。 これは今回採用した重みからの代数的解釈であり、独立したLean定理としての等式追加は次段に残す。

    3. 全高次比較構成子への保存証明¶

    EightCellには元の22種類の比較構成子があり、 その全構成子の帰納法でSの保存を証明した。 zigzagDiamondの両辺の整数重みは0と4になり得るため、 必要なのは整数の等式でなく法4での等式である。

    次にTriangleEightCell、InvolutionEightCell、 InverseCompEightCellの追加構成子それぞれについて保存を証明。 最後にIdentityEightCell.identityDoubleを含む全部の構成子と 左右whiskering、逆元文脈、合成文脈を証明する。

    中心定理は次の形式を持つ。

    theorem identityEightCell_preservesUnitTorsionResidue
    {s t : SevenRewrite W long short c d}
    (q : IdentityEightCell W long short s t) :
    sevenUnitTorsionResidue s = sevenUnitTorsionResidue t

    Quotient.liftを使い、新しい選択商上の真正観測量 identityHistoryUnitTorsionを構成した。これは七セルraw構文そのものの 等式を意味せず、別presentationの証拠履歴を上書きしない。

    4. 真正な「単位則ダイヤモンド」反例¶

    任意のw : Wについて、共通のraw六セル始終点は

    [ (\operatorname{refl}(w);\operatorname{refl}(w)) \;\longrightarrow\; \operatorname{refl}(w). ]

    二つの元のSevenRewrite原始生成元を使う。

    [ H_L:=\operatorname{leftUnit}(\operatorname{refl}(w)),\qquad H_R:=\operatorname{rightUnit}(\operatorname{refl}(w)). ]

    Leanで、三整数組と残余偶奇が一致することを直接証明した。

    [ \mathbf Q(H_L)=\mathbf Q(H_R),\qquad \bar R(H_L)=\bar R(H_R)=0. ]

    一方、新しい保存量では

    [ \boxed{S(H_L)=0,\qquad S(H_R)=2\pmod 4.} ]

    したがって全構成子保存定理と矛盾するため

    [ \boxed{\neg\operatorname{Nonempty} \bigl(\operatorname{IdentityEightCell}(H_L,H_R)\bigr).} ]

    これは単なる比較証拠の未発見ではない。 現行の全IdentityEightCell構文では比較不可能という構成的証明である。 よってidentityHistoryClassでも両者は異なる。 sevenIdentityParity_notCompleteForIdentityでは、 偶奇一致⇒比較存在という無条件の主張を反証し、 sevenUnitTorsion_notFactorThroughParityでは、 法4観測量が偶奇値の任意の非線形関数からも復元できないことを証明する。

    このunit diamondは既存のv4.99混合critical pairとは異なり、 既存の比較構成子の貼合せで埋まるものではない。

    5. 元P77 raw添字への型付き輸送とauthority境界¶

    二つの単位則履歴に同じ真正六セルsource生成元cを横合成し、 sevenUnitDiamondCompositeLeft cと sevenUnitDiamondCompositeRight cを作る。

    両者は同じ六セル始終点を持ち、R\bmod2は等しいが、 Sは0対2なので比較できない。 pentagonActualUnitDiamondFourTorsionWithSourceObstructionは 任意の真正P77最終raw添字に対し pentagonAdjoinedSixCell_generatorを使ってその事実を輸送し、 ¬ PentagonAdjoinedSixCellEqualityInterpreterも同時に証明する。

    元F55/P77/GK5CGのsource Type値証拠・証拠履歴・strict Eq、 独立Kuuの高次presentation、各段階の商は互いに別である。 新しい選択商の等式を元sourceのstrict Eqへ昇格させない。

    8. 次段 Qi v5.01¶

    今回形式証明した真正unitDiamond障害に限り、 必要な場合は一つの原始比較unitDiamondを別の独立presentationへ最小追加し、 従来のIdentityEightCellおよび全sourceを変更しない。 その後、残余四剰余がどの商まで降下するか、 新しい混合critical pairが既存証拠で埋まるかを判定する。

    append-only／tighten-only／overwrite-forbidden／same-root。 厳密なauthority境界と元Type値証拠履歴を維持する。
