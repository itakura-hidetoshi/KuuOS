    2．元の真正依存型に直接定義したunit-free条件¶

    前段v5.88の SelectedV588UnitFreeTerm は補助構文であり、元旧18Dの「全zero-unit証拠がその像にある」とは未証明だった。今回は任意の元の依存証拠 M : SelectedLocalEighteen W l r J N について、元の5構成子をそのまま再帰し、独立の selectedV589OriginalUnitCount l r M : Nat を定義した。

    • strictでは0。
    • 実際の unitLeft／unitRight では各1。
    • reverseは元の個数を保存。
    • chainは内部2証拠の個数を加算し、非結合の括弧構造を消さない。

    selectedV589OriginalIsUnitFree l r M := selectedV589OriginalUnitCount l r M = 0 は元の型付き証拠そのものに付した条件であり、埋込像に属することを定義で仮定していない。

    selectedV589OriginalUnitCount_observed は、この元証拠のunit個数と、v5.73の既存 selectedLocalEighteenInnerBracket に対するv5.88 selectedV588InnerUnitCount が一致することを元の5構成子について帰納的に証明する。これは観測の整合性であり、raw証拠と観測値の等号ではない。

    3．真正raw17D端点を保持した全域性（新規中核定理）¶

    selectedV589OriginalFree_exhausted は、任意の元証拠 M : SelectedLocalEighteen W l r J N に対して

    selectedV589OriginalIsUnitFree l r M
  → ∃ (h : J = N) (t : SelectedV588UnitFreeTerm),
      M = selectedV589CastFree l r h t

    を証明した。h : J=N は真正依存添字の等号証明であって、異なる17D端点を勝手に同一視する仮定ではない。reverseとchainはその等号証拠で正当に輸送し、単位構成子の枝は元証拠unitCount=0に矛盾する。

    従って固定した同じ真正raw17D端点 N→N では、元の任意の証拠 M : SelectedLocalEighteen W l r N N に対し、次の必要十分条件を証明：

    selectedV589OriginalIsUnitFree l r M
  ↔ ∃ t : SelectedV588UnitFreeTerm,
      M = selectedV588UnitFreeRawEmbed l r N t

    これは selectedV589OriginalLoopFree_iff_image。v5.88の「明示的に構成した像上の忠実性」を、元の真正旧18D型のzero-unit部分全体へ拡張できる全域性の認証である。元旧18D全体への無条件拡張ではない。

    4．拡張できる忠実性と、できない大域化¶

    上の完全性から、同じN→N fiberの両方が元のunit-free条件を満たす真正旧18D証拠M,Lについて、次をそれぞれLeanで証明した。

    1. selectedV589OriginalLoopBracketFaithful：元の内部括弧観測 bracket(M)=bracket(L) ↔ M=L。
    2. selectedV589OriginalLoopOldClassFaithful：真正旧5生成元の独立selected19 quotientで classOld(inherited M)=classOld(inherited L) ↔ M=L。
    3. selectedV589OriginalLoopNewClassFaithful：真正新7生成元の別のselected19 quotientで classNew(inherited M)=classNew(inherited L) ↔ M=L。

    旧5と新7の比較Type全体の同値や同一視は作っていない。元の依存型の構成子・比較公理・仮定は変更していない。

    6．保持すべき障害と次段¶

    • 認証済みなのは、元の真正旧18D依存型に直接付けたunitCount=0という条件の全域性、及び同じN→N fiberのその部分に限る3種の忠実性。
    • unitLeft／unitRightが一つでも含まれる場合の全域復元、同一raw fiber内の同指紋・異raw対の存在／不存在、正のunitCount領域における識別、元旧・新Type19Dの大域同値は未認証（NO_DATA）。
    • v5.87の異なるraw17D fiberにまたがるtotal-space collisionは本成果と両立するが、同一fiberの衝突証明へ移し替えない。
    • WORLD横断のdescent／gluing、実行・制度的権限、哲学上の「空」概念との数学的同一性についても何も証明していない。
    • 次段候補Qi v5.90：もし同一N→N fiberに同指紋・異raw証拠対が存在するなら、双方の元unitCountが正であるという必要条件を実際の型付き元証拠・独立の旧新商で形式化し、unit原子の個数だけで見落とす可能性のある元内部情報を検討する。存在の主張へ先走らない。
