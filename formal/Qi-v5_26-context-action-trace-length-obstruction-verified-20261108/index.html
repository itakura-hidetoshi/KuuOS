    1. 旧商と文脈閉包後の新商に残る「履歴長」¶

    元の第十セルwhiskering構文履歴framedWhiskerRawTraceから

    [ \boxed{\ell(F):=\left|\operatorname{Trace}_{10}(F)\right|\in\mathbb N} ]

    を定める。framedDoubleWhisker_preservesTraceLengthは旧full framed12Dの全構成子を帰納し、比較があるときの長さ保存を証明する。 さらにcontextClosed_preservesTraceLengthはv5.25の全6構成子（旧比較の包含、反射・反転・連結、左右の真正文脈閉包）で長さの保存を証明：

    [ \boxed{T:\mathrm{ContextClosed12}(F,G)\Longrightarrow\ell(F)=\ell(G).} ]

    左右の新構成子は、両端の生履歴に同じBool値を1項だけ先頭追加する。従って順序を捨てずに元証拠を保持しながら、長さだけは比較不変になる。

    contextClosedTraceLength、originalFramedTraceLengthは各商からNatへのQuotient.lift。 contextClosedTraceLength_factorsOldは、旧→新商写像oldToContextClosedQuotientに沿って長さ観測が一致すると証明する。

    v5.24の末尾列drop 2はv5.25の新商で失われたが、総長さは残る。観測可能な情報の階層が変化したのであり、raw証拠自体は削除されていない。

    2. 元の六セル境界に沿った左右作用は長さを1増やす¶

    contextBoundaryTraceLengthは真正元6Dの両端c,dを添字に持つpacket商Q(c,d)へ観測を降下する。

    実在する元第七セル文脈before:b→c、after:d→eからv5.25の

    [ L_{before}:Q(c,d)\to Q(b,d), \qquad R_{after}:Q(c,d)\to Q(c,e) ]

    を用いる。contextLeftAction_traceLengthとcontextRightAction_traceLengthは、すべての商の元xについて

    [ \boxed{\begin{aligned} \ell(L_{before}(x))&=\ell(x)+1,\ \ell(R_{after}(x))&=\ell(x)+1 \end{aligned}} ]

    を証明した。両辺の型が異なる境界を持つ場合でも、Nat観測なので比較できる。元の第七セルの文脈が反射証拠である場合にもこの増分は消えない。

    3. 反射第七セルの形式的文脈は恒等作用ではない¶

    任意の実在するF : ContextFrameEleven W l r c dについて、新商の類[F]に反射第七セル文脈を付けると

    [ \ell(L_{\mathrm{refl}}([F]))=\ell([F])+1, \qquad \ell(R_{\mathrm{refl}}([F]))=\ell([F])+1 ]

    となる。自然数にn+1=nは成立しないため、

    [ \boxed{L_{\mathrm{refl}}([F])\ne[F], \qquad R_{\mathrm{refl}}([F])\ne[F].} ]

    contextLeftReflexive_notIdentity・contextRightReflexive_notIdentityが実際の型付き入力ごとにこの差を証明。 contextLeftAction_noUniversalUnit・contextRightAction_noUniversalUnitは、inhabitedな各原fiberでの万能な恒等作用法則を否定する。

    ここでSevenRewrite.reflは元第七セルの生の構成子であり、その上の作用が商で自動的に恒等となると取り違えない。

    4. 同じ側の二重作用と一回の合成文脈は一致しない¶

    元の第七セルbefore:a→b、after:b→cを与える。v5.25の境界商に対し、

    [ \begin{aligned} \ell(L_{before}(L_{after}([F])))&=\ell([F])+2,\ \ell(L_{before\cdot after}([F]))&=\ell([F])+1 \end{aligned} ]

    であるから

    [ \boxed{L_{before}(L_{after}([F]))\ne L_{before\cdot after}([F])} ]

    をcontextLeftAction_compositionGapとして証明する。 右についても合成可能な二つの元第七セル文脈からcontextRightAction_compositionGapを証明した。

    これはv5.25のcontextClosedActions_commuteと矛盾しない。後者は反対側の左右作用について、いずれも合計2イベントを生むことを前提とした型付き比較である。一方、今回の問題は同じ側の二文脈を一つの元第七セル合成構文にした場合であり、履歴長が異なる。

    5. authority境界と次段階Qi v5.27¶

    Qi v5.26は既存のv5.25文脈閉包商に対して単位則・同側合成則が厳密には成立しないことを証明した。新たな比較生成元も公理も追加していない。将来別のunital/compositional completionを作ることが不可能だとは述べない。

    次の研究候補は、元の文脈が反射または合成であることを明示する独立の選択12D比較を追加し、単位則・同側合成則を成立させる必要最小の商を構成すること。 ただし、この新商では上記の\ellはもはや降下できないはずであり、これは新しい定理として要証明である。v5.25で保存した元3計数が引き続き降下するかも、全新構成子について厳密に検証する。
