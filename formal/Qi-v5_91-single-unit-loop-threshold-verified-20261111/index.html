    2．元依存型の単一unit証拠はraw閉路になれない¶

    真正旧18D型 M : SelectedLocalEighteen W l r J N の5つの元の構成子に対して、v5.89のselectedV589OriginalUnitCount l r Mを直接適用する。

    中核のselectedV591OneUnitEndpointsDistinctは

    OriginalUnitCount(M) = 1  ->  J ≠ N

    を型付き帰納法で証明した。各分岐の根拠：

    • strict：unitCountは0であるため1という前提に矛盾。
    • 真正unitLeft／unitRight：元v5.35で証明済みの生17D端点非等号 selectedSeventeenUnitLeft_rawDistinct／selectedSeventeenUnitRight_rawDistinctを直接使用。
    • reverse：unitCountを保存し、元の真の始終端を反転する。
    • chain A B：unitCount(A)+unitCount(B)=1なので、片方がzero-unit、もう片方がone-unit。zero-unit脚はv5.89のselectedV589OriginalFree_exhaustedにより元のraw17D端点が実際に等しい。この端点等号を接続し、one-unit脚の帰納法の非等号から合成の始終端非等号を得る。

    ここでは商クラス等号で生端点を置き換えず、未認証の異fiber gluingを行っていない。

    3．全真正N→N閉路のunit数ギャップ¶

    元の任意の真正raw17D端点Nと元旧18D型の閉路M : SelectedLocalEighteen W l r N Nについて、

    OriginalUnitCount(M) = 0
  or
2 ≤ OriginalUnitCount(M)

    をselectedV591LoopZeroOrAtLeastTwoで証明した。selectedV591LoopUnitCount_ne_oneはcount=1からN ≠ Nが生じる矛盾を形式化する。unitCount正の閉路は必ず2以上（selectedV591LoopPositiveAtLeastTwo）。

    unitCount=0側の全域性は既にv5.89が証明済みであり、v5.88の忠実な埋込像に一致する。unitCount=2側の全raw証拠が同じ指紋になるとは主張しない。

    4．下界が鋭いことを示す真正2-unit往復閉路¶

    任意の本当に供給された元証拠A : SelectedLocalEighteen W l r J Nから、元のchain／reverseだけで

    Forward(A)  = chain A (reverse A) : J -> J
Backward(A) = chain (reverse A) A : N -> N

    を構成した。両者は元の型であり、独立した新しい閉路代理Typeではない。selectedV591ForwardRoundTrip_unitCount／BackwardRoundTrip_unitCountはどちらもunit数が2 * OriginalUnitCount(A)であることを証明。

    さらにselectedV591ForwardRoundTrip_bracket／BackwardRoundTrip_bracketは、元の真正v5.73内部括弧がそれぞれjoined (bracket A) (reversed (bracket A))、joined (reversed (bracket A)) (bracket A)を保つことを証明。勝手な逆元律・括弧結合律は追加しない。

    v5.35の実際に与えられたbefore/F/G/C/after依存データで元のunitLeftとunitRightを用いる定理selectedV591ActualLeftUnitTwoRoundTrips／selectedV591ActualRightUnitTwoRoundTripsは、各々の元17D始終端がraw値として異なり、ForwardとBackwardのそれぞれがunitCount=2であり、具体的な左右の括弧観測が異なる順序を保つことを検証する。

    したがって「unitを含む閉路のunitCountは2以上」という数値下界は達成可能である。ただし、二つの往復閉路は一般に異なるJ→JとN→Nのfiberに存在する。同じfiberの元証拠対を構成した、あるいは同じ指紋の衝突があるという結果ではない。

    5．v5.90の同一fiber衝突障害を2原子へ強化¶

    selectedV591BracketCollision_requiresTwoUnitsは、同一の本当のraw17D N→N fiberにある元証拠M,Lについて

    bracket(M) = bracket(L)  and  M ≠ L
  => 2 ≤ OriginalUnitCount(M) and
     2 ≤ OriginalUnitCount(L)

    を形式証明した。前段v5.90の両側positive証明に、今回認証した「正の閉路unit数は2以上」を厳密に接続する。

    別々の元旧5構成子真正selected19商、新7構成子真正selected19商への必要条件（selectedV591OldClassCollision_requiresTwoUnits／NewClassCollision_requiresTwoUnits）、およびそれぞれ真に居住することを仮定した元の異なる型付き19D比較（selectedV591OldTypedCollision_requiresTwoUnits／NewTypedCollision_requiresTwoUnits）も独立に検証した。

    いずれも「同指紋・異raw対が存在する」ことを主張せず、前件が成立した場合のみに2原子必要という条件付き結論を持つ。旧5／新7 Type19の大域同値も主張しない。

    6．Lean4修正・公理・障害の境界¶

    NO_DATA：unitを含む同一真正raw17D exact fiber内の同指紋・異raw旧18D対の実在、count≥2の十分性、元unitパラメータの一意性、旧新19D Type全体の同値、異fibertransport、WORLD／20Dの降下、実行・制度的権限。v5.87の異なるraw17D fiberにまたがる衝突を本定理へ移し替えない。
